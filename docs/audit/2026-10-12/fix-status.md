## Maintainer decisions

- F001: do not ship third-party license notices with the package. The SSE parser was rewritten to the WHATWG specification, and the adapted attribution and `THIRD_PARTY_NOTICES.md` were removed
- Reconnect budget: both SSE and WebSocket count per disconnect; after a successful connection the budget and the backoff exponent reset to zero; a connection that drops as soon as it connects keeps reconnecting at the base delay, and can be stopped with `shouldReconnect`
- Log safety: the default message describes only the type that was received and does not include the original value; a record's keys belong to the path and appear in the message
- HTTP Content-Type: the inferred type is stored only on `request.bodyContentType`, and the library no longer writes headers; an explicit `content-type` header always wins; the body is detected again after it is replaced
- Under server runtimes, FormData paired with `onUploadProgress` is sent in chunks and without `Content-Length`; endpoints that need a length should omit `onUploadProgress`
- New public exports `isAbortCause` and `isTimeoutCause`; abort sentinels carry a `Symbol.for` brand and can be recognized across Core instances
- The documentation domain changed to `https://defjs.lyz.cloud`; `CODE_OF_CONDUCT.md` was deleted; the Codecov badge was removed
- F051 (policy change on 2026-10-15): accept Fumadocs' official default search-cache behavior, and withdraw the local dependency patch and the same-page recovery extension. Keep the existing `16.17.1` version, and do not treat cache-recovery capability as a required production gate; after an index fails to load, refresh the page to load it again

## Round 2 fixes and verification (2026-10-15)

- All five defects were reconfirmed on the current baseline, then a failing regression, a minimal fix, and a key mutation check were added. F036 also covers a type red test; the object identity of a single-member intersection was not removed, and no fake type overload was added.
- Independent review filled in HTTP cross-copy response compatibility, listener cleanup after an SSE failure, incomplete SSE/WebSocket handles, a literal `?` query key and first-item promotion, and the recursive bypass when an intersection merge meets an opaque value.
- F027 uses a 256-level container budget. Exceeding a declared container reports `invalid_type`; exceeding it during intersection merge reports `invalid_intersection`, and encode merge keeps `TypeError`. A union can still try later candidates; exceptions from a caller getter or from `errorMap` propagate unchanged, and `RangeError` is not caught broadly.
- `any`/`unknown` are not themselves validated recursively, but the intersection merge of two different container values shares the same total budget; identical references are kept directly, including shared cyclic values.
- For F036, a fixed single member returns its own type, a definite multi-member keeps required-intersection semantics, and a tuple spread that might be a single member infers both results. An uninstantiated `ReturnType<typeof struct.intersection>` is therefore more conservative; when the argument count is known, instantiate it explicitly.
