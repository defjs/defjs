## Boundaries

- The local Node is `v26.12.1`, not the remote CI's Node 24; this round does not claim that remote CI has run.
- Build and pack-manifest checks are not an npm publish or a production deployment; repository variables, domains, and live state were not modified.
- This round did not rerun performance benchmarks, and makes no claim of zero performance overhead or a performance improvement.
- The guide of a borrowed opaque value belongs to this request and the original reference, and is not copied by a shallow spread of the root object or an array child node. `body: input` keeps the pass-through semantics of that reference; `body: { ...input }` is a new anonymous container, its already-tagged child nodes are encoded under the anonymous-container rules, and alias can take effect. An independent Base comparison confirmed this compatibility boundary; it is an explicit boundary after removing input pollution, and does not promise to copy hidden metadata that is no longer written onto the original object.
- Historical audits and performance records are kept as they are; externally visible changes from this round are recorded in the [unreleased notes](../../releases/unreleased.md).
