# بناء SDK ونشره [#publish-an-http-sdk-without-hiding-execute]

حزمة SDK تغلف واجهة API التي يقدّمها فريقك. مع Defjs، صدّر تعريفات نقاط النهاية وعقود بياناتها؛ وتوفّر التطبيقات المستهلكة إعداد العميل وتقرر متى تستدعيها. تستخدم هذه الوصفة HTTP، وحد الحزمة نفسه يعمل لتعريفات SSE وWebSocket.

## 1. عرّف عمليات SDK

أنشئ `src/users.ts` في مشروع SDK. أبقِ المسارات وربط المدخل والاستجابات وأخطاء الخدمة هنا. لا حاجة إلى نسخة عميل أو عنوان نشر أو بيانات اعتماد حالية لتعريف هذه العملية.

<include cwd meta='title="src/users.ts"'>
  examples/recipes/publish-http-sdk/users-sdk.ts#example
</include>

اعرضها من `src/index.ts`:

```ts
export { getUser } from "./users";
```

أضف وحدات عمليات أخرى وأعد تصدير نقاط نهايتها مع نمو SDK.

## 2. غلّف JavaScript والتصريحات

لمشروع SDK حد حزمة خاص به:

```txt
users-sdk/
  package.json
  tsconfig.json
  src/
    index.ts
    users.ts
```

استخدم `package.json` هذا، مع استبدال اسم المثال بنطاق حزمة تملكه:

```json
{
  "name": "@company/users-sdk",
  "version": "0.1.0",
  "type": "module",
  "sideEffects": false,
  "files": ["dist"],
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "default": "./dist/index.js"
    }
  },
  "scripts": {
    "build": "tsdown --platform neutral"
  },
  "peerDependencies": {
    "@defjs/core": "^0.5.0"
  },
  "devDependencies": {
    "@defjs/core": "^0.5.0",
    "tsdown": "^0.23.3",
    "typescript": "^7.0.2"
  }
}
```

يبقى Core اعتمادية تشغيل خارجية مشتركة مع التطبيق. يبيّن نطاق peer إصدارات Core التي يدعمها SDK؛ وتتيح اعتمادية التطوير البناء والاختبار مقابل ذلك النطاق. يطابق هذا المثال عقد `0.4.x` الحالي. اختر النطاق واختبره لـ SDK قبل النشر؛ فالتصاريح وسلوك التشغيل يعتمدان عليه معًا.

أضف `tsconfig.json`:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "lib": ["ES2022", "ESNext.Disposable", "DOM", "DOM.Iterable"],
    "strict": true,
    "noEmit": true
  },
  "include": ["src/**/*.ts"]
}
```

توفّر تصريحات المكتبة هذه الأنواع، لا polyfill لوقت التشغيل. ما زال التطبيق يحتاج واجهات Web API التي تستخدمها وسائل النقل التي اختارها.

يجمّع `tsdown` المدخل في `dist/index.js` ويُصدر `dist/index.d.ts`.

ابنِ الحزمة وافحصها:

```sh
bun install
bun run build
bun pm pack --dry-run
bun pm pack
```

تحقق من أن الأرشيف يحتوي `dist/index.js` و`dist/index.d.ts`. ثبّت ذلك الأرشيف في تطبيق منفصل وتحقق من أنواعه وتنفيذه قبل النشر. يجب أن يوثّق README الخاص بـ SDK واجهة الخدمة وإصدارات Core المتوافقة والمصادقة المتوقعة وأي قيم افتراضية اختيارية.

## 3. استدعها من التطبيق المستهلك

يبقي المثال المحلي التعريف في `users-sdk.ts` بجانب `app.ts` حتى يعمل دون شبكة. استيراده لا ينشئ عميلًا؛ يضبط التطبيق معالج Fetch محليًا ويستدعي العملية المستوردة:

<include cwd meta='title="app.ts"'>
  examples/recipes/publish-http-sdk/app.ts#example
</include>

```txt
Ada
```

لحزمة SDK المغلفة، ثبّتها مع إصدار Core متوافق:

```sh
bun add @company/users-sdk @defjs/core@^0.5.0
```

استبدل الاستيراد النسبي في المثال بـ:

```ts
import { getUser } from "@company/users-sdk";
```

اضبط عنوان الخدمة والمصادقة على عميل التطبيق. أبقِ `withHTTPHandle(...)` للاختبارات المحلية؛ وأزله لاستخدام تنفيذ Fetch الخاص بالمنصة. يمكن لتطبيق ثانٍ استيراد نقطة النهاية نفسها واختيار إعدادات عميل مختلفة دون تغيير تعريف SDK.

## 4. تحقق وانشر

استخدم [اختبارات محلية للعميل](/ar/recipes/test-with-handle) لتمرين التعريف المصدَّر وربط الطلب والتحقق من الاستجابة والأخطاء المعلَنة. تحقق من نقطة النهاية نفسها مع عميلين مضبوطين لعناوين خدمة وبيانات اعتماد مختلفة. أبقِ معالجة `HTTP_STATUS` محدَّدة الأنواع متاحة في موقع الاستدعاء، واختبر الإلغاء وتنظيف التدفق لوسائل النقل التي يصدّرها SDK.

عندما تجتاز الحزمة فحوصك، انشر من مجلد SDK بحساب npm الخاص بك:

```sh
bun publish --access public
```

ينشر هذا الأمر حزمة عامة. استخدم سجل مؤسستك وسياسة الوصول لحزمة SDK خاصة. لا يولّد Defjs الحزمة ولا ينشرها نيابةً عنك.

مصانع العميل ودوال التيسير إضافات اختيارية. يمكنها توفير قيم افتراضية للخدمة أو سلوك مجال مع قبول إعداد المستدعي والحفاظ على تصدير نقاط النهاية مباشرة. وثّق أي تعيين أخطاء أو سياسة دورة حياة تُدخلها. لا شيء منهما مطلوب لـ SDK قابل لإعادة الاستخدام.

انظر [HTTP](/ar/docs/http) و[العميل](/ar/docs/client) و[قرارات التصميم](/ar/docs/design-decisions) للعقود الأساسية.
