# انشر SDK لـ HTTP دون إخفاء execute

SDK من الطرائق يبتلع `client.execute` عادةً يطوي `404` المعلَن في رمي غير محدَّد النوع أو «خطأ API» مشترك. أبقِ العقد كنقاط نهاية مع عميل صريح؛ وما زال المستدعون يملكون التفرّع على الحالة.

انظر [الأوامر](/ar/docs/commands) و[العميل](/ar/docs/client) و[قرارات التصميم](/ar/docs/design-decisions).
