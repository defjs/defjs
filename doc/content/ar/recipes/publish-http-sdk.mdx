# انشر SDK لـ HTTP دون إخفاء execute

حزمة SDK التي تخفي `client.execute` وراء طرقها تحوّل عادةً `404` المعلَن إلى استثناء غير محدَّد النوع أو «خطأ API» عام. أبقِ العقد كنقاط نهاية مع عميل صريح؛ ويظل التفرّع بحسب الحالة مسؤولية المستدعين.

انظر [الأوامر](/ar/docs/commands) و[العميل](/ar/docs/client) و[قرارات التصميم](/ar/docs/design-decisions).
