# مفاتيح تساوي الأثر (Idempotency keys)

افتراضياً، لا تعيد `withRetry` محاولة سوى طرق HTTP متساوية الأثر (`GET` و`HEAD` و`PUT` و`DELETE` و`OPTIONS` و`TRACE`). عند تفعيل إعادة المحاولة على نقاط نهاية `POST` أو `PATCH`، اقرن `withRetry` مع `idempotencyKeyHttpInterceptor()` بحيث تعيد كل محاولة إعادة إرسال لنفس الاستدعاء المنطقي استخدام `req.correlationId` في ترويسة `Idempotency-Key` بينما تحصل الاستدعاءات اللاحقة على مفاتيح جديدة.
