# مقبض HTTP عبر Undici Pool

في طبقات BFF وخدمات الخادم عالية الإنتاجية على Node.js، احقن `undici.Pool` مشتركاً عبر [`withHTTPHandle`](/ar/api/core/withhttphandle) حتى تبقى الاتصالات المتعددة بالخوادم الخلفية دافئة ومحدودة، بينما تبقى تعريفات SDK (`sdk/orders.ts`) محايدة تماماً عن المنصة. وتذكّر استدعاء `await pool.close()` عند إيقاف التشغيل.
