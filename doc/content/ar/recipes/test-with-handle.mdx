# الاختبار بـ Fetch محلي

`withHTTPHandle(...)` يستبدل Fetch لذلك العميل فقط. ما زلت تحصل على بناء URL والمعترضات وتوزيع الحالة وفك Struct — بلا DNS أو TLS أو خادم حقيقي.

انظر [العميل](/ar/docs/client) للتفاصيل.
