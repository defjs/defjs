# الاختبار بمعالج Fetch محلي

`withHTTPHandle(...)` يستبدل Fetch لذلك العميل فقط. ما زلت تحصل على بناء عنوان URL والمعترضات والتوزيع بحسب الحالة وفك Struct — دون DNS أو TLS أو خادم حقيقي.

انظر [العميل](/ar/docs/client) للتفاصيل.
