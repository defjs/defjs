# إرسال بيانات JSON (POST JSON)

مرّر كائن مدخلات ذا نوع محدد إلى دالة `builder` وأرجع `{ body: input }`. تُبقي `.alias("customer_name")` اسم `customerName` داخل TypeScript، مع ترميز `"customer_name"` سلكياً وفك ترميزه مجدداً من استجابة `201`.

عندما يستجيب الخادم بحالة `201` مع `{ "id": 1, "status": "paid", "customer_name": "Ada" }`، يطبع البرنامج:

```txt
Created paid → 201
```

راجع دليلي [عمليات HTTP](/ar/docs/http) و[Struct والمخططات](/ar/docs/struct) للمزيد من التفاصيل.
