# POST JSON

سلّم الجسم محدَّد النوع إلى الـ builder. تبقى أسماء الحقول المنطقية في TypeScript؛ وتصبح الأسماء المستعارة على الـ struct مفاتيح JSON. جسم الكائن هو `application/json`.

انظر [HTTP](/ar/docs/http) و[العميل](/ar/docs/client) للتفاصيل.

<include cwd meta="create-user.ts">
  examples/recipes/post-json.ts#example
</include>

`api.example.com` عنوان توضيحي. مع خادم يجيب بـ `201` و`{ "id": 1, "name": "Ada", "email": "ada@example.com" }`، تطبع الشيفرة:

```txt
Created Ada → 201
```
