# حدود التزامن والاستدعاءات المجمّعة

استخدم `concurrencyLimitHttpInterceptor` على `Client` كعازل سعة (bulkhead) على مستوى العميل (رتل FIFO مع حماية اختيارية ضد الفيض عبر `maxQueue`)، واستخدم `@defjs/core/concurrent` (`concurrentMap` و`concurrentMapSettled` و`concurrentAll` و`concurrentAllSettled`) للاستدعاءات المتوازية سريعة الفشل (fail-fast) أو المكتملة (settled) المربوطة مباشرة بذلك العميل `Client`.
