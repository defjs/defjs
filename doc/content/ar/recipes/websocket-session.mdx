# فتح جلسة WebSocket وإدارتها

عندما يجيب الخادم على `{ "type": "subscribe", "symbol": "ACME" }` بـ `{ "type": "tick", "symbol": "ACME", "price": 142.5 }`، يطبع البرنامج:

```txt
ACME 142.5
```

- ميزتا إعادة الاتصال (`withRetry`) ونبضات القلب (`withWebSocketHeartbeat`) اختياريتان تماماً على العميل.
- لا يمكن لمقابس WebSocket في المتصفح إرسال ترويسات HTTP اعتباطية أثناء مصافحة الترقية؛ استخدم ملفات تعريف الارتباط، أو البروتوكولات الفرعية، أو تذاكر الاتصال قصيرة العمر بدلاً من ذلك. راجع [جلسات WebSocket](/ar/docs/web-socket).
