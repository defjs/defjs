# GET مع 404 معلَن

أعلن جسمي النجاح و404 معًا. تفرّع على `error.code` و`error.status` — تحصل على `error.data` محدَّد النوع للغياب المعلَن.

انظر [HTTP](/ar/docs/http) و[الأخطاء](/ar/docs/errors) للتفاصيل.

<include cwd meta="get-user.ts">
  examples/recipes/get-declared-404.ts#example
</include>

`api.example.com` عنوان توضيحي. مع خادم يجيب على `GET /users/7` بـ `200` و`{ "id": 7, "name": "Ada" }`، تطبع الشيفرة:

```txt
Loaded Ada from 200
```

الحالة غير-2xx هي `HTTP_STATUS`. إعلان `error` يعطي جسمه نوعًا؛ وحذف `error` يترك `error.data` بقيمة `undefined` والجسم غير مقروء. إذا تعذّرت قراءة جسم `error` معلَن (نوع وسائط خاطئ، أو JSON غير صالح، أو شكل خاطئ)، تكون النتيجة عطل `RES_*` بدل ذلك. struct `error` واحد يغطي كل حالة غير-2xx، فاستخدم `struct.or(...)` أو اتحادًا مميّزًا عندما تختلف الأشكال.
