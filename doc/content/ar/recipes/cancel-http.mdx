# إلغاء استدعاء HTTP

اجمع إشارة المستدعي مع مهلة على `signal`. `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` إشارة واحدة. يُصنَّف الإجهاض اليدوي `NET_ABORTED`. وتُصنَّف المهلة `NET_TIMEOUT`.

انظر [HTTP](/ar/docs/http#cancel-the-work) للتفاصيل.

<include cwd meta="cancel-report.ts">
  examples/recipes/cancel-http.ts#example
</include>

```txt
caller cancelled
```

يخبرك الإلغاء بما رآه المستدعي. وهو لا يثبت أن كتابة على الخادم قد تراجعت — أبقِ إعادة محاولة التغييرات خلف عقد تماثل.
