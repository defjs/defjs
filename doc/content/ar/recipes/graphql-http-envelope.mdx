# فك تغليف غلاف GraphQL عبر HTTP

لا يدمج Defjs عميل GraphQL ولا يوفّر سياسة `errorPolicy`. بل صمّم GraphQL عبر HTTP كعملية `POST` قياسية تُرسل دالة `builder` الخاصة بها الكائن `{ query, operationName, variables }`. عيّن `data` كـ `.nullish()` في بنية الغلاف (Struct envelope) بحيث تجتاز كل من `data` المحذوفة و`data: null` التحقق البنيوي بنجاح، ثم فك تغليف `errors[]` عبر دالة مساعدة في كود التطبيق:

- تعني استجابة HTTP `200` فقط أن غلاف GraphQL قد وصل سليماً عبر الشبكة. أما أخطاء النطاق داخل مصفوفة `errors[]` (حتى عندما تصاحبها `data: null`) فهي نتائج على مستوى التطبيق وليست أخطاء بنيوية `RES_STRUCT_MISMATCH`.
- راجع [معمارية النواة](/ar/docs/design-decisions) لمعرفة سبب إبقاء أغلفة البروتوكولات الخاصة داخل دوال مساعدة في التطبيق.
