# فك غلاف GraphQL عبر HTTP

Defjs لا تنفّذ `errorPolicy` لـ GraphQL. نمذج السلك كـ HTTP POST يضع الـ builder فيه مستند الاستعلام والمتغيرات، ثم فك `errors[]` / `data` المفقود في مساعد خاص بك.

انظر [قرارات التصميم](/ar/docs/design-decisions).
