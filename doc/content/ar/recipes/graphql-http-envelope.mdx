# فك غلاف GraphQL عبر HTTP

لا تنفّذ Defjs سياسة `errorPolicy` لـ GraphQL. مثّل النقل بطلب HTTP POST يضع الـ builder فيه مستند الاستعلام والمتغيرات. صرّح بـ `data` في الغلاف باستخدام `.nullish()` حتى تصل حالتا غياب `data` و`data: null` إلى الدالة المساعدة، ثم عالج `errors[]` قبل فحص `data`.

انظر [قرارات التصميم](/ar/docs/design-decisions).

نجاح HTTP يعني فقط أن الغلاف وصل. تبقى أخطاء التطبيق في `errors[]` حتى ترمي دالة فك الغلاف استثناءً أو تُرجع نتيجة، بما في ذلك الاستجابة التي تحتوي على `data: null`. يتعامل المثال مع غياب `data` ومع `data: null` المصحوبة بـ `errors[]` بوصفهما أخطاء تطبيق، لا حالات عدم مطابقة Struct.
