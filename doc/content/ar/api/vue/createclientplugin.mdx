<ApiReference identity="@defjs/vue:createClientPlugin" />

```ts
function createClientPlugin(client: Client): Plugin
```

- **client** — نسخة من `createClient`. لا تنشئها الإضافة ولا تخزّنها ولا تتخلّص منها.
- **يعيد** إضافة Vue لـ `app.use(...)`. يستدعي تثبيتها `app.provide(HTTP_CLIENT, client)`، فتقرأ المكوّنات العميل بـ `injectClient()`.
