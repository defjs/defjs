```ts
const HTTP_CLIENT: InjectionKey<Client>
```

المفتاح الذي توفّر `createClientPlugin` العميل تحته. فضّل `injectClient()` على `inject(HTTP_CLIENT)` الذي يُرجع `undefined` عندما لا يُوفَّر شيء. لتجاوز شجرة فرعية: `provide(HTTP_CLIENT, childClient)`.
