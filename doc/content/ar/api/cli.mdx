# أداة سطر الأوامر (`@defjs/cli`)

أداة سطر أوامر لوقت التطوير ومولّد برمجي يحوّلان مواصفات Swagger 2.0 وOpenAPI 3.0–3.2 إلى وحدات `@defjs/core` بصيغة ESM عديمة الحالة. راجع [دليل تكامل CLI](/ar/docs/integrations/cli).
