<ApiReference identity="@defjs/core:ERR_TIMEOUT" />

```ts
const ERR_TIMEOUT: Error // message: 'Request timed out'
```

قيمة `cause` والرسالة المشتركة للمهلات. يربطها `createNetworkFault`، ومعها أي خطأ باسم `TimeoutError`، بالرمز `NET_TIMEOUT`. معترض HTTP الذي يرميها يجعل الاستدعاء ينتهي بخطأ `NET_TIMEOUT`. أما معترضات SSE وWebSocket التي ترميها فيُبلَّغ عنها بالرمز `EXT_INTERCEPTOR_FAILED`.
