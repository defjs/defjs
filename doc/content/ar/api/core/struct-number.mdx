<ApiReference identity="@defjs/core:struct.number" />

```ts
function number(): Struct<number, number>
```

- يقبل قيم `number`، ومنها `Infinity`. أما `NaN` وغير الأرقام فتفشل بـ `invalid_type`.
- لا تُحوَّل السلاسل إلى أرقام.
