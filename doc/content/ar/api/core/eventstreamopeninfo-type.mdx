```ts
interface EventStreamOpenInfo {
  response: HttpResponse<unknown>
  url: string
}
```

`response` هي استجابة المصافحة، و`url` هو عنوان الطلب المحلول. وكائن `EventStreamOpenInfo` هذا هو العنصر الثالث في نتيجة `client.execute` الناجحة، وقيمة `EventStreamHandle.open`.
