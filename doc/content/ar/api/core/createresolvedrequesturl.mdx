<ApiReference identity="@defjs/core:createResolvedRequestUrl" />

```ts
function createResolvedRequestUrl(baseEndpoint: string, path: string, queryString?: string): URL
```

- **baseEndpoint** — عنوان مطلق صالح لنقطة نهاية العميل. يُسقَط الاستعلام والتجزئة (hash) منها، وتُضاف شرطة مائلة لاحقة إلى مسارها ليبقى المسار الأساسي: `https://api.example.com/v1` مع `/users` يعطي `https://api.example.com/v1/users`.
- **path** — مسار نقطة نهاية نسبي. تُزال شرطة مائلة بادئة واحدة. بعد الحلّ، يجب أن يحتفظ عنوان URL بالأصل (origin) الأساسي وأن يبقى ضمن دليله. تُرفض المسارات المطلقة أو النسبية إلى البروتوكول، ومحارف التحكم C0 (بما فيها tab وCR وLF)، والشرطات المائلة العكسية، و`?` و`#`، والمسارات التي تخرج من الدليل. تُرفض الأشكال الشبيهة بـ scheme والنسبية إلى البروتوكول حتى مع مسافات بادئة؛ ويُسمح بمسافة عادية داخل المسار وتُرسَل كـ `%20`.
- **queryString** — استعلام بلا `?` بادئة. عندما لا يكون فارغًا يُضبط كما هو حرفيًا على search في عنوان URL.
- **يُرجع** `URL` المحلول.

يرمي `TypeError` عندما تكون نقطة النهاية الأساسية أو المسار غير صالحين. أثناء `client.execute`، يؤدي غياب العنوان الأساسي أو كونه نسبيًا أو غير صالح، أو وجود مسار غير مسموح به، إلى `REQ_BUILD_FAILED` قبل تشغيل أي معترض أو وسيلة نقل، حتى المعترض الذي يُنهي السلسلة مبكرًا؛ وينطبق ذلك على HTTP وSSE وWebSocket جميعًا. ويُتحقَّق أيضًا من `req.endpoint` النهائي للمعترض بالنسبة إلى `req.baseEndpoint` النهائي؛ ويُسمح باستبدال العنوان الأساسي عمدًا بعنوان مطلق صالح آخر. لا تُعاد محاولة أخطاء URL الحتمية.
