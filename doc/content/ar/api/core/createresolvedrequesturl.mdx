```ts
function createResolvedRequestUrl(baseEndpoint: string, path: string, queryString?: string): URL
```

- **baseEndpoint** — نقطة نهاية العميل. يُسقَط الاستعلام والتجزئة (hash) منها، وتُضاف شرطة مائلة لاحقة إلى مسارها ليبقى المسار الأساسي: `https://api.example.com/v1` مع `/users` يعطي `https://api.example.com/v1/users`.
- **path** — مسار نقطة نهاية نسبي. تُزال شرطة مائلة بادئة واحدة.
- **queryString** — استعلام بلا `?` بادئة. عندما لا يكون فارغًا يُضبط كما هو حرفيًا على search في عنوان URL.
- **يُرجع** `URL` المحلول.

يرمي `TypeError('Client endpoint must be a valid URL')` عندما يتعذّر تحليل `baseEndpoint`. ويرمي `Error` عندما يحوي `path` مخططًا (scheme) أو يبدأ بـ `//` (`Endpoint path must not be an absolute URL`)، أو يحوي `?` أو `#` (`Endpoint path must not include query or hash`).
