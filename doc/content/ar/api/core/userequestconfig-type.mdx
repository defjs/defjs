<ApiReference identity="@defjs/core:UseRequestConfig" />

```ts
type UseRequestConfig = {
  onDownloadProgress?: HttpProgressFn
  onUploadProgress?: HttpProgressFn
} & ({ abort?: AbortSignal; timeout?: never } | { abort?: never; timeout?: number })
```

الجزء الخاص بـ HTTP من [`HttpExecuteOptions`](/ar/api/core/httpexecuteoptions-type)، الذي يضيف `signal`.

- `onDownloadProgress` و`onUploadProgress` هما دالتا استدعاء من نوع [`HttpProgressFn`](/ar/api/core/httpprogressfn-type). تستقبلان [`HttpProgressEvent`](/ar/api/core/httpprogressevent-type) الذي يحمل `loaded` و`total` و`lengthComputable`.
- الإلغاء إما `abort` وإما `timeout`، ولا يجوز الاثنان معًا. يرفض النوع الجمع بينهما، وتمريرهما معًا وقت التشغيل يفشل بعطل `REQ_OPTIONS_INVALID`.
- يجب أن يكون `timeout` عددًا صحيحًا آمنًا موجبًا لا يتجاوز `2_147_483_647`. وهو يستبدل القيمة الافتراضية التي يضبطها [`withTimeout`](/ar/api/core/withtimeout) لهذا الاستدعاء. أما `abort` فيتحد مع تلك القيمة الافتراضية.
