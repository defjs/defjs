<ApiReference identity="@defjs/core:withHeaders" />

```ts
function withHeaders(headers: HeadersInit): ClientOption
```

يعيّن رؤوسًا افتراضية ثابتة لطلبات HTTP وSSE التي يبنيها هذا العميل. لا تستخدمها اتصالات WebSocket.

- تُنسخ `HeadersInit` إلى كائن `Headers` عند تطبيق الخيار. استدعاء لاحق يستبدل الرؤوس السابقة بدل الدمج معها.
- الرؤوس التي يُرجعها `builder` الطلب تستبدل الرأس الافتراضي ذا الاسم نفسه عندما تكون القيمة قيمة مفردة (scalar) أو نسخة `Headers`. أما القيم المصفوفة (مدخل في سجل يحمل مصفوفة، أو `HeadersInit` على شكل مصفوفة أزواج) فتُلحق بالرأس الافتراضي.
- بيانات الاعتماد الخاصة بكل طلب أو المحسوبة، مثل رمز Bearer مُجدَّد أو توقيع HMAC، مكانها [معترض](/ar/api/interceptors)، لأنها تحتاج الجسم النهائي أو قيمة جديدة.
