<ApiReference identity="@defjs/core:struct.bigint" />

```ts
function bigint(): Struct<bigint | string, bigint>
```

- يقبل `bigint`، أو سلسلة يستطيع `BigInt()` تحليلها. أما `number` فيُرفض.
- المخرجات دائمًا `bigint`؛ والسلسلة غير القابلة للتحليل تفشل بـ `invalid_type`.
- عند الترميز للسلك تصبح القيمة سلسلة عشرية.
