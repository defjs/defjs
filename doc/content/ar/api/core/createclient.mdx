<ApiReference identity="@defjs/core:createClient" />

```ts
function createClient(...options: ClientOption[]): Client
```

الخيارات تُطبَّق بالترتيب؛ والخيار اللاحق يستبدل السابق لنفس الإعداد، أما المعترضات فتتراكم. فضّل إنشاء العميل داخل حدود الطلب عندما تحتفظ المعترضات ببيانات المصادقة أو المستأجرين ضمن إغلاقاتها (closures).

- **options** — مساعدات خيارات مثل `withEndpoint`.
- **يُرجع** عميلًا تكون لدالة `execute` فيه صيغ استدعاء متعددة حسب وسيلة النقل.
