<ApiReference identity="@defjs/core:STRUCT" />

```ts
declare const STRUCT: unique symbol
```

يُصدَّر `STRUCT` كـ **نوع** فقط (`export type { STRUCT }`). ولا يملك `@defjs/core` تصدير `STRUCT` وقت التشغيل، فـ `import { STRUCT } from '@defjs/core'` يفشل في الترجمة ولا يعطي قيمة.

وهو يسمّي الوسم القابل للتعداد الذي يعلّم الكائنات الناتجة أثناء تحليل مدخل نقطة النهاية، ليعرف المرمِّز الصادر أي struct أنتجها. أما `struct.parse` وفك ترميز الاستجابة فلا يضبطانه. الرمز داخلي؛ ولا ينبغي أن يعتمد عليه كود التطبيق.
