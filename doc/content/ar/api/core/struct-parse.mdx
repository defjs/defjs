<ApiReference identity="@defjs/core:struct.parse" />

```ts
function parse<S extends StructLike<unknown, unknown, boolean>>(
  struct: S,
  value: unknown,
  options?: { aliases?: boolean; errorMap?: ErrorMap },
): ParseResult<S['_struct']['output']>
```

- **struct** هو الـ struct المستخدم في التحليل. والقيمة التي ليست struct ترمي `TypeError`.
- **value** هي المدخل المجهول.
- **options.aliases** افتراضيها `false`: تُقرأ مفاتيح الكائن بأسمائها **المنطقية** (`displayName`). ومع `true` تُقرأ بأسمائها بصيغة النقل (`display_name`)، بالطريقة نفسها التي تقرأ بها ترميزات HTTP/JSON. أما المخرجات فتستخدم الأسماء المنطقية دائمًا.
- **options.errorMap** هو [`ErrorMap`](/ar/api/core/errormap-type) يعيد كتابة رسائل المشاكل لهذا الاستدعاء فقط، بما فيها إخفاقات تحويل bigint/date من struct أنشأته نسخة أخرى من Core. أي سلسلة، بما فيها `''`، تستبدل الرسالة؛ وحده `undefined` يُبقي الرسالة الافتراضية. ويُستخدم النص المخصص كما هو حرفيًا.
- **يُرجع** `[null, output]` أو `[StructError, undefined]`. إخفاقات التحقق لا ترمي استثناءات. أما الاستثناءات الصادرة عن دوال getter وردود نداء `errorMap` التي يوفّرها المستدعي، فتنتقل كما هي.
- التحليل fail-fast: يتوقف عند أول إخفاق، فيحمل الخطأ مشكلة واحدة. وتُزال مفاتيح الكائن المجهولة من المخرجات، ولا يُعدَّل المدخل.
- تُزار على طول كل مسار **256 حاوية متداخلة** كحد أقصى (`object` أو `array` أو `record` أو `tuple`)، وتُحسب الحاوية الجذرية كأول حاوية. تفشل الحاوية التالية بخطأ `invalid_type` عند مسارها المنطقي، مع `expected: 'value nested at most 256 levels deep'`. داخل الاتحاد، قد تنجح المرشحات اللاحقة؛ وإذا لم يطابق أيٌّ منها المدخل، يُبلّغ الاتحاد عن `invalid_union`. كما تصل الدورات عبر حقول الحاويات المعلَنة إلى هذا الحد؛ ويُسمح بالعقد الفرعية المشتركة غير الدورية. لا تضيف فروع الاتحاد والتقاطع مستوى حاوية إضافيًا، وتبقى قيم `any`/`unknown` معتمة بدلًا من اجتيازها.

```ts
const [error, user] = struct.parse(User, { id: 1, displayName: 'Ada' })
if (error) return console.error(error.prettify())
```

`any` و`unknown` لا يجتازان قيمهما، لكن التقاطع قد يدمج بشكل عودي قيمتين مختلفتين من الكائنات أو المصفوفات تُرجعهما هذه العقد الورقية. يشترك هذا الدمج والمسار المنطقي المحيط به في حد واحد قدره 256 حاوية. يؤدي تجاوزه إلى `invalid_intersection` عند المسار المنطقي للحاوية المرفوضة. يُحتفظ بالمراجع المتطابقة دون اجتياز، بما في ذلك قيمة دورية مشتركة.
