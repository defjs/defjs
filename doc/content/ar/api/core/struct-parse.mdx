<ApiReference identity="@defjs/core:struct.parse" />

```ts
function parse<S extends StructLike<unknown, unknown, boolean>>(
  struct: S,
  value: unknown,
  options?: { aliases?: boolean; errorMap?: ErrorMap },
): ParseResult<S['_struct']['output']>
```

- **struct** هو الـ struct المستخدم في التحليل. والقيمة التي ليست struct ترمي `TypeError`.
- **value** هي المدخل المجهول.
- **options.aliases** افتراضيها `false`: تُقرأ مفاتيح الكائن بأسمائها **المنطقية** (`displayName`). ومع `true` تُقرأ بأسماء السلك (`display_name`)، بالطريقة نفسها التي تقرأ بها ترميزات HTTP/JSON. أما المخرجات فتستخدم الأسماء المنطقية دائمًا.
- **options.errorMap** هو [`ErrorMap`](/ar/api/core/errormap-type) يعيد كتابة رسائل المشاكل لهذا الاستدعاء فقط. وإرجاع `undefined` يُبقي الرسالة الافتراضية.
- **يُرجع** `[null, output]` أو `[StructError, undefined]`. المدخل غير الصالح لا يرمي أبدًا.
- التحليل fail-fast: يتوقف عند أول إخفاق، فيحمل الخطأ مشكلة واحدة. وتُزال مفاتيح الكائن المجهولة من المخرجات، ولا يُعدَّل المدخل.

```ts
const [error, user] = struct.parse(User, { id: 1, displayName: 'Ada' })
if (error) return console.error(error.prettify())
```

انظر [`ParseResult`](/ar/api/core/parseresult-type) و[`StructError`](/ar/api/core/structerror-type).
