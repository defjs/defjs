<ApiReference identity="@defjs/core:withEndpoint" />

```ts
function withEndpoint(endpoint: string): ClientOption
```

يعيّن عنوان URL أساسيًا مطلقًا صالحًا يُضاف أمام مسارات الطلب النسبية. الافتراضي سلسلة فارغة، لذا يتطلب التنفيذ نقطة نهاية صريحة.

- **endpoint** — نقطة نهاية أساس مطلقة صالحة. يُحتفظ بمسارها بوصفه دليلًا؛ ويُحذف الاستعلام والجزء hash منها.
- في أوامر WebSocket، يصبح الأساس `http:` هو `ws:` ويصبح `https:` هو `wss:`.

نقطة النهاية المفقودة أو النسبية أو غير الصالحة، أو مسار الطلب غير المسموح به، تُفشل البناء بـ `REQ_BUILD_FAILED` قبل تشغيل أي معترض أو وسيلة نقل، حتى لو كان المعترض سيُنهي السلسلة مبكرًا. تشترك HTTP وSSE وWebSocket في هذه القاعدة. يجب أن يبقى عنوان الطلب الناتج ضمن أصل عنوان الأساس ودليله؛ وتُرفض محارف التحكم C0 (بما فيها tab وCR وLF) والشرطات المائلة العكسية و`?` و`#` ومحاولات الخروج من الدليل في المسار. تُرفض الأشكال الشبيهة بـ scheme والنسبية إلى البروتوكول حتى مع مسافات بادئة؛ ويُسمح بمسافة عادية داخل المسار وتُرسَل كـ `%20`. تُفحص قيمة `req.endpoint` النهائية بعد المعترض مقابل قيمة `req.baseEndpoint` النهائية بالقاعدة نفسها، لكن يجوز للمعترض أن يستبدل الأساس عمدًا بعنوان URL مطلق صالح آخر. لا تُعاد محاولة التنفيذ عند أخطاء URL الحتمية.
