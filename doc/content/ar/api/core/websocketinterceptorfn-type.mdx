<ApiReference identity="@defjs/core:WebSocketInterceptorFn" />

```ts
type WebSocketInterceptorFn = (req: HttpRequest, next: WebSocketHandler) => Promise<WebSocketSessionLike>
```

يجوز له فحص `req` أو استبداله، ثم استدعاء [`next`](/ar/api/core/websockethandler-type) لمتابعة السلسلة، أو إرجاع [`WebSocketSessionLike`](/ar/api/core/websocketsessionlike-type) خاصة به لاختصار المسار. غلّفه بـ `createWebSocketInterceptor(fn)` لتسجيله عبر `withInterceptors`.

تعمل السلسلة مرة واحدة لكل `execute`. تحدث إعادات الاتصال داخل الجلسة التي يُرجعها ولا تشغّله مرة أخرى.
