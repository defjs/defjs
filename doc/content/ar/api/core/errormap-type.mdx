```ts
type ErrorMap = (issue: StructIssue) => string | undefined
```

تُمرَّر كخيار `errorMap` إلى `struct.parse`. تُستدعى لكل مشكلة (`code` و`expected` و`message` و`path` و`received`) قبل تسجيلها. أَعِد سلسلة لتستبدل الرسالة الافتراضية، أو `undefined` لإبقائها.
