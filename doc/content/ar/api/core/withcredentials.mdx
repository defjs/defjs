---
title: 'withCredentials'
description: 'خيار عميل يرسل بيانات الاعتماد مع طلبات HTTP وSSE.'
---

<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

عندما يكون `true`، يستخدم Fetch `credentials: 'include'` لطلبات HTTP وSSE، فتُرسل ملفات تعريف الارتباط وبيانات الاعتماد الأخرى مع الطلبات عبر الأصول المختلفة (cross-origin). وعندما يكون `false` أو لم يُضبط أبدًا، تبقى `credentials` غير معيَّنة ويستخدم Fetch قيمته الافتراضية.

لا يتلقى مُنشئ WebSocket هذا الإعداد.
