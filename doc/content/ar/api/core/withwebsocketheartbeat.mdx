<ApiReference identity="@defjs/core:withWebSocketHeartbeat" />

```ts
function withWebSocketHeartbeat(options: ClientWebSocketOptions['heartbeat']): ClientOption
```

يفعّل رسائل النبض مع كشف اختياري للإقرار. تمرير `undefined` يمسح إعدادًا سابقًا. نوع الخيار:

```ts
{
  intervalMs: number
  isAck?: (message: unknown) => boolean
  message?: <T = unknown>() => T | unknown
  timeoutMs?: number
}
```

- كل `intervalMs` تُستدعى `message()` وتُرسل نتيجتها عبر struct الـ `outgoing` الخاص بنقطة النهاية. لا تُرسل رسالة عند حذف `message` أو عندما تُرجع `undefined`.
- مع `timeoutMs` يُنتظر إقرار بعد كل نبض. تستقبل `isAck` الرسالة الواردة المفكوكة؛ وعندما تُرجع `true` يُمسح المؤقت و**لا** تُسلَّم تلك الرسالة إلى `receive`.
- إذا لم يصل إقرار خلال `timeoutMs`، أو تعذّر إرسال نبض، تفشل الجلسة. لا يؤدي هذا إلى إعادة اتصال.
- يجب أن يكون `intervalMs` و`timeoutMs` موجبين ومنتهيين وبحد أقصى `2_147_483_647`؛ وإلا يفشل execute بـ `REQ_OPTIONS_INVALID`.
- `heartbeat` في خيارات execute يستبدل هذا الخيار لذلك الاستدعاء.
