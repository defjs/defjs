<ApiReference identity="@defjs/core:withWebSocketHandle" />

```ts
function withWebSocketHandle(WebSocketImpl: WebSocketHandleConstructor): ClientOption
```

يستبدل مُنشئ WebSocket المستخدم لاتصالات المقبس. الافتراضي هو `globalThis.WebSocket`.

- **WebSocketImpl** هو [`WebSocketHandleConstructor`](/ar/api/core/websockethandleconstructor-type) يُرجع [`WebSocketHandle`](/ar/api/core/websockethandle-type).
- إن لم يتوافر مُنشئ، يفشل تنفيذ أمر WebSocket بعطل `ENV_UNSUPPORTED`.
