<ApiReference identity="@defjs/core:FlattenedStructError" />

```ts
interface FlattenedStructError {
  formErrors: string[]
  fieldErrors: { [key: string]: string[] }
}
```

نتيجة `StructError.flatten()`. يحمل `formErrors` رسائل المشكلات ذات المسار الفارغ (مشكلات الجذر). ويحمل `fieldErrors` الرسائل مفهرسةً بأول مقطع من المسار، فتُجمَع المشكلات المتداخلة تحت حقلها الأعلى.
