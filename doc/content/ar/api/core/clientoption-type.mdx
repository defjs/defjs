<ApiReference identity="@defjs/core:ClientOption" />

```ts
type ClientOption = (config: ClientConfig) => void
```

يعدّل [`ClientConfig`](/ar/api/core/clientconfig-type) التي يبنيها `createClient`. كل مساعد `with*` يُرجع واحدًا منها. يطبّق `createClient` الخيارات بالترتيب، فالخيار اللاحق يستبدل السابق لنفس الإعداد، باستثناء `withInterceptors` فهو يُلحِق.
