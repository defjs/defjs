<ApiReference identity="@defjs/core:struct.date" />

```ts
function date(): Struct<Date | number | string, Date>
```

- يقبل `Date` أو طابعًا زمنيًا بالميلي ثانية أو سلسلة، ويحوّلها بـ `new Date(value)`.
- المخرجات `Date`. والقيمة التي تنتج تاريخًا غير صالح تفشل بـ `invalid_type`.
- عند الترميز للنقل تصبح القيمة سلسلة ISO 8601 (`toISOString()`).
