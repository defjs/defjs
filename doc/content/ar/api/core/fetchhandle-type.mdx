<ApiReference identity="@defjs/core:FetchHandle" />

```ts
type FetchHandle = (input: RequestInfo | URL, init?: RequestInit) => Promise<Response>
```

توقيع الاستدعاء `(input, init?) => Promise<Response>` الذي تستدعيه Defjs. وهو عن قصد ليس `typeof fetch`، فلا تحتاج المحاكاة (mock) إلى إضافات المضيف مثل `preconnect`. يستدعي HTTP دالة Fetch الأصلية للمنصة، ما لم تُستبدل، بالشكل `(url, init)`؛ أما Fetch العامة المستبدلة أو المقبض المخصّص فيستقبلان `Request`. يستخدم المقبض الافتراضي الدالة العامة الحالية عند كل استدعاء. ويمرّر SSE دائمًا `Request`، حتى إلى مقبضه الافتراضي.

يقبله `withHTTPHandle` و`withSSEHandle` و`fetchHandler`.
