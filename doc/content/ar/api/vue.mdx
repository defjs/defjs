# Vue

قدّم عميل `@defjs/core` موجودًا إلى تطبيق Vue. لا تنشئ هذه الحزمة العميل ولا تخزّنه ولا تتخلص منه. يلزم Vue 3 أو أحدث.

انظر [دليل Vue](/ar/docs/integrations/vue).

## createClientPlugin()

<ApiSignature name="createClientPlugin" />

- **client** — نسخة من `createClient`.
- **يُرجع** إضافة Vue لـ `app.use(...)`. تثبيتها تستدعي `app.provide(HTTP_CLIENT, client)`.

## injectClient()

<ApiSignature name="injectClient" />

يقرأ `injectClient(key)` أقرب موفّر لذلك المفتاح؛ والقيمة المحذوفة أو `undefined` تستخدم `HTTP_CLIENT`. استدعها في سياق حقن Vue صالح: `setup()` متزامن أو `app.runWithContext()` (Vue 3.3+). يوفّر الأخير سياق التطبيق المتزامن فقط، لا تجاوزات الشجرة الفرعية ولا السياق عبر `await` عادي. تبقى السياقات التي يستعيدها المترجم بعد `await` في المستوى الأعلى داخل `<script setup>` صالحة. مرّر ذلك العميل إلى عملية. القيمة المحقونة هي [`DerivableClient`](/ar/api/core/derivableclient-type) الذي جرى توفيره؛ استدعِها بخيارات الطلب حيث تعمل العملية لاشتقاق قيمة `Client`. لا تستخدمها مصدرًا لـ `watch` أو `computed`، لأنهما يستدعيان الدالة. قيمة `Client` المشتقة لا تقبلها الإضافة ولا `injectClient`.

لمفتاح `InjectionKey<Client>` مخصص، استخدم `app.provide(key, client)` أو `provide(key, client)` من سلف. شارك كائن `Symbol` نفسه؛ والأوصاف المتطابقة لا تجعل المفاتيح متساوية. ما زال `createClientPlugin(client)` يأخذ العميل فقط ويوفّر `HTTP_CLIENT`.

- **يُرجع** العميل الموفَّر نفسه للمفتاح المختار.
- **يرمي** `Error` دون سياق حقن نشط أو عميل للمفتاح المختار. المفتاح المخصص الغائب لا يعود أبدًا إلى `HTTP_CLIENT`؛ وتثبيت الإضافة وحدها لا ينشئ سياق حقن.

## HTTP_CLIENT

<ApiSignature name="HTTP_CLIENT" />

مفتاح حقن Vue. فضّل `injectClient()` على `inject(HTTP_CLIENT)`. غلّب شجرة فرعية بـ `provide(HTTP_CLIENT, childClient)`.
