# مرجع API

<ApiIndex />

استخدم هذا المرجع أثناء بناء SDK من Defjs أو استهلاكه. يبدأ مؤلفو SDK من [`defineRequest`](/ar/api/core/definerequest) و[`defineEventStream`](/ar/api/core/defineeventstream) و[`defineWebSocket`](/ar/api/core/definewebsocket) و[Structs](/ar/api/struct). تستخدم التطبيقات [إعداد العميل](/ar/api/client) لاستدعاء تلك العمليات و[الأخطاء](/ar/api/errors) لمعالجة النتائج.

التوقيعات هي العقد. اتبع [البدء السريع](/ar/docs/start) و[دليل نشر SDK](/ar/recipes/publish-http-sdk) لمسار العمل الكامل.

## الحزم

| الحزمة                                                        | ما تبحث عنه                                                       |
| ------------------------------------------------------------- | ----------------------------------------------------------------- |
| [`@defjs/core`](/ar/api/client)                               | `createClient` و`defineRequest` و`struct` وHTTP / SSE / WebSocket |
| [`@defjs/vue`](/ar/api/vue)                                   | `createClientPlugin` و`injectClient` و`HTTP_CLIENT`               |
| [`@defjs/react`](/ar/api/react)                               | `ClientProvider` و`useClient`                                     |
| [`@defjs/opentelemetry-server`](/ar/api/opentelemetry-server) | `withOpenTelemetryServer` وخيارات كل وسيلة نقل                    |

## @defjs/core

| الصفحة                            | ما تبحث عنه                                                           |
| --------------------------------- | --------------------------------------------------------------------- |
| [العميل](/ar/api/client)          | `createClient` وخيارات `with*` و`Client`                              |
| [HTTP](/ar/api/http)              | `defineRequest` و`HttpExecuteOptions` و`HttpRequest` / `HttpResponse` |
| [Struct](/ar/api/struct)          | `struct.*` و`Infer` و`StructError`                                    |
| [الأخطاء](/ar/api/errors)         | صيغ `Fault` والمصانع                                                  |
| [المعترضات](/ar/api/interceptors) | مساعدات معترضات HTTP / SSE / WebSocket                                |
| [SSE](/ar/api/sse)                | `defineEventStream` ومقبض التدفق                                      |
| [WebSocket](/ar/api/web-socket)   | `defineWebSocket` والجلسة                                             |
