# React

وفّر عميل `@defjs/core` موجودًا لشجرة React. هذه الحزمة لا تنشئ العميل ولا تخزّنه ولا تتخلّص منه. مدخلها موسوم بـ `'use client'`، فاستورده من مكوّنات العميل. يلزم React 18 أو أحدث.

انظر [دليل React](/ar/docs/integrations/react).

## ClientProvider

<ApiSignature name="ClientProvider" />

## useClient()

<ApiSignature name="useClient" />

`useClient(overrideClient)` يعطي الأولوية للعميل الصريح؛ عند حذف الوسيط أو تمرير `undefined` يقرأ أقرب `ClientProvider`. لا يُرمى `Error` إلا إذا لم يوفّر أي من المصدرين عميلًا. يظل الاستدعاء بلا وسيط `useClient()` صالحًا.

استدعِ `useClient(explicitClient)` دائمًا في المستوى الأعلى لمكوّن أو خطاف مخصص، حتى مع عميل صريح؛ وليس في دالة عادية أو رد نداء لحدث. لا تكتب `explicitClient ?? useClient()` لأنه يستدعي خطافًا بشكل مشروط. لا يكتب التجاوز في Context ولا ينشئ مزوّدًا؛ ويظل الخطاف مشتركًا في Context.

- **يعيد** العميل الصريح نفسه أو العميل الذي يوفّره أقرب مزوّد.
- **يرمي** `Error` إذا لم يوفّر الوسيط الصريح ولا Context عميلًا.
