# React

قدّم عميل `@defjs/core` موجودًا إلى شجرة React. لا تنشئ هذه الحزمة العميل ولا تخزّنه ولا تتخلص منه. مدخلها معلَّم بـ `'use client'`، فاستوردها من مكوّنات العميل. يلزم React 18 أو أحدث.

انظر [دليل React](/ar/docs/integrations/react).

## ClientProvider

<ApiSignature name="ClientProvider" />

موفّر سياق. مرّر `DerivableClient` الذي تُرجعه `createClient`. يغلّب `ClientProvider` متداخل العميل لشجرته الفرعية؛ ويقرأ `useClient()` الأقرب. تمرير `client` مختلف يغيّر قيمة السياق للأحفاد.

## useClient()

<ApiSignature name="useClient" />

يفضّل `useClient(overrideClient)` العميل الصريح؛ والقيمة المحذوفة أو `undefined` تقرأ أقرب `ClientProvider`. يُلقى `Error` فقط عندما لا يوفّر أي المصدرين عميلًا. تبقى استدعاءات `useClient()` بلا وسائط صالحة. مرّر ذلك العميل إلى عملية. يُرجع الخطاف [`DerivableClient`](/ar/api/core/derivableclient-type) الذي جرى توفيره؛ استدعِه بخيارات الطلب حيث تعمل العملية لاشتقاق قيمة `Client`. لا تمرّره إلى ضابط حالة، لأن `setState(client)` سيستدعيه كمُحدِّث. قيمة `Client` المشتقة لا يقبلها `ClientProvider` ولا `useClient`.

استدعِ `useClient(explicitClient)` دائمًا في المستوى الأعلى لمكوّن أو Hook مخصص، حتى مع عميل صريح؛ لا في دالة عادية أو ردّ نداء حدث. لا تكتب `explicitClient ?? useClient()`، فهذا يستدعي Hook شرطيًا. التجاوز لا يكتب السياق ولا ينشئ موفّرًا، ويظل Hook مشتركًا في السياق.

- **يُرجع** العميل الصريح نفسه أو أقرب عميل موفَّر.
- **يُلقي** `Error` عندما لا يوفّر عميل صريح ولا السياق عميلًا.
