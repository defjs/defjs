يسهّل Defjs، أي define js، بناء SDK من تعريفات API قابلة لإعادة الاستخدام. ينشر مؤلف SDK العقد، ويتولى التطبيق المستهلك إعداد Defjs Client والتنفيذ.

## تطوير SDK [#البدء]

1. راجع [نظرة عامة على المشروع](/ar) لتحديد مسؤوليات المؤلف والتطبيق.
2. اتبع [البدء السريع](/ar/docs/start) لتصدير تعريف وتنفيذه بعميل في ملف آخر.
3. تحقّق من العقد وقت التشغيل باستخدام [اختبارات HTTP المحلية](/ar/recipes/test-with-handle).
4. وزّع التعريفات وتصريحات الأنواع باتباع [بناء SDK ونشره](/ar/recipes/publish-http-sdk).

## العقود والتنفيذ [#الاستدعاءات-والعقود]

- [عقود البيانات / Struct](/ar/docs/struct) — عرّف المدخلات والمخرجات والأخطاء وتمثيلها أثناء النقل.
- [التعريف والتنفيذ / Command](/ar/docs/commands) — ميّز بين التعريف ونقطة النهاية والأمر الخاص بتنفيذ واحد.
- [إعداد العميل / Client](/ar/docs/client) — اضبط عنوان الخدمة والمصادقة ووسائل النقل في التطبيق.
