# نقل Port (`@defjs/core/port`)

تتيح وحدة `@defjs/core/port` لأي سياق معزول (`SharedWorker`، أو Dedicated Worker، أو `iframe` معزول بـ sandbox، أو عارض Electron، أو Popup / Side Panel / Content Script في ملحق WebExtension) تنفيذ تعريفات SDK النقية من `@defjs/core` عبر منفذ واحد متعدد القنوات دون ربط التعريفات بناقل الوكيل.

- خالية من الاعتماديات وقت التشغيل؛ تتوفر كمساري تصدير فرعيين اختياريين `@defjs/core/port` و`@defjs/core/port/webext` دون أي عبء إضافي على الحزمة ما لم يتم استيرادهما
- تشارك منفذاً واحداً بالتزامن عبر HTTP (بما في ذلك عمليات الرفع والتنزيل عبر `ReadableStream`)، وSSE (`text/event-stream`)، واتصالات WebSocket
- **أمان مُغلق عند الفشل افتراضياً (fail-closed)**: ترفض `attachPortHost` كل حركة المرور ما لم يحدد المضيف صراحةً `allowedOrigins` أو `allowRequest` أو `allowAnyOrigin: true`

```bash
bun add @defjs/core
```

## وكيل ملحقات MV3 WebExtension (`@defjs/core/port/webext`)

لا يستطيع `runtime.Port` في ملحقات المتصفح نقل كائنات `ArrayBuffer` مباشرة عبر حدود ملحقات Chromium/Firefox/Safari، كما ينقطع اتصاله كلما دخل عامل الخدمة (Service Worker) في Manifest V3 في وضع السكون. توفر `@defjs/core/port/webext` المحول البنيوي الخالي من الاعتماديات `fromWebExtPort` (ولا يتطلب `@types/chrome`) الذي يستخدم تأطير `"json"` المقسَّم إلى قطع Base64 ويدعم دوال الربط الكسولة لإعادة الاتصال تلقائياً بعد سبات Service Worker:
