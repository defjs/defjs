# معالجة الأخطاء

في Defjs، لا تؤدي إخفاقات الطلبات أو وسائل النقل أو فك الترميز إلى إلقاء استثناءات (exceptions) عند نقطة الاستدعاء. بل تُرجع كل عملية مصفوفة بنمط الخطأ أولاً (`[error, ...]`) حيث تكون قيمة `error` إما `null` أو كائن `Fault` محدد الأنواع (وهو نسخة أصلية من `Error` يتم تمييزها بخاصية `error.code`).

### لماذا يحمل `error` بيانات الاستجابة الوصفية عند فشل طلبات HTTP

عند فشل طلب HTTP، يكون شكل مصفوفة النتائج `[error, undefined, undefined]`. وتُرفق أي بيانات وصفية استُلمت مع الاستجابة (`status`، و`statusText`، و`headers`، و`url`) مباشرة بكائن `error.response` حتى تتمكن من تمرير كائن `error` بمفرده إلى مسجل السجلات أو معالج الأخطاء دون فقدان السياق.

## 2. فئات الأخطاء ومجموعة الرموز المغلقة

تُحدد البادئة التي تسبق أول شرطة سفلية `_` فئة الخطأ (`HTTP`، و`REQ`، و`NET`، و`RES`، و`EXT`، و`CAP`، و`ENV`)، بينما يشكل رمز `code` الكامل اتحاداً مغلقاً يتيح استخدام جمل `switch` الشاملة:

| الفئة  | رموز الأخطاء                                                           | المعنى وطريقة المعالجة                                                                                                                                    |
| ------ | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `HTTP` | `HTTP_STATUS`                                                          | أجاب الخادم بحالة غير `2xx` (`3xx` أو `4xx` أو `5xx`) وفُك ترميز بنية `error` المعلنة إن وجدت.                                                            |
| `REQ`  | `REQ_INPUT_INVALID`، `REQ_OPTIONS_INVALID`، `REQ_BUILD_FAILED`         | فشل التحقق من مدخلات المستدعي، أو كانت خيارات العميل خارج النطاق، أو كان المسار/الرابط غير صالح، أو ألقت دالة `builder` استثناءً. لا تُعد المحاولة أبداً. |
| `RES`  | `RES_MEDIA_TYPE_INVALID`، `RES_DECODE_FAILED`، `RES_STRUCT_MISMATCH`   | خالفت استجابة الخادم نوع الوسائط المعلن، أو التمثيل، أو عقد بنية `struct`.                                                                                |
| `NET`  | `NET_ABORTED`، `NET_TIMEOUT`، `NET_UNREACHABLE`، `NET_BODY_INCOMPLETE` | ألغى المستدعي الطلب (`NET_ABORTED`)، أو انتهت المهلة (`NET_TIMEOUT`)، أو فشل الاتصال، أو انقطع التدفق أثناء القراءة.                                      |
| `EXT`  | `EXT_INTERCEPTOR_FAILED`، `EXT_HOOK_FAILED`، `EXT_OBSERVER_FAILED`     | ألقى معترض تطبيق، أو خطاف، أو مراقب تقدم/حالة استثناءً أو أرجع قيمة غير صالحة.                                                                            |
| `CAP`  | `CAP_BUFFER_EXCEEDED`، `CAP_QUEUE_OVERFLOW`                            | تجاوز المخزن المؤقت لإطار SSE أو قائمة انتظار مستهلك SSE/WebSocket الحد الأقصى المضبوط.                                                                   |
| `ENV`  | `ENV_UNSUPPORTED`                                                      | تفتقر بيئة تشغيل المضيف إلى واجهات ويب برمجية مطلوبة (مثل تدفق جسم الطلب في Firefox).                                                                     |

### خصائص كائن الخطأ حسب الرمز

| رمز الخطأ     | `status`  | `response`                                      | `data`                              | `cause`                            |
| ------------- | --------- | ----------------------------------------------- | ----------------------------------- | ---------------------------------- |
| `HTTP_STATUS` | `number`  | `DecodedResponse<TErr>` أو `HttpMeta`           | بنية `error` مفكوكة، أو `undefined` | السبب الأساسي إن وجد               |
| `RES_*`       | `number`  | `HttpMeta` (**لا يوجد حقل `body`**)             | غير موجود                           | كائن `StructError` أو خطأ المحلل   |
| باقي الرموز   | غير موجود | `HttpMeta` إذا وصلت الترويسات، وإلا `undefined` | غير موجود                           | كائن `Error` الأساسي / سبب الإلغاء |

## 4. أخطاء بدء التشغيل مقابل أخطاء ما بعد الفتح في SSE وWebSocket

بالنسبة للاتصالات طويلة العمر، تُبلغ مصفوفة نتائج العملية عن إخفاقات **بدء التشغيل** فقط (قبل فتح التدفق أو المقبس). وبمجرد الفتح، تُسلّم الإخفاقات اللاحقة وقت التشغيل عبر المقبض أو دورة حياة الجلسة:

| وسيلة النقل   | إخفاق بدء التشغيل (يُرجع في المصفوفة)                                                                                                | إخفاق ما بعد الفتح (بعد حل المصفوفة)                                                                                                                                                                                                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **HTTP**      | تُحل جميع الإخفاقات في مصفوفة العملية مرة واحدة.                                                                                     | لا ينطبق                                                                                                                                                                                                                                                                                                                                 |
| **SSE**       | استجابة غير `2xx` (`HTTP_STATUS`)، أو نوع وسائط خاطئ (`RES_MEDIA_TYPE_INVALID`)، أو جسم مصافحة مفقود/غير صالح (`RES_DECODE_FAILED`). | يرفض مكرر الأحداث غير المتزامن الاستمرار؛ وتُحل `stream.closed` بـ `{ kind: 'error', code }`.                                                                                                                                                                                                                                            |
| **WebSocket** | إغلاق قبل الفتح، أو فشل دالة البناء، أو إلغاء أثناء المصافحة.                                                                        | تُطلق أخطاء الإطارات غير الفادحة حدث `session.onRuntimeError`؛ بينما ترفض الأخطاء الفادحة `session.receive` وتُحل `session.closed` بـ `{ kind: 'error', cause }`. يستخدم تجاوز حد قائمة الانتظار الواردة `cause.code === 'CAP_QUEUE_OVERFLOW'`؛ وتحتفظ مهلة نبضات القلب واستنفاد محاولات إعادة الاتصال بأسباب `Error` عادية وقت التشغيل. |
