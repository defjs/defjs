# Struct والمخططات

يعلن `struct` عن عقد البيانات السلكي المشترك بين حزمة SDK ومستهلكيها: مدخلات المستدعي، ومخرجات النجاح `2xx`، وأخطاء الخدمة المعلنة، وأحداث SSE، وإطارات WebSocket.

- **استنتاج الأنواع الثابتة (Static inference)**: اشتقاق أنواع TypeScript تلقائياً عبر `Infer<typeof Schema>`.
- **التحقق بنمط الخطأ أولاً**: التحقق من صحة القيم وقت التشغيل عبر `struct.parse(Schema, value)` — تُرجع الدالة `[null, data]` أو `[StructError, undefined]` دون إلقاء أي استثناءات.

## 2. الحقول الإلزامية والاختيارية والقابلة للقيمة الخالية (Nullable)

يفصل Defjs بين **وجود الحقل** (`undefined`) و**قبول القيمة الفارغة** (`null`). وتكون جميع دوال بناء struct إلزامية تماماً وغير قابلة للقيمة الخالية افتراضياً:

| الإعلان                      | غير موجود / `undefined`       | القيمة `null` | القيمة المقبولة        |
| ---------------------------- | ----------------------------- | ------------- | ---------------------- |
| `struct.string()`            | رفض                           | رفض           | قبول `string`          |
| `struct.string().optional()` | قبول (يُحذف عند تسلسل الكائن) | رفض           | قبول `string`          |
| `struct.string().null()`     | رفض                           | قبول          | قبول `string`          |
| `struct.string().nullish()`  | قبول (يُحذف عند تسلسل الكائن) | قبول          | قبول `string`          |
| `struct.null()`              | رفض                           | قبول          | رفض أي قيمة غير `null` |

<include cwd lang="typescript">
  examples/struct/required-optional-null.ts#example
</include>

ترفض دالتا `struct.any()` و`struct.unknown()` أيضاً القيمتين `null` و`undefined` ما لم تُربطا صراحة بـ `.null()` أو `.optional()` أو `.nullish()`.

## 3. الأسماء البديلة السلكية ثنائية الاتجاه (`.alias()`)

استخدم `.alias("wire_name")` عندما تستخدم الواجهة الخلفية نمط `snake_case` أو ترويسات خاصة بينما تعتمد حزمة TypeScript SDK لديك نمط `camelCase`. تعلن عن الاسم البديل مرة واحدة على مستوى الحقل، ويعمل بكفاءة في كلا الاتجاهين:

| الحد الفاصل                                                              | المفتاح المستخدم                                            |
| ------------------------------------------------------------------------ | ----------------------------------------------------------- |
| مدخلات العملية `input` واستدعاء `struct.parse(Schema, value)`            | الاسم المنطقي (`customerName`)                              |
| كائن struct محدد الأنواع تُرجعه `builder` (`body`، و`query`، و`headers`) | الاسم البديل السلكي (`customer_name`)                       |
| فك ترميز استجابة JSON أو حدث SSE أو إطار WebSocket                       | الاسم السلكي `customer_name` ← الاسم المنطقي `customerName` |
| مفتاح كائن مجهول مكتوب مباشرة داخل `builder`                             | المفتاح الحرفي كما كُتب تماماً                              |

<include cwd lang="typescript">
  examples/struct/aliases.ts#example
</include>

يحافظ نشر كائن ذي نوع محدد داخل `builder` (`{ ...input.order, extra: 1 }`) على ترميز struct وأسمائه البديلة. بينما كتابة المفتاح المنطقي واسمه البديل السلكي معاً في نفس الكائن يفشل فوراً بخطأ `REQ_BUILD_FAILED`.

## 4. موضع الطلب ومحولات النماذج (Form Codecs)

يعرّف `input` المعلمات؛ بينما تضعها دالة `builder` داخل `{ path, query, headers, body }`. وفيما يخص الأجسام المُرمَّزة بنماذج الاستمارات، تضع دالتا `struct.urlencoded(shape)` و`struct.formData(shape)` وسماً على الكائن الجذري لتقوم وسيلة النقل بتسلسله تلقائياً كـ `URLSearchParams` أو `FormData`:

<include cwd lang="typescript">
  examples/struct/request-placement.ts#example
</include>

| جذر الجسم الذي تُرجعه `builder`                          | التنسيق السلكي           | ترويسة `Content-Type` الافتراضية                  |
| -------------------------------------------------------- | ------------------------ | ------------------------------------------------- |
| كائن ذو نوع محدد، مصفوفة، رقم محدود، قيمة منطقية، `null` | نص JSON                  | `application/json`                                |
| بنية `string` أو نص خام `string`                         | نص UTF-8                 | `text/plain;charset=UTF-8`                        |
| `struct.urlencoded(shape)` في جذر الجسم                  | `URLSearchParams`        | `application/x-www-form-urlencoded;charset=UTF-8` |
| `struct.formData(shape)` في جذر الجسم                    | `FormData`               | `multipart/form-data; boundary=...`               |
| `Blob` / `File` (`struct.file()`)                        | كائن ثنائي (Binary blob) | `blob.type` أو `application/octet-stream`         |
| `ArrayBuffer` / مصفوفة عرض / `ReadableStream`            | بايتات خام               | `application/octet-stream`                        |

## 5. معالجة `StructError` والمشكلات (Issues)

تُرجع الدالة `struct.parse(Schema, data, { aliases?, errorMap? })` القيمة `[StructError, undefined]` عند الفشل. يرث `StructError` من كائن الخطأ الأصلي `Error` ويوفر الخصائص والدوال: `issues` و`format()` و`flatten()` و`prettify()`:

<include cwd lang="typescript">
  examples/struct/parse-failures.ts#example
</include>

يحتوي كل عنصر `StructIssue` على: `code` (مثل `invalid_type` أو `missing_key` أو `invalid_literal` أو `invalid_enum` أو `invalid_union` أو `invalid_intersection` أو `custom`)، و`path`، و`expected`، و`received`، و`message`. تحذف الرسائل الافتراضية القيمة المستلمة وتُبلّغ عن _نوعها_ فقط، لكن المسارات تحتفظ بمفاتيح record الديناميكية، التي قد تحتوي على قيم حساسة. ليست `String(error)` و`error.prettify()` حد تنقيح؛ استخدم قائمة سماح للحقول الآمنة عند التسجيل، وعامل قيم `received` الخام والرسائل المخصصة على أنها حساسة.

## 6. مرجع دوال البناء (Constructors)

| دالة البناء                                                | المدخلات المقبولة                         | المخرجات المستنتجة                                       |
| ---------------------------------------------------------- | ----------------------------------------- | -------------------------------------------------------- |
| `struct.string()` / `struct.boolean()`                     | النوع الأولي المطابق                      | `string` / `boolean`                                     |
| `struct.number()`                                          | أي رقم `number` باستثناء `NaN`            | `number` (يُرفض `NaN`؛ وتُرفض `±Infinity` في أجسام JSON) |
| `struct.bigint()`                                          | قيمة `bigint` أو نص رقمي                  | `bigint`                                                 |
| `struct.date()`                                            | كائن `Date` صالح، أو طابع زمني، أو نص ISO | `Date`                                                   |
| `struct.literal(value)`                                    | القيمة الأولية الحرفية المطابقة بدقة      | نوع حرفي (Literal type)                                  |
| `struct.enum(values)`                                      | عضو معلن من النصوص أو الأرقام             | اتحاد قيم حرفية (Union of literals)                      |
| `struct.array(item)` / `struct.tuple(items)`               | مصفوفة / Tuple محدد الطول                 | `T[]` / `[...]`                                          |
| `struct.object(shape)` / `struct.record(val)`              | كائن بسيط (Plain object)                  | كائن محدد الأنواع / `Record<string, V>`                  |
| `struct.discriminatedUnion(key, options)`                  | كائن يحتوي على مفتاح تمييز حرفي `key`     | اتحاد فروع الكائنات                                      |
| `struct.or(branches)`                                      | أول فرع مطابق                             | اتحاد أنواع الفروع                                       |
| `struct.intersection(members)`                             | قيمة تستوفي شروط جميع الأعضاء             | تقاطع مدمج بعمق (Deep-merged intersection)               |
| `struct.file()` / `struct.blob()` / `struct.arrayBuffer()` | `File` / `Blob` / `ArrayBuffer`           | تمثيل ثنائي (Binary representation)                      |

### هياكل struct العودية

يقرأ النوع المرجعي الذاتي نفسه عبر خاصية getter في الـ shape. يعمل الـ getter عندما يصل التحليل إلى ذلك الحقل، لذا يمكن للثابت أن يشير إلى نفسه. أضف التعليق النوعي `Struct<T>` إلى الثابت: لا يستطيع TypeScript استنتاج نوع يشير إلى نفسه.

<include cwd lang="typescript">
  examples/struct/recursive.ts#example
</include>

### ما لا يفعله `struct`

- يعلن `struct` البنية فقط. طول السلاسل والأنماط ونطاقات الأرقام وقواعد العمل تنتمي إلى شيفرة التطبيق بعد التحليل.
- يتوقف التحليل عند أول حقل غير صالح. ولا يملأ أبدًا حقلًا مفقودًا بقيمة صفرية ولا يُرجع مخرجات جزئية.
