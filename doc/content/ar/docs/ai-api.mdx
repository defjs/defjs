ينشر هذا الموقع Markdown بالإنجليزية للمساعدين. لا تحمل هذه العناوين بادئة لغة، وليست ترجمات للأدلة المترجمة.

## فهرس الصفحات [#llms-txt]

يسرد [llms.txt](/llms.txt) الصفحات الإنجليزية ويربط بعناوين مواقعها. وهو نقطة البداية عندما يحتاج المساعد إلى العثور على صفحة أولًا.

## الأدلة المجمّعة [#llms-full]

يجمع [llms-full.txt](/llms-full.txt) الأدلة الإنجليزية في ملف واحد. استخدمه عندما يحتاج المساعد إلى سياق واسع في مستند واحد وتسمح ميزانية الرموز بذلك.

## صفحة واحدة بصيغة Markdown [#page-markdown]

كل صفحة إنجليزية متاحة أيضًا بصيغة Markdown على `/llms.mdx/<path>/content.md`. مثلًا، [Quick start بصيغة Markdown](/llms.mdx/docs/start/content.md) هو النص الإنجليزي لصفحة Quick start.

## التحقق من الإصدار [#version]

يوثّق هذا الموقع الفرع الافتراضي؛ وقد يثبّت المشروع إصدارًا مختلفًا من `@defjs/core`. تحقّق من واجهات API مقابل الحزمة المثبّتة قبل تطبيق أي اقتراح. أزل الأسرار وراجع سياسات المشروع قبل مشاركة الشيفرة أو السياق مع أداة ذكاء اصطناعي.
