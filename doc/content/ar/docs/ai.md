تكليف مساعد بكتابة شيفرة Defjs واستدعاء خدمة ذكاء اصطناعي من التطبيق مهمتان مختلفتان. هذه الصفحة مسار المساعد. [استدعاء واجهات الذكاء الاصطناعي](/ar/docs/ai-api) هو مسار التطبيق. يمكن للمساعد المتوافق تحميل الـ skill المثبّتة عند الحاجة؛ ويعتمد التفعيل على الأداة.

## تثبيت الـ skill [#install]

تتطلب واجهة skills إصدار Node.js 22.20 أو أحدث. هذا متطلب أداة التثبيت، وليس بيئة تشغيل `@defjs/core`. بيئة التشغيل موضّحة في [البدء السريع](/ar/docs/start).

شغّل الأمر في المشروع الذي يجب أن يتلقى الـ skill. تثبّتها الأداة في المشروع الحالي افتراضيًا، وقد تكتشف الوكيل الحالي أو تطلب اختياره؛ استخدم `-a` لتحديد وكيل صراحةً.

```sh
npx skills add defjs/defjs --skill defjs
```

بعد النشر، يمكن قراءة تعليمات الـ skill في [skills/defjs/SKILL.md](https://github.com/defjs/defjs/blob/main/skills/defjs/SKILL.md). مصدر GitHub هو الفرع الافتراضي وقد لا يطابق إصدار `@defjs/core` المثبّت في المشروع.

## اطلب نقطة نهاية واحدة [#prompt]

أعطِ المساعد مهمة. يطلب هذا النص `GET /users/:id` محدَّد الأنواع يبقى عميله في التطبيق:

```txt
Use @defjs/core to define GET /users/:id.
The input is { id: number }; a successful response is { id: number, name: string }.
Keep the SDK definition and application client in separate modules,
and verify the result with the project’s existing tests.
```

## تحقق من النتيجة [#verify]

اقرأ التعريف والتطبيق كلًا على حدة. يصدّر التعريف العملية ولا ينشئ العميل. ينشئ التطبيق العميل ويستدعي العملية، مثل `getUser(client, { id: 1 })`. حيث يُعلَن `input`، يكون `builder` دالة متزامنة نقية مكتوبة صراحة. تُستخدم قيمة النجاح فقط بعد أن يخلو موضع الخطأ.

ثم شغّل فحص الأنواع في ذلك المشروع والاختبارات التي تغطي العقد. يبقى تثبيت الاعتماديات وقواعد CI مع ذلك المشروع.

## Markdown إنجليزي للمساعدين [#resources]

الأدلة والأمثلة ومراجعات API في هذا الموقع مكتوبة للناس وموجودة في كل لغة. هذه العناوين الثلاثة تُولَّد من الصفحات الإنجليزية فقط. ليس لها بادئة لغة، وليست ترجمات للصفحة التي تقرأها.

- [فهرس الصفحات الإنجليزية](/llms.txt) يسرد الصفحات الإنجليزية ويربط بعناوينها على الموقع.
- [الأدلة الإنجليزية المجمَّعة](/llms-full.txt) تضم تلك الصفحات في ملف واحد.
- [البدء السريع بصيغة Markdown](/llms.mdx/docs/start/content.md) هو النص الإنجليزي لصفحة واحدة. كل صفحة إنجليزية أخرى تستخدم الشكل نفسه، `/llms.mdx/…/content.md`.

اقرأ [البدء السريع](/ar/docs/start) عندما تريد ذلك الدليل بهذه اللغة. وجّه المساعد إلى عنوان Markdown عندما يجب أن يتبع واجهة API. ويظل على المساعد الالتزام بإصدار `@defjs/core` المثبّت في المشروع: قد يختلف توثيق هذا الموقع عن الإصدار المثبّت، فتحقق من الواجهات مقابل ذلك الإصدار. مصدر GitHub للتوثيق هو الفرع الافتراضي وقد لا يطابق ذلك الإصدار المثبّت أيضًا. أزل الأسرار وتحقق من سياسات مشروعك قبل مشاركة الشيفرة أو السياق مع أداة ذكاء اصطناعي.
