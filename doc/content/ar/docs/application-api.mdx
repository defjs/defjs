# طبقة API داخل التطبيق [#application-api-layer]

تستخدم معظم المشاريع Defjs مباشرةً داخل مستودع التطبيق (`src/api/`) لاستبدال أغلفة `fetch` أو `axios` المتناثرة. حتى عندما لا تخطط لنشر حزمة npm خارجية، فإن الفصل بين `src/api/schema/` و`src/api/request/` و`src/api/client.ts` يبقي طبقة الطلبات لديك ذات أنواع صارمة، وقابلة للاختبار في الذاكرة، وآمنة عبر بيئات المتصفح وSSR.

---

## 1. هيكل المجلدات الموصى به داخل `src/api/`

نظّم طبقة الطلبات في مشروعك إلى ثلاثة أجزاء مركّزة تحت `src/api/`:

```text
src/
├── api/
│   ├── schema/           # 1. مخططات struct المشتركة + أنواع Infer<typeof ...>
│   │   └── order.ts      #    ApiError, OrderStatus, Order, OrderPage
│   ├── request/         # 2. تعريفات عمليات نقية مجمّعة حسب النطاق
│   │   └── orders.ts     #    getOrder, listOrders, createOrder
│   └── client.ts         # 3. العميل المملوك للتطبيق (نقطة النهاية، معترض المصادقة، إعادة المحاولة)
└── checkout.ts           # 4. منطق الأعمال / مكوّنات الواجهة التي تستدعي العمليات
```

## 3. أنماط أساسية لمشاريع التطبيقات

### نسخة المتصفح المفردة مقابل عميل SSR لكل طلب

- **المتصفح / تطبيقات الصفحة الواحدة SPA (`apiClient`)**: صدِّر نسخة `createClient(...)` واحدة على مستوى الوحدة لكل أصل خلفي (origin). تضمن مشاركة هذه النسخة الحفاظ على حالة صحة موزّع الحمل وميزانية إعادة محاولة طلبات HTTP على مستوى العميل عبر تفاعلات الصفحة. وفي تطبيقات React أو Vue، وفِّر `apiClient` عند الجذر عبر [`@defjs/react`](/ar/docs/integrations/react) (`ClientProvider` / `useClient`) أو [`@defjs/vue`](/ar/docs/integrations/vue) (`createClientPlugin` / `injectClient`).
- **SSR / BFF (`createServerApiClient(accessToken)`)**: كلما اختلفت بيانات الاعتماد أو ملفات تعريف الارتباط أو ترويسات المستأجر لكل طلب HTTP وارد، استدعِ دالة مصنع داخل معالج طلبات الخادم لإنشاء `Client` معزول. وبما أن `getOrder` و`listOrders` و`createOrder` دوال نقية، فإن تعريفات `request/orders.ts` ذاتها تعمل مع كلٍّ من `apiClient` و`createServerApiClient(token)`.

### المهل الزمنية والإلغاء لكل استدعاء

لا تنشئ عميلاً جديداً عبر `createClient(...)` لمجرد تمرير مهلة زمنية أو `AbortSignal`. بدلاً من ذلك، اشتق عميلاً لاستدعاء واحد مباشرةً من عميلك المشترك:

```ts
const [err, created] = await createOrder(
  apiClient({ signal: AbortSignal.timeout(5_000) }),
  {
    customerName: "Ada Lovelace",
    totalCents: 4200,
    idempotencyKey: "idem-2026-101",
  },
);
```

### غلاف الأخطاء المشترك (`ApiError`)

صرح عن غلاف الخطأ القياسي لواجهتك الخلفية مرة واحدة (`export const ApiError = struct.object(...)`) في `src/api/schema/` ومرّر `error: ApiError` في كل استدعاء `defineRequest` داخل `src/api/request/`. عندما يعيد الطلب رمز حالة غير `2xx`، يمنحك تضييق النوع عبر `if (err.code === "HTTP_STATUS")` داخل `if (err)` وصولاً ذا أنواع صارمة إلى `err.data.code` و`err.data.message` و`err.data.requestId`.
