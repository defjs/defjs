# Vue

تربط حزمة `@defjs/vue` عميل `@defjs/core` المملوك للتطبيق بتطبيق Vue 3.2+ عبر `createClientPlugin(client)` والرمز `HTTP_CLIENT` ودالة `injectClient()`. تبقى تعريفات SDK لديك وحدات `@defjs/core` نقية دون أي اعتمادية على Vue.

```sh
bun add @defjs/core @defjs/vue vue
```

## ما توفره `@defjs/vue` مقابل ما يملكه تطبيقك

- **ما توفره `@defjs/vue`**: الدالة `createClientPlugin(client)`، والرمز `HTTP_CLIENT` (من نوع `InjectionKey<Client>`)، ودالة `injectClient(key?)`.
- **ما يملكه تطبيقك**: إنشاء عميل [`DerivableClient`](/ar/api/core/derivableclient-type)، وإلغاء العمل الجاري في المراقبين عبر (`onCleanup`) أو في دوال Composables عبر (`onScopeDispose`)، وإغلاق مقابض SSE/WebSocket، ودمج مكتبات الاستعلام (مثل Vue Query).
- **تنبيه هام**: تُرجع `injectClient()` كائن-دالة `DerivableClient`. استدعِ `client({ signal })` حيث تُشغّل العملية (`getOrder(client({ signal }), input)`). ولا تمرر `client` أبداً كمعامل أول لـ `watch(client, ...)` أو `computed(client)` لأن Vue يعامل وسيط الدالة كدالة جلب تفاعلية (reactive getter).

## 2. الحقن والتجاوز في الأشجار الفرعية

تبحث الدالة `injectClient(key?)` عن أقرب موفر للمفتاح `key` (افتراضياً `HTTP_CLIENT`) وتلقي خطأ `Error` إذا استُدعيت خارج سياق حقن Vue نشط (`setup()` أو `app.runWithContext()`) أو إذا لم يتوفر أي عميل لهذا المفتاح.

- تستلم المكونات التابعة العميل `childClient`، بينما تحتفظ الأشجار الفرعية الشقيقة بالعميل الجذري.

## 3. تنظيف تدفقات SSE وWebSocket عند التخلص من النطاق

للعمليات التي تبدأ داخل composable أو مكون خارج المراقبين، اجمع بين `AbortController` و`onScopeDispose`. ألغِ بدء التشغيل، وأغلق أي مقبض يُحل بعد التخلص من النطاق، واستهلك مكرره غير المتزامن المفرد، وانتظر `.closed`:

- يؤدي إيقاف النطاق إلى إنهاء حلقة `for await` لتدفق SSE بشكل طبيعي.
- يؤدي إلغاء جلسة WebSocket إلى إنهائها كـ `aborted` ورفض `session.receive` بخطأ `AbortError`، لذا احرص على حماية كتلة `catch` بعد التخلص من النطاق وإلغاء اشتراك مستمعي `onStateChange` و`onRuntimeError` داخل كتلة `finally`.

---

## 4. العرض من الخادم (SSR) ونطاق التطبيق

- **المتصفح**: شارك عميلاً واحداً لكل تطبيق Vue عندما تكون نقطة النهاية والمعترضات مستقلة عن الطلب.
- **الخادم (SSR)**: أنشئ عميلاً جديداً وثبّته لكل طلب SSR كلما اختلفت الترويسات أو ملفات تعريف الارتباط أو المستأجرون أو بيانات الاعتماد.
- تفكيك تطبيق Vue أو التخلص من نطاق المكون **لا** يُلغي تلقائياً طلبات HTTP، ولا يُغلق تدفقات SSE/WebSocket، ولا يتخلص من عميل Core الأساسي.
