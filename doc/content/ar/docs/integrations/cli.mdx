# أداة CLI ومولّد OpenAPI

حزمة `@defjs/cli` هي أداة سطر أوامر لوقت التطوير على Node.js (`>= 22.18.0`) وBun — تُشحَن كحزمة ESM أحادية الملف دون أي اعتماديات وقت تشغيل (مع كون `@defjs/core` اعتمادية نظيرة اختيارية) — تحوّل مواصفات Swagger 2.0 وOpenAPI 3.0–3.2 (عبر `@scalar/openapi-parser` المدمج) إلى تعريفات `@defjs/core` **عديمة الحالة بصيغة ESM** ومخططات `struct` باستخدام طابعة AST مدمجة بمسافة بادئة من فراغين. لا تحتجز الوحدات المولَّدة أي عميل، ولا تنشئ أصنافاً، وتعلّم التصريحات النقية بالتعليق `/*#__PURE__*/`.

ثبّتها كاعتمادية تطوير:

```bash
bun add -D @defjs/cli
```

يؤدي تشغيل `defjs` دون وسائط إلى طباعة التعليمات والخروج بنجاح.

## الإعداد وواجهة البرمجة

## الرايات الأساسية وضوابط Defjs

| الراية / الخيار                     | القيم                                                                                                        | السلوك                                                                                                                                                                                                 |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--input`، `input`                  | ملف محلي `.yaml`/`.yml`/`.json`/`.ts`/`.mts`/`.js`/`.mjs`، أو رابط `http(s):`، أو كائن مستورد، أو دالة تحميل | يحمّل وحدات `.ts`/`.mts`/`.js`/`.mjs` عبر `import()` الأصلي في Node `>= 22.18` / Bun والمواصفات عبر Scalar (`upgrade` لمستندات Swagger 2.0 / 3.0 أحادية الملف؛ ويحافظ على مراجع `$ref` متعددة الملفات) |
| `--format`، `format`                | `ts` (افتراضي)، `tsx`، `js` (`.js` + `.d.ts`)، `mjs` (`.mjs` + `.d.mts`)                                     | يُخرج وحدات ESM عديمة الحالة مجمَّعة حسب الوسم ضمن `schema/` و`request/` (مع وحدة `util` جذرية مشتركة عند الحاجة)                                                                                      |
| `--mode`، `mode`                    | `sync` (افتراضي)، `scaffold`                                                                                 | يزيل `sync` الملفات المدارة المتقادمة ويتحقق من ملكية الترويسة؛ بينما يكتب `scaffold` الملفات المفقودة فقط                                                                                             |
| `--error-strategy`، `errorStrategy` | `none` (افتراضي)، `union`                                                                                    | يتجنب `none` فك ترميز أخطاء البوابة HTML خارج 2xx؛ بينما يركّب `union` مخطط `error` struct موثقاً لحالات غير 2xx                                                                                       |
| `--mixed-2xx`، `mixed2xxStrategy`   | `omit` (افتراضي)، `split`                                                                                    | عندما تمزج العملية بين استجابات 2xx ذات جسم و`204`، يحذّر `omit` بوضوح ويُغفل `output`، بينما يضيف `split` عملية `<op>NoContent`                                                                       |
| `--check`                           | boolean                                                                                                      | يخرج برمز `1` إذا اختلف أي ملف مُدار أو كان سيتعرض للحذف                                                                                                                                               |

تلتزم الشيفرة المولَّدة بجميع عقود Defjs:

- `input` + دالة `builder` تزامنية صريحة (مع تمرير `body: input.body` المحدد النوع مباشرة عندما تحمل أجسام JSON إعادة تسمية `.alias(...)`)
- تصدر أنماط الاستعلام غير الافتراضية (`deepObject` و`pipeDelimited` و`spaceDelimited` و`form` مع `explode: false` و`json`)، وكذلك مسلسِلات معاملات المسار والترويسة غير الافتراضية (`label` و`matrix` و`simple` للمصفوفات والكائنات)، الانغلاق المساعد المطلوب فقط إلى وحدة `util` جذرية مشتركة (`util.ts`/`.tsx`/`.js`/`.mjs` + `util.d.ts`/`.d.mts` لصيغ JS)، تستوردها ملفات `request/<group>` من `../util`
- تصدر استجابات البث `text/event-stream` (`itemSchema`) عبر `defineEventStream` بدلاً من `defineRequest`
- تصدر المخططات المتبادلة أو ذاتية الاستدعاء العودي بترتيب طوبولوجي لاحق (topological post-order) مع خصائص getter كسولة على دورات الكائنات، لمنع أعطال `ReferenceError` الناتجة عن TDZ عند تحميل الوحدة
