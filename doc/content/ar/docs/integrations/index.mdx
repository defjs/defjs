# الإضافات

الإضافات حزم اختيارية يركّبها التطبيق المستهلك على عميل Defjs الذي يملكه. `@defjs/core` لا يستوردها، وتعريفات SDK لا تستوردها أيضًا. يملك التطبيق العميل ونقطة النهاية وبيانات الاعتماد واختيار الإضافات.

الإضافات نوعان. **إضافات الإطار** تسلّم `Client` موجودًا إلى شجرة الإطار. **الإضافة الوسيطة** هي شكل الإضافة لسلسلة المعترضات: تُلحق معترضات بعميل التطبيق. انظر [المعترضات](/ar/docs/interceptors).

| الإضافة                                                                 | الحزمة                        | ما تضيفه                                                                     | ما لا تفعله                                                                              |
| ----------------------------------------------------------------------- | ----------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [React](/ar/docs/integrations/react) · إطار                             | `@defjs/react`                | `ClientProvider` و`useClient()` لعميل موجود                                  | لا تنشئ العميل ولا تخزّنه ولا تعيد المحاولة ولا تتخلص منه. ليست مكتبة استعلام أو حالة    |
| [Vue](/ar/docs/integrations/vue) · إطار                                 | `@defjs/vue`                  | إضافة Vue و`HTTP_CLIENT` و`injectClient()`                                   | لا تنشئ ولا تخزّن ولا تعيد المحاولة. لا تغلق النقل عند إلغاء التركيب. ليست مكتبة استعلام |
| [خادم OpenTelemetry](/ar/docs/integrations/opentelemetry-server) · وسيط | `@defjs/opentelemetry-server` | `withOpenTelemetryServer(...)`، خيار عميل يُلحق معترضات HTTP وSSE وWebSocket | لا تهيئ OpenTelemetry SDK ولا ترصد الطلبات الواردة إلى الخادم                            |

تسلّم React وVue عميلًا موجودًا إلى شجرة الإطار. ينشئ التطبيق ذلك العميل بـ `createClient` من `@defjs/core`. توفّر إضافة React العميل عبر Context. توفّر إضافة Vue العميل عبر `app.use(createClientPlugin(client))`. لا تبدأ أي الحزمتين طلبًا.

إضافة خادم OpenTelemetry الوسيطة هي `ClientOption`. مرّر `withOpenTelemetryServer(...)` إلى `createClient`. تُلحق معترضًا واحدًا لكل وسيلة نقل مفعّلة، بالترتيب HTTP ثم SSE ثم WebSocket. انظر [المعترضات](/ar/docs/interceptors). لا تهيئ الحزمة OpenTelemetry SDK.
