# نظرة عامة على التكاملات

يُوسّع التكامل عميل التطبيق `Client` عند نقاط تمديد محددة بدقة دون تعديل حزمة `@defjs/core` ودون ربط تعريفات SDK بأي إطار عمل أو حزمة قياس ومراقبة. تبقى تعريفات SDK لديك وحدات ESM نقية تتبع `@defjs/core` فقط؛ بينما يختار التطبيق المستهلك التكاملات التي يرغب في تثبيتها واستخدامها.

تخضع كل إضافة في Defjs لـ **عقد الإضافات الرشيقة (thin plugin contract)**:

- **لا تخزين مؤقت خفي ولا إدارة حالة ضمنية**: لا تخزن الإضافات أي استجابات، ولا تعيد محاولة الطلبات تلقائياً، ولا تدير حالة استعلامات البيانات.
- **لا استبدال لوسيلة النقل**: لا تغلف الإضافات وسيلة النقل الأساسية لـ HTTP أو SSE أو WebSocket ولا تستبدلها أبداً.
- **دورة حياة مملوكة للمستدعي**: إلغاء تثبيت موفر واجهة المستخدم (UI Provider) أو إيقاف تشغيل حزمة القياس عن بُعد لا يُلغي تلقائياً الطلبات الجارية ولا يُغلق التدفقات النشطة.

## بنيتان أساسيتان لتطوير الإضافات

### 1. إضافات أطر العمل (`@defjs/react`، `@defjs/vue`)

تمرر إضافة إطار العمل عميل [`DerivableClient`](/ar/api/core/derivableclient-type) الحالي عبر شجرة المكونات باستخدام آليات حقن الاعتمادية الأصلية (React Context أو Vue `provide` / `inject`):

<Tabs items={["sdk/orders.ts", "app/main.tsx", "app/OrderCard.tsx"]}>
  <Tab value="sdk/orders.ts">
```ts
import { defineRequest, struct } from "@defjs/core";

export const Order = struct.object({
  id: struct.number(),
  status: struct.string(),
});

export const getOrder = defineRequest({
  method: "GET",
  path: "/orders/:id",
  input: struct.object({ id: struct.number() }),
  builder: (input) => ({ path: { id: input.id } }),
  output: Order,
});
```
  </Tab>
  <Tab value="app/main.tsx">
```tsx
import { createClient, withEndpoint } from "@defjs/core";
import { ClientProvider } from "@defjs/react";
import { OrderCard } from "./OrderCard.tsx";

const client = createClient(withEndpoint("https://api.example.com"));

export function App() {
  return (
    <ClientProvider client={client}>
      <OrderCard id={42} />
    </ClientProvider>
  );
}
```
  </Tab>
  <Tab value="app/OrderCard.tsx">
```tsx
import { useClient } from "@defjs/react";
import { getOrder } from "../sdk/orders.ts";

export function OrderCard({ id }: { id: number }) {
  const client = useClient();
  // مرّر `client` أو `client({ signal })` إلى `getOrder(...)` داخل أثر جانبي أو خطاف استعلام
  void id;
  void getOrder;
  void client;
  return null;
}
```
  </Tab>
</Tabs>

### 2. الإضافات الوسيطة (`@defjs/opentelemetry-server`)

الإضافة الوسيطة هي دالة مصنع تُرجع خيار عميل [`ClientOption`](/ar/api/core/clientoption-type). وعند تمريرها إلى `createClient(...)`، تقوم بإلحاق معترضات HTTP وSSE و/أو WebSocket عبر `withInterceptors`:
