# React

تربط حزمة `@defjs/react` عميل `@defjs/core` المملوك للتطبيق بشجرة مكونات React 18+ عبر React Context وخطاف `useClient()`. تبقى تعريفات SDK لديك وحدات `@defjs/core` نقية دون أي اعتمادية على React.

```sh
bun add @defjs/core @defjs/react react
```

## ما توفره `@defjs/react` مقابل ما يملكه تطبيقك

- **ما توفره `@defjs/react`**: المكون `ClientProvider` والخطاف `useClient(overrideClient?)`.
- **ما يملكه تطبيقك**: إنشاء عميل [`DerivableClient`](/ar/api/core/derivableclient-type)، وإلغاء الطلبات الجارية عند تفكيك المكون أو تغير الاعتماديات (`AbortController`)، وإغلاق مقابض SSE/WebSocket، ودمج أدوات التخزين المؤقت للاستعلامات مثل TanStack Query.
- **تنبيه هام**: يُرجع `useClient()` كائن-دالة `DerivableClient`. استدعِ `client({ signal })` حيث تُشغّل العملية (`getOrder(client({ signal }), input)`). ولا تمرر `client` أبداً مباشرة إلى `setState(client)` لأن React يعامل وسيط الدالة الممرر لمغير الحالة كدالة تحديث (updater function).

## 2. القراءة والتجاوز باستخدام `useClient`

تُرجع الدالة `useClient(overrideClient)` العميل `overrideClient` عند تمريره، أو تقرأ من أقرب `ClientProvider` عند إغفاله أو تعيينه كـ `undefined`. وتلقي خطأ `Error` فقط إذا لم يوفر أيٌّ من المصدرين عميلاً صالحاً.

<include cwd>examples/react/read-with-use-client.tsx#example</include>

- استدعِ دائماً `useClient(explicitClient)` دون شروط في المستوى الأعلى للمكون أو الخطاف المخصص. ولا تكتب أبداً `explicitClient ?? useClient()` لأن ذلك يخالف قواعد الخطافات (Rules of Hooks).

## 3. التكامل مع TanStack Query

تقتصر حزمة `@defjs/react` على حقن الاعتماديات فقط، وهي **لا** تشحن خطاف `useRequest`. وعند استخدام مكتبة لجلب البيانات مثل TanStack Query، مرّر خاصية `signal` الخاصة بدالة الاستعلام عبر `client({ signal })` وحوّل مصفوفة الخطأ أولاً داخل محول الاستعلام:

## 4. إدارة دورات حياة SSE وWebSocket في Effects

تعيش مقابض SSE وWebSocket لفترة أطول من استدعاء `openStream(...)` أو `connectChat(...)` الأولي. سجّل كود التنظيف قبل انتظار بدء التشغيل، وأغلق أي مقبض يُحل بعد تفكيك المكون، واستهلك مكرره غير المتزامن المفرد، وانتظر `.closed`:

<include cwd>examples/react/own-realtime-work.tsx#example</include>

- يؤدي إلغاء إشارة `signal` الممررة إلى عملية WebSocket إلى إنهاء الجلسة كـ `aborted` ورفض `session.receive` بخطأ `AbortError`. قم بحماية كتلة `catch` عند تفكيك المكون حتى لا تطفو إلا أخطاء وقت التشغيل الحقيقية (مثل فيضان قائمة الانتظار أو مهلة نبضات القلب).
- يؤدي إلغاء تدفق SSE إلى إنهاء حلقة `for await (const msg of stream)` بنظافة ودون إلقاء أي استثناءات.

## 5. العرض من الخادم (SSR) ونطاق الموفر

- **المتصفح**: شارك عميلاً واحداً على نطاق الوحدة عندما تكون نقطة النهاية والمعترضات مستقلة عن الطلب.
- **الخادم (SSR)**: أنشئ عميلاً جديداً داخل حدود كل طلب خادم كلما كانت الترويسات أو ملفات تعريف الارتباط أو المستأجرون أو بيانات الاعتماد تختلف بين طلب وآخر.
- إلغاء تثبيت `<ClientProvider>` **لا** يُلغي تلقائياً طلبات HTTP النشطة، ولا يُغلق اتصالات SSE/WebSocket، ولا يتخلص من العميل.

- `ClientProvider` — يوفر عميل `DerivableClient` (`ClientProviderProps: { client: DerivableClient; children?: ReactNode }`).
