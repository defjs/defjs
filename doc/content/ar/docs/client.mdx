# العميل

`Client` هو إعداد تنفيذ التطبيق المستهلك. تُرجع `createClient(...)` [`DerivableClient`](/ar/api/core/derivableclient-type). استدعاء المصنع مع خيارات الطلب يُرجع قيمة `Client`، وقيمة `Client` هي ما تقبله العمليات. وهي غير قابلة للاستدعاء. استورد العمليات من SDK، واختر عنوان الخدمة وبيانات الاعتماد والمعترضات ووسيلة النقل، ثم استدعِ عملية بالعميل. `getUser(client({ abort }), { id: 1 })` يبدأ استدعاءً يعلن مدخلًا. `health(client)` يبدأ استدعاءً لا يعلنه. عندما يكون struct المدخل كاملًا اختياريًا، يكون كل من `search(client)` و`search(client, input)` صالحًا. لا وسيط ثالث للخيارات. استدعاء العملية يبدأها. `await` ينتظر فقط الـ tuple الذي يضع الخطأ أولًا.

تعريفات SDK لا تربط هذه النسخة. يمكن لمتصفح وطلب خادم واختبار محلي استخدام العملية المصدَّرة نفسها مع عملاء مختلفين. ويظل الجميع يتبعون عقد Defjs نفسه وإصدارات Core المتوافقة. اضبط عنوان خدمة كل عميل للعمليات التي تستدعيها من خلاله.

يمكن تمرير قيمة العميل نفسها إلى عمليات كثيرة. تختار التطبيقات سياسات التخزين المؤقت وإعادة المحاولة وتملك العمل الذي تبدأه. لا يُعاد محاولة HTTP تلقائيًا. إعادة اتصال التدفق اختيارية.

المصنع دالة وهو أيضًا `Client` بلا خيارات طلب. لا تمرّر المصنع إلى ضابط حالة في React: `setState(factory)` سيستدعيه كمُحدِّث. لا تستخدمه مصدرًا لـ `watch` أو `computed` في Vue: فهما يستدعيان الدالة. قيمة العميل المشتقة كائن عادي.

## اشتق عميلًا

يُرجع `client(options?)` قيمة `Client` لاستدعاء واحد. عند استدعاء `client(options)` تُنسخ الحقول السبعة المعروفة من كائن الوسيط: لقطة للمستوى الأعلى في كائن خيارات جديد. تُتجاهل الحقول غير المعروفة وتُحذف الحقول التي قيمتها `undefined`. لا يوجد تركيب فوق الأصل: `client()` و`client(undefined)` و`client({})` تُرجع عميلًا بلا خيارات طلب. تُحفَظ قيم `heartbeat` و`protocols` و`reconnect` المتداخلة بالمرجع، دون استنساخ. يقرأها WebSocket عند تشغيل العملية (ينسخ حينها حقول heartbeat وقائمة protocols)، لذا قد يؤثر تغيير تلك الكائنات بعد الاشتقاق في استدعاء لاحق. ينبغي للتطبيقات أن تعاملها كغير قابلة للتغيير بعد تمريرها. الاشتقاق لا يؤدي أي إدخال/إخراج. الـ getter الذي يرمي يخرج من `client(options)` ويبقى المصنع صالحًا للاستخدام. قيمة العميل غير قابلة للاستدعاء؛ أنشئ واحدة لكل استدعاء.

لا يُجمَع `abort`. إعادة استخدام قيمة عميل تحمل `abort` تشارك تلك الإشارة بين الاستدعاءات، لذا أنشئ قيمة عميل لكل استدعاء. اجمع الإشارات بـ `AbortSignal.any` في شيفرة التطبيق.

الإعداد الأساسي من `createClient` مشترك بين كل قيمة عميل، وهو غير مُجمَّد وقت التشغيل. هو ثابت بالاصطلاح: لا شيء في المكتبة يغيّره، ولا ينبغي للتطبيقات أن تغيّره. [`RequestOptions`](/ar/api/core/requestoptions-type) على العميل هي لقطة المستوى الأعلى تلك. تمرّر شيفرة التطبيق العميل إلى عملية. وهي لا تقرأ تلك الحالة الداخلية.

## خيارات الطلب

لـ [`RequestOptions`](/ar/api/core/requestoptions-type) سبعة حقول مسطحة. يقرأ كل بروتوكول الحقول التي يعرفها فقط ويتجاهل الباقي. تمرير `heartbeat` إلى عملية HTTP يُتجاهل، وليس عطلًا. يقرأ SSE من خيارات الطلب `abort` فقط. إعادة اتصال SSE تأتي من إعداد العميل (`withSSEReconnect`)، لذا `client({ reconnect })` يؤثر في WebSocket فقط. لا يوجد مرشح بروتوكول وقت الترجمة.

| الحقل                | يستخدمه              | القاعدة                                                                                                |
| -------------------- | -------------------- | ------------------------------------------------------------------------------------------------------ |
| `abort`              | HTTP وSSE وWebSocket | يُجهض الاستدعاء. المهلة هي `AbortSignal.timeout(ms)` (`NET_TIMEOUT`). الإجهاض اليدوي هو `NET_ABORTED`. |
| `onUploadProgress`   | HTTP                 | يتجاهله SSE وWebSocket.                                                                                |
| `onDownloadProgress` | HTTP                 | يتجاهله SSE وWebSocket.                                                                                |
| `beforeConnect`      | WebSocket            | يستبدل إعداد العميل لذلك الاستدعاء.                                                                    |
| `protocols`          | WebSocket            | يستبدل قائمة العميل. وهو لا يُلحَق.                                                                    |
| `heartbeat`          | WebSocket            | يُستبدل كاملًا. `timeoutMs` هو انتظار إقرار النبض، وليس مهلة للطلب.                                    |
| `reconnect`          | WebSocket            | يُستبدل كاملًا.                                                                                        |

لا يوجد حقل `timeout`، ولا حقل `signal`، ولا مهلة افتراضية على مستوى العميل. في SSE وWebSocket، يغطي `abort` الاتصال كاملًا، بما فيه ما بعد فتحه. لا توجد مهلة للبدء فقط. التطبيق الذي يريد واحدة ينشئ `AbortController` خاصًا به، ويجهضه بـ `new DOMException("...", "TimeoutError")` من مؤقت، ويمسح المؤقت بعد أن يُرجع `await`. انظر [SSE](/ar/docs/sse#close-and-dispose).

`HttpExecuteOptions` هو شريحة HTTP: `abort` مع ردود نداء التقدّم. `EventStreamExecuteOptions` هو `{ abort? }`. `WebSocketExecuteOptions` هو شريحة WebSocket مع `abort`.

## النتائج حسب وسيلة النقل

- HTTP → `[error, data, response]`
- SSE → `[error, stream, open]`. `open` هو لقطة أول مصافحة ناجحة للاتصال المُرجَع لمقابض Defjs الأصلية أو الأغلفة التي تمرّر كائن `open` الحي نفسه؛ وتستخدم المقابض المخصصة أو الأغلفة التي تغلّب `open` قيمة `open` العامة الحالية حتى بعد إعادة الاتصال، بينما يبقى `stream.open` حيًا (انظر [SSE](/ar/docs/sse)).
- WebSocket → `[error, session, connection]`

عُد قبل استخدام قيمة النجاح عندما تكون `error` مضبوطة.

أنت تملك التنظيف: أجهض HTTP، وأغلق SSE + `await stream.closed`، وأغلق WebSocket + `await session.closed`.

## النطاق على الخادم مقابل المتصفح

على الخادم، أنشئ العميل داخل حدود الطلب عندما تلتقط الخيارات أو إغلاقات المعترضات المصادقة أو ملفات تعريف الارتباط أو المستخدمين أو المستأجرين. هوية العميل ليست حد أمان بذاتها.

## الترحيل

| القديم                                      | الجديد                                         |
| ------------------------------------------- | ---------------------------------------------- |
| `client.execute(getUser(input), options)`   | `getUser(client(options), input)`              |
| `execute(cmd, { timeout: 5000 })`           | `client({ abort: AbortSignal.timeout(5000) })` |
| `execute(cmd, { signal })`                  | `client({ abort: signal })`                    |
| `client({ abort })({ onDownloadProgress })` | `client({ abort, onDownloadProgress })`        |
| `createClient(withTimeout(5000), ...)`      | مرّر `abort` عند الاستدعاء، أو غلّف دالة تطبيق |

## مرجع

| المساعد                                                                                                       | الأثر                                                         |
| ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `withEndpoint(url)`                                                                                           | نقطة نهاية أساسية مطلقة لكل وسائل النقل                       |
| `withHeaders(HeadersInit)`                                                                                    | رؤوس افتراضية ثابتة لـ HTTP/SSE؛ رؤوس الـ builder تغلّبها     |
| `withHTTPHandle(fetch)`                                                                                       | استبدل Fetch لـ HTTP                                          |
| `withSSEHandle(fetch)`                                                                                        | استبدل Fetch لـ SSE                                           |
| `withWebSocketHandle(WebSocket)`                                                                              | استبدل منشئ WebSocket                                         |
| `withInterceptors(...items)`                                                                                  | ألحق معترضات مختلطة                                           |
| `withQuerySerializer(fn)`                                                                                     | رمّز كائن استعلام مُسمّى أصلًا إلى سلسلة استعلام              |
| `withCredentials(boolean)`                                                                                    | `credentials: 'include'` في Fetch لـ HTTP/SSE عندما تكون true |
| `withXSRF(options?)`                                                                                          | ملف تعريف ارتباط XSRF في HTTP → رأس                           |
| `withSSEReconnect` / `withSSEOnInvalidEvent`                                                                  | مقابض SSE                                                     |
| `withWebSocketReconnect` / `withWebSocketHeartbeat` / `withWebSocketProtocols` / `withWebSocketBeforeConnect` | مقابض WebSocket                                               |
