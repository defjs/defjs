# العميل

`Client` هو إعداد تنفيذ التطبيق المستهلك. تُرجع `createClient(...)` [`DerivableClient`](/ar/api/core/derivableclient-type). استدعاء المصنع مع خيارات الطلب يُرجع قيمة `Client`، وقيمة `Client` هي ما تقبله العمليات. وهي غير قابلة للاستدعاء. استورد العمليات من SDK، واختر عنوان الخدمة وبيانات الاعتماد والمعترضات ووسيلة النقل، ثم استدعِ عملية بالعميل. `getOrder(client({ signal }), { id: 1 })` يبدأ استدعاءً يعلن مدخلًا. `health(client)` يبدأ استدعاءً لا يعلنه. عندما يكون struct المدخل كاملًا اختياريًا، يكون كل من `search(client)` و`search(client, input)` صالحًا. لا وسيط ثالث للخيارات. استدعاء العملية يبدأها. `await` ينتظر فقط الـ tuple الذي يضع الخطأ أولًا.

تعريفات SDK لا تربط هذه النسخة. يمكن لمتصفح وطلب خادم واختبار محلي استخدام العملية المصدَّرة نفسها مع عملاء مختلفين. ويظل الجميع يتبعون عقد Defjs نفسه وإصدارات Core المتوافقة. اضبط عنوان خدمة كل عميل للعمليات التي تستدعيها من خلاله.

يمكن تمرير قيمة العميل نفسها إلى عمليات كثيرة. تختار التطبيقات سياسات التخزين المؤقت وإعادة المحاولة وتملك العمل الذي تبدأه. لا يُعاد محاولة HTTP تلقائيًا. إعادة اتصال التدفق اختيارية.

المصنع دالة وهو أيضًا `Client` بلا خيارات طلب. لا تمرّر المصنع إلى ضابط حالة في React: `setState(factory)` سيستدعيه كمُحدِّث. لا تستخدمه مصدرًا لـ `watch` أو `computed` في Vue: فهما يستدعيان الدالة. قيمة العميل المشتقة كائن عادي.

## اشتق عميلًا

يُرجع `client(options?)` قيمة `Client` لاستدعاء واحد. لا يخزّن `client()` ولا `client(undefined)` أي خيارات طلب. يُبقي `client({})` لقطة فارغة؛ ولا يسقطها Defjs بفحص المفاتيح. عند استدعاء `client(options)` يُقرأ كل حقل طلب في المستوى الأعلى مرة واحدة ويُوضَع على كائن خيارات جديد. تُنسَخ مصفوفة `protocols`. ينسخ `heartbeat` الحقول `intervalMs` و`isAck` و`message` و`timeoutMs`. ينسخ `reconnect` الحقول `attempts` و`delayMs` و`factor` و`jitter` و`maxDelayMs` و`shouldReconnect`. تبقى الكتل المتداخلة الغائبة غائبة، فلا تُشغِّل النبض أو إعادة المحاولة. يحتفظ `signal` و`beforeConnect` وكل `callback` بهويته. يمكن تمرير كائن الخيارات نفسه مرة أخرى؛ ويلتقط كل استدعاء حاوياته الخاصة. الاشتقاق لا يؤدي أي إدخال/إخراج. يعمل الـ getter على هذه الحقول الثابتة أثناء `client(options)`. إذا رمى، يخرج الاستثناء من ذلك الاستدعاء ويبقى المصنع صالحًا للاستخدام. لا يُحوَّل إلى عطل. ما زالت الأعداد الخارجة عن النطاق تُفحَص عند تشغيل العملية وتُرجع `REQ_OPTIONS_INVALID`. قيمة العميل غير قابلة للاستدعاء؛ أنشئ واحدة لكل استدعاء.

لا يُجمَع `signal`. إعادة استخدام قيمة عميل تحمل `signal` تشارك تلك الإشارة بين الاستدعاءات، لذا أنشئ قيمة عميل لكل استدعاء. اجمع الإشارات بـ `AbortSignal.any` في شيفرة التطبيق.

الإعداد الأساسي من `createClient` مشترك بين كل قيمة عميل، وهو غير مُجمَّد وقت التشغيل. هو ثابت بالاصطلاح: لا شيء في المكتبة يغيّره، ولا ينبغي للتطبيقات أن تغيّره. تنسخ المساعدات القياسية مثل `withWebSocketHeartbeat` و`withWebSocketReconnect` و`withSSEReconnect` و`withWebSocketProtocols` الـ records الثابتة الخاصة بها عند تطبيق المساعدة. يمكن لخيار عميل مخصص أن يُبقي مرجعه الخاص. يُلحِق `withInterceptors` سجل `{ kind, fn }` جديدًا لكل مدخل ويُبقي `fn` نفسه. يحمل العميل المشتق كائن [`RequestOptions`](/ar/api/core/requestoptions-type) ملتقطًا فقط عندما تُمرَّر خيارات. لا يحمل المصنع ولا `client()` ولا `client(undefined)` مثل هذا الكائن. تمرّر شيفرة التطبيق العميل إلى عملية. وهي لا تقرأ تلك الحالة الداخلية.

## خيارات الطلب

لـ [`RequestOptions`](/ar/api/core/requestoptions-type) سبعة حقول مسطحة. يقرأ كل بروتوكول الحقول التي يعرفها فقط ويتجاهل الباقي. تمرير `heartbeat` إلى عملية HTTP يُتجاهل، وليس عطلًا. يقرأ SSE من خيارات الطلب `signal` فقط. إعادة اتصال SSE تأتي من إعداد العميل (`withSSEReconnect`)، لذا `client({ reconnect })` يؤثر في WebSocket فقط. لا يوجد مرشح بروتوكول وقت الترجمة.

| الحقل                | يستخدمه              | القاعدة                                                                                                |
| -------------------- | -------------------- | ------------------------------------------------------------------------------------------------------ |
| `signal`             | HTTP وSSE وWebSocket | يُجهض الاستدعاء. المهلة هي `AbortSignal.timeout(ms)` (`NET_TIMEOUT`). الإجهاض اليدوي هو `NET_ABORTED`. |
| `onUploadProgress`   | HTTP                 | يتجاهله SSE وWebSocket.                                                                                |
| `onDownloadProgress` | HTTP                 | يتجاهله SSE وWebSocket.                                                                                |
| `beforeConnect`      | WebSocket            | يستبدل إعداد العميل لذلك الاستدعاء.                                                                    |
| `protocols`          | WebSocket            | يستبدل قائمة العميل. وهو لا يُلحَق.                                                                    |
| `heartbeat`          | WebSocket            | يُستبدل كاملًا. `timeoutMs` هو انتظار إقرار النبض، وليس مهلة للطلب.                                    |
| `reconnect`          | WebSocket            | يُستبدل كاملًا.                                                                                        |

لا يوجد حقل `timeout`، ولا حقل `abort`، ولا مهلة افتراضية على مستوى العميل. في SSE وWebSocket، يغطي `signal` الاتصال كاملًا، بما فيه ما بعد فتحه. لا توجد مهلة للبدء فقط. التطبيق الذي يريد واحدة ينشئ `AbortController` خاصًا به، ويجهضه بـ `new DOMException("...", "TimeoutError")` من مؤقت، ويمسح المؤقت بعد أن يُرجع `await`. انظر [SSE](/ar/docs/sse#close-and-dispose).

`HttpExecuteOptions` هو شريحة HTTP: `signal` مع ردود نداء التقدّم. `EventStreamExecuteOptions` هو `{ signal? }`. `WebSocketExecuteOptions` هو شريحة WebSocket مع `signal`.

## النتائج حسب وسيلة النقل

- HTTP → `[error, data, response]`
- SSE → `[error, stream, open]`. `open` هو لقطة أول مصافحة ناجحة للاتصال المُرجَع لمقابض Defjs الأصلية أو الأغلفة التي تمرّر كائن `open` الحي نفسه؛ وتستخدم المقابض المخصصة أو الأغلفة التي تغلّب `open` قيمة `open` العامة الحالية حتى بعد إعادة الاتصال، بينما يبقى `stream.open` حيًا (انظر [SSE](/ar/docs/sse)).
- WebSocket → `[error, session, connection]`

عُد قبل استخدام قيمة النجاح عندما تكون `error` مضبوطة.

أنت تملك التنظيف: أجهض HTTP، وأغلق SSE + `await stream.closed`، وأغلق WebSocket + `await session.closed`.

## النطاق على الخادم مقابل المتصفح

على الخادم، أنشئ العميل داخل حدود الطلب عندما تلتقط الخيارات أو إغلاقات المعترضات المصادقة أو ملفات تعريف الارتباط أو المستخدمين أو المستأجرين. هوية العميل ليست حد أمان بذاتها.

## مرجع

| المساعد                                                                                                       | الأثر                                                         |
| ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `withEndpoint(url)`                                                                                           | نقطة نهاية أساسية مطلقة لكل وسائل النقل                       |
| `withHeaders(HeadersInit)`                                                                                    | رؤوس افتراضية ثابتة لـ HTTP/SSE؛ رؤوس الـ builder تغلّبها     |
| `withHTTPHandle(fetch)`                                                                                       | استبدل Fetch لـ HTTP                                          |
| `withSSEHandle(fetch)`                                                                                        | استبدل Fetch لـ SSE                                           |
| `withWebSocketHandle(WebSocket)`                                                                              | استبدل منشئ WebSocket                                         |
| `withInterceptors(...items)`                                                                                  | ألحق معترضات مختلطة                                           |
| `withQuerySerializer(fn)`                                                                                     | رمّز كائن استعلام مُسمّى أصلًا إلى سلسلة استعلام              |
| `withCredentials(boolean)`                                                                                    | `credentials: 'include'` في Fetch لـ HTTP/SSE عندما تكون true |
| `withXSRF(options?)`                                                                                          | ملف تعريف ارتباط XSRF في HTTP → رأس                           |
| `withSSEReconnect` / `withSSEOnInvalidEvent`                                                                  | مقابض SSE                                                     |
| `withWebSocketReconnect` / `withWebSocketHeartbeat` / `withWebSocketProtocols` / `withWebSocketBeforeConnect` | مقابض WebSocket                                               |
