## أنشئ العميل مرة واحدة عند الحد [#client-boundary]

أنشئ العميل حيث يقرأ التطبيق إعداده: نقطة دخول خادم، أو وحدة تملك النشر، أو إعداد اختبار. ومرّر ذلك العميل إلى الشيفرة التي تستدعي العمليات.

```ts
const client = createClient(
  withEndpoint("https://api.example.com"),
  withInterceptors(auth),
);
```

تجنّب عميلًا على مستوى وحدة داخل SDK أو جسم مكوّن أو معالِج طلب. فالعميل المنشأ لكل عرض أو لكل طلب يفقد الإعداد المشترك ويجعل الاختبارات تعتمد على حالة محيطة.

## ضع السياسة العابرة للطبقات في المعترضات [#interceptors]

تنتمي المصادقة والتتبع وافتراضيات الرؤوس وسياسة إعادة المحاولة المُراجَعة إلى معترض. فالـ `builder` يضع المدخل الحالي؛ وهو لا يعرف بيانات الاعتماد ولا القياس عن بُعد للتطبيق.

```ts
const auth = createHttpInterceptor(async (request, next) => {
  const response = await next(request);
  return response;
});
```

## استخدم خيارات العميل لاستدعاء واحد [#per-call]

`client(options)` يُرجع قيمة عميل لاستدعاء واحد. والقيمة غير قابلة للاستدعاء. استخدمها لإشارة أو لردود نداء التقدّم أو لخطاف WebSocket ينطبق على ذلك الاستدعاء فقط؛ وأبقِ العميل الأساسي لكل ما عدا ذلك.

```ts
const [error, order] = await getOrder(
  client({ signal: AbortSignal.timeout(5_000) }),
  { id: 1 },
);
```

## دع إضافات الأطر تمرّر العميل [#plugins]

تمرّر `@defjs/react` و`@defjs/vue` عميل التطبيق عبر شجرة الإطار. وهي لا تنشئ عميلًا ولا تخزّنه مؤقتًا ولا تعيد محاولته ولا تتخلص منه. قدّم العميل الذي يملكه التطبيق أصلًا، واحقن القيمة نفسها حيث تلزم.

```tsx
<ClientProvider client={client}>
  <Orders />
</ClientProvider>
```

## أبقِ نقطة النهاية خارج SDK [#endpoint]

يمكن للتعريف نفسه أن يعمل على الإنتاج أو بيئة الاختبار أو تركيبة محلية أو وسيلة نقل للاختبار. اختر نقطة النهاية في التطبيق؛ ولا تُضمّن مضيف نشر في حزمة SDK.
