# Defjs

**حزمة TypeScript SDK والعميل المرن — عرّف عقد واجهة برمجة التطبيقات (API) مرة واحدة. واضبط التنفيذ لكل تطبيق على حدة.**

يفصل Defjs بين شقين أساسيين في حزم TypeScript SDK:

- **تعريف SDK (`@defjs/core`، `@defjs/cli`)** — أعلن عن عمليات HTTP وSSE وWebSocket محددة الأنواع مع مخططات `struct` (مكتوبة يدوياً أو مولَّدة كوحدات ESM عديمة الحالة من مواصفات OpenAPI 2.0/3.0/3.1/3.2). التعريف بيانات خالصة: استيراده لا يطلق أي اتصال شبكي ولا يربط عميلاً عاماً.
- **تنفيذ تطبيقي مرن (`@defjs/core`)** — تنشئ التطبيقات عميلها الخاص `Client` عبر `createClient(withEndpoint(...))`، وتربط بيانات الاعتماد والمعترضات (`basicAuth*`، `idempotencyKeyHttpInterceptor`، `concurrencyLimitHttpInterceptor`)، وتضبط موازنة الحمل P2C وكشف القيم الشاذة `outlierDetection` (`halfOpen`، `maxEjectionPercent`)، وتفعّل إعادة المحاولة لحالات `429`/`Retry-After`، وتوزّع الاستدعاءات المتوازية عبر `@defjs/core/concurrent`، أو تمد جسور التواصل مع الـ workers والملحقات عبر `@defjs/core/port`.

## لماذا نفصل بين التعريفات والعملاء؟

| المسؤولية    | مؤلف حزمة SDK (التعريف)                                                                                               | التطبيق المستهلك (التنفيذ)                                                                                    |
| ------------ | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **المِلكية** | طريقة الطلب، وقالب المسار، ومخططات `input` و`output` و`error`، ودالة `builder`، و`meta` الاختياري الذي يعرّفه التطبيق | العناوين الأساسية، وبيانات الاعتماد، ومعترضات المصادقة، وتوزيع الحمل، والمهل الزمنية، وتنظيف الموارد وإغلاقها |
| **ما يُشحن** | وحدات ESM وتصريحات الأنواع `.d.ts` قابلة لإعادة الاستخدام كلياً                                                       | إعدادات وقت التشغيل للمتصفح أو الخادم أو بيئة الاختبار                                                        |
| **الفائدة**  | استقلالية كاملة عن البيئة؛ تعمل بسلاسة في المتصفح وبيئات المعالجة من الخادم (SSR) والاختبارات                         | تحكم شامل في سياسات إعادة المحاولة، والتبديل عند الفشل، والقياسات عن بُعد، ودورات حياة الاتصال                |

## اختر مسارك

1. **[البدء السريع](/ar/docs/start)** — عرّف عملية، واختبرها محلياً دون شبكة باستخدام مقبض Fetch محلي، ثم وجّه عميلاً نحو خدمة حية.
2. **[معمارية النواة](/ar/docs/design-decisions)** — تعرّف على قواعد فك ترميز الاستجابة الست، ومصفوفات الخطأ أولاً (error-first tuples)، وملكية الموارد.
3. **[المقارنة ومعمارية BFF الهجينة](/ar/docs/comparison-and-architecture)** — قارن Defjs مع `fetch` و`ky` و`ofetch` و`openapi-fetch` و`oRPC`، واطّلع على مخطط BFF الهجين بـ Defjs + oRPC/Hono والاختبارات القياسية.
4. **[تعريف حزم SDK](/ar/docs/struct)** — أعلن عن عقود البيانات السلكية عبر [Struct](/ar/docs/struct) وصدّر عمليات [HTTP](/ar/docs/http) و[SSE](/ar/docs/sse) و[WebSocket](/ar/docs/web-socket).
5. **[العميل وتنفيذ الطلبات](/ar/docs/client)** — اضبط [العملاء](/ar/docs/client)، وتعامل مع [الأخطاء](/ar/docs/errors) محددة الأنواع، وأرفق [المعترضات](/ar/docs/interceptors)، واضبط [توزيع الحمل والتبديل عند الفشل](/ar/docs/load-balancing).
6. **[أفضل الممارسات والاختبارات](/ar/docs/best-practices)** — اتبع [الاتفاقيات الهندسية](/ar/docs/best-practices)، ونظّم [طبقة API للتطبيق](/ar/docs/application-api) أو [تصميم حزمة SDK عامة](/ar/docs/public-sdk)، واكتب [اختبارات](/ar/docs/testing) قطعية وسريعة.

## وسائل النقل المدعومة ومصفوفات النتائج

تُرجع كل عملية مصفوفة من ثلاثة عناصر يكون الخطأ في أولها ومصمَّمة لتناسب دورة حياة وسيلة النقل الخاصة بها:

| وسيلة النقل                          | نقطة الإدخال        | شكل المصفوفة                 | مِلكية دورة الحياة                                                              |
| ------------------------------------ | ------------------- | ---------------------------- | ------------------------------------------------------------------------------- |
| **[HTTP](/ar/docs/http)**            | `defineRequest`     | `[err, data, response]`      | إلغاء الطلبات الجارية عبر `client({ signal })`                                  |
| **[SSE](/ar/docs/sse)**              | `defineEventStream` | `[err, stream, open]`        | التحرير عبر `await using` أو `stream.close()` متبوعة بـ `await stream.closed`   |
| **[WebSocket](/ar/docs/web-socket)** | `defineWebSocket`   | `[err, session, connection]` | التحرير عبر `await using` أو `session.close()` متبوعة بـ `await session.closed` |

عند حدوث خطأ في طلب HTTP، يكون شكل المصفوفة `[err, undefined, undefined]` لأن كائن `err` يحمل بالفعل بيانات الاستجابة الوصفية `HttpMeta`. أما في حالتي SSE وWebSocket، فيحمل الموضع الثالث لقطة لحظة الاتصال متى ما تم التقاطها قبل حدوث الفشل.

| ----------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `@defjs/core`                 | تعريفات SDK خالية من الاعتماديات، و`struct`، والعميل، والمرونة، والبرمجيات الوسيطة، و`concurrent` و`port` | [البدء السريع](/ar/docs/start)                                   |
| `@defjs/cli`                  | أداة سطر أوامر للتطوير تولّد تعريفات ESM عديمة الحالة من مواصفات OpenAPI 2.0–3.2                          | [تكامل CLI](/ar/docs/integrations/cli)                           |
| `@defjs/react`                | سياق العميل `ClientProvider` وحقنه عبر `useClient()` لتطبيقات React 18+                                   | [تكامل React](/ar/docs/integrations/react)                       |
| `@defjs/vue`                  | إضافة `createClientPlugin` ورمز الحقن `HTTP_CLIENT` و`injectClient()` لتطبيقات Vue 3 أو أحدث              | [تكامل Vue](/ar/docs/integrations/vue)                           |
| `@defjs/opentelemetry-server` | تتبع الطلبات الصادرة من الخادم وتوليد القياسات وسجلات التشخيص                                             | [خادم OpenTelemetry](/ar/docs/integrations/opentelemetry-server) |
