# Defjs

**عرّف عقد واجهة برمجة التطبيقات (API) مرة واحدة. واضبط التنفيذ لكل تطبيق على حدة.**

يفصل Defjs بين شقين أساسيين في حزم TypeScript SDK:

- **تعريف SDK (`@defjs/core`)** — يصرّح مؤلفو حزمة SDK عن عمليات HTTP وSSE وWebSocket محددة الأنواع جنباً إلى جنب مع مخططات `struct`. التعريف هنا عبارة عن بيانات خالصة: استيراده لا يُطلق أي طلب عبر الشبكة ولا يربط أي عميل عام.
- **تنفيذ التطبيق** — تنشئ التطبيقات المستهلكة عميلها الخاص `Client` عبر `createClient(withEndpoint(...))`، وتربط بيانات الاعتماد والمعترضات (Interceptors) وموازنات الحمل، ثم تمرّر هذا العميل عند استدعاء أي عملية.

## لماذا نفصل بين التعريفات والعملاء؟

| المسؤولية    | مؤلف حزمة SDK (التعريف)                                                                                           | التطبيق المستهلك (التنفيذ)                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **المِلكية** | طريقة الطلب، وقالب المسار، ومخططات `input` و`output` و`error`، ودالة `builder`، والاسم الثابت للعملية `operation` | العناوين الأساسية، وبيانات الاعتماد، ومعترضات المصادقة، وتوزيع الحمل، والمهل الزمنية، وتنظيف الموارد وإغلاقها |
| **ما يُشحن** | وحدات ESM وتصريحات الأنواع `.d.ts` قابلة لإعادة الاستخدام كلياً                                                   | إعدادات وقت التشغيل للمتصفح أو الخادم أو بيئة الاختبار                                                        |
| **الفائدة**  | استقلالية كاملة عن البيئة؛ تعمل بسلاسة في المتصفح وبيئات المعالجة من الخادم (SSR) والاختبارات                     | تحكم شامل في سياسات إعادة المحاولة، والتبديل عند الفشل، والقياسات عن بُعد، ودورات حياة الاتصال                |

## اختر مسارك

1. **[البدء السريع](/ar/docs/start)** — عرّف عملية، واختبرها محلياً دون شبكة باستخدام مقبض Fetch محلي، ثم وجّهها نحو خدمة حية.
2. **[معمارية النواة](/ar/docs/design-decisions)** — تعرّف على قواعد فك ترميز الاستجابة الست، ومصفوفات الخطأ أولاً (error-first tuples)، وملكية الموارد.
3. **[تعريف حزم SDK](/ar/docs/struct)** — أعلن عن عقود البيانات السلكية عبر [Struct](/ar/docs/struct) وصدّر عمليات [HTTP](/ar/docs/http) و[SSE](/ar/docs/sse) و[WebSocket](/ar/docs/web-socket).
4. **[العميل وتنفيذ الطلبات](/ar/docs/client)** — اضبط [العملاء](/ar/docs/client)، وتعامل مع [الأخطاء](/ar/docs/errors) محددة الأنواع، وأرفق [المعترضات (Interceptors)](/ar/docs/interceptors)، واضبط [توزيع الحمل والتبديل عند الفشل](/ar/docs/load-balancing)، ونفّذ [اختبارات](/ar/docs/testing) قطعية وسريعة.

## وسائل النقل المدعومة ومصفوفات النتائج

تُرجع كل عملية مصفوفة من ثلاثة عناصر يكون الخطأ في أولها ومصمَّمة لتناسب دورة حياة وسيلة النقل الخاصة بها:

| وسيلة النقل                          | نقطة الإدخال        | شكل المصفوفة                   | مِلكية دورة الحياة                                                              |
| ------------------------------------ | ------------------- | ------------------------------ | ------------------------------------------------------------------------------- |
| **[HTTP](/ar/docs/http)**            | `defineRequest`     | `[error, data, response]`      | إلغاء الطلبات الجارية عبر `client({ signal })`                                  |
| **[SSE](/ar/docs/sse)**              | `defineEventStream` | `[error, stream, open]`        | التحرير عبر `await using` أو `stream.close()` متبوعة بـ `await stream.closed`   |
| **[WebSocket](/ar/docs/web-socket)** | `defineWebSocket`   | `[error, session, connection]` | التحرير عبر `await using` أو `session.close()` متبوعة بـ `await session.closed` |

عند حدوث خطأ في طلب HTTP، يكون شكل المصفوفة `[error, undefined, undefined]` لأن كائن `error` يحمل بالفعل بيانات الاستجابة الوصفية `HttpMeta`. أما في حالتي SSE وWebSocket، فيحمل الموضع الثالث لقطة لحظة الاتصال متى ما تم التقاطها قبل حدوث الفشل.

| ----------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `@defjs/core`                 | تعريفات حزم SDK خالية من الاعتماديات الخارجية، مع `struct` والعميل والوسائط             | [البدء السريع](/ar/docs/start)                                   |
| `@defjs/react`                | سياق العميل `ClientProvider` وحقنه عبر `useClient()` لتطبيقات React 18+                 | [تكامل React](/ar/docs/integrations/react)                       |

| `@defjs/opentelemetry-server` | تتبع الطلبات الصادرة من الخادم وتوليد القياسات وسجلات التشخيص                           | [خادم OpenTelemetry](/ar/docs/integrations/opentelemetry-server) |
