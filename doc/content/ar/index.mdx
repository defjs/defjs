# مصمّم لبناء SDK أفضل [#defjs]

**Defjs = define js.** عبّر عن API بتعريفات JavaScript / TypeScript لتسهيل تصميم SDK وكتابته ونشره.

يصدّر مؤلف SDK واجهات API محدَّدة الأنواع وقابلة لإعادة الاستخدام عبر `defineRequest` و`defineEventStream` و`defineWebSocket`. تحدّد Struct عقود البيانات للمدخلات والمخرجات والأخطاء، ويضع `builder` المدخلات في الطلب. يستورد التطبيق المستهلك هذه التعريفات وينفّذها عبر Defjs Client يضبطه بنفسه.

| المسؤولية            | مؤلف SDK                                        | التطبيق المستهلك                                                    |
| -------------------- | ----------------------------------------------- | ------------------------------------------------------------------- |
| عقد API              | يعرّف الطريقة والمسار النسبي وStruct و`builder` | ينشئ الأوامر من التعريفات المنشورة                                  |
| بيئة التنفيذ         | يصدّر تعريفات قابلة لإعادة الاستخدام            | يضبط عنوان الخدمة والمصادقة والمعترضات ووسيلة النقل المناسبة للمنصة |
| النتائج ودورة الحياة | يعلن النجاح والأخطاء والأحداث محدَّدة الأنواع   | يعالج نتيجة `execute` ويتولى الإلغاء وإغلاق التدفقات                |
| التوزيع              | ينشر التعريفات وتصريحات الأنواع في حزمة         | يثبّت SDK وإصدارًا متوافقًا من `@defjs/core`                        |

## انشر التعريف ونفّذه في التطبيق

يصدّر ملف SDK المسمى `get-health.ts` تعريفًا دون عنوان خدمة أو بيانات اعتماد.

<include cwd meta="get-health.ts">
  examples/home/get-health.ts#example
</include>

يستورد ملف التطبيق `app.ts` التعريف وينشئ عميلًا يناسب بيئة التنفيذ.

<include cwd meta="app.ts">
  examples/home/app.ts#example
</include>

احفظ الملفين في المجلد نفسه. بعد نشر SDK كحزمة، استبدل الاستيراد النسبي في التطبيق باسم الحزمة. إعادة الاستخدام هنا تقوم على تعريفات Defjs وعقد تنفيذها؛ يمكن لكل تطبيق ضبط Client مستقل مع استخدام تعريف API نفسه.

## الممارسة الموصى بها

يبقى التعريف مستقلاً عن العميل. استدعاؤه ينشئ command فقط. امنح هذا command اسمًا، ثم مرّره إلى `client.execute` على العميل الذي يملكه التطبيق. يملك التطبيق أيضًا عنوان الخدمة وبيانات الاعتماد. افحص صف error-first أولًا. عندما تكون `error` موجودة، أبلغ `error.code` وعُد من الدالة قبل قراءة قيمة النجاح.

شغّل هذا المسار المكوّن من ملفين في [البدء السريع](/ar/docs/start)، ثم تعلّم بنية الحزمة وتوزيعها في [بناء SDK ونشره](/ar/recipes/publish-http-sdk). يشرح دليل [قرارات التصميم](/ar/docs/design-decisions) أسباب هذا الفصل.

لا يضيف Defjs تخزينًا مؤقتًا للنتائج أو إعادة محاولة تلقائية، ولا يغلق التدفقات التي يملكها التطبيق تلقائيًا.

## اختر وسيلة النقل

| ما تحتاجه                    | ابدأ من                          | النتيجة عند النجاح                                                           |
| ---------------------------- | -------------------------------- | ---------------------------------------------------------------------------- |
| طلب + استجابة حسب الحالة     | [HTTP](/ar/docs/http)            | بيانات مفكوكة + `DecodedResponse`، أو `HttpMeta` عندما لا يُعلَن struct مخرج |
| تغذية أحداث خادم طويلة العمر | [SSE](/ar/docs/sse)              | تدفق واحد + لقطة `open` عند البدء                                            |
| جلسة ثنائية الاتجاه          | [WebSocket](/ar/docs/web-socket) | جلسة واحدة + لقطة `connection` عند البدء                                     |

## اختر الحزمة

| الحزمة                        | متى                                                                                                  |
| ----------------------------- | ---------------------------------------------------------------------------------------------------- |
| `@defjs/core`                 | تعريفات API وStruct و`createClient` (HTTP + SSE + WebSocket)                                         |
| `@defjs/react`                | `ClientProvider` / `useClient` — انظر [React](/ar/docs/integrations/react)                           |
| `@defjs/vue`                  | إضافة + `injectClient` — انظر [Vue](/ar/docs/integrations/vue)                                       |
| `@defjs/opentelemetry-server` | spans ومقاييس وسجلات صادرة — انظر [OpenTelemetry Server](/ar/docs/integrations/opentelemetry-server) |

## أشكال النتيجة

وسائل النقل الثلاث تُرجع tuple من ثلاثة عناصر يضع الخطأ أولاً. المواضع متطابقة؛ المعاني ليست كذلك:

- HTTP → `[error, data, response]`
- SSE → `[error, stream, open]`
- WebSocket → `[error, session, connection]`

عند الفشل يكون العنصر الثاني `undefined`. وفي HTTP يكون العنصر الثالث `undefined` أيضًا لأن الـ fault يحمل بيانات الاستجابة الوصفية. أما في SSE وWebSocket فالعنصر الثالث هو لقطة البدء إن التُقطت قبل الفشل. انظر [الأخطاء](/ar/docs/errors).

## الملكية بجملة واحدة

أجهض HTTP عندما يصبح قديماً. أغلق SSE و`await stream.closed`. أغلق WebSocket و`await session.closed`. على الخادم، أنشئ العميل داخل حدود الطلب عندما تلتقط الخيارات ملفات تعريف الارتباط أو المصادقة أو بيانات المستأجر. احجب عناوين URL والرؤوس والأجسام قبل تسجيلها.
