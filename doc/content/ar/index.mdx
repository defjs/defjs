# Defjs

**مصمّم لبناء SDK أفضل.**

يساعد Defjs الفرق على تحويل واجهاتها إلى حزم TypeScript SDK قابلة لإعادة الاستخدام. `def` تعني `define`: صف العمليات التي تقدّمها خدمتك، وصدّرها من وحدة أو حزمة npm، ودع كل تطبيق يضبط عميله الخاص لاستدعائها.

## عرّف SDK، واضبط التطبيق

| مؤلف SDK                                               | مستهلك SDK                                                  |
| ------------------------------------------------------ | ----------------------------------------------------------- |
| يعرّف العمليات والمدخل وربط الطلب والاستجابات والأخطاء | يختار عنوان الخدمة وبيانات الاعتماد والمعترضات ووسيلة النقل |
| يصدّر نقاط نهاية HTTP وSSE وWebSocket محدَّدة الأنواع  | يستورد تلك النقاط ويستدعيها بعميل Defjs                     |
| يصون عقد API وينشره                                    | يعالج النتائج ويملك الإلغاء والتدفقات والجلسات              |

تعريف SDK لا يلتقط عميل تطبيق. نقطة النهاية المصدَّرة نفسها يمكن أن تخدم تطبيق متصفح أو خادمًا أو اختبارًا محليًا بإعدادات عميل مختلفة. ويظل الطرفان يستخدمان عقد تنفيذ Defjs وإصدارات Core المتوافقة.

يصدّر SDK عملية:

<include cwd meta="get-health.ts">
  examples/home/get-health.ts#example
</include>

يستوردها التطبيق ويملك التنفيذ:

<include cwd meta="app.ts">
  examples/home/app.ts#example
</include>

استدعاء `getHealth(client)` يبدأ الطلب. عند نشر التعريف، يستورده المستهلكون من حزمة SDK بدل الملف المحلي.

## الممارسة الموصى بها

يبقى التعريف مستقلاً عن العميل. مرّر عميل التطبيق وسيطًا أول، كما في `getHealth(client)`. يملك التطبيق أيضًا عنوان الخدمة وبيانات الاعتماد. افحص صف error-first أولًا. عندما تكون `error` موجودة، أبلغ `error.code` وعُد من الدالة قبل قراءة قيمة النجاح.

## ابنِ SDK

1. [عرّف أول عملية وشغّلها](/ar/docs/start) في ملفين منفصلين لـ SDK والتطبيق.
2. صف [عقود البيانات](/ar/docs/struct) و[عمليات HTTP](/ar/docs/http) التي يصدّرها SDK.
3. [اختبر وانشر حزمة SDK](/ar/recipes/publish-http-sdk) مع JavaScript والتصريحات واعتمادية Core متوافقة.
4. اضبط [العميل](/ar/docs/client) في التطبيق المستهلك، ثم أضف تكامل إطار أو مراقبة حيث يلزم.

تشرح [قرارات التصميم](/ar/docs/design-decisions) لماذا لتعريفات API والتنفيذ مالكان منفصلان. يمكنك استخدام البنية نفسها داخل تطبيق واحد قبل نشر حزمة.

## اختر وسيلة النقل

| ما تحتاجه                    | ابدأ من                          | النتيجة عند النجاح                                                  |
| ---------------------------- | -------------------------------- | ------------------------------------------------------------------- |
| طلب + استجابة حسب الحالة     | [HTTP](/ar/docs/http)            | بيانات مفكوكة + `DecodedResponse` (`HttpMeta` عندما لا يُعلَن مخرج) |
| تغذية أحداث خادم طويلة العمر | [SSE](/ar/docs/sse)              | تدفق واحد + لقطة `open` عند البدء                                   |
| جلسة ثنائية الاتجاه          | [WebSocket](/ar/docs/web-socket) | جلسة واحدة + لقطة `connection` عند البدء                            |

وسائل النقل الثلاث تتبع التسلسل نفسه: عرّف عملية، ثم استدعها بعميل التطبيق ومدخل المستدعي.

## اختر الحزمة

| الحزمة                        | متى                                                                                                  |
| ----------------------------- | ---------------------------------------------------------------------------------------------------- |
| `@defjs/core`                 | عرّف عمليات SDK وعقودها؛ أنشئ العملاء واستدعِ عمليات HTTP وSSE وWebSocket                            |
| `@defjs/react`                | `ClientProvider` / `useClient` — انظر [React](/ar/docs/integrations/react)                           |
| `@defjs/vue`                  | إضافة + `injectClient` — انظر [Vue](/ar/docs/integrations/vue)                                       |
| `@defjs/opentelemetry-server` | spans ومقاييس وسجلات صادرة — انظر [OpenTelemetry Server](/ar/docs/integrations/opentelemetry-server) |

## أشكال النتيجة

وسائل النقل الثلاث تُرجع tuple من ثلاثة عناصر يضع الخطأ أولًا. المواضع متطابقة؛ المعاني ليست كذلك:

- HTTP → `[error, data, response]`
- SSE → `[error, stream, open]`
- WebSocket → `[error, session, connection]`

عند الفشل يكون العنصر الثاني `undefined`. وفي HTTP يكون العنصر الثالث `undefined` أيضًا لأن الـ fault يحمل بيانات الاستجابة الوصفية. أما في SSE وWebSocket فالعنصر الثالث هو لقطة البدء إن التُقطت قبل الفشل. انظر [الأخطاء](/ar/docs/errors).

## الملكية بجملة واحدة

أجهض HTTP عندما يصبح قديمًا. أغلق SSE و`await stream.closed`. أغلق WebSocket و`await session.closed`. على الخادم، أنشئ العميل داخل حدود الطلب عندما تلتقط الخيارات ملفات تعريف الارتباط أو المصادقة أو بيانات المستأجر. احجب عناوين URL والرؤوس والأجسام قبل تسجيلها.

يوفر Defjs التعريفات والتحقق والتنفيذ. تختار التطبيقات سياسات التخزين المؤقت وإعادة المحاولة؛ وإعادة اتصال التدفق اختيارية. حزم SDK المكتوبة يدويًا مدعومة اليوم. تبقى أدوات CLI وتوليد OpenAPI/SDK مخططًا لها.
