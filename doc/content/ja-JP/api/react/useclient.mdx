<ApiReference identity="@defjs/react:useClient" />

```ts
function useClient(): Client
```

一番近い `ClientProvider` からクライアントを読みます。

- **戻り値** 渡されたクライアントです。
- **例外** `ClientProvider` の外で呼ぶと `Error` を throw します。
