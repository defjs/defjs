# API リファレンス

<ApiIndex />

ワークスペースパッケージの参照です。シグネチャが契約で、いつ使うかはガイドとレシピが説明します。

## 定義と実行の入口

| 目的                       | 参照先                                                                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| SDK の API 定義を作る      | [HTTP](/ja-JP/api/http) の `defineRequest`、[SSE](/ja-JP/api/sse) の `defineEventStream`、[WebSocket](/ja-JP/api/web-socket) の `defineWebSocket` |
| データ契約と型を作る       | [Struct](/ja-JP/api/struct) の `struct.*` と `Infer`                                                                                              |
| アプリケーションで実行する | [Client](/ja-JP/api/client) の `createClient`、`with*`、`Client.execute`                                                                          |
| 実行結果と方針を扱う       | [Errors](/ja-JP/api/errors)、[Interceptors](/ja-JP/api/interceptors)、各トランスポートの handle / session                                         |

SDK の作成者は定義を export します。利用アプリケーションは互換性のある Defjs Client を構成し、結果、キャンセル、ストリームのライフサイクルを管理します。実装から配布までの流れは [クイックスタート](/ja-JP/docs/start) と [SDK の作成と公開](/ja-JP/recipes/publish-http-sdk) を参照してください。
