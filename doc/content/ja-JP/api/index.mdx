# API リファレンス

<ApiIndex />

Defjs SDK を作るとき、または使うときにこのリファレンスを引いてください。SDK の作成者は [`defineRequest`](/ja-JP/api/core/definerequest)、[`defineEventStream`](/ja-JP/api/core/defineeventstream)、[`defineWebSocket`](/ja-JP/api/core/definewebsocket)、[Struct](/ja-JP/api/struct) から始めます。アプリケーションは [Client 設定](/ja-JP/api/client) でそれらの操作を呼び、[Errors](/ja-JP/api/errors) で結果を扱います。

シグネチャが契約です。一連の流れは [クイックスタート](/ja-JP/docs/start) と [SDK の作成と公開](/ja-JP/recipes/publish-http-sdk) に従ってください。

## パッケージ

| パッケージ                                                       | ここで探すもの                                                    |
| ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| [`@defjs/core`](/ja-JP/api/client)                               | `createClient`, `defineRequest`, `struct`, HTTP / SSE / WebSocket |
| [`@defjs/vue`](/ja-JP/api/vue)                                   | `createClientPlugin`, `injectClient`, `HTTP_CLIENT`               |
| [`@defjs/react`](/ja-JP/api/react)                               | `ClientProvider`, `useClient`                                     |
| [`@defjs/opentelemetry-server`](/ja-JP/api/opentelemetry-server) | `withOpenTelemetryServer`, トランスポートごとのオプション         |
