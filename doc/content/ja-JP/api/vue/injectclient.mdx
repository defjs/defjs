<ApiReference identity="@defjs/vue:injectClient" />

```ts
function injectClient(): Client
```

一番近い `HTTP_CLIENT` provider を読みます。Vue の `inject` が使える `setup()` のような場所で呼んでください。

- **戻り値** 注入されたクライアントです。
- **例外** クライアントが提供されていないとき（たとえばプラグインが入っていないとき）に `Error` を throw します。
