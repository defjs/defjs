<ApiReference identity="@defjs/core:struct.intersection" />

```ts
function intersection<const T extends readonly [StructLike, ...StructLike[]]>(...structs: T): IntersectionStruct<T>
```

`struct.intersection` は可変長引数です。各 struct を個別の引数として渡します。

- 入力をすべての struct でパースし、結果をマージします。
- すべてがオブジェクト struct の場合、出力はそれらすべてのフィールドを持つ 1 つのオブジェクトになります。どれも宣言していないキーは取り除かれます。
- 2 つの struct が同じキーに対して互換性のない値を生成した場合は、`invalid_intersection` で失敗します。
- struct が 1 つだけの場合は、そのまま返されます。struct を渡さずに呼ぶと `TypeError` を投げ、struct でない引数でも同様です。

`IntersectionStruct<T>` はエクスポートされません。入力と出力が、各メンバー型の交差になる `Struct` です。
