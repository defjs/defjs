description: '未知の値を struct でパースし、エラーを先頭に置くタプルを返します。'
---

<ApiReference identity="@defjs/core:struct.parse" />

```ts
function parse<S extends StructLike<unknown, unknown, boolean>>(
  struct: S,
  value: unknown,
  options?: { aliases?: boolean; errorMap?: ErrorMap },
): ParseResult<S['_struct']['output']>
```

- **struct** はパースに使う struct です。struct ではない値を渡すと `TypeError` を投げます。
- **value** は未知の入力です。
- **options.aliases** のデフォルトは `false` で、オブジェクトのキーは**論理**名（`displayName`）で読まれます。`true` にすると、HTTP/JSON コーデックと同じようにワイヤ名（`display_name`）で読まれます。出力は常に論理名を使います。
- **options.errorMap** は、この呼び出しだけの issue メッセージを書き換える [`ErrorMap`](/ja-JP/api/core/errormap-type) です。別の Core コピーで作られた struct の bigint/date 変換失敗にも適用されます。`''` を含む任意の文字列でメッセージを置き換え、`undefined` の場合だけデフォルトを維持します。カスタムテキストはそのまま使われます。
- **戻り値** は `[null, output]` または `[StructError, undefined]` です。検証の失敗では例外を投げません。呼び出し側が提供するゲッターや `errorMap` コールバックからの例外は、そのまま伝播します。
- パースは fail-fast です。最初の失敗で止まるため、エラーが持つ issue は 1 つです。未知のオブジェクトキーは出力から取り除かれ、入力は変更されません。
- 各パスでは、ルートコンテナーを 1 階層目として、最大 **256 階層のコンテナー**（`object`、`array`、`record`、`tuple`）までたどります。次のコンテナーは、その論理パスで `invalid_type` により失敗し、`expected: 'value nested at most 256 levels deep'` となります。ユニオンでは後続の候補が成功することもあります。どの候補も一致しなければ、ユニオンは `invalid_union` を報告します。宣言されたコンテナーフィールドを通る循環もこの上限に達しますが、循環しない子ノードの共有は許可されます。ユニオンと交差の分岐はコンテナーの階層を増やさず、`any`/`unknown` の値は内部をたどらず、不透明な値として扱います。

```ts
const [error, user] = struct.parse(User, { id: 1, displayName: 'Ada' })
if (error) return console.error(error.prettify())
```

`any` と `unknown` は値の内部をたどりませんが、交差では、これらの葉ノードが返した異なる 2 つのオブジェクト値または配列値を再帰的にマージする場合があります。このマージは、外側の論理パスと合計 256 コンテナーという同じ上限を共有します。上限を超えると、拒否されたコンテナーの論理パスで `invalid_intersection` が発生します。同一の参照は内部をたどらずに保持されます。共有されている値が循環を含む場合も同様です。

[`ParseResult`](/ja-JP/api/core/parseresult-type) と [`StructError`](/ja-JP/api/core/structerror-type) を参照してください。
