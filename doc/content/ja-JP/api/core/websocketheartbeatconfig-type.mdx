<ApiReference identity="@defjs/core:WebSocketHeartbeatConfig" />

```ts
interface WebSocketHeartbeatConfig<TIncoming = unknown, TOutgoing = unknown> {
  intervalMs: number
  isAck?: (message: TIncoming) => boolean
  message?: () => TOutgoing
  timeoutMs?: number
}
```

- `intervalMs` はハートビートメッセージの間隔です。
- `message()` はペイロードを作ります。`outgoing` struct を通して送られます。省略した場合や `undefined` を返す場合は何も送りません。
- struct によるエンコード後、JSON で表現できない値は `session.send` と同じシリアライザーで `TypeError` になります。このハートビートの失敗は、再接続せずに論理セッションを終了させます。
- `isAck(message)` はデコードされた受信メッセージごとに呼ばれます。`true` を返すと、そのメッセージは確認応答として扱われ、`receive` には渡されません。
- `timeoutMs` はハートビートのあと、確認応答を待つ時間です。間に合わないとセッションは失敗します。
- `intervalMs` と `timeoutMs` は、正の有限な値で、`2_147_483_647` 以下でなければなりません。

[`withWebSocketHeartbeat`](/ja-JP/api/core/withwebsocketheartbeat) か、execute の `heartbeat` option で設定します。
