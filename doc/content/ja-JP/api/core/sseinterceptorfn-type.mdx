<ApiReference identity="@defjs/core:SSEInterceptorFn" />

```ts
type SSEInterceptorFn = (req: HttpRequest, next: SSEHandler) => Promise<EventStreamHandle<unknown>>
```

`req` を確認または置き換えたうえで、[`next`](/ja-JP/api/core/ssehandler-type) を呼んでチェーンを続けるか、独自の `EventStreamHandle` を返してショートサーキットします。`withInterceptors` で登録するには、`createSSEInterceptor(fn)` で包みます。

ショートサーキットするハンドルは、`[Symbol.asyncDispose](): PromiseLike<void>` を提供し、同じ close ライフサイクルへ繋ぐ必要があります。
