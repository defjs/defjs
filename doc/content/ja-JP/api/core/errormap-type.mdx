<ApiReference identity="@defjs/core:ErrorMap" />

```ts
type ErrorMap = (issue: StructIssue) => string | undefined
```

`struct.parse` の `errorMap` オプションとして渡します。issue（`code`、`expected`、`message`、`path`、`received`）が記録される前に、issue ごとに呼ばれます。文字列を返すとデフォルトのメッセージが置き換わり、`undefined` を返すとそのまま残ります。
