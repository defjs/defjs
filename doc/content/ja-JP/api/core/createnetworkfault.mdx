```ts
function createNetworkFault(cause: unknown, response?: HttpMeta): PreflightFault
```

- **cause** — 根本にあるキャンセル、タイムアウト、またはトランスポートの失敗です。
- **response** — トランスポートが報告できるメタデータを既に持っていた場合にだけ渡します。指定すると fault に付与されます。
- **戻り値** `cause` によって code が決まる `PreflightFault` です。
  - `ERR_ABORTED`、または名前が `AbortError` の `DOMException` なら `NET_ABORTED` です。メッセージは `Request was aborted` です。
  - `ERR_TIMEOUT`、または名前が `TimeoutError` のエラーなら `NET_TIMEOUT` です。メッセージは cause のメッセージで、空の場合は `Request timed out` です。
  - それ以外はすべて `NET_UNREACHABLE` で、cause のメッセージを使います。

cause は `cause` として保持されます。
