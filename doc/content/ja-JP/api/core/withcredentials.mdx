<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

`true` のとき、HTTP と SSE のリクエストで Fetch は `credentials: 'include'` を使うので、cookie などの認証情報がクロスオリジンのリクエストでも送られます。`false` のとき、または一度も設定しないときは `credentials` を設定せず、Fetch のデフォルトに従います。

WebSocket コンストラクタにはこの設定は渡されません。
