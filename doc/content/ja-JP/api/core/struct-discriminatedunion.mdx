---
title: 'struct.discriminatedUnion'
description: 'タグフィールドの値で、オブジェクト struct を 1 つ選ぶ struct です。'
---

<ApiReference identity="@defjs/core:struct.discriminatedUnion" />

```ts
function discriminatedUnion<
  const TDiscriminator extends string,
  const TOptions extends readonly [ObjectStruct<ObjectShape>, ...ObjectStruct<ObjectShape>[]],
>(
  discriminator: TDiscriminator,
  options: TOptions & RequiredDiscriminatorOptions<TDiscriminator, TOptions>,
): DiscriminatedUnionStruct<TOptions>
```

```ts
const Event = struct.discriminatedUnion('kind', [
  struct.object({ kind: struct.literal('created'), id: struct.number() }),
  struct.object({ kind: struct.literal('deleted'), id: struct.number() }),
])
```

- すべてのオプションは、`discriminator` フィールドが必須の [`struct.literal()`](/ja-JP/api/core/struct-literal) であるオブジェクト struct でなければなりません。フィールドがない、リテラルでない、オプションである、またはタグの値が重複している場合、struct の作成時に `TypeError` を投げます。
- 入力はプレーンオブジェクトでなければなりません。タグの値でオプションが選ばれ、そのオプションがオブジェクト全体をパースします。
- タグがない場合は `missing_key`、未知のタグの場合は `invalid_union` で失敗します。どちらもタグフィールドのパスを報告します。それ以外の失敗は、選ばれたオプションによるものです。
- `struct.parse(..., { aliases: true })` では、タグはフィールドのエイリアスから読み取られます。

`RequiredDiscriminatorOptions` と `DiscriminatedUnionStruct` はエクスポートされません。型チェックでは、タグフィールドがない、または `undefined` になりうるオプションは拒否されます。
