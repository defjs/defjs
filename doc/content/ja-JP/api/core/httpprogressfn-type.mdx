<ApiReference identity="@defjs/core:HttpProgressFn" />

```ts
type HttpProgressFn = (event: HttpProgressEvent) => Promise<void> | void
```

`HttpExecuteOptions` の `onDownloadProgress` または `onUploadProgress` として渡します。コールバックは非同期でもかまいません。次のチャンクを処理する前に、その完了を待ちます。コールバックが例外を投げるか、返したプロミスが拒否されると、ダウンロードでもアップロードでも、投げられた値を `cause` として呼び出しが `EXT_OBSERVER_FAILED` で失敗します。呼び出し側のキャンセルと `timeout` は引き続き優先され、それぞれ `NET_ABORTED` と `NET_TIMEOUT` になります。アップロードの進捗が報告されるのは、リクエストボディのストリーミングに対応するランタイムに限られます（Bun、Node、Deno）。ブラウザーでは、`Blob` / `File`、`ArrayBuffer`、または `FormData` のボディはそのまま送られ、`onUploadProgress` は呼び出されません。`onDownloadProgress` は影響を受けません。
