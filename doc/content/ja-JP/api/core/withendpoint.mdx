<ApiReference identity="@defjs/core:withEndpoint" />

```ts
function withEndpoint(endpoint: string): ClientOption
```

相対リクエストパスの前に付ける、有効な絶対ベース URL を設定します。デフォルトは空文字列なので、実行にはエンドポイントの明示的な設定が必要です。

- **endpoint** — 有効な絶対ベースエンドポイントです。pathname はディレクトリとして保持され、クエリとハッシュは破棄されます。
- WebSocket コマンドでは、`http:` のベースは `ws:` に、`https:` は `wss:` になります。

エンドポイントが未設定、相対、または無効な場合や、リクエストパスが不正な場合は、ビルド中に `REQ_BUILD_FAILED` で失敗します。これは、ショートサーキットするインターセプターがあっても、どのインターセプターやトランスポートが実行されるよりも前に起こります。HTTP、SSE、WebSocket に共通の規則です。解決後のリクエスト URL はベースと同じオリジンを維持し、そのディレクトリ配下に収まる必要があります。パスに含まれる C0 制御文字（タブ、CR、LF を含む）、バックスラッシュ、`?`、`#`、ディレクトリ外への移動は拒否されます。先頭に空白があっても、スキームらしき形式とプロトコル相対形式は拒否されます。パス内部の普通の空白は許可され、`%20` として送られます。インターセプターが最終的に返す `req.endpoint` も、最終的な `req.baseEndpoint` に対して同じ規則で検証されます。ただし、ベースを別の有効な絶対 URL に意図的に置き換えることはできます。入力によって必ず発生する URL エラーは再試行されません。
