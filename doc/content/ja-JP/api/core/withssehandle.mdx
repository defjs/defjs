<ApiReference identity="@defjs/core:withSSEHandle" />

```ts
function withSSEHandle(fetchImpl: FetchHandle): ClientOption
```

SSE のイベントストリームを開くのに使う、Fetch 互換の関数を差し替えます。デフォルトはプラットフォームの `fetch` です。

- **fetchImpl** は [`FetchHandle`](/ja-JP/api/core/fetchhandle-type) です。
- 影響するのは SSE だけです。HTTP は [`withHTTPHandle`](/ja-JP/api/core/withhttphandle) を使います。
