<ApiReference identity="@defjs/core:struct.formData" />

```ts
function formData<T extends ObjectShape>(shape: T): ObjectStruct<T>
```

[`struct.object()`](/ja-JP/api/core/struct-object) と同じようにパースし、`formData` コーデックタグを持ちます。

- タグが適用されるのは、この struct の値がリクエストボディのルートであるときだけです。その場合、ボディはプラットフォームの multipart 境界を持つ `FormData` として送られます。
- 配列はフィールド名を繰り返し、`undefined` のフィールドはスキップされ、`Blob` / `File` の値はファイルとして追加されます。ネストしたオブジェクトがあると、リクエストは `REQ_BUILD_FAILED` で失敗します。
- `struct.parse` はこのタグを無視します。`FormData` インスタンスは受け付けず、プレーンオブジェクトだけを受け付けます。
