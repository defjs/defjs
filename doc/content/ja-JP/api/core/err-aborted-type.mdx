title: 'ERR_ABORTED'
description: 'リクエストが中断されたことを示す、共有の Error センチネルです。'
---

<ApiReference identity="@defjs/core:ERR_ABORTED" />

```ts
const ERR_ABORTED: Error // message: 'Request was aborted'
```

呼び出し側によるキャンセルを表す、共有の `cause` とメッセージの値です。`createNetworkFault` は、これと名前が `AbortError` の `DOMException` を `NET_ABORTED` に対応づけます。HTTP インターセプターがこれを throw すると、呼び出しは `NET_ABORTED` fault で解決されます。SSE や WebSocket のインターセプターがこれを throw した場合は、`EXT_INTERCEPTOR_FAILED` として報告されます。

[Errors ガイド](/ja-JP/docs/errors) を参照してください。

このセンチネルは、列挙不可の `Symbol.for('defjs.cause.aborted')` ブランドを持ちます。[`isAbortCause`](/ja-JP/api/core/isabortcause) はオブジェクトの同一性を比較せず、どの Core コピーのセンチネルも認識します。分類は、それ以前の無関係な実行に左右されません。
