<ApiReference identity="@defjs/core:WebSocketIncomingData" />

```ts
type WebSocketIncomingData<TIncoming extends AnyStruct> = Infer<TIncoming>
```

`session.receive` が返す各メッセージの型で、エンドポイントの `incoming` struct の [`Infer`](/ja-JP/api/core/infer-type) 出力です。エイリアスされたフィールドは論理名を使います。
