---
title: 'ERR_TIMEOUT'
description: 'リクエストがタイムアウトしたことを示す、共有の Error センチネルです。'
---

<ApiReference identity="@defjs/core:ERR_TIMEOUT" />

```ts
const ERR_TIMEOUT: Error // message: 'Request timed out'
```

タイムアウトを表す、共有の `cause` とメッセージの値です。`createNetworkFault` は、これと名前が `TimeoutError` のエラーを `NET_TIMEOUT` に対応づけます。HTTP インターセプターがこれを throw すると、呼び出しは `NET_TIMEOUT` fault で解決されます。SSE や WebSocket のインターセプターがこれを throw した場合は、`EXT_INTERCEPTOR_FAILED` として報告されます。

[Errors ガイド](/ja-JP/docs/errors) を参照してください。

このセンチネルは、列挙不可の `Symbol.for('defjs.cause.timeout')` ブランドを持ちます。[`isTimeoutCause`](/ja-JP/api/core/istimeoutcause) はオブジェクトの同一性を比較せず、どの Core コピーのセンチネルも認識します。分類は、それ以前の無関係な実行に左右されません。
