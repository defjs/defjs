```ts
function createResolvedRequestUrl(baseEndpoint: string, path: string, queryString?: string): URL
```

- **baseEndpoint** — クライアントのエンドポイントです。そのクエリとハッシュは破棄され、ベースパスを保つために pathname の末尾にスラッシュが追加されます。`https://api.example.com/v1` と `/users` からは `https://api.example.com/v1/users` になります。
- **path** — 相対のエンドポイントパスです。先頭のスラッシュは 1 つだけ取り除かれます。
- **queryString** — 先頭の `?` を含まないクエリです。空でなければ、そのまま URL の search に設定されます。
- **戻り値** 解決された `URL` です。

`baseEndpoint` がパースできない場合は `TypeError('Client endpoint must be a valid URL')` を throw します。`path` にスキームがある、または `//` で始まる場合（`Endpoint path must not be an absolute URL`）、あるいは `?` か `#` を含む場合（`Endpoint path must not include query or hash`）は `Error` を throw します。
