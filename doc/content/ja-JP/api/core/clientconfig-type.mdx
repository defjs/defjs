```ts
interface ClientConfig {
  endpoint: string
  headers?: Headers
  http: { handle: FetchHandle }
  interceptors: Interceptor[]
  querySerializer?: QuerySerializer
  timeout?: number
  withCredentials?: boolean
  xsrf?: {
    cookieName: string
    headerName: string
    tokenProvider?: (context: { request: HttpRequest }) => string | null | undefined
  }
  sse: ClientSSEConfig
  webSocket: ClientWebSocketOptions
}
```

`createClient` が組み立て、すべての option ヘルパーが書き換える、解決済みスナップショットです。HTTP のメンバーは非公開の `HttpClientConfig` 基底型に由来し、ここではインラインで示しています。

option が何も適用されていない状態では、`endpoint` は `''`、`interceptors` は空で、`http.handle` と `sse.handle` はグローバルの `fetch` です。`webSocket.handle` は `globalThis.WebSocket` で、`webSocket` のその他の設定は未設定です。`withXSRF` は、`xsrf.cookieName` と `xsrf.headerName` が省略された場合に、それぞれ `XSRF-TOKEN` と `X-XSRF-TOKEN` で埋めます。
