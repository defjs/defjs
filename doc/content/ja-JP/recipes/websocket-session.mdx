# WebSocket セッションを開く

`defineWebSocket` で `incoming` と `outgoing` の Struct スキーマを、受信キューを制限する `maxIncomingQueueSize` とともに宣言します。アプリケーション側では、`session.onRuntimeError(...)` を購読し、`session.receive` を消費し、`finally` ブロック内で必ず購読解除、`session.close(...)` の呼び出し、および `await session.closed` を行います。

サーバーが `{ "type": "subscribe", "symbol": "ACME" }` に対して `{ "type": "tick", "symbol": "ACME", "price": 142.5 }` を返した場合、スクリプトの出力は以下のようになります。

```txt
ACME 142.5
```

- 再接続（`withWebSocketReconnect`）およびハートビート（`withWebSocketHeartbeat`）は、クライアント側のオプトイン設定です。
- ブラウザの WebSocket はアップグレードハンドシェイク時に任意の HTTP ヘッダーを送信できません。Cookie、サブプロトコル、または短寿命のチケットを使用してください。詳細は [WebSocket セッション](/ja-JP/docs/web-socket) を参照してください。
