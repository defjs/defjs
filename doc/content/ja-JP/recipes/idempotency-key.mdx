# 冪等性キー

デフォルトでは、`withRetry` は冪等な HTTP メソッド（`GET`、`HEAD`、`PUT`、`DELETE`、`OPTIONS`、`TRACE`）のみをリトライします。`POST` や `PATCH` のエンドポイントでリトライを有効にする場合は、`withRetry` と `idempotencyKeyHttpInterceptor()` を組み合わせてください。これにより、同じ論理呼び出しの各リトライ試行では `req.correlationId` が `Idempotency-Key` ヘッダーとして再利用され、後続の新しい呼び出しには新しいキーが割り当てられます。
