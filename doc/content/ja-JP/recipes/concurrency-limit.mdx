# 同時実行数制限とプールされた呼び出し

`Client` に対してクライアント全体のバルクヘッドとして `concurrencyLimitHttpInterceptor`（任意の `maxQueue` オーバーフロー保護付きの FIFO キューイング）を使用し、その `Client` に直接紐付けたフェイルファストまたは全件完了型の並列呼び出しには `@defjs/core/concurrent`（`concurrentMap`、`concurrentMapSettled`、`concurrentAll`、`concurrentAllSettled`）を使用します。
