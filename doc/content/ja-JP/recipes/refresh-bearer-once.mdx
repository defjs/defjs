# 401 で Bearer トークンを一度だけ更新する

`next()` は**この**オニオンの残りです — 外から `axios(config)` のように再ディスパッチするものではありません。付与と single-flight の更新と 1 回の再送を、**1 つ**の HTTP インターセプターに置いて、外側の層が二度走らないようにします。

詳細は [Interceptors](/ja-JP/docs/interceptors) を見てください。

<include cwd meta="refresh-bearer.ts">
  examples/recipes/refresh-bearer-once.ts#example
</include>

```txt
null 42
```

`next` を再び呼んでも、再入するのはこの層の**内側**のインターセプター（と Fetch ハンドラ）だけです。外側の計時や認証のラッパーは再実行されません — だから 401 の組み立ては、2 回目の `execute` ではなく 1 つのインターセプターに置きます。
