# HTTP 呼び出しのキャンセル

呼び出し元の `AbortController` と期限を `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` で結合し、`client({ signal })` 経由で渡します。Defjs は、呼び出し元による手動の中断を `NET_ABORTED`、タイムアウトによる中断を `NET_TIMEOUT` として分類します。

キャンセルの通知は「クライアント側が待機を中止した」ことを表すのみであり、サーバー側で更新処理がロールバックされたことまで保証するものではありません。書き込み操作のリトライを行う場合は、冪等性キーで保護してください。詳細は [HTTP のキャンセルとタイムアウト](/ja-JP/docs/http#cancel-the-work) を参照してください。
