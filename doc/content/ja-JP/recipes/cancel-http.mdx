# HTTP 呼び出しをキャンセルする

呼び出し側のシグナルと期限を `abort` に合成します。`AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` は一つのシグナルです。手動の abort は `NET_ABORTED` に分類されます。期限は `NET_TIMEOUT` に分類されます。

詳細は [HTTP](/ja-JP/docs/http#cancel-the-work) を見てください。

<include cwd meta="cancel-report.ts">
  examples/recipes/cancel-http.ts#example
</include>

```txt
caller cancelled
```

キャンセルは呼び出し側が観測したことを伝えます。サーバー側の書き込みがロールバックされたことの証明にはなりません — ミューテーションのリトライは冪等性の契約の後ろに置いてください。
