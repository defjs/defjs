# ETag と 304 で再検証する

`ok` は 2xx を意味するので、`304` は `HTTP_STATUS` の fault として届きます。リダイレクト status もエラーボディではないので、`error` は宣言しないでください。ボディは読まれず、fault が status を運び、キャッシュした商品は自分で返します。

詳細は [HTTP](/ja-JP/docs/http) を見てください。
