# Undici Pool HTTP ハンドル

高スループットな Node.js 製 BFF やバックエンドサービスでは、[`withHTTPHandle`](/ja-JP/api/core/withhttphandle) 経由で共有 `undici.Pool` を注入します。これにより、SDK 定義（`sdk/orders.ts`）をプラットフォーム非依存のままに保ちつつ、複数のアップストリーム接続をウォームかつ上限付きで維持できます。シャットダウン時には必ず `await pool.close()` を呼び出してください。
