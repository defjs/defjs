# JSON を POST する

型付けされた入力オブジェクトを `builder` に渡し、`{ body: input }` を返します。`.alias("customer_name")` を指定することで、TypeScript 上では `customerName` というプロパティ名を維持したまま、ワイヤ上では `"customer_name"` としてエンコードし、`201` レスポンスからは元の論理名へデコードします。

サーバーが `201` と `{ "id": 1, "status": "paid", "customer_name": "Ada" }` を返した場合、スクリプトの出力は以下のようになります。

```txt
Created paid → 201
```

詳細は [HTTP 操作](/ja-JP/docs/http) および [Struct とスキーマ](/ja-JP/docs/struct) を参照してください。
