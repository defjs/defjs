# POST JSON

型付きのボディをビルダーに渡します。論理フィールド名は TypeScript 側に残り、struct 上のワイヤエイリアスが JSON のキーになります。オブジェクトのボディは `application/json` です。

詳細は [HTTP](/ja-JP/docs/http) と [Client](/ja-JP/docs/client) を見てください。

<include cwd meta="create-order.ts">
  examples/recipes/post-json.ts#example
</include>

`api.example.com` はプレースホルダーです。`201` と `{ "id": 1, "status": "paid", "customer_name": "Ada" }` を返すサーバーに対して、このスニペットは次のように出力します。

```txt
Created paid → 201
```
