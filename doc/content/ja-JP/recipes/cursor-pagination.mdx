# カーソルページネーション

ページネーションを行う操作定義（`listOrders`）は SDK モジュールに置き、カーソル継続の処理は純粋なアプリケーションヘルパー関数（`listAllOrders`）の中にラップします。このヘルパーは Go スタイルの `[err, item]` タプルを yield し、エラーや呼び出し元のキャンセルが発生すると即座に停止します。
