# Struct とスキーマ

`struct` は、SDK と利用側アプリケーションの間で共有される通信データ契約（呼び出し元の入力、`2xx` の出力、宣言されたサービスエラー、SSE イベント、WebSocket フレーム）を宣言します。

- **静的な型推論**: `Infer<typeof Schema>` を使って TypeScript の型を自動導出します。
- **エラーファーストのバリデーション**: `struct.parse(Schema, value)` により、例外を throw することなく `[null, data]` または `[StructError, undefined]` を返します。

パースされたオブジェクトには宣言されたフィールドのみが残り（未知のプロパティは自動的に削除されます）、プロトタイプは `null` に設定されます。必須キーの欠落、基本型の不一致、無効な分岐が発生した場合、不完全なデータを出力することなく `StructError` を返します。

## 2. 必須フィールド、オプショナル、nullable

Defjs では、**フィールドの存在有無**（`undefined`）と **値の null 許容性**（`null`）を明確に区別します。すべての struct コンストラクターは、デフォルトで厳格に「必須かつ非 null」です。

| 宣言                         | 未指定 / `undefined`                     | `null` | 有効な値               |
| ---------------------------- | ---------------------------------------- | ------ | ---------------------- |
| `struct.string()`            | 拒否                                     | 拒否   | `string` のみ許可      |
| `struct.string().optional()` | 許可（オブジェクトシリアライズ時は除外） | 拒否   | `string` のみ許可      |
| `struct.string().null()`     | 拒否                                     | 許可   | `string` または `null` |
| `struct.string().nullish()`  | 許可（オブジェクトシリアライズ時は除外） | 許可   | `string` または `null` |
| `struct.null()`              | 拒否                                     | 許可   | `null` 以外は拒否      |

<include cwd lang="typescript">
  examples/struct/required-optional-null.ts#example
</include>

`struct.any()` や `struct.unknown()` も、`.null()`、`.optional()`、`.nullish()` を明示的にチェーンしない限り、`null` や `undefined` を拒否します。

## 3. 双方向の通信用エイリアス (`.alias()`)

バックエンドが `snake_case` や特定のヘッダー名を使用し、TypeScript SDK 側では `camelCase` を使いたい場合は、`.alias("wire_name")` を使用します。フィールドに一度エイリアスを宣言するだけで、双方向で機能します。

| 境界                                                                 | 使用されるキー名                               |
| -------------------------------------------------------------------- | ---------------------------------------------- |
| 操作の `input` および `struct.parse(Schema, value)`                  | 論理名（`customerName`）                       |
| `builder` が返す型付けされた struct 値（`body`, `query`, `headers`） | 通信用エイリアス（`customer_name`）            |
| JSON レスポンス / SSE イベント / WebSocket フレームのデコード時      | 通信用 `customer_name` → 論理名 `customerName` |
| `builder` 内で直接記述された匿名オブジェクトのキー                   | 記述されたままのリテラルキー                   |

<include cwd lang="typescript">
  examples/struct/aliases.ts#example
</include>

`builder` 内で型付けされたオブジェクトを展開（スプレッド: `{ ...input.order, extra: 1 }`）しても、struct のエンコード設定とエイリアスはそのまま保持されます。同じオブジェクト上で論理キーと通信用エイリアスの両方を同時に指定すると、`REQ_BUILD_FAILED` で失敗します。

## 4. リクエストへの配置とフォームコーデック

`input` はパラメータを定義し、`builder` はそれらを `{ path, query, headers, body }` へと配置します。フォームエンコードされたボディの場合、`struct.urlencoded(shape)` や `struct.formData(shape)` をルートオブジェクトに指定することで、トランスポートが自動的に `URLSearchParams` や `FormData` としてシリアライズします。

<include cwd lang="typescript">
  examples/struct/request-placement.ts#example
</include>

| `builder` が返すボディのルート値                           | 送信時の形式      | デフォルトの `Content-Type`                       |
| ---------------------------------------------------------- | ----------------- | ------------------------------------------------- |
| 型付けされたオブジェクト、配列、有限の数値、真偽値、`null` | JSON テキスト     | `application/json`                                |
| `string` struct または生の `string`                        | UTF-8 テキスト    | `text/plain;charset=UTF-8`                        |
| ボディルートの `struct.urlencoded(shape)`                  | `URLSearchParams` | `application/x-www-form-urlencoded;charset=UTF-8` |
| ボディルートの `struct.formData(shape)`                    | `FormData`        | `multipart/form-data; boundary=...`               |
| `Blob` / `File` (`struct.file()`)                          | バイナリ Blob     | `blob.type` または `application/octet-stream`     |
| `ArrayBuffer` / ビュー / `ReadableStream`                  | 生のバイト列      | `application/octet-stream`                        |

## 5. `StructError` とバリデーション問題（issues）の処理

`struct.parse(Schema, data, { aliases?, errorMap? })` は、検証失敗時に `[StructError, undefined]` を返します。`StructError` はネイティブの `Error` を継承しており、`issues`、`format()`、`flatten()`、`prettify()` を提供します。

<include cwd lang="typescript">
  examples/struct/parse-failures.ts#example
</include>

各 `StructIssue` には、`code`（`invalid_type`、`missing_key`、`invalid_literal`、`invalid_enum`、`invalid_union`、`invalid_intersection`、`custom`）、`path`、`expected`、`received`、`message` が含まれます。デフォルトのメッセージは受信した値を省き、その _型_ だけを報告しますが、path は動的な record のキーを保持し、そこに機密性の高い値が含まれることがあります。`String(error)` と `error.prettify()` は秘匿化の境界ではありません。ログに出すときは安全なフィールドの許可リストを使い、生の `received` 値とカスタムメッセージは機密情報として扱ってください。

## 6. コンストラクターリファレンス

<include cwd lang="typescript">
  examples/struct/any.ts#example
</include>

| コンストラクター                                           | 受け付ける入力値                                 | 推論される出力型                                             |
| ---------------------------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------ |
| `struct.string()` / `struct.boolean()`                     | 一致するプリミティブ値                           | `string` / `boolean`                                         |
| `struct.number()`                                          | `NaN` を除く任意の数値                           | `number`（`NaN` は拒否、JSON ボディでは `±Infinity` も拒否） |
| `struct.bigint()`                                          | `bigint` または数値形式の文字列                  | `bigint`                                                     |
| `struct.date()`                                            | 有効な `Date`、タイムスタンプ、または ISO 文字列 | `Date`                                                       |
| `struct.literal(value)`                                    | 正確に一致するプリミティブリテラル               | リテラル型                                                   |
| `struct.enum(values)`                                      | 宣言された文字列または数値の要素                 | リテラルの union 型                                          |
| `struct.array(item)` / `struct.tuple(items)`               | 配列 / 固定長タプル                              | `T[]` / `[...]`                                              |
| `struct.object(shape)` / `struct.record(val)`              | プレーンオブジェクト                             | 型付けされたオブジェクト / `Record<string, V>`               |
| `struct.discriminatedUnion(key, options)`                  | リテラルの `key` 識別子を持つオブジェクト        | オブジェクトブランチの union 型                              |
| `struct.or(branches)`                                      | 最初にマッチしたブランチ                         | 各ブランチ型の union 型                                      |
| `struct.intersection(members)`                             | すべての構成要素を満たす値                       | ディープマージされた交差型（intersection）                   |
| `struct.file()` / `struct.blob()` / `struct.arrayBuffer()` | `File` / `Blob` / `ArrayBuffer`                  | バイナリ表現                                                 |
