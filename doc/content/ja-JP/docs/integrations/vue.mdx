# Vue

`@defjs/vue` は、アプリケーションが所有する `@defjs/core` のクライアントを、`createClientPlugin(client)`、`HTTP_CLIENT`、および `injectClient()` を通じて Vue 3.2+ アプリケーションに組み込みます。SDK 定義は Vue に一切依存しない純粋な `@defjs/core` モジュールのまま保たれます。

```sh
bun add @defjs/core @defjs/vue vue
```

## `@defjs/vue` が提供するもの vs 開発者が所有するもの

- **`@defjs/vue` が提供するもの**: `createClientPlugin(client)`、`HTTP_CLIENT`（`InjectionKey<Client>`）、および `injectClient(key?)`。
- **アプリケーション側が所有するもの**: [`DerivableClient`](/ja-JP/api/core/derivableclient-type) の生成、ウォッチャー（`onCleanup`）やコンポーザブル（`onScopeDispose`）内での通信キャンセル、SSE/WebSocket ハンドルのクローズ、Vue Query などのクエリライブラリとの連携。
- **重要**: `injectClient()` は `DerivableClient` 関数オブジェクトを返します。操作を実行する箇所で `client({ signal })` を呼び出してください（`getOrder(client({ signal }), input)`）。Vue は関数引数をリアクティブなゲッターとして解釈するため、`client` を `watch(client, ...)` や `computed(client)` の第 1 引数に直接渡してはいけません。

アプリケーションのエントリポイントでクライアントを作成し、`createClientPlugin(client)` をインストールします。Watcher 内で非同期処理を開始する前に `onCleanup` を登録します。

- `onCleanup` は、Watcher が再実行される直前、およびコンポーネントがアンマウントされる時の両方で実行されます。

## 2. `injectClient` による注入とサブツリーでのオーバーライド

`injectClient(key?)` は、指定された `key`（デフォルトは `HTTP_CLIENT`）に最も近いプロバイダーを探索し、アクティブな Vue インジェクションコンテキスト（`setup()` または `app.runWithContext()`）の外部で呼び出された場合や、そのキーに対応するクライアントが見つからない場合に `Error` を throw します。

Vue ネイティブの `provide(HTTP_CLIENT, childClient)` を使用して、特定のコンポーネントサブツリーに対してクライアントをオーバーライドできます。

<include cwd>examples/vue/inject-and-override.vue#example</include>

- 子孫コンポーネントは `childClient` を受け取りますが、兄弟サブツリーはルートクライアントを維持します。
- ヘルパー関数が任意の明示的クライアントを受け取る設計にする場合（`explicitClient ?? injectClient()`）、フォールバック側のみがアクティブな Vue インジェクションコンテキストを必要とします。クライアントの取得は、`await` を呼ぶ前の `setup()` 内で同期的に行ってください。

## 3. スコープ破棄時における SSE と WebSocket のクリーンアップ

Watcher の外側のコンポーザブルやコンポーネント内で処理を開始する場合、`AbortController` と `onScopeDispose` を組み合わせます。接続開始処理を中断し、破棄後に解決されたハンドルも確実にクローズし、単一の非同期イテレーターを消費して `.closed` を await します。

<include cwd>examples/vue/realtime-scope.vue#example</include>

- スコープの停止によって、SSE の `for await` ループは通常通り終了します。
- WebSocket セッションを abort すると、セッションは `aborted` として終了し、`session.receive` は `AbortError` で reject されます。そのため、破棄後は `catch` ブロックでエラーをガードし、`finally` で `onStateChange` / `onRuntimeError` のリスナーを確実に解除（unsubscribe）してください。

---

## 4. SSR とアプリケーションスコープ

- **ブラウザ**: エンドポイントやインターセプターがリクエストに依存しない場合、Vue アプリケーションごとに単一クライアントを共有します。
- **SSR**: ヘッダー、Cookie、テナント、認証情報がリクエストごとに異なる場合、SSR リクエストごとに新しいクライアントを作成してインストールします。
- Vue アプリケーションのアンマウントやコンポーネントスコープの破棄によって、HTTP リクエストが自動中止されたり、SSE/WebSocket ストリームが切断されたり、コアクライアントが破棄されることはありません。
