# llms.txt

このサイトはアシスタント向けの英語 Markdown を公開しています。以下のアドレスにはロケール接頭辞がなく、ローカライズされたガイドの翻訳でもありません。

## ページ索引 [#llms-txt]

[llms.txt](/llms.txt) は英語ページの一覧と各ウェブページへのリンクです。アシスタントがまずページを探すときの入口です。

## まとめたガイド [#llms-full]

[llms-full.txt](/llms-full.txt) は英語ガイドを 1 つのファイルにまとめたものです。1 つのドキュメントで広範なコンテキストが必要で、トークン予算が許す場合に使います。

## 1 ページの Markdown [#page-markdown]

各英語ページは `/llms.mdx/<path>/content.md` でも Markdown として取得できます。たとえば [クイックスタートの Markdown](/llms.mdx/docs/start/content.md) はクイックスタートページの英語本文です。

## バージョンの確認 [#version]

このサイトはデフォルトブランチを記録しています。プロジェクトにインストールされた `@defjs/core` のバージョンは異なる場合があります。提案を適用する前に、インストール済みパッケージに対して API を確認してください。AI ツールにコードやコンテキストを渡す前に、秘密情報を削除し、プロジェクトのポリシーを確認してください。
