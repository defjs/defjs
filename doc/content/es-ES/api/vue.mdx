# Vue

Proporciona un cliente `@defjs/core` existente a una app de Vue. Este paquete no crea, no cachea ni libera (dispose) el cliente. Se requiere Vue 3 o posterior.

Mira la [guía de Vue](/es-ES/docs/integrations/vue).

## createClientPlugin()

```ts
function createClientPlugin(client: Client): Plugin
```

- **client** — Instancia de `createClient`.
- **Devuelve** un plugin de Vue para `app.use(...)`. Al instalarlo se llama a `app.provide(HTTP_CLIENT, client)`.

## injectClient()

```ts
function injectClient(): Client
```

Lee el proveedor `HTTP_CLIENT` más cercano. Llámalo en un contexto de inyección válido de Vue, como la ejecución síncrona de `setup()` o un callback síncrono de `app.runWithContext()` (Vue 3.3+). También son válidos los contextos que el compilador restaura después de un `await` de nivel superior en `<script setup>`.

- **Devuelve** el cliente inyectado.
- **Lanza** un `Error` si no hay un contexto de inyección activo o no se proporcionó ningún cliente. Proporciona un cliente con `app.use(createClientPlugin(client))` o `provide(HTTP_CLIENT, client)` en un componente ancestro; instalar el plugin no basta para llamar fuera de un contexto de inyección.

## HTTP_CLIENT

```ts
const HTTP_CLIENT: InjectionKey<Client>
```

Clave de inyección de Vue. Prefiere `injectClient()` a `inject(HTTP_CLIENT)`. Sustituye el cliente de un subárbol con `provide(HTTP_CLIENT, childClient)`.
