title: 'ClientOptions'
description: 'Opciones del cliente con forma de entrada que reflejan lo que configuran los helpers de opción.'
---

<ApiReference identity="@defjs/core:ClientOptions" />

```ts
interface ClientOptions extends HttpClientOptions {
  sse?: ClientSSEOptions
  webSocket?: ClientWebSocketOptions
}

// Non-exported base, shown inline.
interface HttpClientOptions {
  endpoint: string
  headers?: Headers
  http?: { handle?: FetchHandle }
  interceptors?: Interceptor[]
  querySerializer?: QuerySerializer
  timeout?: number
  withCredentials?: boolean
  xsrf?: {
    cookieName?: string
    headerName?: string
    tokenProvider?: (context: { request: HttpRequest }) => string | null | undefined
  }
}
```

La forma de los ajustes de cara al usuario antes de aplicar los valores por defecto. `createClient` no acepta este objeto; configura un cliente con helpers de opción como `withEndpoint` y `withTimeout`. [`ClientConfig`](/es-ES/api/core/clientconfig-type) es su contraparte resuelta.
