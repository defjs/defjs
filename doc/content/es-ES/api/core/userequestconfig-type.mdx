description: 'Opciones de execute HTTP para callbacks de progreso y cancelación.'
---

<ApiReference identity="@defjs/core:UseRequestConfig" />

```ts
type UseRequestConfig = {
  onDownloadProgress?: HttpProgressFn
  onUploadProgress?: HttpProgressFn
} & ({ abort?: AbortSignal; timeout?: never } | { abort?: never; timeout?: number })
```

La parte específica de HTTP de [`HttpExecuteOptions`](/es-ES/api/core/httpexecuteoptions-type), que añade `signal`.

- `onDownloadProgress` y `onUploadProgress` son callbacks [`HttpProgressFn`](/es-ES/api/core/httpprogressfn-type). Reciben un [`HttpProgressEvent`](/es-ES/api/core/httpprogressevent-type) con `loaded`, `total` y `lengthComputable`.
- La cancelación es `abort` o `timeout`, nunca ambos. El tipo rechaza pasar los dos y, en runtime, pasarlos falla con un fault `REQ_OPTIONS_INVALID`.
- `timeout` debe ser un entero seguro positivo no mayor que `2_147_483_647`. Sustituye, para esa llamada, el valor por defecto fijado con [`withTimeout`](/es-ES/api/core/withtimeout). `abort`, en cambio, se combina con ese valor por defecto.
