```ts
function createNetworkFault(cause: unknown, response?: HttpMeta): PreflightFault
```

- **cause** — La cancelación, el timeout o el fallo de transporte subyacente.
- **response** — Metadatos, solo cuando el transporte ya tenía alguno que informar. Se adjunta al fault cuando se da.
- **Devuelve** un `PreflightFault` cuyo código depende de `cause`:
  - `NET_ABORTED` para `ERR_ABORTED` o una `DOMException` llamada `AbortError`. El mensaje es `Request was aborted`.
  - `NET_TIMEOUT` para `ERR_TIMEOUT` o un error llamado `TimeoutError`. El mensaje es el de la causa, o `Request timed out` cuando está vacío.
  - `NET_UNREACHABLE` para cualquier otra cosa, con el mensaje de la causa.

La causa se conserva como `cause`.
