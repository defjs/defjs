```ts
interface ClientSSEConfig extends ClientSSEOptions {
  handle: FetchHandle
}
```

El tipo de `ClientConfig.sse`. Es [`ClientSSEOptions`](/es-ES/api/core/clientsseoptions-type) con `handle` siempre presente; el wrapper por defecto resuelve el `fetch` global actual en cada intento, en lugar de capturarlo en el momento del import.
