<ApiReference identity="@defjs/core:struct.boolean" />

```ts
function boolean(): Struct<boolean, boolean>
```

Acepta solo `true` y `false`. Cualquier otro valor, incluidos `'true'` y `1`, falla con `invalid_type`.
