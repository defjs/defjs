---
title: 'struct.blob'
description: 'Struct que acepta un Blob.'
---

<ApiReference identity="@defjs/core:struct.blob" />

```ts
function blob(): Struct<Blob, Blob>
```

- Acepta un `Blob` (un `File` es un `Blob`). Cualquier otra cosa falla con `invalid_type`.
- Como raíz de body se envía tal cual, con el tipo propio del blob o `application/octet-stream`.
- Como struct `output` o `error` hace que el body de la respuesta se lea como un `Blob`.
