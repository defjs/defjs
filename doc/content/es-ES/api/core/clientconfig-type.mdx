<ApiReference identity="@defjs/core:ClientConfig" />

```ts
interface ClientConfig {
  endpoint: string
  headers?: Headers
  http: { handle: FetchHandle }
  interceptors: Interceptor[]
  querySerializer?: QuerySerializer
  timeout?: number
  withCredentials?: boolean
  xsrf?: {
    cookieName: string
    headerName: string
    tokenProvider?: (context: { request: HttpRequest }) => string | null | undefined
  }
  sse: ClientSSEConfig
  webSocket: ClientWebSocketOptions
}
```

La instantánea resuelta que construye `createClient` y que muta cada helper de opción. Los miembros HTTP proceden de una base `HttpClientConfig` no exportada y se muestran en línea.

Antes de que se aplique cualquier opción, `endpoint` es `''`, `interceptors` está vacío, y `http.handle` y `sse.handle` son el `fetch` global. `webSocket.handle` es `globalThis.WebSocket` y el resto de los ajustes de `webSocket` no están definidos. `withXSRF` rellena `xsrf.cookieName` con `XSRF-TOKEN` y `xsrf.headerName` con `X-XSRF-TOKEN` cuando se omiten.
