---
title: 'withCredentials'
description: 'Opción de cliente que envía credenciales con las solicitudes HTTP y SSE.'
---

<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

Con `true`, Fetch usa `credentials: 'include'` para las solicitudes HTTP y SSE, de modo que las cookies y otras credenciales se envían también en solicitudes cross-origin. Con `false` o si nunca se define, `credentials` se deja sin establecer y Fetch usa su valor por defecto.

El constructor de WebSocket no recibe este ajuste.
