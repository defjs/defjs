---
title: 'FaultOf'
description: 'Unión de faults expresada por el tipo de su cuerpo de error decodificado.'
---

<ApiReference identity="@defjs/core:FaultOf" />

```ts
type FaultOf<TData = undefined> = DecodeFault | HttpStatusFaultOf<TData> | PreflightFault
```

`TData` es el cuerpo `error` decodificado, o `undefined` cuando no se declaró un struct de error. `Fault<TErr>` es `FaultOf` aplicado a `Infer<TErr>`, y `HttpAwaitResult` usa `FaultOf<TErrorData>`. Pasa un tipo decodificado, no un struct: escribe `FaultOf<Infer<typeof errorStruct>>`, o usa `Fault<typeof errorStruct>`.
