```ts
function withSSEHandle(fetchImpl: FetchHandle): ClientOption
```

Reemplaza la función compatible con Fetch que se usa para abrir streams de eventos SSE. Por defecto es el `fetch` de la plataforma.

- **fetchImpl** es un [`FetchHandle`](/es-ES/api/core/fetchhandle-type).
- Solo afecta a SSE. HTTP usa [`withHTTPHandle`](/es-ES/api/core/withhttphandle).
