description: 'Unión de todos los fallos que client.execute puede devolver, discriminada por code.'
---

<ApiReference identity="@defjs/core:Fault" />

```ts
type Fault<TErr extends AnyStruct | undefined = undefined> = FaultOf<[TErr] extends [undefined] ? undefined : Infer<TErr>>
```

`TErr` es el struct `error` declarado por el endpoint, o `undefined` cuando no declara ninguno. `Fault<TErr>` es [`FaultOf`](/es-ES/api/core/faultof-type) aplicado al tipo del cuerpo decodificado, así que es la unión de tres variantes: [`DecodeFault`](/es-ES/api/core/decodefault-type), [`HttpStatusFault<TErr>`](/es-ES/api/core/httpstatusfault-type) y [`PreflightFault`](/es-ES/api/core/preflightfault-type). Haz switch sobre `fault.code`.

Cada variante es un `Error` nativo llamado `DefjsFault`, así que `String(fault)` produce directamente un `DefjsFault: <message>` listo para registrar. `code` y los metadatos de la variante (`status`, `response`, `data`) son propiedades propias enumerables. La cadena nativa de `cause` no es enumerable.
