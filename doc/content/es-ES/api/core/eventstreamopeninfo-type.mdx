<ApiReference identity="@defjs/core:EventStreamOpenInfo" />

```ts
interface EventStreamOpenInfo {
  response: HttpResponse<unknown>
  url: string
}
```

`response` es la respuesta del handshake y `url` es la URL de la solicitud ya resuelta. Es el tercer elemento de un resultado exitoso de `client.execute` y el valor de `EventStreamHandle.open`.
