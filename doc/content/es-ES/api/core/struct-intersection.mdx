<ApiReference identity="@defjs/core:struct.intersection" />

```ts
function intersection<const T extends readonly [StructLike, ...StructLike[]]>(...structs: T): IntersectionStruct<T>
```

`struct.intersection` es variádico: pasa cada struct como un argumento propio.

- Parsea la entrada con cada struct y fusiona los resultados.
- Cuando todos los structs son structs de objeto, la salida es un único objeto con los campos de todos ellos. Las claves que ninguno declara se eliminan.
- Cuando dos structs producen valores incompatibles para la misma clave, falla con `invalid_intersection`.
- Un único struct se devuelve sin cambios. Llamarlo sin structs lanza `TypeError`, igual que un argumento que no sea un struct.

`IntersectionStruct<T>` no se exporta. Es un `Struct` cuya entrada y salida son las intersecciones de los tipos de los miembros.
