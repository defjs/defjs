<ApiReference identity="@defjs/core:withHTTPHandle" />

```ts
function withHTTPHandle(fetchImpl: FetchHandle): ClientOption
```

Reemplaza la función compatible con Fetch que se usa en las solicitudes HTTP. Por defecto es el `fetch` de la plataforma.

- **fetchImpl** es un [`FetchHandle`](/es-ES/api/core/fetchhandle-type), la firma de llamada `(input, init?) => Promise<Response>`. No es `typeof fetch`, así que un doble de prueba no necesita extras del host como `fetch.preconnect`.
- Solo afecta a HTTP. SSE usa [`withSSEHandle`](/es-ES/api/core/withssehandle).
