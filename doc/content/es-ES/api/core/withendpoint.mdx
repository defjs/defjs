<ApiReference identity="@defjs/core:withEndpoint" />

```ts
function withEndpoint(endpoint: string): ClientOption
```

Fija la URL base que se antepone a los paths de solicitud relativos. Por defecto es una cadena vacía.

- **endpoint** — endpoint base, absoluto o relativo.
- Para comandos WebSocket, una base `http:` pasa a `ws:` y `https:` pasa a `wss:`.
