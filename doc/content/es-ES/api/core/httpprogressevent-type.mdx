description: 'Instantánea de progreso que se pasa a los callbacks de subida y descarga.'

<ApiReference identity="@defjs/core:HttpProgressEvent" />

```ts
interface HttpProgressEvent {
  readonly lengthComputable: boolean
  readonly loaded: number
  readonly total: number
}
```

Refleja los campos de `ProgressEvent`. `loaded` cuenta los bytes leídos del stream de subida o de descarga, no los bytes confirmados por el servidor. Los bytes de descarga pueden estar ya descomprimidos. Un total de descarga solo es calculable con un `Content-Length` positivo y un `Content-Encoding` ausente o `identity`; las descargas comprimidas informan `total: 0` y `lengthComputable: false`. Una subida FormData en stream también tiene un total desconocido, salvo que lo aporte un `Content-Length` explícito válido. Los demás streams de longitud desconocida usan los mismos campos `0` / `false`.

Mira [`HttpProgressFn`](/es-ES/api/core/httpprogressfn-type), la [guía de HTTP](/es-ES/docs/http) y [Comandos](/es-ES/docs/commands).
