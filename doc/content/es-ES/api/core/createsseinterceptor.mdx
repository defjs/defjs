<ApiReference identity="@defjs/core:createSSEInterceptor" />

```ts
function createSSEInterceptor(fn: SSEInterceptorFn): SSEInterceptor

type SSEHandler = (req: HttpRequest) => Promise<EventStreamHandle<unknown>>
type SSEInterceptorFn = (req: HttpRequest, next: SSEHandler) => Promise<EventStreamHandle<unknown>>
```

Devuelve `{ kind: 'sse', fn }`. Los interceptores SSE se ejecutan solo para comandos SSE, en orden de registro; `next(req)` abre el stream a través de los interceptores restantes.

`EventStreamHandle` extiende `AsyncDisposable`. Una implementación estructural que cortocircuite debe proporcionar `[Symbol.asyncDispose](): PromiseLike<void>` y conectarlo al mismo ciclo de vida de cierre.
