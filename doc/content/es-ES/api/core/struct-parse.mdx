title: 'struct.parse'
description: 'Parsea un valor desconocido con un struct y devuelve una tupla con el error primero.'
---

<ApiReference identity="@defjs/core:struct.parse" />

```ts
function parse<S extends StructLike<unknown, unknown, boolean>>(
  struct: S,
  value: unknown,
  options?: { aliases?: boolean; errorMap?: ErrorMap },
): ParseResult<S['_struct']['output']>
```

- **struct** es el struct con el que se parsea. Un valor que no sea un struct lanza `TypeError`.
- **value** es la entrada desconocida.
- **options.aliases** vale `false` por defecto: las claves de objeto se leen por sus nombres **lógicos** (`displayName`). Con `true` se leen por sus nombres de cable (`display_name`), como las leen los códecs HTTP/JSON. La salida siempre usa nombres lógicos.
- **options.errorMap** es un [`ErrorMap`](/es-ES/api/core/errormap-type) que reescribe los mensajes de issue solo en esta llamada. Si devuelve `undefined`, se mantiene el mensaje por defecto.
- **Devuelve** `[null, output]` o `[StructError, undefined]`. Una entrada inválida nunca lanza.
- El parseo es fail-fast: se detiene en el primer fallo, así que el error contiene un único issue. Las claves de objeto desconocidas se descartan de la salida y la entrada no se modifica.

```ts
const [error, user] = struct.parse(User, { id: 1, displayName: 'Ada' })
if (error) return console.error(error.prettify())
```

Consulta [`ParseResult`](/es-ES/api/core/parseresult-type) y [`StructError`](/es-ES/api/core/structerror-type).
