---
title: 'ObjectStruct'
description: 'Tipo de struct con forma de objeto que produce struct.object.'
---

<ApiReference identity="@defjs/core:ObjectStruct" />

```ts
interface ObjectStruct<T extends ObjectShape>
  extends StructMethods<ObjectInput<T>, ObjectOutput<T>, false>, StructLike<ObjectInput<T>, ObjectOutput<T>, false> {
  readonly _struct: ObjectStructTypes<T>
  null(): PreservedStruct<ObjectStruct<T>, ObjectInput<T> | null, ObjectOutput<T> | null, false>
  nullable(): PreservedStruct<ObjectStruct<T>, ObjectInput<T> | null, ObjectOutput<T> | null, false>
  nullish(): PreservedStruct<ObjectStruct<T>, ObjectInput<T> | null | undefined, ObjectOutput<T> | null | undefined, true>
  optional(): PreservedStruct<ObjectStruct<T>, ObjectInput<T> | undefined, ObjectOutput<T> | undefined, true>
}

type ObjectShape = { [key: string]: any }
```

Lo produce `struct.object(shape)`. Los campos son obligatorios por defecto; un campo marcado con `optional()` o `nullish()` se convierte en una clave opcional. Las claves desconocidas se descartan al parsear. Los nombres del cable pueden diferir de las claves de TypeScript mediante `.alias()`. Un parse fallido devuelve `[StructError, undefined]`. `ObjectInput`, `ObjectOutput`, `ObjectStructTypes` y `PreservedStruct` son tipos auxiliares internos.
