# React

Proporciona un cliente `@defjs/core` existente a un árbol React. Este paquete no crea, no cachea ni dispone el cliente. Su entrada está marcada `'use client'`, así que impórtalo desde componentes de cliente. Se requiere React 18 o posterior.

Consulta la [guía de React](/es-ES/docs/integrations/react).

## ClientProvider

<ApiSignature name="ClientProvider" />

Provider de Context. Pasa el [`DerivableClient`](/es-ES/api/core/derivableclient-type) que devuelve `createClient`. Un `ClientProvider` anidado sustituye el cliente de su subárbol; `useClient()` lee el más cercano. Pasar un `client` distinto cambia el valor de contexto para los descendientes.

## useClient()

<ApiSignature name="useClient" />

`useClient(overrideClient)` prefiere el cliente explícito; omitido o `undefined` lee el `ClientProvider` más cercano. Solo se lanza un `Error` cuando ninguna de las dos fuentes aporta un cliente. Las llamadas `useClient()` sin argumentos siguen siendo válidas. Pasa ese cliente a una operación. El hook devuelve el [`DerivableClient`](/es-ES/api/core/derivableclient-type) que se proporcionó; llámalo con opciones de solicitud donde se ejecuta la operación para derivar un valor `Client`. No lo pases a un setter de estado, porque `setState(client)` lo llamaría como updater. `ClientProvider` y `useClient` no aceptan un valor `Client` derivado.

Llama siempre a `useClient(explicitClient)` en el nivel superior de un componente o de un Hook personalizado, incluso con un cliente explícito; no en una función ordinaria ni en un callback de evento. No escribas `explicitClient ?? useClient()`, que llama a un Hook de forma condicional. La sustitución no escribe en el Context ni crea un provider, y el Hook sigue suscrito al Context.

- **Devuelve** el cliente explícito exacto o el cliente proporcionado más cercano.
- **Lanza** un `Error` cuando ni un cliente explícito ni el Context aportan un cliente.

## ClientProviderProps

<ApiSignature name="ClientProviderProps" />

`client` es obligatorio y lo posee la aplicación. `children` es opcional: el árbol que puede llamar a `useClient`.
