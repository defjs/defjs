```ts
interface ClientProviderProps {
  client: Client
  children?: ReactNode
}
```

- `client` — Obligatorio. El cliente de Defjs que pertenece a la aplicación.
- `children` — Opcional. El árbol de React que puede llamar a `useClient`.
