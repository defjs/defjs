# Referencia de API

<ApiIndex />

Usa esta referencia mientras construyes o consumes un SDK de Defjs. Los autores del SDK empiezan por [`defineRequest`](/es-ES/api/core/definerequest), [`defineEventStream`](/es-ES/api/core/defineeventstream), [`defineWebSocket`](/es-ES/api/core/definewebsocket) y [Struct](/es-ES/api/struct). Las aplicaciones usan la [configuración del Client](/es-ES/api/client) para llamar a esas operaciones y [Errores](/es-ES/api/errors) para tratar los resultados.

Las firmas son el contrato. Sigue el [inicio rápido](/es-ES/docs/start) y la [guía de publicación del SDK](/es-ES/recipes/publish-http-sdk) para el recorrido completo.

## Paquetes

| Paquete                                                          | Qué consultas                                                     |
| ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| [`@defjs/core`](/es-ES/api/client)                               | `createClient`, `defineRequest`, `struct`, HTTP / SSE / WebSocket |
| [`@defjs/vue`](/es-ES/api/vue)                                   | `createClientPlugin`, `injectClient`, `HTTP_CLIENT`               |
| [`@defjs/react`](/es-ES/api/react)                               | `ClientProvider`, `useClient`                                     |
| [`@defjs/opentelemetry-server`](/es-ES/api/opentelemetry-server) | `withOpenTelemetryServer`, opciones por transporte                |
