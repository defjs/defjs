# Referencia de API

<ApiIndex />

Esta referencia describe las piezas públicas para autores de SDK y aplicaciones. Las firmas establecen el contrato; la [guía](/es-ES/docs/start) y la [receta de publicación](/es-ES/recipes/publish-http-sdk) muestran su uso completo.

- **Crear un SDK:** empieza por [`struct`](/es-ES/api/struct), [`defineRequest`](/es-ES/api/http), [`defineEventStream`](/es-ES/api/sse) o [`defineWebSocket`](/es-ES/api/web-socket) y exporta los endpoints obtenidos.
- **Consumir un SDK:** configura [`createClient` y `with*`](/es-ES/api/client), ejecuta los endpoints importados y gestiona [errores](/es-ES/api/errors) y recursos de transporte.
- **Integrar la aplicación:** añade [interceptores](/es-ES/api/interceptors), [React](/es-ES/api/react), [Vue](/es-ES/api/vue) u [OpenTelemetry](/es-ES/api/opentelemetry-server) al cliente de la aplicación.
