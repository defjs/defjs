# CLI (`@defjs/cli`)

CLI de desarrollo y generador programático que convierte especificaciones Swagger 2.0 y OpenAPI 3.0–3.2 en módulos ESM `@defjs/core` sin estado. Consulta la [guía de integración del CLI](/es-ES/docs/integrations/cli).
