# Paginación por cursor

Mantén la operación paginada en el módulo del SDK (`listOrders`) y envuelve la continuación por cursor dentro de un helper puro de la aplicación (`listAllOrders`) que emita tuplas estilo Go `[err, item]` y se detenga de inmediato ante un fallo o una cancelación de quien llama.
