# Cancelar una llamada HTTP

Combina el signal de quien llama con un plazo en `abort`. `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` es un solo signal. Un abort manual se clasifica como `NET_ABORTED`. Un plazo se clasifica como `NET_TIMEOUT`.

Ver detalles en [HTTP](/es-ES/docs/http#cancel-the-work).

<include cwd meta="cancel-report.ts">

</include>

```txt
caller cancelled
```

La cancelación te dice lo que observó quien llama. No demuestra que una escritura en el servidor se revirtiera — mantén los reintentos de mutación detrás de un contrato de idempotencia.
