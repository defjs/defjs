# Cancelar una llamada HTTP

Combina un `AbortController` de quien llama con un plazo límite mediante `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` y pasa la señal combinada con `client({ signal })`. Defjs clasifica una cancelación manual de quien llama como `NET_ABORTED` y el vencimiento de un plazo como `NET_TIMEOUT`.

La cancelación informa de lo que observó el cliente; no garantiza que una mutación de escritura en el servidor haya sido revertida. Condiciona los reintentos de mutación a una clave de idempotencia. Consulta [Cancelación y límites de tiempo en HTTP](/es-ES/docs/http#cancel-the-work).
