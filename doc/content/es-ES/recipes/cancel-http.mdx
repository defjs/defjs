# Cancelar una llamada HTTP

Combina un `AbortController` de quien llama con un plazo límite mediante `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` y pasa la señal combinada con `client({ signal })`. Defjs clasifica una cancelación manual del llamador como `NET_ABORTED` y el vencimiento de un plazo como `NET_TIMEOUT`.

<Tabs items={["sdk/reports.ts", "app/main.ts", "cancel-report.ts"]}>
  <Tab value="sdk/reports.ts">
```ts
import { defineRequest } from "@defjs/core";

export const getReport = defineRequest({
  method: "GET",
  path: "/report",
});
```
  </Tab>
  <Tab value="app/main.ts">
```ts
import { createClient, withEndpoint } from "@defjs/core";
import { getReport } from "../sdk/reports.ts";

const client = createClient(withEndpoint("https://api.example.com"));

const controller = new AbortController();
const pending = getReport(
client({
signal: AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)]),
}),
);

controller.abort("screen closed");

async function main() {
const [error] = await pending;
if (error?.code === "NET_ABORTED") {
console.log("caller cancelled");
return;
}
if (error?.code === "NET_TIMEOUT") {
console.log("timed out");
return;
}
if (error) {
console.error(error.code);
return;
}
console.log("got the report");
}

void main();

````

La cancelación informa de lo que observó el cliente; no garantiza que una mutación de escritura en el servidor haya sido revertida. Protege los reintentos de mutación tras una clave de idempotencia. Consulta [Cancelación y límites de tiempo en HTTP](/es-ES/docs/http#cancel-the-work).
