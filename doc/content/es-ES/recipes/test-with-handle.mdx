# Prueba con un handle Fetch local

`withHTTPHandle(...)` sustituye Fetch solo para ese cliente. Sigues teniendo construcción de URL, interceptores, despacho por estado y decodificación Struct — sin DNS, TLS ni un servidor real.

Ver detalles en [Cliente](/es-ES/docs/client).
