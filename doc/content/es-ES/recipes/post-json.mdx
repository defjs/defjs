# Enviar JSON con POST

Pasa un objeto de entrada tipado al `builder` y devuelve `{ body: input }`. Declarar `.alias("customer_name")` conserva `customerName` en TypeScript mientras codifica `"customer_name"` en la red y lo decodifica de vuelta desde la respuesta `201`.

Con un servidor que responda `201` y `{ "id": 1, "status": "paid", "customer_name": "Ada" }`, el script imprime:

```txt
Created paid → 201
```
