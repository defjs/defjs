# Crear y publicar un SDK [#publish-an-http-sdk-without-hiding-execute]

Un SDK basado en Defjs exporta definiciones de operaciones puras y esquemas Struct como un paquete npm, dejando la llamada a `createClient(...)`, los endpoints, las credenciales y los interceptores en manos de la aplicación consumidora.

---

## 1. Definir el paquete del SDK

Mantén las definiciones de tus operaciones, las exportaciones del punto de entrada (barrel), `package.json` y `tsconfig.json` en un directorio de paquete dedicado, declarando `@defjs/core` como una `peerDependency`:

  <Tab value="src/index.ts">
```ts
export { getOrder } from "./orders";
```
  </Tab>
  <Tab value="package.json">
```json
{
  "name": "@company/orders-sdk",
  "version": "0.1.0",
  "type": "module",
  "sideEffects": false,
  "files": ["dist"],
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "default": "./dist/index.js"
    }
  },
  "scripts": {
    "build": "tsdown --platform neutral"
  },
  "peerDependencies": {
    "@defjs/core": "^0.6.0"
  },
  "devDependencies": {
    "@defjs/core": "^0.6.0",
    "tsdown": "^0.23.3",
    "typescript": "^7.0.2"
  }
}
```
  </Tab>
  <Tab value="tsconfig.json">
```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "lib": ["ES2022", "ESNext.Disposable", "DOM", "DOM.Iterable"],
    "strict": true,
    "noEmit": true
  },
  "include": ["src/**/*.ts"]
}
```
  </Tab>
</Tabs>

- `@defjs/core` se mantiene como una dependencia externa en tiempo de ejecución (`peerDependency`) compartida con la aplicación consumidora.
- `"sideEffects": false` permite a los empaquetadores eliminar código muerto (_tree-shaking_) cuando una aplicación importa únicamente un subconjunto de operaciones.

---

## 2. Construir y verificar el archivo tarball

Empaqueta `dist/index.js` y `dist/index.d.ts` con `tsdown`, e inspecciona el contenido del paquete antes de publicarlo:

```sh
bun install
bun run build
bun pm pack --dry-run
bun pm pack
```

Comprueba que `dist/index.js` y `dist/index.d.ts` estén incluidos en el tarball.

---

## 3. Consumir el SDK en una aplicación

Instala tu SDK junto a `@defjs/core`:

```sh
bun add @company/orders-sdk @defjs/core@^0.6.0
```

La aplicación crea su propio `Client` y lo pasa a la operación importada:

<include cwd meta='title="app.ts"'>
  examples/recipes/publish-http-sdk/app.ts#example
</include>

```txt
paid
```

En código de producción, sustituye la importación relativa `./orders-sdk` por `@company/orders-sdk` y elimina `withHTTPHandle(...)` para utilizar el `fetch` nativo de la plataforma.

---

## 4. Probar y publicar

Ejercita tus definiciones exportadas con [pruebas en memoria con manejadores](/es-ES/recipes/test-with-handle) que cubran el mapeo de la petición, la decodificación de `output`, errores declarados `HTTP_STATUS` y la cancelación. Una vez verificadas, publica el paquete:

```sh
bun publish --access public
```

Consulta [Operaciones HTTP](/es-ES/docs/http), [Cliente](/es-ES/docs/client), [Pruebas](/es-ES/docs/testing) y [Arquitectura central](/es-ES/docs/design-decisions).
