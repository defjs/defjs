# Renueva un Bearer token una vez ante un 401

`next()` es el resto de **esta** cebolla — no un reenvío `axios(config)` desde fuera. Pon el attach, el refresh single-flight y un único replay en **un** interceptor HTTP para que las capas exteriores no corran dos veces.

Ver [Interceptores](/es-ES/docs/interceptors).

<include cwd meta="refresh-bearer.ts">
  examples/recipes/refresh-bearer-once.ts#example
</include>

```txt
42
```

Llamar a `next` otra vez solo vuelve a entrar en los interceptores **dentro** de esta capa (y en el handler de Fetch). No vuelve a ejecutar los wrappers exteriores de tiempo o auth — por eso el 401 va en un interceptor, no en una segunda llamada a la operación.
