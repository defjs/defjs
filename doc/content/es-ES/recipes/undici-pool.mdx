# Handle HTTP con Undici Pool

En BFFs y servicios backend de Node.js de alto rendimiento, inyecta un `undici.Pool` compartido mediante [`withHTTPHandle`](/es-ES/api/core/withhttphandle) para que múltiples conexiones upstream permanezcan activas y acotadas mientras las definiciones del SDK (`sdk/orders.ts`) siguen siendo completamente independientes de la plataforma. Recuerda llamar a `await pool.close()` durante el apagado.
