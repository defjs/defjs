# Desenvolver un envelope GraphQL por HTTP

Defjs no implementa `errorPolicy` de GraphQL. Modela el cable como un POST HTTP cuyo builder coloca el documento de query y las variables, y luego desenvuelve `errors[]` / un `data` ausente en tu propio helper.

Ver [Decisiones de diseño](/es-ES/docs/design-decisions).

El éxito HTTP solo significa que llegó el envelope. Los errores de aplicación se quedan en `errors[]` hasta que tu unwrap lance o devuelva.
