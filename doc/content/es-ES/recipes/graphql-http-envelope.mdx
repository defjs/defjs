# Desempaquetar una envoltura GraphQL sobre HTTP

Defjs no incluye un cliente de GraphQL ni una opción `errorPolicy`. Modela GraphQL sobre HTTP como una operación `POST` estándar cuyo `builder` envíe `{ query, operationName, variables }`. Marca `data` como `.nullish()` en el Struct de la envoltura para que tanto la omisión de `data` como `data: null` superen la validación estructural, y luego desempaqueta `errors[]` en una función auxiliar de tu aplicación:

- Un código HTTP `200` solo significa que la envoltura GraphQL llegó intacta. Los errores de dominio dentro de `errors[]` (incluso acompañados de `data: null`) son resultados del nivel de aplicación, no fallos `RES_STRUCT_MISMATCH`.
- Consulta [Arquitectura central](/es-ES/docs/design-decisions) para entender por qué las envolturas específicas de protocolo se gestionan en funciones auxiliares de la aplicación.
