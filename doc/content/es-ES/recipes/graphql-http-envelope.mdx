# Desempaquetar una envoltura GraphQL sobre HTTP

Defjs no incluye un cliente de GraphQL ni políticas de error propietarias. Modela GraphQL sobre HTTP como una operación `POST` estándar cuyo `builder` envíe `{ query, operationName, variables }`. Marca `data` como `.nullish()` en el Struct del sobre para que tanto la omisión de `data` como `data: null` superen la validación estructural, y luego desempaqueta `errors[]` en una función auxiliar de tu aplicación:

<Tabs items={["sdk/viewer.ts", "app/load-viewer.ts", "graphql-viewer.ts"]}>
  <Tab value="sdk/viewer.ts">
```ts
import { defineRequest, struct } from "@defjs/core";

const VIEWER_QUERY = "query Viewer { viewer { id login } }" as const;

export const runViewer = defineRequest({
  method: "POST",
  path: "/graphql",
  builder: () => ({
    body: { query: VIEWER_QUERY, operationName: "Viewer" },
  }),
  output: struct.object({
    data: struct
      .object({
        viewer: struct
          .object({ id: struct.string(), login: struct.string() })
          .null(),
      })
      .nullish(),
    errors: struct
      .array(struct.object({ message: struct.string() }))
      .optional(),
  }),
});
```
  </Tab>
  <Tab value="app/load-viewer.ts">
```ts
import type { Client } from "@defjs/core";
import { runViewer } from "../sdk/viewer.ts";

export async function loadViewer(client: Client) {
  const [error, result] = await runViewer(client);
  if (error) throw error;
  if (result.errors?.length) {
    throw new Error(result.errors.map((item) => item.message).join("; "));
  }
  if (!result.data) {
    throw new Error("GraphQL response contained neither data nor errors");
  }
  return result.data.viewer;
}
```

- Un código HTTP `200` solo significa que la envoltura GraphQL llegó intacta. Los errores de dominio dentro de `errors[]` (incluso acompañados de `data: null`) son resultados del nivel de aplicación, no fallos `RES_STRUCT_MISMATCH`.
- Consulta [Arquitectura central](/es-ES/docs/design-decisions) para entender por qué las envolturas específicas de protocolo se gestionan en asistentes del código de aplicación.
