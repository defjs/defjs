# Desenvolver un envelope GraphQL por HTTP

Defjs no implementa `errorPolicy` de GraphQL. Modela el cable como un POST HTTP cuyo builder coloca el documento de query y las variables. Declara el `data` del envelope como `.nullish()` para que tanto un `data` ausente como `data: null` lleguen a tu helper, y luego desenvuelve `errors[]` antes de comprobar `data`.

Ver [Decisiones de diseño](/es-ES/docs/design-decisions).


El éxito HTTP solo significa que llegó el envelope. Los errores de aplicación se quedan en `errors[]` hasta que tu unwrap lance o devuelva, incluida una respuesta con `data: null`. El ejemplo trata tanto un `data` ausente como `data: null` junto con `errors[]` como errores de aplicación, no como desajustes de Struct.
