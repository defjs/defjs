# Struct y esquemas

`struct` declara el contrato de datos en la red que comparten un SDK y sus consumidores: entradas de quien llama, salidas `2xx`, errores declarados del servicio, eventos SSE y tramas WebSocket.

- **Inferencia estática**: deriva tipos de TypeScript con `Infer<typeof Schema>`.
- **Validación con error por delante**: valida valores en tiempo de ejecución con `struct.parse(Schema, value)`, que devuelve `[null, data]` o `[StructError, undefined]` sin lanzar excepciones.

## 1. Definir un esquema en el SDK y validar en la aplicación

<Tabs items={["sdk/schema.ts", "app/validate.ts"]}>
<Tab value="sdk/schema.ts">

```ts
import { struct, type Infer } from "@defjs/core";

export const Order = struct.object({
  id: struct.number(),
  status: struct.enum(["pending", "paid", "shipped"] as const),
  customerName: struct.string().alias("customer_name"),
  notes: struct.string().optional(),
});

export type Order = Infer<typeof Order>;
```

Los objetos analizados conservan únicamente los campos declarados (las propiedades desconocidas se eliminan) y usan un prototipo `null`. Cualquier clave requerida que falte, tipo primitivo incorrecto o rama no válida genera un `StructError` sin salida parcial.

## 2. Campos requeridos, opcionales y nulleables

Defjs separa la **presencia del campo** (`undefined`) de la **admisión de nulos** (`null`). Todo constructor de struct es estrictamente obligatorio y no nulo de forma predeterminada:

| Declaración                  | Ausente / `undefined`                     | `null`  | Valor válido      |
| ---------------------------- | ----------------------------------------- | ------- | ----------------- |
| `struct.string()`            | Rechaza                                   | Rechaza | Acepta `string`   |
| `struct.string().optional()` | Acepta (se omite al serializar el objeto) | Rechaza | Acepta `string`   |
| `struct.string().null()`     | Rechaza                                   | Acepta  | Acepta `string`   |
| `struct.string().nullish()`  | Acepta (se omite al serializar el objeto) | Acepta  | Acepta `string`   |
| `struct.null()`              | Rechaza                                   | Acepta  | Rechaza no `null` |

<include cwd lang="typescript">
  examples/struct/required-optional-null.ts#example
</include>

`struct.any()` y `struct.unknown()` también rechazan `null` y `undefined` a menos que se encadenen con `.null()`, `.optional()` o `.nullish()`.

## 3. Alias de red bidireccionales (`.alias()`)

Usa `.alias("wire_name")` cuando el backend utilice `snake_case` o cabeceras específicas mientras tu SDK de TypeScript utiliza `camelCase`. Declaras el alias una sola vez en el campo y funciona en ambas direcciones:

| Frontera                                                                   | Clave utilizada                                |
| -------------------------------------------------------------------------- | ---------------------------------------------- |
| `input` de la operación y `struct.parse(Schema, value)`                    | Nombre lógico (`customerName`)                 |
| Valor de struct tipado devuelto por `builder` (`body`, `query`, `headers`) | Alias de red (`customer_name`)                 |
| Decodificación de respuesta JSON / evento SSE / trama WebSocket            | `customer_name` en red → `customerName` lógico |
| Clave de objeto anónimo escrita directamente en `builder`                  | Clave literal tal como se escribió             |

<include cwd lang="typescript">
  examples/struct/aliases.ts#example
</include>

Hacer spread de un objeto tipado dentro de `builder` (`{ ...input.order, extra: 1 }`) conserva su codificación de struct y sus alias. Escribir tanto la clave lógica como su alias de red en el mismo objeto falla con `REQ_BUILD_FAILED`.

## 4. Ubicación en la petición y códecs de formulario

`input` define los parámetros; `builder` los coloca en `{ path, query, headers, body }`. Para cuerpos codificados en formulario, `struct.urlencoded(shape)` y `struct.formData(shape)` etiquetan el objeto raíz para que el transporte lo serialice automáticamente como `URLSearchParams` o `FormData`:

<include cwd lang="typescript">
  examples/struct/request-placement.ts#example
</include>

| Raíz del cuerpo devuelta por `builder`                | Formato en la red | `Content-Type` predeterminado                     |
| ----------------------------------------------------- | ----------------- | ------------------------------------------------- |
| Objeto tipado, array, número finito, booleano, `null` | Texto JSON        | `application/json`                                |
| Struct de `string` o `string` sin procesar            | Texto UTF-8       | `text/plain;charset=UTF-8`                        |
| `struct.urlencoded(shape)` en la raíz del cuerpo      | `URLSearchParams` | `application/x-www-form-urlencoded;charset=UTF-8` |
| `struct.formData(shape)` en la raíz del cuerpo        | `FormData`        | `multipart/form-data; boundary=...`               |
| `Blob` / `File` (`struct.file()`)                     | Blob binario      | `blob.type` o `application/octet-stream`          |
| `ArrayBuffer` / vista / `ReadableStream`              | Bytes directos    | `application/octet-stream`                        |

## 5. Gestión de `StructError` e incidencias (_issues_)

`struct.parse(Schema, data, { aliases?, errorMap? })` devuelve `[StructError, undefined]` en caso de fallo. `StructError` extiende la clase nativa `Error` y ofrece `issues`, `format()`, `flatten()` y `prettify()`:

<include cwd lang="typescript">
  examples/struct/parse-failures.ts#example
</include>

Cada `StructIssue` contiene `code` (`invalid_type`, `missing_key`, `invalid_literal`, `invalid_enum`, `invalid_union`, `invalid_intersection` o `custom`), `path`, `expected`, `received` y `message`. Los mensajes predeterminados reportan únicamente el _tipo_ recibido (nunca el valor sin procesar de la carga) para que ni `String(error)` ni `error.prettify()` filtren datos confidenciales a los registros.

## 6. Referencia de constructores

<include cwd lang="typescript">
  examples/struct/any.ts#example
</include>

| Constructor                                                | Entrada admitida                        | Salida inferida                                           |
| ---------------------------------------------------------- | --------------------------------------- | --------------------------------------------------------- |
| `struct.string()` / `struct.boolean()`                     | Primitivo coincidente                   | `string` / `boolean`                                      |
| `struct.number()`                                          | Cualquier `number` excepto `NaN`        | `number` (`NaN` rechazado; `±Infinity` rechazado en JSON) |
| `struct.bigint()`                                          | `bigint` o cadena numérica              | `bigint`                                                  |
| `struct.date()`                                            | `Date` válido, marca temporal o ISO     | `Date`                                                    |
| `struct.literal(value)`                                    | Primitivo literal exacto                | Tipo literal                                              |
| `struct.enum(values)`                                      | Miembro declarado como string o número  | Unión de literales                                        |
| `struct.array(item)` / `struct.tuple(items)`               | Array / tupla de longitud fija          | `T[]` / `[...]`                                           |
| `struct.object(shape)` / `struct.record(val)`              | Objeto plano                            | Objeto tipado / `Record<string, V>`                       |
| `struct.discriminatedUnion(key, options)`                  | Objeto con discriminador literal `key`  | Unión de ramas de objeto                                  |
| `struct.or(branches)`                                      | Primera rama coincidente                | Unión de tipos de las ramas                               |
| `struct.intersection(members)`                             | Valor que cumple con todos los miembros | Intersección combinada en profundidad                     |
| `struct.file()` / `struct.blob()` / `struct.arrayBuffer()` | `File` / `Blob` / `ArrayBuffer`         | Representación binaria                                    |
