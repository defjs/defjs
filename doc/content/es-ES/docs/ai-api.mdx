Este sitio publica Markdown en inglés para asistentes. Estas direcciones no tienen prefijo de idioma y no son traducciones de las guías localizadas.

## Índice de páginas [#llms-txt]

[llms.txt](/llms.txt) enumera las páginas en inglés y enlaza a sus URL. Es el punto de entrada cuando un asistente necesita encontrar primero una página.

## Guías compiladas [#llms-full]

[llms-full.txt](/llms-full.txt) reúne las guías en inglés en un solo archivo. Úsalo cuando el asistente necesite un contexto amplio en un único documento y el presupuesto de tokens lo permita.

## Una página como Markdown [#page-markdown]

Cada página en inglés también está disponible como Markdown en `/llms.mdx/<path>/content.md`. Por ejemplo, [Quick start como Markdown](/llms.mdx/docs/start/content.md) es el texto inglés de la página Quick start.

## Comprobar la versión [#version]

Este sitio documenta la rama predeterminada; el proyecto puede instalar otra versión de `@defjs/core`. Verifica las API con el paquete instalado antes de aplicar una sugerencia. Elimina secretos y revisa las políticas del proyecto antes de compartir código o contexto con una herramienta de IA.
