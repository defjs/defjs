# Visión general de integraciones

Una integración extiende el propio `Client` de la aplicación en un punto de extensión definido sin modificar `@defjs/core` ni acoplar una definición de SDK a un framework o stack de telemetría específico. Tus definiciones de SDK siguen siendo módulos puros de `@defjs/core`; la aplicación consumidora elige qué integraciones instalar.

Cada plugin de Defjs respeta el **contrato de plugin ligero**:

- **Sin almacenamiento en caché ni estado ocultos**: los plugins nunca guardan respuestas, no reintentan peticiones por su cuenta ni gestionan el estado de consultas.
- **Sin sustitución de transporte**: los plugins nunca envuelven ni reemplazan el transporte subyacente de HTTP, SSE o WebSocket.
- **Ciclo de vida bajo control del llamador**: desmontar un proveedor en la interfaz o apagar un SDK de telemetría no cancela automáticamente peticiones en curso ni cierra flujos activos.

## Dos arquitecturas de plugins

### 1. Plugins de framework (`@defjs/react`, `@defjs/vue`)

Un plugin de framework transmite un [`DerivableClient`](/es-ES/api/core/derivableclient-type) existente a través del árbol de componentes mediante inyección de dependencias nativa (Context de React o `provide` / `inject` de Vue):

<Tabs items={["sdk/orders.ts", "app/main.tsx", "app/OrderCard.tsx"]}>
<Tab value="sdk/orders.ts">

```ts
import { defineRequest, struct } from "@defjs/core";

export const Order = struct.object({
  id: struct.number(),
  status: struct.string(),
});

export const getOrder = defineRequest({
  method: "GET",
  path: "/orders/:id",
  input: struct.object({ id: struct.number() }),
  builder: (input) => ({ path: { id: input.id } }),
  output: Order,
});
```

</Tab>
<Tab value="app/main.tsx">

```tsx
import { createClient, withEndpoint } from "@defjs/core";
import { ClientProvider } from "@defjs/react";
import { OrderCard } from "./OrderCard.tsx";

const client = createClient(withEndpoint("https://api.example.com"));

export function App() {
  return (
    <ClientProvider client={client}>
      <OrderCard id={42} />
    </ClientProvider>
  );
}
```

</Tab>
<Tab value="app/OrderCard.tsx">

```tsx
import { useClient } from "@defjs/react";
import { getOrder } from "../sdk/orders.ts";

export function OrderCard({ id }: { id: number }) {
  const client = useClient();
  // Pasa `client` o `client({ signal })` a `getOrder(...)` dentro de un efecto o hook de consulta
  void id;
  void getOrder;
  void client;
  return null;
}
```

</Tab>
</Tabs>

### 2. Plugins de middleware (`@defjs/opentelemetry-server`)

Un plugin de middleware es una factoría que devuelve un [`ClientOption`](/es-ES/api/core/clientoption-type). Al pasarse a `createClient(...)`, añade interceptores HTTP, SSE o WebSocket mediante `withInterceptors`:

<Tabs items={["plugins/request-id.ts", "app/client.ts"]}>
<Tab value="plugins/request-id.ts">

</Tab>
<Tab value="app/client.ts">

```ts
import { createClient, withEndpoint } from "@defjs/core";
import { withRequestIdHeader } from "../plugins/request-id.ts";

export const client = createClient(
  withEndpoint("https://api.example.com"),
  withRequestIdHeader(),
);
```
