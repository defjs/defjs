<ApiReference identity="@defjs/vue:injectClient" />

```ts
function injectClient(): Client
```

가장 가까운 `HTTP_CLIENT` provider를 읽어요. `setup()`처럼 Vue의 `inject`를 쓸 수 있는 곳에서 호출하세요.

- **반환** 주입된 클라이언트예요.
- **던짐** 클라이언트가 제공되지 않았을 때, 예를 들어 플러그인을 설치하지 않았을 때 `Error`를 던져요.
