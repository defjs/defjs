```ts
type AnyFault = DecodeFault | HttpStatusFaultOf<undefined> | HttpStatusFaultOf<unknown> | PreflightFault
```

디코딩된 오류 body 타입과 상관없이 모든 fault를 가리켜요. 어느 엔드포인트가 냈는지 신경 쓰지 않고 fault를 분류하는 핸들러에 쓰세요. body 타입이 중요한 곳에서는 `Fault<typeof yourErrorStruct>`를 고르세요.
