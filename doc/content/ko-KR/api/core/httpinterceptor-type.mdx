```ts
interface HttpInterceptor {
  kind: 'http'
  fn: InterceptorFn
}
```

`createHttpInterceptor`가 만들어요. `kind`는 `withInterceptors`가 HTTP, SSE, WebSocket 인터셉터를 한 목록으로 받을 수 있게 해 주는 판별자예요.
