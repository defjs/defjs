<ApiReference identity="@defjs/core:withSSEHandle" />

```ts
function withSSEHandle(fetchImpl: FetchHandle): ClientOption
```

SSE 이벤트 스트림을 여는 Fetch 호환 함수를 바꿔요. 기본값은 플랫폼의 `fetch`예요.

- **fetchImpl**은 [`FetchHandle`](/ko-KR/api/core/fetchhandle-type)이에요.
- SSE에만 영향을 줘요. HTTP는 [`withHTTPHandle`](/ko-KR/api/core/withhttphandle)을 써요.
