<ApiReference identity="@defjs/core:Interceptor" />

```ts
type Interceptor = HttpInterceptor | SSEInterceptor | WebSocketInterceptor
```

`kind`(`'http'`, `'sse'`, `'web-socket'`)가 인터셉터를 어떤 명령에서 실행할지 정해요. `withInterceptors`는 어떤 조합이든 받고, 각 전송은 자기 kind의 인터셉터만 등록 순서대로 실행해요.
