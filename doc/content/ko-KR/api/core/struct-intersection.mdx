<ApiReference identity="@defjs/core:struct.intersection" />

```ts
function intersection<const T extends readonly [StructLike, ...StructLike[]]>(
  ...structs: T
): T extends readonly [unknown]
  ? T[0]
  : T extends readonly [unknown, unknown, ...unknown[]]
    ? IntersectionStruct<T>
    : T[0] | IntersectionStruct<T>
```

`struct.intersection`은 가변 인자 함수예요. 각 struct를 별도 인자로 넘기세요.

- 모든 struct로 입력을 파싱하고 결과를 병합해요.
- 모든 struct가 객체 struct이면, 출력은 이들의 필드를 모두 가진 객체 하나예요. 어느 struct도 선언하지 않은 키는 제거돼요.
- 두 struct가 같은 키에 호환되지 않는 값을 만들면 `invalid_intersection`으로 실패해요.
- `.null()`로 표시된 중첩 교차 struct를 포함해 모든 struct가 `null`을 허용할 때만 `null`을 허용해요.
- struct 하나만 주면 그대로 반환하므로 `.optional()`과 `.null()`을 포함한 원래 타입을 유지해요. struct 없이 호출하면 `TypeError`를 던지고, struct가 아닌 인자도 마찬가지예요.
- 멤버가 하나뿐일 수도 있는 튜플을 펼치면 단일 멤버와 여러 멤버의 결과를 모두 추론해요. 따라서 결과의 객체 필드가 선택적일 수 있어요. 멤버가 최소 두 개인 것으로 알려진 튜플에서는 교차 타입의 필수 필드 규칙이 유지돼요.

`IntersectionStruct<T>`는 export되지 않아요. 입력과 출력이 멤버 타입들의 교차 타입인 `Struct`예요.
