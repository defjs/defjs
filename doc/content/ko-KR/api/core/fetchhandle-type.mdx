---

<ApiReference identity="@defjs/core:FetchHandle" />

```ts
type FetchHandle = (input: RequestInfo | URL, init?: RequestInit) => Promise<Response>
```

Defjs가 호출하는 `(input, init?) => Promise<Response>` 호출 시그니처예요. 일부러 `typeof fetch`로 하지 않아서, mock이 `preconnect` 같은 호스트의 추가 멤버를 갖출 필요가 없어요. HTTP는 손대지 않은 플랫폼 Fetch를 `(url, init)`으로 호출하고, 교체된 전역 Fetch나 사용자 지정 handle은 `Request`를 받아요. 기본값은 호출마다 전역을 해석해요. SSE는 기본 handle을 포함해 항상 `Request`를 넘겨요.

`withHTTPHandle`, `withSSEHandle`, `fetchHandler`가 받아요.
