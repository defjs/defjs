<ApiReference identity="@defjs/core:WebSocketHandle" />

```ts
type WebSocketHandle = Omit<
  WebSocket,
  | 'binaryType'
  | 'CLOSED'
  | 'CLOSING'
  | 'CONNECTING'
  | 'dispatchEvent'
  | 'onclose'
  | 'onerror'
  | 'onmessage'
  | 'onopen'
  | 'OPEN'
  | 'readyState'
> & { readonly readyState: number }
```

이벤트 핸들러 프로퍼티, `binaryType`, `dispatchEvent`, 상태 상수를 뺀 DOM `WebSocket`이에요. 그래서 직접 만든 구현에는 `url`, `protocol`, `extensions`, `bufferedAmount`, `send`, `close`, `addEventListener`, `removeEventListener`, 숫자형 `readyState`가 필요해요.

전송은 그 프로퍼티가 있으면 `binaryType = 'arraybuffer'`로 설정하고, 없으면 무시해요. setter가 throw하면 만든 handle을 최선을 다해 닫은 뒤 그 시도를 `NET_UNREACHABLE`로 실패시켜요. 소켓을 정리 밖에 두지 않아요. 이 프로퍼티는 최적화이고, 디코더는 Blob 프레임도 받아요. [`WebSocketHandleConstructor`](/ko-KR/api/core/websockethandleconstructor-type)가 만들어 내는 인스턴스 타입이에요.
