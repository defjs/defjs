<ApiReference identity="@defjs/core:ERR_ABORTED" />

```ts
const ERR_ABORTED: Error // message: 'Request was aborted'
```

호출자의 취소를 나타내는 공유 `cause`이자 message 값이에요. `createNetworkFault`는 이것과, 이름이 `AbortError`인 `DOMException`을 `NET_ABORTED`로 매핑해요. HTTP 인터셉터가 이것을 던지면 호출은 `NET_ABORTED` fault로 resolve돼요. SSE와 WebSocket 인터셉터가 던지면 `EXT_INTERCEPTOR_FAILED`로 보고돼요.
