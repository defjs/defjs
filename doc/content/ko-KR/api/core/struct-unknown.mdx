<ApiReference identity="@defjs/core:struct.unknown" />

```ts
function unknown(): Struct<NonNullable<unknown>, unknown>
```

- `null`과 `undefined`를 뺀 모든 값을 받아 그대로 돌려줘요. 안쪽은 검증하지도 제거하지도 않아요.
- `null`이나 `undefined`도 받으려면 `.null()`, `.optional()`, `.nullish()`를 이어 붙이세요.
- 출력 타입은 `unknown`이라서, 쓰기 전에 호출하는 쪽에서 좁혀야 해요.
