<ApiReference identity="@defjs/core:createDecodeFault" />

```ts
function createDecodeFault(code: DecodeFaultCode, cause: unknown, response: HttpMeta): DecodeFault
```

- **code** — 읽기의 어느 단계가 실패했는지를 나타내요. `RES_DECODE_FAILED`, `RES_MEDIA_TYPE_INVALID`, `RES_STRUCT_MISMATCH` 중 하나예요.
- **cause** — 밑바탕의 파서 또는 struct 실패이며, `cause`로 보관돼요. 보통 그 message가 fault의 message가 돼요 (`Error`가 아니면 `String(cause)`). `RES_DECODE_FAILED`이고 이름이 `SyntaxError`인 `Error`이면 message는 `Response body could not be decoded`가 되어, 파서 조각이 `String(fault)`에 들어가지 않아요. 기본 Struct message는 받은 종류를 담고 값은 담지 않아요. 원본 값과 파서 텍스트는 cause에 남아요.
- **response** — 읽을 수 없었던 응답의 메타데이터예요. `status`를 여기서 복사해요.
- **반환** `body`가 없는, 이름이 `DefjsFault`인 네이티브 `Error`예요.
