<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

`true`이면 Fetch가 HTTP와 SSE 요청에 `credentials: 'include'`를 써서 쿠키와 그 밖의 자격 증명이 cross-origin 요청에도 함께 전송돼요. `false`이거나 설정하지 않으면 `credentials`를 지정하지 않으므로 Fetch의 기본 동작을 따라요.

WebSocket 생성자에는 이 설정이 전달되지 않아요.
