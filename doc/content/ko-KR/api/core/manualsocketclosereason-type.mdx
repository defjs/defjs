<ApiReference identity="@defjs/core:ManualSocketCloseReason" />

```ts
type ManualSocketCloseReason = {
  code?: number
  kind: 'manual-web-socket-close'
  reason?: string
}
```

`session.close(code?, reason?)`에 넘긴 `code`와 `reason`을 기록해요. 상대의 close 이벤트에 값이 없으면, 최종 `{ kind: 'closed' }` close 정보의 `code`와 `reason`을 이 값으로 채워요. `close`는 `code`가 1000이 아니고 3000~4999 범위도 아니면, 그리고 `reason`이 UTF-8 123바이트를 넘으면 `DOMException`을 던져요.
