<ApiReference identity="@defjs/core:withXSRF" />

```ts
function withXSRF(options?: {
  cookieName?: string
  headerName?: string
  tokenProvider?: (context: { request: HttpRequest }) => string | null | undefined
}): ClientOption
```

**HTTP** 요청에 XSRF 토큰 전달을 켜요. SSE와 WebSocket 요청에는 헤더가 붙지 않아요.

- `cookieName`의 기본값은 `XSRF-TOKEN`이고 `headerName`의 기본값은 `X-XSRF-TOKEN`이에요.
- 헤더는 다음이 모두 성립할 때만 설정돼요. 메서드가 `GET`, `HEAD`, `OPTIONS`, `TRACE`가 아니고, 요청에 이미 그 헤더가 없고, 클라이언트에 endpoint가 있고, 브라우저에서는 요청 URL이 페이지와 same-origin이에요.
- `tokenProvider`가 없으면 토큰을 `document.cookie`에서 읽고 URL 디코딩해요. 브라우저 밖에는 쿠키가 없으므로 헤더가 설정되지 않아요.
- `tokenProvider`가 있으면 쿠키는 읽지 않아요. provider가 요청을 받고, 그 결과가 토큰이에요. 빈 문자열, `null`, `undefined`는 헤더를 설정하지 않는다는 뜻이에요.
