<ApiReference identity="@defjs/react:ClientProviderProps" />

```ts
interface ClientProviderProps {
  client: Client
  children?: ReactNode
}
```

- `client` — 필수예요. 애플리케이션이 소유하는 Defjs 클라이언트예요.
- `children` — 선택이에요. `useClient`를 호출할 수 있는 React 트리예요.
