# 로컬 Fetch 핸들로 테스트하기

`withHTTPHandle(...)`은 그 클라이언트의 Fetch만 바꿔요. DNS, TLS, 실제 서버 없이도 URL 구성, interceptor, status 디스패치, Struct 디코딩은 그대로예요.

자세한 내용은 [클라이언트](/ko-KR/docs/client)를 보세요.
