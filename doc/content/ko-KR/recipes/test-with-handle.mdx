# 로컬 Fetch 핸들로 테스트하기

`withHTTPHandle(...)`은 네트워크 소켓을 열지 않고도 단일 클라이언트 인스턴스의 기반 `fetch` 함수를 교체하여 입력값 검증, `builder` 매핑, URL 해석, 인터셉터, 상태 코드 분류, Struct 디코딩 등 전체 Defjs 파이프라인을 그대로 실행합니다:
