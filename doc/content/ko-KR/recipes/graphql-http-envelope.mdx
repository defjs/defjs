# GraphQL HTTP 엔벨로프 언래핑

Defjs는 별도의 GraphQL 클라이언트나 `errorPolicy`를 내장하지 않습니다. HTTP 상의 GraphQL은 `builder`가 `{ query, operationName, variables }`를 전송하는 표준 `POST` 작업으로 모델링하세요. 엔벨로프 Struct에서 `data`를 `.nullish()`로 선언하면 생략된 `data`와 `data: null` 모두 구조적 유효성 검증을 통과하며, `errors[]`는 애플리케이션 헬퍼 함수에서 언래핑합니다:

- HTTP `200`은 GraphQL 엔벨로프가 손상 없이 온전히 수신되었음을 의미할 뿐입니다. `errors[]` 내부의 비즈니스 도메인 오류(`data: null`과 함께 오는 경우 포함)는 `RES_STRUCT_MISMATCH` 결함이 아니라 애플리케이션 수준의 결과값입니다.
- 프로토콜별 엔벨로프 처리를 애플리케이션 헬퍼에 유지하는 이유에 대해서는 [핵심 아키텍처](/ko-KR/docs/design-decisions)를 참조하세요.
