# 동시성 제한 및 풀링된 호출

`Client`에서는 클라이언트 전체의 벌크헤드(선택적 `maxQueue` 오버플로 보호를 갖춘 FIFO 큐잉)로 `concurrencyLimitHttpInterceptor`를 사용하고, 해당 `Client`에 직접 바인딩된 fail-fast 또는 settled 병렬 호출에는 `@defjs/core/concurrent`(`concurrentMap`, `concurrentMapSettled`, `concurrentAll`, `concurrentAllSettled`)를 사용하세요.
