`{ "type": "subscribe", "symbol": "ACME" }` 요청에 대해 `{ "type": "tick", "symbol": "ACME", "price": 142.5 }`로 응답하는 서버를 대상으로 이 스크립트를 실행하면 다음과 같이 출력됩니다:

```txt
ACME 142.5
```

- 재연결(`withRetry`)과 하트비트(`withWebSocketHeartbeat`)는 모두 클라이언트에서 선택적으로 활성화(opt-in)합니다.
- 브라우저의 WebSocket은 업그레이드 핸드셰이크 중에 임의의 HTTP 헤더를 보낼 수 없으므로, 쿠키, 서브프로토콜, 또는 짧은 수명의 티켓을 대신 사용하세요. 자세한 내용은 [WebSocket 세션](/ko-KR/docs/web-socket) 문서를 참조하세요.
