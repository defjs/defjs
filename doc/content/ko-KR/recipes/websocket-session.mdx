# WebSocket 세션 열기

각 방향은 struct 하나예요. unsubscribe, `close`, `await session.closed`는 호출하는 쪽이 소유해요. 잘못된 프레임은 `onRuntimeError`로 가요.

자세한 내용은 [WebSocket](/ko-KR/docs/web-socket)을 보세요.

<include cwd meta="chat.ts">
  examples/recipes/websocket-session.ts#example
</include>

`chat.example.com`은 placeholder예요. `{ "type": "send", "text": "Hello" }`에 `{ "type": "message", "text": "Hello" }`로 응답하는 서버에서는 이 스니펫이 다음을 출력해요.

```txt
message Hello
```

재연결은 opt-in이에요 (`withWebSocketReconnect`). Heartbeat도 opt-in이에요. 브라우저 WebSocket은 임의 handshake 헤더를 받을 수 없어요. 쿠키, 서브프로토콜, 또는 짧은 수명의 티켓을 쓰세요.
