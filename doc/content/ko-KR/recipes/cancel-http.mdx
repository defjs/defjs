# HTTP 호출 취소하기

호출자의 신호와 데드라인을 `signal`에 합쳐요. `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])`은 신호 하나예요. 수동 취소는 `NET_ABORTED`로 분류돼요. 데드라인은 `NET_TIMEOUT`으로 분류돼요.

자세한 내용은 [HTTP](/ko-KR/docs/http#cancel-the-work)를 보세요.

<include cwd meta="cancel-report.ts">
  examples/recipes/cancel-http.ts#example
</include>

```txt
caller cancelled
```

취소는 호출자가 관찰한 결과를 알려 줘요. 서버 쪽 쓰기가 롤백됐다는 증명은 아니에요 — 변경 재시도는 멱등성 계약 뒤에 두세요.
