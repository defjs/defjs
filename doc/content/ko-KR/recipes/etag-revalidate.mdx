# ETag와 304로 재검증하기

`ok`는 2xx를 뜻해서 `304`는 `HTTP_STATUS` fault로 도착해요. 리다이렉트 status도 오류 body가 아니니 `error`는 선언하지 않은 채로 두세요. body는 읽히지 않고, fault가 status를 가져요. 캐시된 상품은 직접 돌려주세요.
