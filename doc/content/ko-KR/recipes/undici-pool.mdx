# Undici Pool HTTP 핸들

처리량이 높은 Node.js BFF 및 백엔드 서비스에서는 SDK 정의(`sdk/orders.ts`)를 완전히 플랫폼 중립적으로 유지하면서도, 여러 업스트림 연결을 warm 상태로 유지하고 제한하기 위해 [`withHTTPHandle`](/ko-KR/api/core/withhttphandle)을 통해 공유 `undici.Pool`을 주입하세요. 종료 시에는 반드시 `await pool.close()`를 호출해야 합니다.
