# POST JSON

타입화된 입력 객체를 `builder`에 전달하고 `{ body: input }`을 반환합니다. `.alias("customer_name")`을 사용하면 TypeScript 코드에서는 카멜케이스인 `customerName`을 유지하면서, 통신 시에는 `"customer_name"`으로 인코딩되고 `201` 응답으로부터 다시 올바르게 디코딩됩니다.

`201` 상태 코드와 함께 `{ "id": 1, "status": "paid", "customer_name": "Ada" }`를 반환하는 서버를 대상으로 이 스크립트를 실행하면 다음과 같이 출력됩니다:

```txt
Created paid → 201
```

자세한 내용은 [HTTP 작업](/ko-KR/docs/http) 및 [Struct 및 스키마](/ko-KR/docs/struct) 가이드를 참조하세요.
