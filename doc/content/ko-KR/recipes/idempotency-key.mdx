# 멱등성 키

기본적으로 `withRetry`는 멱등성이 보장되는 HTTP 메서드(`GET`, `HEAD`, `PUT`, `DELETE`, `OPTIONS`, `TRACE`)만 재시도합니다. `POST` 또는 `PATCH` 엔드포인트에 재시도를 활성화할 때는 `withRetry`와 `idempotencyKeyHttpInterceptor()`를 함께 사용하여, 동일한 논리적 호출의 모든 재시도 시도가 `req.correlationId`를 `Idempotency-Key` 헤더로 재사용하고 이후 새 호출에는 새로운 키가 발급되도록 하세요.
