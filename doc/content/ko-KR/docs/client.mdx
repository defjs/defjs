# Client

`Client`는 SDK를 사용하는 애플리케이션의 런타임 실행 환경 설정을 담고 있습니다: 기본 URL, 기본 헤더, 자격 증명, 인터셉터, 쿼리 직렬화, 전송 계층 핸들 등을 관리합니다.

`createClient(...options)`는 [`DerivableClient`](/ko-KR/api/core/derivableclient-type)를 반환합니다:

- 호출별 요청 옵션이 필요하지 않을 때는 `client`를 작업에 직접 전달합니다 (`getOrder(client, { id: 1 })`).
- 호출별 옵션이 필요할 때는 `client(requestOptions)`를 호출하여 단일 호출용 `Client` 값을 파생(derive)합니다 (`getOrder(client({ signal }), { id: 1 })`). 파생 과정에서는 I/O가 전혀 발생하지 않으며, 반환된 파생 객체는 순수 객체(호출 불가능)입니다.

### 옵션 합성 규칙

- 옵션은 **왼쪽에서 오른쪽** 순서로 적용됩니다.
- 단일 값 설정자(`withEndpoint`, `withHeaders`, `withQuerySerializer`, `withCredentials`, `withXSRF`)는 이전 값을 **대체**합니다.
- `withInterceptors(...items)`는 기존 인터셉터 목록의 뒤에 **추가**되며, 작업이 실행될 때 전송 방식(`http`, `sse`, `web-socket`)에 따라 필터링되어 적용됩니다.

> [!IMPORTANT]
> `createClient(...)`가 반환하는 값은 호출 가능한 함수(`DerivableClient`)이므로, 함수를 업데이터나 getter로 취급하는 React의 `setState(client)` 또는 Vue의 `watch(client)` / `computed(client)` 소스로 직접 전달해서는 **안 됩니다**.

### 호출별 `RequestOptions` 레퍼런스

`RequestOptions`는 7개의 평면 필드를 갖습니다. 각 전송 방식은 자신에게 해당하는 필드만 읽고 나머지는 무시합니다:

| 필드                 | 대상 전송 방식       | 동작 설명                                                                                                                          |
| -------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `signal`             | HTTP, SSE, WebSocket | 호출 취소 (`AbortSignal.timeout(ms)` → `NET_TIMEOUT`, 수동 abort → `NET_ABORTED`).                                                 |
| `onUploadProgress`   | HTTP                 | 스트리밍 요청 본문 업로드 진행률 보고.                                                                                             |
| `onDownloadProgress` | HTTP                 | 선언된 응답 본문 다운로드 진행률 보고.                                                                                             |
| `beforeConnect`      | WebSocket            | 이 세션에 한해 클라이언트 수준의 `beforeConnect` 훅을 대체.                                                                        |
| `protocols`          | WebSocket            | 이 세션에 한해 클라이언트 수준의 서브프로토콜 목록을 대체.                                                                         |
| `heartbeat`          | WebSocket            | 이 세션에 한해 클라이언트 수준의 하트비트 설정을 대체.                                                                             |
| `reconnect`          | WebSocket            | 이 세션에 한해 클라이언트 수준의 WebSocket 재연결 정책을 대체. (SSE 재연결은 클라이언트 수준에서 `withSSEReconnect`로 구성합니다.) |

## 3. 브라우저 싱글톤 vs. 서버 요청 스코프

- **브라우저 애플리케이션**: 엔드포인트, 인터셉터, 자격 증명이 브라우저 전역에서 공유될 때는 모듈 스코프의 단일 `DerivableClient`를 공유하여 사용합니다.
- **서버 / SSR 애플리케이션**: 헤더, 쿠키, 인증 토큰, 테넌트 컨텍스트가 요청마다 다를 때는 반드시 **각 수신 요청 경계 내부에서** 매번 새로운 클라이언트를 생성해야 합니다. 프로세스 전역 클라이언트에 사용자별 자격 증명을 저장해서는 절대 안 됩니다.

## 4. 다중 엔드포인트 및 로드 밸런싱 [#multiple-endpoints]

`withEndpoint(...urls)`는 하나 이상의 후보 기본 URL을 전달받을 수 있습니다. 기본 동작은 다음과 같습니다:

- 각 클라이언트는 [`pickFirstBalancer`](/ko-KR/api/core/pickfirstbalancer)를 기본으로 사용하여, `NET_UNREACHABLE` 실패나 코드화되지 않은 `502`/`503`/`504` 응답이 발생하여 다음 엔드포인트로 넘어가기 전까지 첫 번째 URL을 계속 유지합니다.
- 안전한 HTTP 메서드(`GET`, `HEAD`, `OPTIONS`, `TRACE`)는 연결 실패(`NET_UNREACHABLE`) 시 공유 Finagle 재시도 예산(`withEndpointFailover`)의 통제하에 아직 시도하지 않은 백업 엔드포인트로 **동일 호출 내 자동 장애 조치(same-call failover)**를 수행합니다.

### 헬스 필터링 및 p2c [#health-filtering-and-p2c]

동일한 역할을 하는 서버 레플리카 집합의 경우, [`roundRobinBalancer`](/ko-KR/api/core/roundrobinbalancer) 및 [`p2cBalancer`](/ko-KR/api/core/p2cbalancer)(PeakEwma RTT × 진행 중인 부하)가 기본적으로 Linkerd 스타일의 연속 실패 기반 서킷 브레이킹(`outlierDetection`)을 활성화합니다.

재시도 예산, 능동/수동 헬스 체크, P2C 부하 추정, 커스텀 밸런서에 대한 자세한 내용은 [로드 밸런싱 및 장애 조치](/ko-KR/docs/load-balancing) 가이드를 참조하세요.

## 6. 클라이언트 옵션 헬퍼 레퍼런스

| 헬퍼                                                                                                          | 목적                                                                                  |
| ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `withEndpoint(...urls)`                                                                                       | 하나 이상의 후보 기본 URL 설정 (이전 목록을 완전히 대체).                             |
| `withHeaders(HeadersInit)`                                                                                    | HTTP 및 SSE용 정적 기본 헤더 설정 (builder 헤더가 우선).                              |
| `withInterceptors(...items)`                                                                                  | 양파 껍질 순서로 HTTP, SSE, WebSocket 인터셉터 추가.                                  |
| `withQuerySerializer(fn)`                                                                                     | 이미 별칭이 적용된 쿼리 객체를 쿼리 스트링으로 직렬화.                                |
| `withCredentials(boolean)`                                                                                    | `true`일 때 HTTP 및 SSE 요청에 대해 Fetch `credentials: "include"` 설정.              |
| `withXSRF(options?)`                                                                                          | 동일 출처의 변경 HTTP 요청에 XSRF 쿠키 값을 헤더로 복사.                              |
| `withEndpointBalancer(balancer)`                                                                              | 엔드포인트 선택 전략 교체 (`pickFirstBalancer`, `roundRobinBalancer`, `p2cBalancer`). |
| `withEndpointFailover(options?)`                                                                              | 동일 호출 내 HTTP 장애 조치 및 클라이언트 재시도 예산 구성.                           |
| `withSSEReconnect` / `withSSEOnInvalidEvent`                                                                  | SSE 재연결 및 유효하지 않은 이벤트 관측 구성.                                         |
| `withWebSocketReconnect` / `withWebSocketHeartbeat` / `withWebSocketProtocols` / `withWebSocketBeforeConnect` | WebSocket 세션 기본 동작 구성.                                                        |
| `withHTTPHandle` / `withSSEHandle` / `withWebSocketHandle`                                                    | 커스텀 또는 테스트 모의 전송 구현체 주입.                                             |
