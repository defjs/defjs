# Vue

`@defjs/vue`는 `createClientPlugin(client)`, `HTTP_CLIENT`, `injectClient()`를 통해 애플리케이션이 소유하는 `@defjs/core` 클라이언트를 Vue 3.2+ 애플리케이션에 연결합니다. 여러분의 SDK 정의는 Vue에 대한 의존성이 전혀 없는 순수한 `@defjs/core` 모듈로 유지됩니다.

```sh
bun add @defjs/core @defjs/vue vue
```

## `@defjs/vue`의 역할 vs. 애플리케이션의 역할

- **`@defjs/vue`가 제공하는 것**: `createClientPlugin(client)`, `HTTP_CLIENT` (`InjectionKey<DerivableClient>`), `injectClient(key?)`.
- **애플리케이션이 소유하는 것**: [`DerivableClient`](/ko-KR/api/core/derivableclient-type) 생성, watcher(`onCleanup`)나 composable(`onScopeDispose`)에서의 진행 중인 작업 취소, SSE/WebSocket 핸들 닫기, Vue Query 등 쿼리 라이브러리 연동.
- **중요**: `injectClient()`는 함수 객체인 `DerivableClient`를 반환합니다. 작업이 실행되는 위치에서 `client({ signal })`을 호출하세요(`getOrder(client({ signal }), input)`). Vue는 함수 인자를 반응형 getter로 취급하므로, `client`를 `watch(client, ...)`의 첫 번째 인자나 `computed(client)`에 직접 전달해서는 절대 안 됩니다.

## 2. 하위 트리에서 클라이언트 주입 및 재정의

`injectClient(key?)`는 `key`(기본값 `HTTP_CLIENT`)에 해당하는 가장 가까운 프로바이더를 조회하며, 활성화된 Vue 주입 컨텍스트(`setup()` 또는 `app.runWithContext()`) 외부에서 호출되거나 해당 키에 대한 클라이언트가 제공되지 않은 경우 `Error`를 던집니다.

Vue의 네이티브 `provide(HTTP_CLIENT, childClient)`를 사용하여 특정 컴포넌트 하위 트리에 대해 클라이언트를 재정의할 수 있습니다:

<include cwd>examples/vue/inject-and-override.vue#example</include>

- 하위 컴포넌트는 `childClient`를 수신하며, 형제(sibling) 서브트리는 루트 클라이언트를 그대로 유지합니다.
- 헬퍼 함수가 선택적 명시 클라이언트를 허용하는 경우(`explicitClient ?? injectClient()`), 폴백 브랜치만 활성 Vue 주입 컨텍스트를 필요로 합니다. 클라이언트는 모든 `await` 이전인 `setup()` 실행 도중 동기식으로 캡처하세요.

## 3. 스코프 해제 시 SSE 및 WebSocket 스트림 정리

watcher 외부의 composable이나 컴포넌트 내부에서 시작된 작업의 경우, `AbortController`를 `onScopeDispose`와 함께 사용하세요. 이 signal은 시작 단계와 열린 스트림을 모두 포괄하므로 abort하는 것이 정리의 전부입니다. 단일 비동기 이터레이터를 소비한 뒤 `finally`에서 핸들을 닫고 `.closed`를 await하세요:

<include cwd>examples/vue/realtime-scope.vue#example</include>

- 튜플의 오류 분기는 HTTP 503을 포함한 초기 핸드셰이크 실패를 표시합니다. 이터레이터의 `catch`는 시작 후 실패를 표시하며, `finally` 블록은 여전히 스트림을 닫고 `.closed`를 await합니다.
- 스코프가 중지되면 SSE의 `for await` 루프는 정상적으로 종료됩니다.
- WebSocket 세션을 abort하면 세션이 `aborted` 상태로 종료되고 `session.receive`가 `AbortError`로 reject되므로, 스코프 해제 후에는 `catch` 블록에서 정리 상태를 걸러내고 `finally`에서 `onStateChange` / `onRuntimeError` 리스너를 구독 해제하세요.

## 4. SSR 및 애플리케이션 스코프

- **브라우저**: 엔드포인트와 인터셉터가 요청과 무관한 경우 Vue 앱당 단일 클라이언트를 공유합니다.
- **SSR**: 헤더, 쿠키, 테넌트, 자격 증명이 요청마다 다를 때는 각 SSR 요청마다 새로운 클라이언트를 생성하여 설치하세요.
- Vue 앱을 언마운트하거나 컴포넌트 스코프를 해제해도 HTTP 요청이 자동으로 취소되거나 SSE/WebSocket 스트림이 닫히거나 코어 클라이언트가 폐기되지 않습니다.
