# React

`@defjs/react`는 React Context와 `useClient()`를 통해 애플리케이션이 소유하는 `@defjs/core` 클라이언트를 React 18+ 컴포넌트 트리에 연결합니다. 작성된 SDK 정의는 React에 대한 의존성이 전혀 없는 순수한 `@defjs/core` 모듈로 유지됩니다.

```sh
bun add @defjs/core @defjs/react react
```

## `@defjs/react`의 역할 vs. 애플리케이션의 역할

- **`@defjs/react`가 제공하는 것**: `ClientProvider` 및 `useClient(overrideClient?)`.
- **애플리케이션이 소유하는 것**: [`DerivableClient`](/ko-KR/api/core/derivableclient-type) 생성, 언마운트나 의존성 변경 시 진행 중인 요청 취소(`AbortController`), SSE/WebSocket 핸들 닫기, TanStack Query와 같은 쿼리 캐시 라이브러리와의 통합.
- **중요**: `useClient()`는 함수 객체인 `DerivableClient`를 반환합니다. 작업이 실행되는 위치에서 `client({ signal })`을 호출하세요(`getOrder(client({ signal }), input)`). React 상태 설정자 함수에 함수 인자를 넘기면 업데이터 함수로 처리되므로, `client`를 `setState(client)`에 직접 전달해서는 절대 안 됩니다.

## 2. `useClient`로 읽기 및 재정의

`useClient(overrideClient)`는 `overrideClient`가 제공되면 이를 반환하고, 생략되거나 `undefined`이면 가장 가까운 `ClientProvider`에서 클라이언트를 읽어옵니다. 둘 다 클라이언트를 제공하지 못할 때만 `Error`를 던집니다.

<include cwd>examples/react/read-with-use-client.tsx#example</include>

- 항상 컴포넌트나 커스텀 Hook의 최상위 레벨에서 조건문 없이 `useClient(explicitClient)`를 호출하세요. Hooks의 규칙을 위반하는 `explicitClient ?? useClient()` 형태의 코드는 작성하지 마세요.

## 3. TanStack Query와의 통합

`@defjs/react`는 순수한 의존성 주입 도구이며 `useRequest` 같은 훅을 제공하지 **않습니다**. TanStack Query 같은 데이터 페칭 라이브러리를 사용할 때는 쿼리 함수의 `signal`을 `client({ signal })`로 전달하고 쿼리 어댑터 내부에서 error-first 튜플을 변환하세요:

<include cwd>examples/react/own-query-work.tsx#example</include>

여기서 `throw error`는 TanStack Query의 거부(rejection) 계약을 충족하기 위한 명시적 어댑터 경계이며, Defjs의 기본 호출 방식이 아닙니다.

## 4. effect 내부에서 SSE 및 WebSocket 수명 주기 관리

SSE 및 WebSocket 핸들은 최초 `openStream(...)`이나 `connectChat(...)` 호출 이후에도 계속 유지됩니다. 연결을 기다리기 전에 정리 로직을 등록하고, 언마운트된 후에 연결이 완료된 핸들을 닫아주며, 단일 비동기 이터레이터를 소비하고 `.closed`를 await하세요:

<include cwd>examples/react/own-realtime-work.tsx#example</include>

- WebSocket 작업에 전달된 `signal`을 abort하면 세션이 `aborted` 상태로 종료되고 `session.receive`가 `AbortError`로 reject됩니다. 정리된 후에는 `catch` 블록에서 정리 상태를 걸러내어 큐 오버플로나 하트비트 타임아웃 등 실제 런타임 오류만 표출되도록 하세요.
- SSE 스트림을 abort하면 예외를 던지지 않고 `for await (const msg of stream)` 루프가 깔끔하게 종료됩니다.

## 5. SSR 및 프로바이더 스코프

- **브라우저**: 엔드포인트와 인터셉터가 요청과 무관한 경우 모듈 스코프의 단일 클라이언트를 공유합니다.
- **SSR**: 헤더, 쿠키, 테넌트, 자격 증명이 요청마다 다를 때는 각 서버 요청 경계 내부에서 매번 새로운 클라이언트를 생성하세요.
- `<ClientProvider>`를 언마운트해도 활성 HTTP 호출이 자동으로 취소되거나 SSE/WebSocket 연결이 닫히거나 클라이언트가 폐기되지 않습니다.

- `useClient(overrideClient?)` — 명시적 재정의 클라이언트 또는 가장 가까운 프로바이더의 클라이언트 반환.
