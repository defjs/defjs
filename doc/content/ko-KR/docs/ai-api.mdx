이 사이트는 어시스턴트를 위한 영어 Markdown을 제공합니다. 아래 주소에는 로케일 접두사가 없으며, 번역된 가이드가 아닙니다.

## 페이지 색인 [#llms-txt]

[llms.txt](/llms.txt)는 영어 페이지 목록과 해당 웹 페이지 링크입니다. 어시스턴트가 먼저 페이지를 찾아야 할 때 시작점입니다.

## 합본 가이드 [#llms-full]

[llms-full.txt](/llms-full.txt)는 영어 가이드를 하나의 파일로 합칩니다. 하나의 문서에서 폭넓은 맥락이 필요하고 토큰 예산이 충분할 때 사용하세요.

## 페이지별 Markdown [#page-markdown]

모든 영어 페이지는 `/llms.mdx/<path>/content.md`에서도 Markdown으로 받을 수 있습니다. 예를 들어 [빠른 시작 Markdown](/llms.mdx/docs/start/content.md)은 빠른 시작 페이지의 영어 본문입니다.

## 버전 확인 [#version]

이 사이트는 기본 브랜치를 문서화합니다. 프로젝트에 설치된 `@defjs/core` 버전은 다를 수 있습니다. 제안을 적용하기 전에 설치된 패키지 기준으로 API를 확인하세요. AI 도구에 코드나 컨텍스트를 제공하기 전에 비밀을 제거하고 프로젝트 정책을 확인하세요.
