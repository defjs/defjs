# Revalidierung mit ETag und Status 304

In Defjs nimmt ausschließlich eine `2xx`-Antwort den Erfolgszweig, weshalb `304 Not Modified` als `HTTP_STATUS`-Fehler eintrifft. Lasse `error` an `defineRequest` undeklariert, damit der leere `304`-Body niemals eingelesen wird, und verwalte deinen `Map`-Cache in einem anwendungsseitigen Wrapper um den Operationsaufruf:

<Tabs items={["sdk/catalog.ts", "app/reader.ts", "etag-cache.ts"]}>
  <Tab value="sdk/catalog.ts">
```ts
import { defineRequest, struct, type Infer } from "@defjs/core";

export const Product = struct.object({
  sku: struct.string(),
  name: struct.string(),
  priceCents: struct.number(),
});

export type Product = Infer<typeof Product>;

export const readProduct = defineRequest({
  method: "GET",
  path: "/catalog/:sku",
  input: struct.object({
    sku: struct.string(),
    etag: struct.string().optional(),
  }),
  builder: (input) => ({
    path: { sku: input.sku },
    headers: { "If-None-Match": input.etag },
  }),
  output: Product,
});
```

  <Tab value="app/reader.ts">
```ts
import type { DerivableClient } from "@defjs/core";
import { readProduct, type Product } from "../sdk/catalog.ts";

export function createReader(client: DerivableClient) {
  const cache = new Map<string, { etag: string; product: Product }>();

return async (sku: string): Promise<Product> => {
const cached = cache.get(sku);
const [error, product, response] = await readProduct(client, {
sku,
etag: cached?.etag,
});

    if (error?.code === "HTTP_STATUS" && error.status === 304 && cached) {
      return cached.product;
    }
    if (error) throw error;

    const etag = response.headers.get("etag");
    if (!etag) throw new Error("missing ETag");
    cache.set(sku, { etag, product });
    return product;

};
}

````

- `if (error) throw error` nach der `304`-Prüfung bildet eine explizite Grenze für `createReader`, das ein `Promise<Product>` zurückgibt.
- Schreibe ein `304` niemals innerhalb eines Interceptors in ein synthetisches `200` um; halte den Cache-Zustand immer im Anwendungscode rund um den Operationsaufruf. Siehe [HTTP-Operationen](/de-DE/docs/http).
