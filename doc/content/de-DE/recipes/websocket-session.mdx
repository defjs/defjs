# Eine WebSocket-Sitzung öffnen

Deklariere `incoming`- und `outgoing`-Structs an `defineWebSocket` zusammen mit einer begrenzten `maxIncomingQueueSize`. Abonniere in deiner Anwendung `session.onRuntimeError(...)`, konsumiere `session.receive` und melde Listener immer ab, rufe `session.close(...)` auf und warte im `finally`-Block auf `await session.closed`:

<Tabs items={["sdk/quotes.ts", "app/main.ts", "quotes.ts"]}>
  <Tab value="sdk/quotes.ts">
```ts
import { defineWebSocket, struct } from "@defjs/core";

export const quotes = defineWebSocket({
  maxIncomingQueueSize: 100,
  path: "/quotes",
  incoming: struct.object({
    type: struct.literal("tick"),
    symbol: struct.string(),
    price: struct.number(),
  }),
  outgoing: struct.object({
    type: struct.literal("subscribe"),
    symbol: struct.string(),
  }),
});
```
  </Tab>
  <Tab value="app/main.ts">
```ts
import { createClient, withEndpoint } from "@defjs/core";
import { quotes } from "../sdk/quotes.ts";

const client = createClient(withEndpoint("https://quotes.example.com"));

async function main() {
const [error, session] = await quotes(client);
if (error) {
console.error(error.code);
return;
}
const unsubscribe = session.onRuntimeError((cause) =>
console.error("runtime", cause),
);
try {
session.send({ type: "subscribe", symbol: "ACME" });
for await (const message of session.receive) {
console.log(message.symbol, message.price);
break;
}
} finally {
unsubscribe();
session.close(1000, "consumer-finished");
await session.closed;
}
}

void main();

````

Antwortet der Server auf `{ "type": "subscribe", "symbol": "ACME" }` mit `{ "type": "tick", "symbol": "ACME", "price": 142.5 }`, gibt das Skript folgendes aus:

```txt
ACME 142.5
````

- Sowohl Reconnect (`withWebSocketReconnect`) als auch Heartbeat (`withWebSocketHeartbeat`) sind am Client Opt-in.
- Browser-WebSockets können beim Upgrade-Handshake keine beliebigen HTTP-Header senden; nutze stattdessen Cookies, Subprotokolle oder kurzlebige Tickets. Siehe [WebSocket-Sitzungen](/de-DE/docs/web-socket).
