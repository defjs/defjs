# WebSocket-Session öffnen

Jede Richtung ist ein Struct. Du besitzt das Abmelden, `close` und `await session.closed`. Ungültige Frames gehen an `onRuntimeError`.

Details siehe [WebSocket](/de-DE/docs/web-socket).

<include cwd meta="quotes.ts">
  examples/recipes/websocket-session.ts#example
</include>

`quotes.example.com` ist ein Platzhalter. Bei einem Server, der `{ "type": "subscribe", "symbol": "ACME" }` mit `{ "type": "tick", "symbol": "ACME", "price": 142.5 }` beantwortet, gibt das Snippet aus:

```txt
ACME 142.5
```

Reconnect ist opt-in (`withWebSocketReconnect`). Heartbeat ebenfalls. Browser-WebSockets können keine beliebigen Handshake-Headers nehmen — nutze Cookies, Subprotocols oder ein short-lived Ticket.
