# Eine WebSocket-Sitzung öffnen

Deklariere `incoming`- und `outgoing`-Structs an `defineWebSocket`. Abonniere in deiner Anwendung `session.onRuntimeError(...)`, konsumiere `session.receive` und melde Listener immer ab, rufe `session.close(...)` auf und warte im `finally`-Block auf `await session.closed`:

Antwortet der Server auf `{ "type": "subscribe", "symbol": "ACME" }` mit `{ "type": "tick", "symbol": "ACME", "price": 142.5 }`, gibt das Skript folgendes aus:

```txt
ACME 142.5
```

- Sowohl die Wiederverbindung (`withRetry`) als auch der Heartbeat (`withWebSocketHeartbeat`) sind am Client Opt-in.
- Browser-WebSockets können beim Upgrade-Handshake keine beliebigen HTTP-Header senden; nutze stattdessen Cookies, Subprotokolle oder kurzlebige Tickets. Siehe [WebSocket-Sitzungen](/de-DE/docs/web-socket).
