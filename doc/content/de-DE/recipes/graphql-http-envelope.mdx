# Einen GraphQL-HTTP-Envelope entpacken

Defjs bettet weder einen GraphQL-Client noch eine eigene `errorPolicy` ein. Modelliere GraphQL über HTTP als reguläre `POST`-Operation, deren `builder` `{ query, operationName, variables }` sendet. Markiere `data` am Envelope-Struct als `.nullish()`, sodass sowohl ein weggelassenes `data` als auch `data: null` die strukturelle Validierung passieren, und entpacke `errors[]` in einem Anwendungs-Helper:

<Tabs items={["sdk/viewer.ts", "app/load-viewer.ts", "graphql-viewer.ts"]}>
  <Tab value="sdk/viewer.ts">
```ts
import { defineRequest, struct } from "@defjs/core";

const VIEWER_QUERY = "query Viewer { viewer { id login } }" as const;

export const runViewer = defineRequest({
  method: "POST",
  path: "/graphql",
  builder: () => ({
    body: { query: VIEWER_QUERY, operationName: "Viewer" },
  }),
  output: struct.object({
    data: struct
      .object({
        viewer: struct
          .object({ id: struct.string(), login: struct.string() })
          .null(),
      })
      .nullish(),
    errors: struct
      .array(struct.object({ message: struct.string() }))
      .optional(),
  }),
});
```
  </Tab>
  <Tab value="app/load-viewer.ts">
```ts
import type { Client } from "@defjs/core";
import { runViewer } from "../sdk/viewer.ts";

export async function loadViewer(client: Client) {
  const [error, result] = await runViewer(client);
  if (error) throw error;
  if (result.errors?.length) {
    throw new Error(result.errors.map((item) => item.message).join("; "));
  }
  if (!result.data) {
    throw new Error("GraphQL response contained neither data nor errors");
  }
  return result.data.viewer;
}
```

- Ein HTTP `200` bedeutet lediglich, dass der GraphQL-Envelope unbeschädigt eingetroffen ist. Fachliche Fehler innerhalb von `errors[]` (selbst wenn sie von `data: null` begleitet werden) sind Ergebnisse auf Anwendungsebene und keine `RES_STRUCT_MISMATCH`-Fehler.
- Siehe [Kernarchitektur](/de-DE/docs/design-decisions) für die Hintergründe, warum protokollspezifische Envelopes in Helpern der Anwendung verbleiben.
