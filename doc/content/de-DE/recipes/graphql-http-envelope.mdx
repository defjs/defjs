# Einen GraphQL-HTTP-Envelope entpacken

Defjs bettet weder einen GraphQL-Client noch eine eigene `errorPolicy` ein. Modelliere GraphQL über HTTP als reguläre `POST`-Operation, deren `builder` `{ query, operationName, variables }` sendet. Markiere `data` am Envelope-Struct als `.nullish()`, sodass sowohl ein weggelassenes `data` als auch `data: null` die strukturelle Validierung passieren, und entpacke `errors[]` in einer Anwendungs-Hilfsfunktion:

- Ein HTTP `200` bedeutet lediglich, dass der GraphQL-Envelope unbeschädigt eingetroffen ist. Fachliche Fehler innerhalb von `errors[]` (selbst wenn sie von `data: null` begleitet werden) sind Ergebnisse auf Anwendungsebene und keine `RES_STRUCT_MISMATCH`-Faults.
- Siehe [Kernarchitektur](/de-DE/docs/design-decisions) für die Hintergründe, warum protokollspezifische Envelopes in Hilfsfunktionen der Anwendung verbleiben.
