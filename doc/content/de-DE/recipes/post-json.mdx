# JSON senden (POST)

Übergib ein typisiertes Eingabeobjekt an den `builder` und gib `{ body: input }` zurück. Mit `.alias("customer_name")` verwendest du in TypeScript weiterhin `customerName`, während auf Wire-Ebene automatisch `"customer_name"` kodiert und aus der `201`-Antwort dekodiert wird.

Antwortet der Server mit Status `201` und `{ "id": 1, "status": "paid", "customer_name": "Ada" }`, gibt das Skript folgendes aus:

```txt
Created paid → 201
```
