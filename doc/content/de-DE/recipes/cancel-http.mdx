# HTTP-Aufruf abbrechen

Kombiniere einen aufruferseitigen `AbortController` mit einer Frist über `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` und übergib das kombinierte Signal via `client({ signal })`. Defjs klassifiziert einen manuellen Abbruch durch den Aufrufer als `NET_ABORTED` und einen zeitlimitbedingten Abbruch als `NET_TIMEOUT`.

Ein Abbruch meldet lediglich, was der Client beobachtet hat – er garantiert keineswegs, dass eine serverseitige Mutation zurückgerollt wurde. Schütze Wiederholungsversuche bei Mutationen durch Idempotenz-Schlüssel. Siehe [HTTP-Abbruch und Zeitlimits](/de-DE/docs/http#cancel-the-work).
