# HTTP-Aufruf abbrechen

Kombiniere das Signal des Aufrufers mit einer Deadline auf `abort`. `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` ist ein Signal. Ein manueller Abbruch wird als `NET_ABORTED` klassifiziert. Eine Deadline wird als `NET_TIMEOUT` klassifiziert.

Details siehe [HTTP](/de-DE/docs/http#cancel-the-work).

<include cwd meta="cancel-report.ts">

</include>

```txt
caller cancelled
```

Cancellation sagt dir, was der Caller beobachtet hat. Sie beweist nicht, dass ein server-seitiger Write zurückgerollt wurde — halte Mutation-Retries hinter einem Idempotency-Vertrag.
