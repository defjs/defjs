# HTTP-Aufruf abbrechen

Kombiniere einen aufruferseitigen `AbortController` mit einer Frist über `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` und übergib das kombinierte Signal via `client({ signal })`. Defjs klassifiziert einen manuellen Abbruch durch den Aufrufer als `NET_ABORTED` und einen zeitlimitbedingten Abbruch als `NET_TIMEOUT`.

<Tabs items={["sdk/reports.ts", "app/main.ts", "cancel-report.ts"]}>
  <Tab value="sdk/reports.ts">
```ts
import { defineRequest } from "@defjs/core";

export const getReport = defineRequest({
  method: "GET",
  path: "/report",
});
```
  </Tab>
  <Tab value="app/main.ts">
```ts
import { createClient, withEndpoint } from "@defjs/core";
import { getReport } from "../sdk/reports.ts";

const client = createClient(withEndpoint("https://api.example.com"));

const controller = new AbortController();
const pending = getReport(
client({
signal: AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)]),
}),
);

controller.abort("screen closed");

async function main() {
const [error] = await pending;
if (error?.code === "NET_ABORTED") {
console.log("caller cancelled");
return;
}
if (error?.code === "NET_TIMEOUT") {
console.log("timed out");
return;
}
if (error) {
console.error(error.code);
return;
}
console.log("got the report");
}

void main();

````

Ein Abbruch meldet lediglich, was der Client beobachtet hat – er garantiert keineswegs, dass eine serverseitige Mutation zurückgerollt wurde. Schütze Wiederholungsversuche bei Mutationen durch Idempotenz-Schlüssel. Siehe [HTTP-Abbruch und Zeitlimits](/de-DE/docs/http#cancel-the-work).
