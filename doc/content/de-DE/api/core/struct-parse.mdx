title: 'struct.parse'
description: 'Parst einen unbekannten Wert mit einem Struct und gibt ein Error-first-Tuple zurück.'
---

<ApiReference identity="@defjs/core:struct.parse" />

```ts
function parse<S extends StructLike<unknown, unknown, boolean>>(
  struct: S,
  value: unknown,
  options?: { aliases?: boolean; errorMap?: ErrorMap },
): ParseResult<S['_struct']['output']>
```

- **struct** ist der Struct, mit dem geparst wird. Ein Wert, der kein Struct ist, wirft `TypeError`.
- **value** ist der unbekannte Input.
- **options.aliases** ist standardmäßig `false`: Object-Keys werden über ihre **logischen** Namen (`displayName`) gelesen. Mit `true` werden sie über ihre Wire-Namen (`display_name`) gelesen, so wie HTTP-/JSON-Codecs es tun. Der Output verwendet immer logische Namen.
- **options.errorMap** ist eine [`ErrorMap`](/de-DE/api/core/errormap-type), die Issue-Messages nur für diesen Aufruf umschreibt, einschließlich bigint-/date-Konvertierungsfehlern eines Structs aus einer anderen Core-Kopie. Jeder String, auch `''`, ersetzt die Message; nur `undefined` behält den Default. Eigener Text wird wörtlich verwendet.
- **Returns** `[null, output]` oder `[StructError, undefined]`. Bei Validierungsfehlern wird keine Ausnahme geworfen. Ausnahmen aus vom Aufrufer bereitgestellten Gettern und `errorMap`-Callbacks werden unverändert weitergegeben.
- Das Parsen ist fail-fast: Es stoppt beim ersten Fehler, daher enthält der Error ein Issue. Unbekannte Object-Keys werden aus dem Output entfernt, und der Input wird nicht verändert.
- Entlang eines Pfads werden höchstens **256 verschachtelte Container** (`object`, `array`, `record` oder `tuple`) besucht, wobei der Wurzelcontainer als erster zählt. Der nächste Container schlägt an seinem logischen Pfad mit `invalid_type` und `expected: 'value nested at most 256 levels deep'` fehl. In einer Union können spätere Kandidaten noch erfolgreich sein; passt keiner, meldet die Union `invalid_union`. Auch Zyklen durch deklarierte Container-Felder erreichen diese Grenze; gemeinsam genutzte, nicht zyklische Kindknoten sind erlaubt. Union- und Intersection-Zweige fügen keine Container-Ebene hinzu, und `any`/`unknown`-Werte werden als opake Werte behandelt, statt durchlaufen zu werden.

```ts
const [error, user] = struct.parse(User, { id: 1, displayName: 'Ada' })
if (error) return console.error(error.prettify())
```

`any` und `unknown` durchlaufen ihre Werte nicht. Eine Intersection kann jedoch zwei unterschiedliche Objekt- oder Array-Werte, die diese Blattknoten zurückgeben, rekursiv zusammenführen. Diese Zusammenführung teilt sich das Budget von 256 Containern mit dem umgebenden logischen Pfad. Wird es überschritten, entsteht `invalid_intersection` am logischen Pfad des abgewiesenen Containers. Identische Referenzen werden ohne Traversierung beibehalten, auch bei einem gemeinsam genutzten zyklischen Wert.

Siehe [`ParseResult`](/de-DE/api/core/parseresult-type) und [`StructError`](/de-DE/api/core/structerror-type).
