<ApiReference identity="@defjs/core:struct.boolean" />

```ts
function boolean(): Struct<boolean, boolean>
```

Akzeptiert nur `true` und `false`. Andere Werte, auch `'true'` und `1`, schlagen mit `invalid_type` fehl.
