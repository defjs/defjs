```ts
function createNetworkFault(cause: unknown, response?: HttpMeta): PreflightFault
```

- **cause** — Der zugrunde liegende Abbruch, Timeout oder Transportfehler.
- **response** — Metadaten, nur wenn der Transport bereits welche zu melden hatte. Sie werden dem Fault angehängt, wenn angegeben.
- **Returns** einen `PreflightFault`, dessen Code von `cause` abhängt:
  - `NET_ABORTED`, wenn [`isAbortCause`](/de-DE/api/core/isabortcause) einen mit Abort gebrandeten `Error` erkennt (einschließlich `ERR_ABORTED` aus einer anderen Core-Kopie) oder eine `DOMException` namens `AbortError`. Die Message lautet `Request was aborted`.
  - `NET_TIMEOUT`, wenn [`isTimeoutCause`](/de-DE/api/core/istimeoutcause) einen mit Timeout gebrandeten `Error` erkennt (einschließlich `ERR_TIMEOUT` aus einer anderen Core-Kopie) oder eine `DOMException` / einen `Error` namens `TimeoutError`. Die Message ist die Message der Cause oder `Request timed out`, wenn diese leer ist.
  - `NET_UNREACHABLE` für alles andere, mit der Message der Cause.

Die Cause wird als `cause` behalten.
