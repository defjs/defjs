---
title: 'Interceptor'
description: 'Union der getaggten Interceptors, die von den Client-Interceptor-Options akzeptiert werden.'
---

<ApiReference identity="@defjs/core:Interceptor" />

```ts
type Interceptor = HttpInterceptor | SSEInterceptor | WebSocketInterceptor
```

`kind` (`'http'`, `'sse'` oder `'web-socket'`) bestimmt, für welche Commands ein Interceptor läuft. `withInterceptors` akzeptiert eine beliebige Mischung; jeder Transport führt nur seine eigene Art aus, in Registrierungsreihenfolge.
