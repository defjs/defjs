<ApiReference identity="@defjs/core:createSSEInterceptor" />

```ts
function createSSEInterceptor(fn: SSEInterceptorFn): SSEInterceptor

type SSEHandler = (req: HttpRequest) => Promise<EventStreamHandle<unknown>>
type SSEInterceptorFn = (req: HttpRequest, next: SSEHandler) => Promise<EventStreamHandle<unknown>>
```

Gibt `{ kind: 'sse', fn }` zurück. SSE-Interceptors laufen nur für SSE-Commands, in Registrierungsreihenfolge; `next(req)` öffnet den Stream durch die übrigen Interceptors.

Ein deterministischer URL-Fehler aus `next(req)` führt zur Ablehnung des zurückgegebenen Promises, sodass die Fehlerbehandlung über `.then` / `.catch` ausgeführt wird; wird der Fehler dort nicht abgefangen, meldet `client.execute` weiterhin `REQ_BUILD_FAILED`.

`EventStreamHandle` erweitert `AsyncDisposable`. Eine strukturelle Short-Circuit-Implementierung muss `[Symbol.asyncDispose](): PromiseLike<void>` liefern und ihn an denselben Close-Lifecycle hängen.
