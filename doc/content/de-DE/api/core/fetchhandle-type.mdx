<ApiReference identity="@defjs/core:FetchHandle" />

```ts
type FetchHandle = (input: RequestInfo | URL, init?: RequestInit) => Promise<Response>
```

Die Aufrufsignatur `(input, init?) => Promise<Response>`, die Defjs aufruft. Sie ist bewusst nicht `typeof fetch`, damit ein Mock keine Host-Extras wie `preconnect` braucht. HTTP ruft unangetastetes Plattform-Fetch als `(url, init)` auf; ein ersetztes globales Fetch oder ein eigenes Handle erhält einen `Request`. Der Default löst das Globale bei jedem Aufruf auf. SSE übergibt immer einen `Request`, auch an sein Default-Handle.

Akzeptiert von `withHTTPHandle`, `withSSEHandle` und `fetchHandler`.
