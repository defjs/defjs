title: 'WebSocketHeartbeatConfig'
description: 'Einstellungen für Heartbeat-Ping und Bestätigung.'
---

<ApiReference identity="@defjs/core:WebSocketHeartbeatConfig" />

```ts
interface WebSocketHeartbeatConfig<TIncoming = unknown, TOutgoing = unknown> {
  intervalMs: number
  isAck?: (message: TIncoming) => boolean
  message?: () => TOutgoing
  timeoutMs?: number
}
```

- `intervalMs` ist die Pause zwischen Heartbeat-Messages.
- `message()` baut die Payload. Sie wird über den `outgoing`-Struct gesendet. Fehlt es oder gibt es `undefined` zurück, wird nichts gesendet.
- `isAck(message)` bekommt jede dekodierte eingehende Message. Gibt es `true` zurück, gilt die Message als Bestätigung und wird nicht an `receive` ausgeliefert.
- `timeoutMs` ist, wie lange nach einem Heartbeat auf eine Bestätigung gewartet wird. Bleibt sie aus, scheitert die Session.
- `intervalMs` und `timeoutMs` müssen positiv, endlich und höchstens `2_147_483_647` sein.

Setze es mit [`withWebSocketHeartbeat`](/de-DE/api/core/withwebsocketheartbeat) oder der Execute-Option `heartbeat`.
