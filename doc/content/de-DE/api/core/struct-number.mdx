<ApiReference identity="@defjs/core:struct.number" />

```ts
function number(): Struct<number, number>
```

- Akzeptiert `number`-Werte, auch `Infinity`. `NaN` und Nicht-Zahlen schlagen mit `invalid_type` fehl.
- Strings werden nicht umgewandelt.
