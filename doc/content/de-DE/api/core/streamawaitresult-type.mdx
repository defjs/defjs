```ts
type StreamAwaitResult<TEvent, TError extends AnyStruct | undefined = undefined> =
  | [error: null, stream: EventStreamHandle<TEvent>, open: EventStreamOpenInfo]
  | [error: Fault<TError>, stream: undefined, open: EventStreamOpenInfo | undefined]
```

Das Ergebnis von `client.execute` für einen SSE-Command.

- Bei Erfolg: `[null, stream, open]`. `open` ist der Snapshot, der beim Öffnen des Streams entstand; `stream.open` kann sich nach einem Reconnect ändern.
- Bei einem Fehler: `[fault, undefined, open]`. `open` enthält den Response-Snapshot, wenn der Fehler nach dem Eintreffen einer Response auftrat, etwa bei einem Handshake ohne 2xx, und ist sonst `undefined`.
- `TError` ist der deklarierte `error`-Struct. Er typisiert den dekodierten Error-Body am Fault.
