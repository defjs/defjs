<ApiReference identity="@defjs/core:EventStreamOpenInfo" />

```ts
interface EventStreamOpenInfo {
  response: HttpResponse<unknown>
  url: string
}
```

`response` ist die Handshake-Response und `url` die aufgelöste Request-URL. Es ist das dritte Element eines erfolgreichen `client.execute`-Ergebnisses und der Wert von `EventStreamHandle.open`.
