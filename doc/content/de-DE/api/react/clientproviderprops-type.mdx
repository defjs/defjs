```ts
interface ClientProviderProps {
  client: Client
  children?: ReactNode
}
```

- `client` — Erforderlich. Der Defjs-Client, der der Anwendung gehört.
- `children` — Optional. Der React-Tree, der `useClient` aufrufen kann.
