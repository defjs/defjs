<ApiReference identity="@defjs/opentelemetry-server:OpenTelemetryServerWebSocketOptions" />

```ts
interface OpenTelemetryServerWebSocketOptions extends OpenTelemetryServerTransportOptions<WebSocketSessionLike> {
  queryPropagation?: boolean
}
```

Wird auf `webSocket` in `OpenTelemetryServerOptions` gesetzt. `enabled`, `startSpanHook`, `requestHook` und `responseHook` kommen von `OpenTelemetryServerTransportOptions`; `responseHook(span, session, req)` bekommt die geöffnete `WebSocketSessionLike` und den ursprünglichen `HttpRequest`.

`queryPropagation` ist standardmäßig `false`: Der WebSocket-Query-String bleibt unverändert, und weder Trace-Context noch Baggage wird in die URL geschrieben. Browser-WebSocket-Clients können meist keine Header setzen, daher wird beim Einschalten der propagierte Kontext ans Ende des Query-Strings geschrieben, wobei gleichnamige Parameter ersetzt werden. Query-Strings können von Proxys, Access-Logs und APM-Tools aufgezeichnet werden, und Baggage-Werte können sensibel sein. Schalte es erst ein, wenn du diese Exposition akzeptierst.

WebSocket wird auf Verbindungsebene getraced. Der Span bleibt offen, bis `session.closed` abgeschlossen ist. Er zeichnet `websocket.connected` auf, dann `websocket.closed` bei einem normalen Close oder `websocket.error`. Ein Close-Frame vom Server zählt bei jedem Code als normal, auch 1011. Ein abruptes Wegbrechen ohne Close-Frame (1006) ist nur dort normal, wo die Laufzeit vor `close` keinen Socket-`error` meldet (Bun); wo sie es tut (Node.js), endet die Session mit einem Fehler und loggt einmal. Ein Abbruch einer offenen Session durch den Caller ist ebenfalls `websocket.error`: Der Span endet mit `ERROR`, und es wird kein Log ausgegeben. `error.type` folgt dem Abort-Grund: `AbortError` bei einem Standard-`abort()`, der `Error.name` bei einem `Error` als Grund, `string` bei einem String als Grund. Ein Abbruch, während sich die WebSocket noch verbindet, beendet den Span mit `ERROR` und `error.type` `DefjsFault`. Spans pro Message werden nicht erzeugt.

Übergib `{ enabled: false }`, um die WebSocket-Instrumentierung zu überspringen. Span-Hooks werden nur mit einem übergebenen `tracer` aufgerufen.
