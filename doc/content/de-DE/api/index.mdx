# API-Referenz

<ApiIndex />

Nutze diese Referenz, während du ein Defjs-SDK baust oder konsumierst. SDK-Autoren starten mit [`defineRequest`](/de-DE/api/core/definerequest), [`defineEventStream`](/de-DE/api/core/defineeventstream), [`defineWebSocket`](/de-DE/api/core/definewebsocket) und [Structs](/de-DE/api/struct). Anwendungen nutzen die [Client-Konfiguration](/de-DE/api/client), um diese Operationen aufzurufen, und [Fehler](/de-DE/api/errors), um Ergebnisse zu behandeln.

Signaturen sind der Vertrag. Folge dem [Schnellstart](/de-DE/docs/start) und [SDK entwickeln und veröffentlichen](/de-DE/recipes/publish-http-sdk) für den vollständigen Ablauf.

## Pakete

| Paket                                                            | Was du nachschlägst                                               |
| ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| [`@defjs/core`](/de-DE/api/client)                               | `createClient`, `defineRequest`, `struct`, HTTP / SSE / WebSocket |
| [`@defjs/vue`](/de-DE/api/vue)                                   | `createClientPlugin`, `injectClient`, `HTTP_CLIENT`               |
| [`@defjs/react`](/de-DE/api/react)                               | `ClientProvider`, `useClient`                                     |
| [`@defjs/opentelemetry-server`](/de-DE/api/opentelemetry-server) | `withOpenTelemetryServer`, Options pro Transport                  |
