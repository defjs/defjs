Diese Site veröffentlicht englische Markdown-Dateien für Assistenten. Die folgenden Adressen haben kein Locale-Präfix und sind keine Übersetzungen der lokalisierten Leitfäden.

## Seitenindex [#llms-txt]

[llms.txt](/llms.txt) listet die englischen Seiten und verlinkt ihre Webadressen. Das ist der Einstieg, wenn ein Assistent zuerst eine Seite finden muss.

## Zusammengefasste Leitfäden [#llms-full]

[llms-full.txt](/llms-full.txt) fasst die englischen Leitfäden in einer Datei zusammen. Verwende es, wenn ein Assistent breiten Kontext in einem einzigen Dokument braucht und das Token-Budget es zulässt.

## Eine Seite als Markdown [#page-markdown]

Jede englische Seite ist auch unter `/llms.mdx/<path>/content.md` als Markdown verfügbar. Zum Beispiel ist [Quick start als Markdown](/llms.mdx/docs/start/content.md) der englische Text der Quick-Start-Seite.

## Version prüfen [#version]

Diese Site dokumentiert den Standardbranch; das Projekt kann eine andere `@defjs/core`-Version installiert haben. Prüfe APIs gegen das installierte Paket, bevor du einen Vorschlag übernimmst. Entferne Geheimnisse und prüfe die Projektrichtlinien, bevor du Code oder Kontext an ein KI-Tool gibst.
