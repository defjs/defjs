# Vue

`@defjs/vue` 透過 `createClientPlugin(client)`、`HTTP_CLIENT` 與 `injectClient()` 將應用程式專屬的 `@defjs/core` Client 注入 Vue 3.2+ 應用程式中。你的 SDK 定義維持純粹的 `@defjs/core` 模組，完全不依賴 Vue。

```sh
bun add @defjs/core @defjs/vue vue
```

## `@defjs/vue` 負責的項目 vs. 應用程式負責的項目

- **由 `@defjs/vue` 提供**：`createClientPlugin(client)`、`HTTP_CLIENT`（`InjectionKey<Client>`）與 `injectClient(key?)`。
- **由你的應用程式掌控**：建立 [`DerivableClient`](/zh-Hant-TW/api/core/derivableclient-type)、在 Watcher（`onCleanup`）或 Composable（`onScopeDispose`）中取消進行中的請求、關閉 SSE/WebSocket 控制代碼，以及整合如 Vue Query 等查詢狀態管理函式庫。
- **重要提示**：`injectClient()` 回傳的是 `DerivableClient` 函式物件。請在實際執行操作處呼叫 `client({ signal })`（如 `getOrder(client({ signal }), input)`）。切勿將 `client` 直接作為第一個參數傳入 `watch(client, ...)` 或 `computed(client)`，因為 Vue 會將函式參數視為響應式 Getter。

## 2. 在子樹中注入與覆寫

`injectClient(key?)` 會向上尋找最接近該 `key` 的提供者（預設為 `HTTP_CLIENT`）。若在作用中的 Vue 注入上下文（`setup()` 或 `app.runWithContext()`）之外呼叫，或該鍵未提供任何 Client，則會拋出 `Error`。

你可以使用 Vue 原生的 `provide(HTTP_CLIENT, childClient)` 為元件子樹覆寫 Client：

<include cwd>examples/vue/inject-and-override.vue#example</include>

- 後代元件會接收到 `childClient`，而平行的其他子樹則繼續沿用根節點的 Client。
- 若輔助函式接受選用的明確 Client 參數（`explicitClient ?? injectClient()`），只有在 fallback 分支時才需要活躍的 Vue 注入上下文。請務必在 `setup()` 期間、任何 `await` 之前同步擷取 Client。

## 3. 在 Scope 銷毀時清理 SSE 與 WebSocket 串流

若工作是在 Composable 內部或 Watcher 之外的元件邏輯中啟動，請將 `AbortController` 與 `onScopeDispose` 搭配使用。先中止啟動階段、關閉在銷毀後才成功解析的控制代碼、消費其唯一的非同步迭代器，並等待 `.closed`：

<include cwd>examples/vue/realtime-scope.vue#example</include>

- Tuple 的錯誤分支會顯示初始握手失敗（包含 HTTP 503）。迭代器的 `catch` 會顯示啟動後的失敗；`finally` 區塊仍會關閉並等待串流結束。

- 停止 Scope 會讓 SSE 的 `for await` 迴圈正常結束。
- 中斷 WebSocket 工作階段會將其終結為 `aborted`，並以 `AbortError` 拒絕 `session.receive`，因此在處置後請對 `catch` 區塊進行防護，並在 `finally` 中取消訂閱 `onStateChange` / `onRuntimeError` 監聽器。

## 4. SSR 與應用程式範圍

- **瀏覽器端**：當端點與攔截器不隨請求變更時，每個 Vue App 可共用單一 Client。
- **SSR 伺服器端**：當標頭、Cookie、租戶或憑證因請求而異時，請在每個 SSR 請求中建立並安裝全新的 Client。
- 卸載 Vue 應用程式或銷毀元件 Scope **不會**自動中止 HTTP 請求、關閉 SSE/WebSocket 串流，也不會處置 Core Client。
