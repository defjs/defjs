# CLI 與 OpenAPI 產生器

`@defjs/cli` 是專為 Node.js（`>= 22.18.0`）與 Bun 設計的開發期 CLI 工具——以零執行時期相依套件的單一檔案 ESM bundle 發布，並將 `@defjs/core` 設為選用 peer dependency，同時內嵌打包了 `@scalar/openapi-parser`——能使用內建的 2 空格 AST printer，將 Swagger 2.0 與 OpenAPI 3.0–3.2 規格轉換成**無狀態 ESM** 格式的 `@defjs/core` 定義與 `struct` schema。產生的模組不會捕捉任何 Client、不建立任何類別，並為純宣告加上 `/*#__PURE__*/` 註記。

作為開發相依套件安裝：

```bash
bun add -D @defjs/cli
```

不帶參數執行 `defjs` 會印出說明訊息並正常結束。

## 設定檔與程式化 API

在 `defjs.config.ts`（或 `.mts` / `.mjs` / `.js`，透過原生 Node `>= 22.18` 或 Bun `import()` 載入）中使用 `defineConfig` 設定目標，或從自訂腳本呼叫 `generateOpenApi`：

```json
      "get": {
        "tags": ["Orders"],
        "operationId": "getOrder",
```


## 關鍵旗標與 Defjs 防護規範

| 旗標 / 選項                         | 可用值                                                                                    | 行為說明                                                                                                                                                         |
| ----------------------------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--input`, `input`                  | 本機 `.yaml`/`.yml`/`.json`/`.ts`/`.mts`/`.js`/`.mjs`、`http(s):` URL、匯入物件或載入函式 | 透過原生 Node `>= 22.18` / Bun `import()` 載入 `.ts`/`.mts`/`.js`/`.mjs` 模組，並透過 Scalar 載入規格（單檔 Swagger 2.0 / 3.0 自動升級；保留多檔案 `$ref` 參照） |
| `--format`, `format`                | `ts`（預設）、`tsx`、`js`（`.js` + `.d.ts`）、`mjs`（`.mjs` + `.d.mts`）                  | 依 tag 分組，在 `schema/` 與 `request/` 下輸出無狀態 ESM 模組（需要時另於根目錄輸出共用的 `util` 模組）                                                          |
| `--mode`, `mode`                    | `sync`（預設）、`scaffold`                                                                | `sync` 會清除過時的受管檔案並驗證檔頭擁有權；`scaffold` 僅寫入尚未存在的檔案                                                                                     |
| `--error-strategy`, `errorStrategy` | `none`（預設）、`union`                                                                   | `none` 避免對非 2xx 的 HTML 閘道錯誤頁面進行解碼；`union` 會為文件已宣告的非 2xx 回應合成 `error` struct                                                         |
| `--mixed-2xx`, `mixed2xxStrategy`   | `omit`（預設）、`split`                                                                   | 當單一操作混用帶本文的 2xx 與 `204` 時，`omit` 會清楚發出警告並省略 `output`，而 `split` 會新增 `<op>NoContent` 操作                                             |
| `--check`                           | 布林值                                                                                    | 當任何受管檔案存在差異或將被刪除時，以結束碼 `1` 離開                                                                                                            |

產生的程式碼完整遵循所有 Defjs 契約：

- `input` 搭配明確的同步 `builder`（當 JSON 請求本文帶有 `.alias(...)` 改名時，直接傳入具型別的 `body: input.body`）
- 非預設 query 序列化樣式（`deepObject`、`pipeDelimited`、`spaceDelimited`、`explode: false` 的 `form`、`json`）以及非預設 path 與 header 參數序列化器（陣列/物件的 `label`、`matrix`、`simple`）只會將所需的輔助函式閉包輸出到共用的根目錄 `util` 模組（`util.ts`/`.tsx`/`.js`/`.mjs`，JS 格式另附 `util.d.ts`/`.d.mts`），並由 `request/<group>` 檔案從 `../util` 匯入
- 串流 `text/event-stream`（`itemSchema`）回應會產生 `defineEventStream` 而非 `defineRequest`
- 相互遞迴或自我遞迴的 schema 會依拓樸後序輸出宣告，並在物件循環參照上使用延遲 getter 屬性，避免模組載入時發生 `ReferenceError` TDZ 崩潰

請參閱 [CLI API 參考](/zh-Hant-TW/api/cli)。
