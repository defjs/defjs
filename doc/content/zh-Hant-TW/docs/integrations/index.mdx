# 整合套件概覽

整合套件會在明確定義的擴充點上擴充應用程式本身的 `Client`，而不會修改 `@defjs/core`，也不會將 SDK 定義綁定到特定框架或遙測技術堆疊。你的 SDK 定義維持純粹的 `@defjs/core` 模組；由取用端應用程式自行決定安裝哪些整合套件。

所有 Defjs 外掛皆遵循**輕量外掛契約（Thin plugin contract）**：

- **無隱藏快取或狀態管理**：外掛絕不儲存回應、不重試請求，也不介入管理 Query 狀態。
- **不替換傳輸層**：外掛絕不包裝或替換底層的 HTTP、SSE 或 WebSocket 傳輸層。
- **呼叫端掌控生命週期**：卸載 UI Provider 或關閉遙測 SDK 不會自動取消進行中的請求，也不會強制中斷活躍中的串流。

## 兩種外掛架構

### 1. 框架外掛 (`@defjs/react`, `@defjs/vue`)

框架外掛透過原生依賴注入（React Context 或 Vue `provide` / `inject`）將既有的 [`DerivableClient`](/zh-Hant-TW/api/core/derivableclient-type) 沿著元件樹向下傳遞：

<Tabs items={["sdk/orders.ts", "app/main.tsx", "app/OrderCard.tsx"]}>
  <Tab value="sdk/orders.ts">
```ts
import { defineRequest, struct } from "@defjs/core";

export const Order = struct.object({
  id: struct.number(),
  status: struct.string(),
});

export const getOrder = defineRequest({
  method: "GET",
  path: "/orders/:id",
  input: struct.object({ id: struct.number() }),
  builder: (input) => ({ path: { id: input.id } }),
  output: Order,
});
```
  </Tab>
  <Tab value="app/main.tsx">
```tsx
import { createClient, withEndpoint } from "@defjs/core";
import { ClientProvider } from "@defjs/react";
import { OrderCard } from "./OrderCard.tsx";

const client = createClient(withEndpoint("https://api.example.com"));

export function App() {
  return (
    <ClientProvider client={client}>
      <OrderCard id={42} />
    </ClientProvider>
  );
}
```
  </Tab>
  <Tab value="app/OrderCard.tsx">
```tsx
import { useClient } from "@defjs/react";
import { getOrder } from "../sdk/orders.ts";

export function OrderCard({ id }: { id: number }) {
  const client = useClient();
  // 在 Effect 或 Query Hook 中將 `client` 或 `client({ signal })` 傳入 `getOrder(...)`
  void id;
  void getOrder;
  void client;
  return null;
}
```
  </Tab>
</Tabs>

### 2. 中介層外掛 (`@defjs/opentelemetry-server`)

中介層外掛是一個回傳 [`ClientOption`](/zh-Hant-TW/api/core/clientoption-type) 的 Factory 函式。傳入 `createClient(...)` 時，它會透過 `withInterceptors` 附加 HTTP、SSE 與／或 WebSocket 攔截器：
