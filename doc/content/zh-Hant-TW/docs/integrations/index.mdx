# 外掛

外掛是可選套件，由使用端應用程式裝到自己的 Defjs Client 上。`@defjs/core` 不匯入它們，SDK 定義也不匯入。Client、endpoint、憑證，以及要裝哪些外掛，都由應用程式擁有。

外掛分兩種。**框架外掛**把既有的 `Client` 交給框架樹。**中介軟體外掛**是攔截器鏈的外掛形態：它把 interceptor 追加到應用程式自己的 Client 上。見 [攔截器](/zh-Hant-TW/docs/interceptors)。

| 外掛                                                                                  | 套件                          | 它加上什麼                                                                                | 它不做什麼                                                          |
| ------------------------------------------------------------------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| [React](/zh-Hant-TW/docs/integrations/react) · 框架                                   | `@defjs/react`                | 為既有 Client 提供 `ClientProvider` 與 `useClient()`                                      | 不建立、不快取、不重試，也不釋放 Client。不是 query 或 state 程式庫 |
| [Vue](/zh-Hant-TW/docs/integrations/vue) · 框架                                       | `@defjs/vue`                  | Vue 外掛、`HTTP_CLIENT` 與 `injectClient()`                                               | 不建立、不快取、不重試。卸載時不關閉傳輸。不是 query 程式庫         |
| [OpenTelemetry server](/zh-Hant-TW/docs/integrations/opentelemetry-server) · 中介軟體 | `@defjs/opentelemetry-server` | `withOpenTelemetryServer(...)`，一個 Client option，追加 HTTP、SSE、WebSocket interceptor | 不初始化 OpenTelemetry SDK，也不做入站伺服器插樁                    |

React 與 Vue 把既有的 `Client` 交給框架樹。應用程式用 `@defjs/core` 的 `createClient` 建立這個 Client。React 外掛透過 Context 提供它。Vue 外掛透過 `app.use(createClientPlugin(client))` 提供它。兩個套件都不會發起請求。

OpenTelemetry server 中介軟體外掛是一個 `ClientOption`。建立 Client 時傳入 `withOpenTelemetryServer(...)`。它依 HTTP、SSE、WebSocket 的順序，為每個啟用的傳輸追加一個 interceptor。見 [攔截器](/zh-Hant-TW/docs/interceptors)。這個套件不初始化 OpenTelemetry SDK。
