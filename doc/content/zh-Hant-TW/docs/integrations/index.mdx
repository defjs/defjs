# 整合套件概覽

整合套件只在既定的擴充點上擴充應用程式自己的 `Client`，不會修改 `@defjs/core`，也不會把 SDK 定義綁到特定框架或遙測技術堆疊。你的 SDK 定義仍然是純粹的 `@defjs/core` 模組；要安裝哪些整合套件，由取用端應用程式決定。

每個 Defjs 外掛都遵守**輕量外掛契約（thin plugin contract）**：

- **不偷偷快取、不保存狀態**：外掛絕不儲存回應、不重送請求，也不管理 query 狀態。
- **不替換傳輸**：外掛絕不包裝或替換底層的 HTTP、SSE 或 WebSocket 傳輸。
- **生命週期由呼叫端擁有**：卸載 UI provider 或關閉遙測 SDK，不會自動取消進行中的請求，也不會關閉進行中的串流。

## 兩種外掛架構

### 1. 框架外掛 (`@defjs/react`, `@defjs/vue`)

框架外掛透過原生依賴注入（React Context 或 Vue `provide` / `inject`），把既有的 [`DerivableClient`](/zh-Hant-TW/api/core/derivableclient-type) 沿著元件樹往下傳：

### 2. 中介層外掛 (`@defjs/opentelemetry-server`)

中介層外掛是一個回傳 [`ClientOption`](/zh-Hant-TW/api/core/clientoption-type) 的 factory 函式。傳入 `createClient(...)` 後，它會透過 `withInterceptors` 附加 HTTP、SSE 與／或 WebSocket 攔截器：
