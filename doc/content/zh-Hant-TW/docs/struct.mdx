# 資料結構 / Struct

`struct` 用於宣告 SDK 與其取用者之間共享的通訊資料契約：呼叫端輸入、`2xx` 輸出、已宣告的服務端錯誤、SSE 事件以及 WebSocket 封包訊息。

- **靜態型別推論**：使用 `Infer<typeof Schema>` 自動衍生出 TypeScript 型別。
- **Error-first 驗證**：在執行時期使用 `struct.parse(Schema, value)` 驗證資料——回傳 `[null, data]` 或 `[StructError, undefined]`，絕不會拋出未捕捉的例外。

## 1. 在 SDK 定義 Schema，在應用程式中進行驗證

<Tabs items={["sdk/schema.ts", "app/validate.ts"]}>
<Tab value="sdk/schema.ts">

```ts
import { struct, type Infer } from "@defjs/core";

export const Order = struct.object({
  id: struct.number(),
  status: struct.enum(["pending", "paid", "shipped"] as const),
  customerName: struct.string().alias("customer_name"),
  notes: struct.string().optional(),
});

export type Order = Infer<typeof Order>;
```

剖析後的物件只會保留宣告過的欄位（未宣告的額外屬性會被移除），並使用 `null` 作為其原型（prototype）。任何缺少必填欄位、原始型別不符或分支無效的情況，都會產生一個 `StructError`，絕不回傳不完整或部分填補的資料。

## 2. 必填、可選與可為 null 的欄位

Defjs 嚴格區分**欄位是否存在**（`undefined`）與**欄位值是否為 null**（`null`）。預設情況下，所有 struct 建構子皆為嚴格必填且不可為 null：

| 宣告方式                     | 缺失 / `undefined`           | `null` | 合法數值         |
| ---------------------------- | ---------------------------- | ------ | ---------------- |
| `struct.string()`            | 拒絕                         | 拒絕   | 接受 `string`    |
| `struct.string().optional()` | 接受（序列化物件時會被省略） | 拒絕   | 接受 `string`    |
| `struct.string().null()`     | 拒絕                         | 接受   | 接受 `string`    |
| `struct.string().nullish()`  | 接受（序列化物件時會被省略） | 接受   | 接受 `string`    |
| `struct.null()`              | 拒絕                         | 接受   | 拒絕非 `null` 值 |

<include cwd lang="typescript">
  examples/struct/required-optional-null.ts#example
</include>

`struct.any()` 與 `struct.unknown()` 同樣會預設拒絕 `null` 與 `undefined`，除非明確鏈結呼叫 `.null()`、`.optional()` 或 `.nullish()`。

## 3. 雙向通訊欄位別名 (.alias())

當後端 API 習慣使用 `snake_case` 或 HTTP 標頭格式，而你的 TypeScript SDK 偏好使用 `camelCase` 時，請使用 `.alias("wire_name")`。你只需在欄位上宣告一次別名，它就能自動在兩個方向上順暢運作：

| 轉換邊界                                                         | 使用的鍵名                                         |
| ---------------------------------------------------------------- | -------------------------------------------------- |
| 操作的 `input` 與 `struct.parse(Schema, value)`                  | 邏輯名稱（`customerName`）                         |
| `builder` 回傳的具型別 struct 物件（`body`、`query`、`headers`） | 通訊別名（`customer_name`）                        |
| JSON 回應 / SSE 事件 / WebSocket 訊息解碼                        | 通訊名稱 `customer_name` → 邏輯名稱 `customerName` |
| 在 `builder` 中直接撰寫的匿名物件鍵名                            | 如實保留所寫的字面值鍵名                           |

<include cwd lang="typescript">
  examples/struct/aliases.ts#example
</include>

在 `builder` 內部展開具型別的物件（`{ ...input.order, extra: 1 }`）仍會保留其 struct 編碼與別名規則。如果在同一個物件上同時撰寫邏輯名稱與通訊別名，執行時會失敗並回傳 `REQ_BUILD_FAILED`。

## 4. 請求放置位置與表單編解碼器

`input` 定義參數；`builder` 則將參數放置到 `{ path, query, headers, body }` 中。針對表單編碼的本文，`struct.urlencoded(shape)` 與 `struct.formData(shape)` 會標記根物件，讓傳輸層自動將其序列化為 `URLSearchParams` 或 `FormData`：

<include cwd lang="typescript">
  examples/struct/request-placement.ts#example
</include>

| `builder` 回傳的本文根物件                 | 通訊格式          | 預設 `Content-Type`                               |
| ------------------------------------------ | ----------------- | ------------------------------------------------- |
| 具型別物件、陣列、有限數值、布林值、`null` | JSON 字串         | `application/json`                                |
| `string` struct 或原生 `string`            | UTF-8 字串        | `text/plain;charset=UTF-8`                        |
| 本文根部的 `struct.urlencoded(shape)`      | `URLSearchParams` | `application/x-www-form-urlencoded;charset=UTF-8` |
| 本文根部的 `struct.formData(shape)`        | `FormData`        | `multipart/form-data; boundary=...`               |
| `Blob` / `File` (`struct.file()`)          | 二進位 Blob       | `blob.type` 或 `application/octet-stream`         |
| `ArrayBuffer` / 視圖 / `ReadableStream`    | 原始位元組        | `application/octet-stream`                        |

## 5. 處理 StructError 與詳細問題

當驗證失敗時，`struct.parse(Schema, data, { aliases?, errorMap? })` 會回傳 `[StructError, undefined]`。`StructError` 繼承自原生 `Error`，並提供 `issues`、`format()`、`flatten()` 與 `prettify()` 等輔助方法：

<include cwd lang="typescript">
  examples/struct/parse-failures.ts#example
</include>

每個 `StructIssue` 包含 `code`（`invalid_type`、`missing_key`、`invalid_literal`、`invalid_enum`、`invalid_union`、`invalid_intersection` 或 `custom`）、`path`、`expected`、`received` 以及 `message`。預設訊息僅會報告收到的**型別名稱**（絕不會洩漏未經處理的原始負載數值），因此 `String(error)` 與 `error.prettify()` 不會將敏感資料外洩至日誌中。

## 6. 建構子快速參考

<include cwd lang="typescript">
  examples/struct/any.ts#example
</include>

| 建構子                                                     | 接受的輸入值                       | 推論的輸出型別                                         |
| ---------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------ |
| `struct.string()` / `struct.boolean()`                     | 相符的原始型別                     | `string` / `boolean`                                   |
| `struct.number()`                                          | 除了 `NaN` 以外的任何 `number`     | `number`（拒絕 `NaN`；在 JSON 本文中拒絕 `±Infinity`） |
| `struct.bigint()`                                          | `bigint` 或純數字字串              | `bigint`                                               |
| `struct.date()`                                            | 合法的 `Date`、時間戳記或 ISO 字串 | `Date`                                                 |
| `struct.literal(value)`                                    | 精確的原始型別常常常數值           | 字面值型別                                             |
| `struct.enum(values)`                                      | 宣告的字串或數值成員               | 字面值的 Union                                         |
| `struct.array(item)` / `struct.tuple(items)`               | 陣列 / 固定長度的 Tuple            | `T[]` / `[...]`                                        |
| `struct.object(shape)` / `struct.record(val)`              | 一般物件（Plain object）           | 具型別物件 / `Record<string, V>`                       |
| `struct.discriminatedUnion(key, options)`                  | 具有字面值 `key` 鑑別欄位的物件    | 物件分支的 Union                                       |
| `struct.or(branches)`                                      | 第一個相符的分支                   | 各分支型別的 Union                                     |
| `struct.intersection(members)`                             | 符合所有成員條件的值               | 深度合併後的交集（Intersection）                       |
| `struct.file()` / `struct.blob()` / `struct.arrayBuffer()` | `File` / `Blob` / `ArrayBuffer`    | 二進位表示                                             |
