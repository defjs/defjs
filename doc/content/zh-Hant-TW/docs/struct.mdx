# Struct 與 schema

`struct` 宣告 SDK 與取用端應用程式共享的傳輸資料契約：呼叫端輸入、`2xx` 輸出、已宣告的服務錯誤、SSE 事件，以及 WebSocket 訊框。

- **靜態推論**：以 `Infer<typeof Schema>` 推導 TypeScript 型別。
- **Error-first 驗證**：在執行時期以 `struct.parse(Schema, value)` 驗證值——回傳 `[null, data]` 或 `[StructError, undefined]`，不會拋出例外。

剖析後的物件只保留宣告過的欄位（未宣告的屬性會被移除），原型為 `null`。缺少必填鍵、原始型別不符或分支無效，都會產生 `StructError`，不會有部分結果。

## 2. 必填、可選與可為 null 的欄位

Defjs 嚴格區分**欄位是否存在**（`undefined`）與**值是否可為 null**（`null`）。每個 struct 建構子預設都是必填且不可為 null：

| 宣告方式                     | 缺失 / `undefined`           | `null` | 合法值           |
| ---------------------------- | ---------------------------- | ------ | ---------------- |
| `struct.string()`            | 拒絕                         | 拒絕   | 接受 `string`    |
| `struct.string().optional()` | 接受（序列化物件時會被省略） | 拒絕   | 接受 `string`    |
| `struct.string().null()`     | 拒絕                         | 接受   | 接受 `string`    |
| `struct.string().nullish()`  | 接受（序列化物件時會被省略） | 接受   | 接受 `string`    |
| `struct.null()`              | 拒絕                         | 接受   | 拒絕非 `null` 值 |

<include cwd lang="typescript">
  examples/struct/required-optional-null.ts#example
</include>

除非串接 `.null()`、`.optional()` 或 `.nullish()`，`struct.any()` 與 `struct.unknown()` 同樣會拒絕 `null` 與 `undefined`。

## 3. 雙向欄位別名 (`.alias()`)

當後端使用 `snake_case` 或標頭名稱，而你的 TypeScript SDK 使用 `camelCase` 時，請用 `.alias("wire_name")`。別名只需在欄位上宣告一次，就能雙向運作：

| 轉換邊界                                                         | 使用的鍵名                                         |
| ---------------------------------------------------------------- | -------------------------------------------------- |
| 操作的 `input` 與 `struct.parse(Schema, value)`                  | 邏輯名稱（`customerName`）                         |
| `builder` 回傳的具型別 struct 物件（`body`、`query`、`headers`） | 通訊別名（`customer_name`）                        |
| JSON 回應 / SSE 事件 / WebSocket 訊息解碼                        | 通訊名稱 `customer_name` → 邏輯名稱 `customerName` |
| 在 `builder` 中直接寫下的匿名物件鍵名                            | 如實保留所寫的字面值鍵名                           |

<include cwd lang="typescript">
  examples/struct/aliases.ts#example
</include>

在 `builder` 內展開具型別的物件（`{ ...input.order, extra: 1 }`）會保留其 struct 編碼與別名。若在同一個物件上同時寫出邏輯名稱與其通訊別名，會以 `REQ_BUILD_FAILED` 失敗。

## 4. 請求放置位置與表單編解碼器

`input` 宣告參數，`builder` 則把它們放進 `{ path, query, headers, body }`。對於表單編碼的本文，`struct.urlencoded(shape)` 與 `struct.formData(shape)` 會標記根物件，讓傳輸層自動序列化為 `URLSearchParams` 或 `FormData`：

<include cwd lang="typescript">
  examples/struct/request-placement.ts#example
</include>

| `builder` 回傳的本文根物件                 | 通訊格式          | 預設 `Content-Type`                               |
| ------------------------------------------ | ----------------- | ------------------------------------------------- |
| 具型別物件、陣列、有限數值、布林值、`null` | JSON 字串         | `application/json`                                |
| `string` struct 或原生 `string`            | UTF-8 字串        | `text/plain;charset=UTF-8`                        |
| 本文根部的 `struct.urlencoded(shape)`      | `URLSearchParams` | `application/x-www-form-urlencoded;charset=UTF-8` |
| 本文根部的 `struct.formData(shape)`        | `FormData`        | `multipart/form-data; boundary=...`               |
| `Blob` / `File` (`struct.file()`)          | 二進位 Blob       | `blob.type` 或 `application/octet-stream`         |
| `ArrayBuffer` / 視圖 / `ReadableStream`    | 原始位元組        | `application/octet-stream`                        |

## 5. 處理 StructError 與詳細問題

驗證失敗時，`struct.parse(Schema, data, { aliases?, errorMap? })` 回傳 `[StructError, undefined]`。`StructError` 繼承原生 `Error`，並提供 `issues`、`format()`、`flatten()` 與 `prettify()`：

<include cwd lang="typescript">
  examples/struct/parse-failures.ts#example
</include>

每個 `StructIssue` 包含 `code`（`invalid_type`、`missing_key`、`invalid_literal`、`invalid_enum`、`invalid_union`、`invalid_intersection` 或 `custom`）、`path`、`expected`、`received` 與 `message`。預設訊息不會寫出收到的值，只報告它的*型別*，但 path 會保留動態 record 的鍵，可能含有敏感值。`String(err)` 與 `err.prettify()` 不具備遮蔽敏感資訊的作用；寫日誌時請使用安全欄位的允許清單，並將原始的 `received` 值與自訂訊息視為敏感資料。

## 6. 建構子快速參考

| 建構子                                                     | 接受的輸入值                       | 推論的輸出型別                                      |
| ---------------------------------------------------------- | ---------------------------------- | --------------------------------------------------- |
| `struct.string()` / `struct.boolean()`                     | 相符的原始型別                     | `string` / `boolean`                                |
| `struct.number()`                                          | 除了 `NaN` 以外的任何 `number`     | `number`（拒絕 `NaN`；JSON 本文中拒絕 `±Infinity`） |
| `struct.bigint()`                                          | `bigint` 或數字字串                | `bigint`                                            |
| `struct.date()`                                            | 合法的 `Date`、時間戳記或 ISO 字串 | `Date`                                              |
| `struct.literal(value)`                                    | 完全相符的原始型別字面值           | 字面值型別                                          |
| `struct.enum(values)`                                      | 宣告的字串或數值成員               | 字面值的聯集                                        |
| `struct.array(item)` / `struct.tuple(items)`               | 陣列 / 固定長度的 tuple            | `T[]` / `[...]`                                     |
| `struct.object(shape)` / `struct.record(val)`              | 一般物件                           | 具型別物件 / `Record<string, V>`                    |
| `struct.discriminatedUnion(key, options)`                  | 具有字面值 `key` 鑑別欄位的物件    | 物件分支的聯集                                      |
| `struct.or(branches)`                                      | 第一個相符的分支                   | 各分支型別的聯集                                    |
| `struct.intersection(members)`                             | 符合所有成員條件的值               | 深度合併的交集                                      |
| `struct.file()` / `struct.blob()` / `struct.arrayBuffer()` | `File` / `Blob` / `ArrayBuffer`    | 二進位表示                                          |

### 遞迴 struct

自我參照的型別透過 shape 上的 getter 屬性讀取自身。getter 不在定義常數時執行，而是在物件 struct 首次被使用時執行一次，因此常數可以引用自己。請以 `Struct<T>` 標註該常數：TypeScript 無法推斷參照自身的型別。

### `struct` 不做的事

- `struct` 只宣告結構。字串長度、正規表示式、數值範圍與業務規則應在解析之後由應用程式碼處理。
- 解析會在第一個無效欄位處停止。它絕不以零值填補缺漏欄位，也絕不回傳部分輸出。
