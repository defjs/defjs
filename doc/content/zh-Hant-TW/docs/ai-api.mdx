本站發佈面向助手的英文 Markdown。這些位址沒有語言前綴，也不是本地化指南的譯文。

## 頁面索引 [#llms-txt]

[llms.txt](/llms.txt) 列出英文頁面，並連到對應網頁。助手需要先找到頁面時，從這裡開始。

## 彙編指南 [#llms-full]

[llms-full.txt](/llms-full.txt) 把英文指南合成一個檔案。需要在一次脈絡中提供較廣的背景，且 token 預算允許一份大文件時使用。

## 單頁 Markdown [#page-markdown]

每個英文頁面也可以透過 `/llms.mdx/<path>/content.md` 取得 Markdown。例如，[快速開始的 Markdown](/llms.mdx/docs/start/content.md) 就是快速開始頁的英文正文。

## 核對版本 [#version]

本站記錄預設分支；專案安裝的 `@defjs/core` 版本可能不同。採用建議之前，先按已安裝的套件核對 API。向 AI 工具提供程式碼或脈絡之前，先移除密鑰並確認專案的資料使用政策。
