# 用 ETag 與 304 重新驗證

`ok` 表示 2xx，所以 `304` 會以 `HTTP_STATUS` fault 到達。重新導向狀態也不是錯誤 body，所以不要宣告 `error`：body 根本不會被讀，fault 帶著 status，你自己回傳快取的內容。

見 [HTTP](/zh-Hant-TW/docs/http)。
