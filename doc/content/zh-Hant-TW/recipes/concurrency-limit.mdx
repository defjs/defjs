# 並行限制與池化呼叫

在 `Client` 上配置 `concurrencyLimitHttpInterceptor` 作為用戶端層級的並行隔艙（支援 FIFO 排隊與選用的 `maxQueue` 溢位保護），並搭配 `@defjs/core/concurrent`（`concurrentMap`、`concurrentMapSettled`、`concurrentAll`、`concurrentAllSettled`）直接綁定該 `Client` 執行快速失敗（fail-fast）或全數收斂（settled）的並行呼叫。
