# 冪等鍵

預設情況下，`withRetry` 只會重試具冪等性的 HTTP 方法（`GET`、`HEAD`、`PUT`、`DELETE`、`OPTIONS`、`TRACE`）。當為 `POST` 或 `PATCH` 端點啟用重試時，請將 `withRetry` 搭配 `idempotencyKeyHttpInterceptor()`，讓同一次邏輯呼叫的每一次重試都重用 `req.correlationId` 作為 `Idempotency-Key` 標頭，而後續新的呼叫則取得全新的鍵值。
