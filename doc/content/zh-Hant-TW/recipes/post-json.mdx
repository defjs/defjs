# POST JSON

把型別化的 body 交給 builder。邏輯欄位名留在 TypeScript；struct 上的 wire alias 會變成 JSON keys。物件 body 是 `application/json`。

細節見 [HTTP](/zh-Hant-TW/docs/http) 與 [Client](/zh-Hant-TW/docs/client)。

`api.example.com` 是 placeholder。若 server 回應 `201` 與 `{ "id": 1, "status": "paid", "customer_name": "Ada" }`，這段 snippet 會印出：

```txt
Created paid → 201
```
