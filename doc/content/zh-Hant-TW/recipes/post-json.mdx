# POST JSON

把具型別的輸入物件傳給 `builder`，回傳 `{ body: input }`。`.alias("customer_name")` 讓 TypeScript 端保留 `customerName`，在傳輸時編碼成 `"customer_name"`，再從 `201` 回應解碼回來。

當伺服器回應 `201` 與 `{ "id": 1, "status": "paid", "customer_name": "Ada" }` 時，該腳本會輸出：

```txt
Created paid → 201
```
