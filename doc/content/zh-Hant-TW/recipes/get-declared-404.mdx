# 帶有已宣告 404 的 GET

在 `defineRequest` 上同時宣告 `output`（用於 2xx 回應）與 `error`（用於非 2xx 回應）。在呼叫端以 `error?.code === "HTTP_STATUS" && error.status === 404` 分支，讀取具型別的 `error.data` 酬載。

當伺服器針對 `GET /orders/7` 回應 `200` 與 `{ "id": 7, "status": "paid" }` 時，該腳本會輸出：

```txt
Loaded paid from 200
```

- 任何非 2xx 狀態碼都會產生 `HTTP_STATUS`。宣告 `error` 會把錯誤本文解碼並驗證進 `error.data`；省略 `error` 則讓 `error.data` 維持 `undefined`，且完全不讀取本文。
- 若宣告的 `error` 本文媒體型別不符、JSON 無效，或未通過 struct 驗證，該操作會回傳 `RES_*` fault。由於單一 `error` struct 涵蓋所有非 2xx 狀態碼，當不同錯誤狀態回傳不同結構時，請使用 `struct.or(...)`。

請參閱 [HTTP 操作](/zh-Hant-TW/docs/http) 與 [錯誤處理](/zh-Hant-TW/docs/errors)。
