# 取消 HTTP 呼叫

把呼叫端的 signal 與期限組合在 `abort` 上。`AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` 是一個 signal。手動取消歸類為 `NET_ABORTED`。期限歸類為 `NET_TIMEOUT`。

細節見 [HTTP](/zh-Hant-TW/docs/http#cancel-the-work)。

<include cwd meta="cancel-report.ts">

</include>

```txt
caller cancelled
```

取消告訴你的是呼叫端觀察到的結果。它不能證明伺服器端寫入已回滾 — mutation 重試請放在 idempotency 契約後面。
