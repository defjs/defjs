# 取消 HTTP 呼叫

用 `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` 把呼叫端的 `AbortController` 與期限結合，再透過 `client({ signal })` 傳入合併後的 signal。Defjs 會把呼叫端手動中止歸類為 `NET_ABORTED`，把逾時中止歸類為 `NET_TIMEOUT`。

取消只回報 client 觀察到的狀況——不保證伺服器端的寫入已回滾。變更型請求若要重試，請加上 idempotency key。詳見 [HTTP 取消與期限](/zh-Hant-TW/docs/http#cancel-the-work)。
