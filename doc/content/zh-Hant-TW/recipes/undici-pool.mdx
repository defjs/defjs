# Undici Pool HTTP Handle

在高吞吐量的 Node.js BFF 與後端服務中，透過 [`withHTTPHandle`](/zh-Hant-TW/api/core/withhttphandle) 注入共用的 `undici.Pool`，即可讓多條上游連線保持預熱與受限重用，而 SDK 定義（`sdk/orders.ts`）則維持完全跨平台的純淨。請務必在服務關閉時呼叫 `await pool.close()` 釋放連線池。
