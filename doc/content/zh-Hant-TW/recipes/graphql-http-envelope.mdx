# 拆開 GraphQL HTTP envelope

Defjs 不實作 GraphQL `errorPolicy`。把 wire 建成 HTTP POST，由 builder 放上 query document 與 variables，再在你自己的 helper 裡拆 `errors[]`／缺少的 `data`。

見 [設計決策](/zh-Hant-TW/docs/design-decisions)。
