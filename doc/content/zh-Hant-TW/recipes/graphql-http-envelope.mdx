# 拆解 GraphQL HTTP 封套

Defjs 不內嵌 GraphQL client，也沒有 `errorPolicy`。請把 HTTP 上的 GraphQL 建模成標準 `POST` 操作，由 `builder` 送出 `{ query, operationName, variables }`。在封套 struct 上把 `data` 標記為 `.nullish()`，讓省略 `data` 與 `data: null` 都能通過 struct 驗證，再於應用程式輔助函式中拆解 `errors[]`：

- HTTP `200` 只代表 GraphQL 封套完整送達。`errors[]` 裡的領域錯誤（即使同時帶著 `data: null`）屬於應用程式層級的結果，不是 `RES_STRUCT_MISMATCH` fault。
- 至於協定專屬的封套為何要留在應用程式輔助函式裡，請參閱[核心架構](/zh-Hant-TW/docs/design-decisions)。
