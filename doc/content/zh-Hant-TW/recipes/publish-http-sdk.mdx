# 建置並發布 SDK [#publish-an-http-sdk-without-hiding-execute]

Defjs SDK 將純粹的操作定義與 Struct schemas 打包發布為 npm 套件，並將 `createClient(...)`、端點、憑證與攔截器完整保留給取用端應用程式自行掌控。

---

## 1. 定義 SDK 套件

將你的操作定義、統一匯出入口（Barrel export）、`package.json` 與 `tsconfig.json` 放置在獨立的套件目錄中，並將 `@defjs/core` 宣告為 `peerDependency`：

<include cwd meta='title="src/orders.ts"'>

  </Tab>
  <Tab value="src/index.ts">
```ts
export { getOrder } from "./orders";
```
  </Tab>
  <Tab value="package.json">
```json
{
  "name": "@company/orders-sdk",
  "version": "0.1.0",
  "type": "module",
  "sideEffects": false,
  "files": ["dist"],
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "default": "./dist/index.js"
    }
  },
  "scripts": {
    "build": "tsdown --platform neutral"
  },
  "peerDependencies": {
    "@defjs/core": "^0.6.0"
  },
  "devDependencies": {
    "@defjs/core": "^0.6.0",
    "tsdown": "^0.23.3",
    "typescript": "^7.0.2"
  }
}
```
  </Tab>
  <Tab value="tsconfig.json">
```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "lib": ["ES2022", "ESNext.Disposable", "DOM", "DOM.Iterable"],
    "strict": true,
    "noEmit": true
  },
  "include": ["src/**/*.ts"]
}
```
  </Tab>
</Tabs>

- `@defjs/core` 維持外部的執行時期 `peerDependency`，與取用端應用程式共用。
- `"sideEffects": false` 讓打包工具在應用程式僅匯入部分操作時，能夠透過 Tree-shaking 移除未使用的端點程式碼。

---

## 2. 建置並驗證 Tarball 封裝

使用 `tsdown` 打包產出 `dist/index.js` 與 `dist/index.d.ts`，並在發布前檢查套件內容：

```sh
bun install
bun run build
bun pm pack --dry-run
bun pm pack
```

驗證 `dist/index.js` 與 `dist/index.d.ts` 是否確實包含在 Tarball 壓縮檔中。

---

## 3. 在應用程式中取用 SDK

將你的 SDK 與 `@defjs/core` 一併安裝至應用程式：

```sh
bun add @company/orders-sdk @defjs/core@^0.6.0
```

應用程式建立專屬的 `Client`，並將其傳入匯入的操作中：

<include cwd meta='title="app.ts"'>
  examples/recipes/publish-http-sdk/app.ts#example
</include>

```txt
paid
```

在正式環境程式碼中，請將相對路徑匯入 `./orders-sdk` 替換為套件名稱 `@company/orders-sdk`，並移除 `withHTTPHandle(...)` 以使用平台原生的 `fetch`。

---

## 4. 測試與發布

使用[記憶體內 Handle 測試](/zh-Hant-TW/recipes/test-with-handle)演練匯出的操作定義，涵蓋請求對應、`output` 解碼、已宣告的 `HTTP_STATUS` 錯誤以及取消機制。驗證無誤後即可發布套件：

```sh
bun publish --access public
```

詳細資訊請參閱 [HTTP 請求](/zh-Hant-TW/docs/http)、[Client](/zh-Hant-TW/docs/client)、[測試](/zh-Hant-TW/docs/testing) 與 [核心架構](/zh-Hant-TW/docs/design-decisions)。
