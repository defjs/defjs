# 建置並發布 SDK [#publish-an-http-sdk-without-hiding-execute]

Defjs SDK 以 npm 套件的形式匯出純粹的操作定義與 struct schema，把 `createClient(...)`、端點、憑證與攔截器全都留給取用端應用程式。

---

## 1. 定義 SDK 套件

把操作定義、barrel 匯出、`package.json` 與 `tsconfig.json` 放在專屬的套件目錄中，並將 `@defjs/core` 宣告為 `peerDependency`：

- `@defjs/core` 維持為外部的執行時期 `peerDependency`，與取用端應用程式共用。
- `"sideEffects": false` 讓打包工具在應用程式只匯入部分操作時，以 tree-shaking 移除未使用的操作程式碼。

---

## 2. 建置並驗證 tarball

使用 `tsdown` 打包產出 `dist/index.js` 與 `dist/index.d.ts`，並在發布前檢查套件內容：

```sh
bun install
bun run build
bun pm pack --dry-run
bun pm pack
```

確認 tarball 中確實包含 `dist/index.js` 與 `dist/index.d.ts`。

---

## 3. 在應用程式中取用 SDK

將你的 SDK 與 `@defjs/core` 一併安裝至應用程式：

```sh
bun add @company/orders-sdk @defjs/core@^0.7.0
```

應用程式建立自己的 `Client`，並把它傳給匯入的操作：

<include cwd meta='title="app.ts"'>
  examples/recipes/publish-http-sdk/app.ts#example
</include>

```txt
paid
```

在正式環境程式碼中，請把相對匯入 `./src/orders.ts` 換成 `@company/orders-sdk`，並移除 `withHTTPHandle(...)`，改用平台的 `fetch`。

---

## 4. 測試與發布

用[記憶體內的 Handle 測試](/zh-Hant-TW/recipes/test-with-handle)測試匯出的定義，涵蓋請求對應、`output` 解碼、已宣告的 `HTTP_STATUS` fault 與取消。確認無誤後再發布套件：

```sh
bun publish --access public
```

請參閱 [HTTP 操作](/zh-Hant-TW/docs/http)、[Client](/zh-Hant-TW/docs/client)、[測試](/zh-Hant-TW/docs/testing) 與[核心架構](/zh-Hant-TW/docs/design-decisions)。
