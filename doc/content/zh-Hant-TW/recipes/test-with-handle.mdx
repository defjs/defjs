# 使用本機 Fetch Handle 進行測試

`withHTTPHandle(...)` 能為單一 Client 實例替換底層的 `fetch` 函式，同時完整演練 Defjs 的全套處理管線——輸入驗證、`builder` 參數對應、URL 解析、攔截器、狀態碼判定與 Struct 解碼——完全不需要開啟實體網路 Socket：
