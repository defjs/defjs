# 用本機 Fetch handle 測試

`withHTTPHandle(...)` 只替換該 client 的 Fetch。你仍會拿到 URL 建立、interceptors、狀態碼分派與 Struct 解碼 — 不需要 DNS、TLS 或真實伺服器。

細節見 [Client](/zh-Hant-TW/docs/client)。
