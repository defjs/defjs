# 使用本機 Fetch handle 進行測試

`withHTTPHandle(...)` 會為單一 client 替換底層的 `fetch`，同時跑完 Defjs 的整條管線——輸入驗證、`builder` 對應、URL 解析、攔截器、狀態分類與 struct 解碼——完全不開網路 socket：
