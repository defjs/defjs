# Vue

把既有的 `@defjs/core` client 提供給 Vue 應用程式。這個套件不會建立、快取或處置 client。需要 Vue 3 或更新版本。

見 [Vue 指南](/zh-Hant-TW/docs/integrations/vue)。

## createClientPlugin()

<ApiSignature name="createClientPlugin" />

- **client** — `createClient` 回傳的 client。
- **回傳** 供 `app.use(...)` 使用的 Vue 外掛。安裝它會呼叫 `app.provide(HTTP_CLIENT, client)`。

## injectClient()

<ApiSignature name="injectClient" />

`injectClient(key)` 會讀取該 key 最近一層的 provider；省略參數或傳入 `undefined` 時使用 `HTTP_CLIENT`。請在有效的 Vue 注入脈絡中呼叫：同步的 `setup()` 或 `app.runWithContext()`（Vue 3.3+）。後者只提供同步的應用程式層級脈絡，不包含子樹覆寫，也不會跨一般的 `await` 保留；`<script setup>` 頂層 `await` 之後由編譯器還原的脈絡仍然有效。請把該 client 傳進操作。注入的值是所提供的 [`DerivableClient`](/zh-Hant-TW/api/core/derivableclient-type)；在操作執行處以 request options 呼叫它，即可衍生出 `Client` 值。不要把它當成 `watch` 或 `computed` 的來源，因為那些會呼叫函式。衍生出的 `Client` 值不被外掛或 `injectClient` 接受。

自訂 `InjectionKey<DerivableClient>` 請用 `app.provide(key, client)` 或祖先的 `provide(key, client)` 設定。提供端與取得端必須共用同一個 `Symbol` 物件，描述相同並不代表 key 相同。`createClientPlugin(client)` 仍只接受 client，並提供 `HTTP_CLIENT`。

- **回傳** 所選 key 對應的同一個 client。
- **拋出** 沒有有效的注入脈絡，或所選 key 未提供 client 時，拋出 `Error`。自訂 key 缺少時不會回退到 `HTTP_CLIENT`；只安裝外掛並不會建立注入脈絡。

## HTTP_CLIENT

<ApiSignature name="HTTP_CLIENT" />

Vue 的 injection key。請優先使用 `injectClient()`，不要直接 `inject(HTTP_CLIENT)`。子樹覆寫請用 `provide(HTTP_CLIENT, childClient)`。
