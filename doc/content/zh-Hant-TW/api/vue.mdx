# Vue

把既有的 `@defjs/core` client 提供給 Vue app。這個套件不會建立、快取或 dispose client。需要 Vue 3 或更新版本。

見 [Vue 指南](/zh-Hant-TW/docs/integrations/vue)。

## createClientPlugin()

```ts
function createClientPlugin(client: Client): Plugin
```

- **client** — `createClient` 給的實例。
- **回傳** 給 `app.use(...)` 用的 Vue plugin。安裝它會呼叫 `app.provide(HTTP_CLIENT, client)`。

<include cwd>examples/api/create-client-plugin.ts#example</include>

## injectClient()

```ts
function injectClient(): Client
```

讀最近的 `HTTP_CLIENT` provider。請在允許 `inject` 的地方呼叫，例如 `setup()`。

- **回傳** 注入的 client。
- **拋出** 沒有提供 client 時丟出 `Error`，例如沒裝 plugin。

## HTTP_CLIENT

```ts
const HTTP_CLIENT: InjectionKey<Client>
```

Vue injection key。優先用 `injectClient()`，別直接 `inject(HTTP_CLIENT)`。子樹覆蓋：`provide(HTTP_CLIENT, childClient)`。
