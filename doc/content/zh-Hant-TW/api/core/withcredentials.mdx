---
title: 'withCredentials'
description: '讓 HTTP 與 SSE request 帶上 credentials 的 client option。'
---

<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

為 `true` 時，HTTP 與 SSE request 的 Fetch 會用 `credentials: 'include'`，因此 cookies 與其他 credentials 會隨跨來源 request 一起送出。為 `false` 或從未設定時，不會設定 `credentials`，由 Fetch 使用它的預設值。

WebSocket constructor 不會收到這個設定。
