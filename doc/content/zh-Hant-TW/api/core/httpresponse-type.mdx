<ApiReference identity="@defjs/core:HttpResponse" />

```ts
type HttpResponse<R> = {
  readonly [HTTP_RESPONSE]: true // internal brand; build values with makeResponse
  readonly url: string
  readonly status: number
  readonly statusText: string
  readonly headers: Headers
  readonly body: R | null | undefined
  readonly ok: boolean
}
```

傳輸層產生、interceptors 看到的 wire 形態：`body` 是文字或已剖析的 JSON，不是解碼後的值。沒有 body 時，`body` 是 `undefined`；JSON 的 `null` 仍是 `null`。對 JSON 表示，字串是 JSON 字串根，不會再剖析一次；位元組與 blob 是原始資料，會剖析一次。`ok` 在 2xx 時為 true。傳輸失敗是 fault，絕不是 response。到達呼叫方的是 `DecodedResponse`。
