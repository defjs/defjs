<ApiReference identity="@defjs/core:ERR_ABORTED" />

```ts
const ERR_ABORTED: Error // message: 'Request was aborted'
```

呼叫方取消時共用的 `cause` 與 message 值。`createNetworkFault` 會把它，以及名為 `AbortError` 的 `DOMException`，對應到 `NET_ABORTED`。HTTP interceptor 拋出它時，該次呼叫會以 `NET_ABORTED` fault resolve。SSE 與 WebSocket interceptors 拋出它時，則回報為 `EXT_INTERCEPTOR_FAILED`。

見 [Errors 指南](/zh-Hant-TW/docs/errors)。
