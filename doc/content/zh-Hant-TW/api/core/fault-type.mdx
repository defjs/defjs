<ApiReference identity="@defjs/core:Fault" />

```ts
type Fault<TErr extends AnyStruct | undefined = undefined> = FaultOf<[TErr] extends [undefined] ? undefined : Infer<TErr>>
```

`TErr` 是端點宣告的 `error` struct；沒有宣告時為 `undefined`。`Fault<TErr>` 是把 [`FaultOf`](/zh-Hant-TW/api/core/faultof-type) 套用到解碼後的 body 型別上，所以它是三種變體的聯集：[`DecodeFault`](/zh-Hant-TW/api/core/decodefault-type)、[`HttpStatusFault<TErr>`](/zh-Hant-TW/api/core/httpstatusfault-type) 與 [`PreflightFault`](/zh-Hant-TW/api/core/preflightfault-type)。請依 `fault.code` 做 switch。

每種變體都是名為 `DefjsFault` 的原生 `Error`，所以 `String(fault)` 會直接產生可寫入 log 的 `DefjsFault: <message>`。`code` 與各變體的 metadata（`status`、`response`、`data`）都是可列舉的 own property。原生的 `cause` 鏈則不可列舉。
