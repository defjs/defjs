<ApiReference identity="@defjs/core:ErrorMap" />

```ts
type ErrorMap = (issue: StructIssue) => string | undefined
```

作為 `struct.parse` 的 `errorMap` 選項傳入。每個 issue（`code`、`expected`、`message`、`path`、`received`）在記錄之前都會呼叫它。任何字串，包含 `''`，都會取代預設值；只有 `undefined` 會保留它。這個 map 屬於這次 parse 呼叫，也會處理另一份 Core 副本所建立之 struct 的 bigint/date 轉換失敗。預設 message 會省略收到的值；自訂文字會原樣使用，因此避免放入敏感的 `received` 值。
