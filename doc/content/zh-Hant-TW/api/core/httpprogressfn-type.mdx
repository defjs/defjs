<ApiReference identity="@defjs/core:HttpProgressFn" />

```ts
type HttpProgressFn = (event: HttpProgressEvent) => Promise<void> | void
```

在 `HttpExecuteOptions` 中作為 `onDownloadProgress` 或 `onUploadProgress` 傳入。回呼可以採用非同步形式，系統會等它完成後才處理下一個資料區塊。無論下載或上傳，回呼拋出錯誤或回傳的 Promise 遭拒絕，都會讓該次呼叫以 `EXT_OBSERVER_FAILED` 失敗，拋出的值作為 `cause`。呼叫端取消與 `timeout` 仍具優先權，分別回報 `NET_ABORTED` 與 `NET_TIMEOUT`。上傳進度只在支援串流請求主體的執行環境中回報（Bun、Node、Deno）。在瀏覽器中，`Blob`／`File`、`ArrayBuffer` 或 `FormData` 主體會原樣送出，不會呼叫 `onUploadProgress`；`onDownloadProgress` 不受影響。

見 [`HttpProgressEvent`](/zh-Hant-TW/api/core/httpprogressevent-type)、[HTTP 指南](/zh-Hant-TW/docs/http) 與 [Commands](/zh-Hant-TW/docs/commands)。
