```ts
function createNetworkFault(cause: unknown, response?: HttpMeta): PreflightFault
```

- **cause** — 底層的取消、逾時或傳輸失敗。
- **response** — metadata，只有傳輸層當時已經有可回報的內容時才有。有給時會附加到 fault 上。
- **回傳** 一個 `PreflightFault`，其 code 取決於 `cause`：
  - `ERR_ABORTED` 或名為 `AbortError` 的 `DOMException` 對應 `NET_ABORTED`。message 為 `Request was aborted`。
  - `ERR_TIMEOUT` 或名為 `TimeoutError` 的 error 對應 `NET_TIMEOUT`。message 為 cause 的 message；為空時為 `Request timed out`。
  - 其他一切對應 `NET_UNREACHABLE`，message 為 cause 的 message。

cause 會保留為 `cause`。
