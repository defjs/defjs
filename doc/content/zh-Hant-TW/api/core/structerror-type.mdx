<ApiReference identity="@defjs/core:StructError" />

```ts
class StructError extends Error {
  readonly issues: StructIssue[]
  constructor(issues: StructIssue[])
  format(): FormattedStructError
  flatten(): FlattenedStructError
  prettify(): string
}
```

`name` 是 `'StructError'`。只有一個 issue 時，`message` 是該 issue 的 message；有多個時是 `N struct issues: <first message>`；沒有 issue 時是 `Struct parse failed`。

- `struct.parse` 在第一個失敗就停止，所以這裡的 `issues` 只有一個 [`StructIssue`](/zh-Hant-TW/api/core/structissue-type)。
- `format()` 回傳 [`FormattedStructError`](/zh-Hant-TW/api/core/formattedstructerror-type) 樹。每個節點都有 `_errors` 陣列，巢狀 key 跟著 `issue.path`。
- `flatten()` 回傳 [`FlattenedStructError`](/zh-Hant-TW/api/core/flattenedstructerror-type)：path 為空的 message 放進 `formErrors`，其他的依 path 第一段分組放進 `fieldErrors`。
- `prettify()` 每個 issue 回傳一行 `× path: message`。空的 path 顯示為 `<root>`。

見 [Struct 指南](/zh-Hant-TW/docs/struct)。
