<ApiReference identity="@defjs/core:HttpResponseType" />

```ts
type HttpResponseType = 'arraybuffer' | 'blob' | 'json' | 'text'
```

由宣告的 struct 種類決定（`string` → `text`，`blob` / `file` → `blob`，`arrayBuffer` → `arraybuffer`，其餘一切 → `json`）。它不是 `defineRequest` 上的欄位，而是以 `responseType` 與 `errorResponseType` 出現在 `HttpRequest` 上。
