<ApiReference identity="@defjs/core:ERR_TIMEOUT" />

```ts
const ERR_TIMEOUT: Error // message: 'Request timed out'
```

逾時時共用的 `cause` 與 message 值。`createNetworkFault` 會把它，以及任何名為 `TimeoutError` 的 error，對應到 `NET_TIMEOUT`。HTTP interceptor 拋出它時，該次呼叫會以 `NET_TIMEOUT` fault resolve。SSE 與 WebSocket interceptors 拋出它時，則回報為 `EXT_INTERCEPTOR_FAILED`。

見 [Errors 指南](/zh-Hant-TW/docs/errors)。
