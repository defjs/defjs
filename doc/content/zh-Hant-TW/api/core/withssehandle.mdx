```ts
function withSSEHandle(fetchImpl: FetchHandle): ClientOption
```

替換開啟 SSE 事件串流所用、與 Fetch 相容的函式。預設是平台的 `fetch`。

- **fetchImpl** 是 [`FetchHandle`](/zh-Hant-TW/api/core/fetchhandle-type)。
- 它只影響 SSE。HTTP 請用 [`withHTTPHandle`](/zh-Hant-TW/api/core/withhttphandle)。
