<ApiReference identity="@defjs/core:createHttpInterceptor" />

```ts
function createHttpInterceptor(fn: InterceptorFn): HttpInterceptor

type InterceptorFn = (req: HttpRequest, next: HttpInterceptorNext) => Promise<HttpResponse<unknown>>
type HttpInterceptorNext = (req: HttpRequest) => Promise<HttpResponse<unknown>>
```

回傳 `{ kind: 'http', fn }`。呼叫 `next(req)`（可帶修改過的 request），或用 `makeResponse` 做 short-circuit。`next` 只會執行排在這個 interceptor 之後註冊的 interceptors，然後是 fetch handler。HTTP interceptors 不會對 SSE 或 WebSocket command 執行。

`next(req)` 發生確定性的 URL 錯誤時，回傳的 promise 會被拒絕，因此 `.then`／`.catch` 的復原處理會執行；若未復原，`client.execute` 仍會回報 `REQ_BUILD_FAILED`。
