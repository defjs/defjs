<ApiReference identity="@defjs/core:struct.blob" />

```ts
function blob(): Struct<Blob, Blob>
```

- 接受 `Blob`（`File` 也是 `Blob`）。其他值以 `invalid_type` 失敗。
- 當 body 根時，原樣送出，使用 blob 自己的 type 或 `application/octet-stream`。
- 當 `output` 或 `error` struct 時，回應 body 會以 `Blob` 讀取。
