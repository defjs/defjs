---
title: 'struct.tuple'
description: '以每個位置一個 struct 解析固定長度陣列的 struct。'
---

<ApiReference identity="@defjs/core:struct.tuple" />

```ts
function tuple<const T extends readonly [StructLike<unknown, unknown, boolean>, ...StructLike<unknown, unknown, boolean>[]]>(
  items: T,
): TupleStruct<T>
```

`struct.tuple` 接受 structs 的**單一陣列**，不是分開的引數：

```ts
const Pair = struct.tuple([struct.string(), struct.number()])
```

- 每個位置用相同索引的 struct 解析。輸入必須是長度完全相同的陣列，否則以 `invalid_type`（expected `tuple of length N`）失敗。
- 把 structs 當成分開的引數傳入，也就是 `struct.tuple(a, b)`，會丟出 `TypeError`。
- 項目不是 struct 時丟出 `TypeError`。

`TupleStruct<T>` 沒有匯出。它是 `Struct`，其輸入與輸出是各項目型別組成的 tuple。
