<ApiReference identity="@defjs/core:struct.formData" />

```ts
function formData<T extends ObjectShape>(shape: T): ObjectStruct<T>
```

parse 行為與 [`struct.object()`](/zh-Hant-TW/api/core/struct-object) 相同，並帶有 `formData` codec tag。

- tag 只有在這個 struct 的值是 request body 根時才生效。此時 body 以 `FormData` 送出，multipart boundary 由平台決定。
- 陣列會重複欄位名稱，`undefined` 欄位會被略過，`Blob` / `File` 值以檔案附加。巢狀物件會讓請求以 `REQ_BUILD_FAILED` 失敗。
- `struct.parse` 忽略這個 tag。它不接受 `FormData` 實例，只接受純物件。
