<ApiReference identity="@defjs/core:Interceptor" />

```ts
type Interceptor = HttpInterceptor | SSEInterceptor | WebSocketInterceptor
```

`kind`（`'http'`、`'sse'` 或 `'web-socket'`）決定 interceptor 會對哪種 command 執行。`withInterceptors` 接受任意混搭；每種傳輸只執行自己 kind 的 interceptor，順序依註冊先後。
