# API 查閱

建置或使用 Defjs SDK 時查這份參考。SDK 作者從 [`defineRequest`](/zh-Hant-TW/api/core/definerequest)、[`defineEventStream`](/zh-Hant-TW/api/core/defineeventstream)、[`defineWebSocket`](/zh-Hant-TW/api/core/definewebsocket) 與 [Struct](/zh-Hant-TW/api/struct) 開始。應用程式用 [Client 設定](/zh-Hant-TW/api/client) 呼叫這些操作，並用 [Errors](/zh-Hant-TW/api/errors) 處理結果。

以下簽章描述 Defjs 的執行階段契約。完整開發流程見[快速開始](/zh-Hant-TW/docs/start)與[建置並發佈 SDK](/zh-Hant-TW/recipes/publish-http-sdk)。
