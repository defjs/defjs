# API 查閱

依職責選擇入口：SDK 作者使用 `defineRequest`、`defineEventStream`、`defineWebSocket` 與 `struct.*` 定義並匯出契約；應用程式使用 `createClient`、`with*` 設定與 `client.execute(...)` 執行這些定義建立的 command。

以下簽章描述 Defjs 的執行階段契約。完整開發流程見[快速開始](/zh-Hant-TW/docs/start)與[建置並發佈 SDK](/zh-Hant-TW/recipes/publish-http-sdk)。
