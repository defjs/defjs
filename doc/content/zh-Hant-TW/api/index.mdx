# API 查閱

建置或取用 Defjs SDK 時，請查這份參考。SDK 作者從 [`defineRequest`](/zh-Hant-TW/api/core/definerequest)、[`defineEventStream`](/zh-Hant-TW/api/core/defineeventstream)、[`defineWebSocket`](/zh-Hant-TW/api/core/definewebsocket) 與 [Struct](/zh-Hant-TW/api/struct) 開始。應用程式用 [Client 設定](/zh-Hant-TW/api/client) 呼叫這些操作，並以 [Errors](/zh-Hant-TW/api/errors) 處理結果。

簽章就是契約。完整流程請見[快速開始](/zh-Hant-TW/docs/start)與[建置並發布 SDK](/zh-Hant-TW/recipes/publish-http-sdk)。
