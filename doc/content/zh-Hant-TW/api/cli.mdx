# CLI (`@defjs/cli`)

開發期 CLI 與程式化產生器，將 Swagger 2.0 與 OpenAPI 3.0–3.2 規格轉換為無狀態 ESM 格式的 `@defjs/core` 模組。請參閱 [CLI 整合指南](/zh-Hant-TW/docs/integrations/cli)。
