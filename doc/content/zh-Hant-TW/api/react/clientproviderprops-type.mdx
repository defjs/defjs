<ApiReference identity="@defjs/react:ClientProviderProps" />

```ts
interface ClientProviderProps {
  client: Client
  children?: ReactNode
}
```

- `client` — 必填。由應用程式擁有的 Defjs client。
- `children` — 選填。可以呼叫 `useClient` 的 React 樹。
