# Defjs

**TypeScript SDK 與高韌性 Client 工具組 — 寫一次 API 契約定義，執行細節交給每個應用程式自己設定。**

無論你是想發布獨立的 npm SDK，還是只想把內部專案的前後端介面層整理乾淨，Defjs 都把兩端職責清楚拆開：

- **SDK 介面定義（`@defjs/core`、`@defjs/cli`）** — 使用 `defineRequest`、`defineEventStream` 與 `defineWebSocket` 宣告具型別的 HTTP、SSE 與 WebSocket 操作，並搭配 `struct` schema（手寫或從 OpenAPI 2.0/3.0/3.1/3.2 規格產生為無狀態 ESM）。定義本身是純資料：光匯入不會發起任何網路呼叫，也不會綁定全域 Client。
- **應用程式高韌性執行（`@defjs/core`）** — 應用程式在邊界建立專屬的 `Client`（`createClient(withEndpoint(...))`），掛上憑證與攔截器（`basicAuth*`、`idempotencyKeyHttpInterceptor`、`concurrencyLimitHttpInterceptor`），設定 P2C 負載平衡與 `outlierDetection`（`halfOpen`、`maxEjectionPercent`），啟用 `429`/`Retry-After` 重試，透過 `@defjs/core/concurrent` 並行扇出，或借助 `@defjs/core/port` 橋接 Worker 與瀏覽器擴充功能。

## 為什麼把定義與 Client 拆開？

| 職責範圍     | 介面定義（專案 `src/api/` 或公開 SDK）                                                               | 應用程式（執行時期）                                          |
| ------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| **負責項目** | HTTP 方法、路徑模板、`input` / `output` / `error` schemas、`builder` 參數對應，以及可選的自訂 `meta` | 基礎網址（Base URLs）、憑證、驗證攔截器、負載平衡、逾時與釋放 |
| **交付形式** | 可在瀏覽器、SSR 與離線測試間共用的 ESM 模組與 `.d.ts` 型別宣告                                       | 瀏覽器、Node 伺服器或單元測試環境各自的執行設定               |
| **主要優勢** | 零環境耦合；同一套定義不用改寫就能在線上、SSR 與本機測試中執行                                       | 完全掌控重試、容錯移轉、遙測追蹤與連線生命週期                |

## 支援的傳輸協定與回傳 Tuple

每項操作都會回傳配合其傳輸生命週期設計的三元素 error-first tuple：

| 傳輸協定                                     | 入口函式            | Tuple 結構                   | 資源怎麼取消與釋放                                                        |
| -------------------------------------------- | ------------------- | ---------------------------- | ------------------------------------------------------------------------- |
| **[HTTP](/zh-Hant-TW/docs/http)**            | `defineRequest`     | `[err, data, response]`      | 透過 `client({ signal })` 取消進行中的請求                                |
| **[SSE](/zh-Hant-TW/docs/sse)**              | `defineEventStream` | `[err, stream, open]`        | 透過 `await using` 或 `stream.close()` + `await stream.closed` 釋放資源   |
| **[WebSocket](/zh-Hant-TW/docs/web-socket)** | `defineWebSocket`   | `[err, session, connection]` | 透過 `await using` 或 `session.close()` + `await session.closed` 釋放資源 |

當 HTTP 請求失敗時，tuple 為 `[err, undefined, undefined]`，因為 `err` 本身已帶有 `HttpMeta` 回應中繼資料。對 SSE 與 WebSocket 而言，只要失敗前曾擷取到啟動快照，第三個欄位就會帶著該快照。
