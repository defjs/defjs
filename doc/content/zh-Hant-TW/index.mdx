# Defjs

**一次定義 API 契約，依個別應用程式靈活設定執行細節。**

Defjs 將 TypeScript SDK 的兩側明確分開：

- **SDK 定義端 (`@defjs/core`)** — SDK 開發者在 `struct` schema 旁宣告具型別的 HTTP、SSE 與 WebSocket 操作。定義本身是純粹的資料：匯入時不會發起任何網路請求，也不會綁定全域 Client。
- **應用程式執行端** — 取用 SDK 的應用程式建立專屬的 `Client`（`createClient(withEndpoint(...))`），設定憑證與攔截器、配置負載平衡，並在呼叫操作時傳入該 Client。

## 為什麼要將「定義」與「Client」拆開？

| 職責範圍     | SDK 開發者（定義端）                                                                                         | 應用程式（執行端）                                                |
| ------------ | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| **負責項目** | HTTP 方法、路徑模板、`input` / `output` / `error` schemas、`builder` 參數對應，以及可選的應用程式自訂 `meta` | 基礎網址（Base URLs）、憑證、驗證攔截器、負載平衡、逾時與資源釋放 |
| **發布內容** | 可重用的 ESM 模組與 `.d.ts` 型別宣告                                                                         | 瀏覽器、伺服器或測試環境的執行時期設定                            |
| **主要優勢** | 零環境耦合；可在瀏覽器、SSR 伺服器端與測試之間無縫共用                                                       | 完全掌控重試、容錯移轉、遙測追蹤與生命週期                        |

## 支援的傳輸協定與回傳 Tuple

每項操作都會回傳配合其傳輸生命週期設計的三元素 error-first tuple：

| 傳輸協定                                     | 入口函式            | Tuple 結構                   | 生命週期擁有權                                                            |
| -------------------------------------------- | ------------------- | ---------------------------- | ------------------------------------------------------------------------- |
| **[HTTP](/zh-Hant-TW/docs/http)**            | `defineRequest`     | `[err, data, response]`      | 透過 `client({ signal })` 取消進行中的請求                                |
| **[SSE](/zh-Hant-TW/docs/sse)**              | `defineEventStream` | `[err, stream, open]`        | 透過 `await using` 或 `stream.close()` + `await stream.closed` 釋放資源   |
| **[WebSocket](/zh-Hant-TW/docs/web-socket)** | `defineWebSocket`   | `[err, session, connection]` | 透過 `await using` 或 `session.close()` + `await session.closed` 釋放資源 |

當 HTTP 請求失敗時，tuple 為 `[err, undefined, undefined]`，因為 `err` 本身已帶有 `HttpMeta` 回應中繼資料。對 SSE 與 WebSocket 而言，只要失敗前曾擷取到啟動快照，第三個欄位就會帶著該快照。
