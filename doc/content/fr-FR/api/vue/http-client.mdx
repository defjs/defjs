<ApiReference identity="@defjs/vue:HTTP_CLIENT" />

```ts
const HTTP_CLIENT: InjectionKey<Client>
```

La clé sous laquelle `createClientPlugin` fournit le client. Préfère `injectClient()` à `inject(HTTP_CLIENT)`, qui renvoie `undefined` quand rien n’a été fourni. Remplace un sous-arbre avec `provide(HTTP_CLIENT, childClient)`.
