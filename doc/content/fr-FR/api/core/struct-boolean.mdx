<ApiReference identity="@defjs/core:struct.boolean" />

```ts
function boolean(): Struct<boolean, boolean>
```

Accepte uniquement `true` et `false`. Les autres valeurs, y compris `'true'` et `1`, échouent avec `invalid_type`.
