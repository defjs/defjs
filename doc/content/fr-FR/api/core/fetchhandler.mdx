```ts
function fetchHandler(httpRequest: HttpRequest, fetchImpl?: FetchHandle): Promise<HttpResponse<unknown>>
```

- **httpRequest** — Requête normalisée (URL, en-têtes, corps, signal d’abort, hooks de progress).
- **fetchImpl** — Un [`FetchHandle`](/fr-FR/api/core/fetchhandle-type) ; le `fetch` global par défaut. Un handle personnalisé reçoit un `Request`, et son corps est lu chunk par chunk.

Transport HTTP par défaut. Le client l’utilise toujours ; `withHTTPHandle` ne remplace que le `fetchImpl` qu’il appelle. Il rejette — au lieu de résoudre avec une réponse synthétique — quand aucune réponse n’a atteint le client.
