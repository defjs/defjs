<ApiReference identity="@defjs/core:createSSEInterceptor" />

```ts
function createSSEInterceptor(fn: SSEInterceptorFn): SSEInterceptor

type SSEHandler = (req: HttpRequest) => Promise<EventStreamHandle<unknown>>
type SSEInterceptorFn = (req: HttpRequest, next: SSEHandler) => Promise<EventStreamHandle<unknown>>
```

Renvoie `{ kind: 'sse', fn }`. Les intercepteurs SSE ne s’exécutent que pour les commandes SSE, dans l’ordre d’enregistrement ; `next(req)` ouvre le flux via les intercepteurs restants.

`EventStreamHandle` étend `AsyncDisposable`. Une implémentation qui court-circuite structurellement doit fournir `[Symbol.asyncDispose](): PromiseLike<void>` et le relier au même cycle de vie de fermeture.
