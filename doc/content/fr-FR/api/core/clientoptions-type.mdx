---
title: 'ClientOptions'
description: 'Options du client en forme d’entrée, qui reflètent ce que configurent les helpers d’options.'
---

<ApiReference identity="@defjs/core:ClientOptions" />

```ts
interface ClientOptions extends HttpClientOptions {
  sse?: ClientSSEOptions
  webSocket?: ClientWebSocketOptions
}

// Non-exported base, shown inline.
interface HttpClientOptions {
  endpoint: string
  headers?: Headers
  http?: { handle?: FetchHandle }
  interceptors?: Interceptor[]
  querySerializer?: QuerySerializer
  timeout?: number
  withCredentials?: boolean
  xsrf?: {
    cookieName?: string
    headerName?: string
    tokenProvider?: (context: { request: HttpRequest }) => string | null | undefined
  }
}
```

La forme côté utilisateur des réglages avant l’application des valeurs par défaut. `createClient` n’accepte pas cet objet ; configure un client avec des helpers d’options comme `withEndpoint` et `withTimeout`. [`ClientConfig`](/fr-FR/api/core/clientconfig-type) en est la contrepartie résolue.
