<ApiReference identity="@defjs/core:FetchHandle" />

```ts
type FetchHandle = (input: RequestInfo | URL, init?: RequestInit) => Promise<Response>
```

La signature d’appel `(input, init?) => Promise<Response>` que Defjs invoque. Ce n’est volontairement pas `typeof fetch`, afin qu’un mock n’ait pas besoin des extras de l’hôte comme `preconnect`. Un handle personnalisé est appelé avec un `Request` ; seule la valeur par défaut de la bibliothèque (le `fetch` global) est appelée sous la forme `(url, init)`.

Accepté par `withHTTPHandle`, `withSSEHandle` et `fetchHandler`.
