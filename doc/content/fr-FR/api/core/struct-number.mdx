<ApiReference identity="@defjs/core:struct.number" />

```ts
function number(): Struct<number, number>
```

- Accepte les valeurs `number`, y compris `Infinity`. `NaN` et les non-nombres échouent avec `invalid_type`.
- Les strings ne sont pas converties.
