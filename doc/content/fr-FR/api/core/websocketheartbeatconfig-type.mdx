<ApiReference identity="@defjs/core:WebSocketHeartbeatConfig" />

```ts
interface WebSocketHeartbeatConfig<TIncoming = unknown, TOutgoing = unknown> {
  intervalMs: number
  isAck?: (message: TIncoming) => boolean
  message?: () => TOutgoing
  timeoutMs?: number
}
```

- `intervalMs` est le délai entre deux messages de heartbeat.
- `message()` construit le payload. Il est envoyé à travers le struct `outgoing`. Rien n’est envoyé s’il est omis ou s’il renvoie `undefined`.
- `isAck(message)` reçoit chaque message entrant décodé. Quand elle renvoie `true`, le message est traité comme l’acquittement et n’est pas livré à `receive`.
- `timeoutMs` est la durée d’attente d’un acquittement après un heartbeat. Le manquer fait échouer la session.
- `intervalMs` et `timeoutMs` doivent être strictement positifs, finis, et au plus égaux à `2_147_483_647`.

Définis-le avec [`withWebSocketHeartbeat`](/fr-FR/api/core/withwebsocketheartbeat) ou l’option d’execute `heartbeat`.
