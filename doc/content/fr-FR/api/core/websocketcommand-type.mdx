<ApiReference identity="@defjs/core:WebSocketCommand" />

```ts
interface WebSocketCommand<
  TInput extends AnyStruct | undefined,
  TIncoming extends AnyStruct,
  TOutgoing extends AnyStruct | undefined,
> extends BaseCommand<typeof WEB_SOCKET_COMMAND> {
  readonly endpoint: WebSocketDefinition<TInput, TIncoming, TOutgoing>
  readonly input: EndpointInput<TInput> | undefined
}
```

Créée en appelant un [`WebSocketEndpoint`](/fr-FR/api/core/websocketendpoint-type). Elle contient la définition de l’endpoint et l’entrée non parsée. Passe-la à `client.execute` pour ouvrir une session ; rien ne se connecte avant.

`BaseCommand` porte des membres à clé symbole qui routent la commande vers le bon transport. Ils sont internes : traite la commande comme opaque.
