<ApiReference identity="@defjs/core:withWebSocketHeartbeat" />

```ts
function withWebSocketHeartbeat(options: ClientWebSocketOptions['heartbeat']): ClientOption
```

Active les messages de heartbeat avec détection optionnelle de l’acquittement. Passer `undefined` efface un réglage précédent. Le type de l’option est :

```ts
{
  intervalMs: number
  isAck?: (message: unknown) => boolean
  message?: <T = unknown>() => T | unknown
  timeoutMs?: number
}
```

- Toutes les `intervalMs`, `message()` est appelé et son résultat est envoyé à travers le struct `outgoing` de l’endpoint. Aucun message n’est envoyé quand `message` est omis ou renvoie `undefined`.
- Avec `timeoutMs`, un acquittement est attendu après chaque heartbeat. `isAck` reçoit le message entrant décodé ; quand elle renvoie `true`, le timer est effacé et ce message n’est **pas** livré à `receive`.
- Si aucun ack n’arrive dans `timeoutMs`, ou si un heartbeat ne peut pas être envoyé, la session échoue. Cela ne déclenche pas de reconnect.
- `intervalMs` et `timeoutMs` doivent être strictement positifs, finis, et au plus égaux à `2_147_483_647` ; sinon execute échoue avec `REQ_OPTIONS_INVALID`.
- Un `heartbeat` dans les options d’execute remplace celui-ci pour cet appel.
