<ApiReference identity="@defjs/core:WebSocketHandle" />

```ts
type WebSocketHandle = Omit<
  WebSocket,
  | 'binaryType'
  | 'CLOSED'
  | 'CLOSING'
  | 'CONNECTING'
  | 'dispatchEvent'
  | 'onclose'
  | 'onerror'
  | 'onmessage'
  | 'onopen'
  | 'OPEN'
  | 'readyState'
> & { readonly readyState: number }
```

Le `WebSocket` du DOM sans ses propriétés de gestionnaires d’événements, `binaryType`, `dispatchEvent` et les constantes d’état. Une implémentation personnalisée a donc besoin de `url`, `protocol`, `extensions`, `bufferedAmount`, `send`, `close`, `addEventListener`, `removeEventListener` et d’un `readyState` numérique.

Le transport pose `binaryType = 'arraybuffer'` quand la propriété existe. C’est le type d’instance produit par un [`WebSocketHandleConstructor`](/fr-FR/api/core/websockethandleconstructor-type).
