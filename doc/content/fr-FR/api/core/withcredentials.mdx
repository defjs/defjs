---
title: 'withCredentials'
description: 'Option de client qui envoie les credentials avec les requêtes HTTP et SSE.'
---

<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

Quand la valeur est `true`, Fetch utilise `credentials: 'include'` pour les requêtes HTTP et SSE, si bien que les cookies et autres credentials sont envoyés avec les requêtes cross-origin. Quand elle est `false` ou jamais définie, `credentials` n’est pas posé et Fetch applique son comportement par défaut.

Le constructeur WebSocket ne reçoit pas ce réglage.
