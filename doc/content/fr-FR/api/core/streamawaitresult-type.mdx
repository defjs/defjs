```ts
type StreamAwaitResult<TEvent, TError extends AnyStruct | undefined = undefined> =
  | [error: null, stream: EventStreamHandle<TEvent>, open: EventStreamOpenInfo]
  | [error: Fault<TError>, stream: undefined, open: EventStreamOpenInfo | undefined]
```

Le résultat de `client.execute` pour une commande SSE.

- En cas de succès : `[null, stream, open]`. `open` est l’instantané pris à l’ouverture du flux ; `stream.open` peut changer après une reconnexion.
- En cas d’échec : `[fault, undefined, open]`. `open` porte l’instantané de la réponse quand l’échec est survenu après l’arrivée d’une réponse, par exemple un handshake non 2xx, et vaut `undefined` sinon.
- `TError` est le struct `error` déclaré. Il type le corps d’erreur décodé sur le fault.
