title: 'ERR_ABORTED'
description: 'Sentinelle Error partagée qui marque une requête comme annulée.'
---

<ApiReference identity="@defjs/core:ERR_ABORTED" />

```ts
const ERR_ABORTED: Error // message: 'Request was aborted'
```

Valeur partagée de `cause` et de message pour l’annulation par l’appelant. `createNetworkFault` l’associe, ainsi qu’une `DOMException` nommée `AbortError`, à `NET_ABORTED`. Un intercepteur HTTP qui la lève fait résoudre l’appel avec un fault `NET_ABORTED`. Les intercepteurs SSE et WebSocket qui la lèvent sont signalés comme `EXT_INTERCEPTOR_FAILED`.

Voir le [guide Gestion des erreurs](/fr-FR/docs/errors).
