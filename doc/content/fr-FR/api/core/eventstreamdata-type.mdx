---
title: 'EventStreamData'
description: 'Union des événements SSE parsés, inférée d’une map EventStructs.'
---

<ApiReference identity="@defjs/core:EventStreamData" />

```ts
type EventStreamData<TEvents extends EventStructs> = TEvents extends EventStructs
  ? KnownEventUnion<TEvents> | DefaultEventUnion<TEvents>
  : never
```

Pour chaque nom d’événement déclaré sauf `default`, l’union contient `{ event: <name>; data: Infer<TEvents[name]>; id?: string }`. Quand un struct `default` est déclaré, elle ajoute `{ event: string; data: Infer<TEvents['default']>; id?: string }` pour chaque nom d’événement qui n’a pas de struct propre. `KnownEventUnion` et `DefaultEventUnion` sont des types utilitaires internes.
