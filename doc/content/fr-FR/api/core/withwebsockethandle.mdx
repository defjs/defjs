<ApiReference identity="@defjs/core:withWebSocketHandle" />

```ts
function withWebSocketHandle(WebSocketImpl: WebSocketHandleConstructor): ClientOption
```

Remplace le constructeur WebSocket utilisé pour les connexions socket. Par défaut, c’est `globalThis.WebSocket`.

- **WebSocketImpl** est un [`WebSocketHandleConstructor`](/fr-FR/api/core/websockethandleconstructor-type) qui renvoie un [`WebSocketHandle`](/fr-FR/api/core/websockethandle-type).
- Si aucun constructeur n’est disponible, l’exécution d’une commande WebSocket échoue avec une fault `ENV_UNSUPPORTED`.
