<ApiReference identity="@defjs/core:EventStreamOpenInfo" />

```ts
interface EventStreamOpenInfo {
  response: HttpResponse<unknown>
  url: string
}
```

`response` est la réponse du handshake et `url` est l’URL de requête résolue. C’est le troisième élément d’un résultat réussi de `client.execute` et la valeur de `EventStreamHandle.open`.
