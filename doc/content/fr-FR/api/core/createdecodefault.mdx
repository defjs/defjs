<ApiReference identity="@defjs/core:createDecodeFault" />

```ts
function createDecodeFault(code: DecodeFaultCode, cause: unknown, response: HttpMeta): DecodeFault
```

- **code** — L’étape de lecture qui a échoué : `RES_DECODE_FAILED`, `RES_MEDIA_TYPE_INVALID` ou `RES_STRUCT_MISMATCH`.
- **cause** — L’échec sous-jacent du parseur ou du struct, conservé comme `cause`. Son message devient normalement le message du fault (`String(cause)` quand ce n’est pas une `Error`). Pour `RES_DECODE_FAILED` avec une `Error` nommée `SyntaxError`, le message est `Response body could not be decoded`, ce qui garde les fragments du parseur hors de `String(fault)`. Les messages Struct par défaut contiennent les kinds reçus, pas les valeurs ; les valeurs brutes et le texte du parseur restent sur la cause.
- **response** — Métadonnées de la réponse qui n’a pas pu être lue. `status` en est copié.
- **Renvoie** une `Error` native nommée `DefjsFault`, sans `body`.
