# Référence API

<ApiIndex />

Cette référence décrit les éléments publics destinés aux auteurs de SDK et aux applications. Les signatures fixent le contrat ; le [guide](/fr-FR/docs/start) et la [recette de publication](/fr-FR/recipes/publish-http-sdk) montrent leur utilisation complète.

- **Créer un SDK :** commence par [`struct`](/fr-FR/api/struct), [`defineRequest`](/fr-FR/api/http), [`defineEventStream`](/fr-FR/api/sse) ou [`defineWebSocket`](/fr-FR/api/web-socket), puis exporte les endpoints obtenus.
- **Utiliser un SDK :** configure [`createClient` et `with*`](/fr-FR/api/client), exécute les endpoints importés et gère les [erreurs](/fr-FR/api/errors) et les ressources de transport.
- **Intégrer l’application :** ajoute les [intercepteurs](/fr-FR/api/interceptors), [React](/fr-FR/api/react), [Vue](/fr-FR/api/vue) ou [OpenTelemetry](/fr-FR/api/opentelemetry-server) au client de l’application.
