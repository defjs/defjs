# Référence API

<ApiIndex />

Utilise cette référence pendant que tu construis ou consommes un SDK Defjs. Les auteurs de SDK commencent par [`defineRequest`](/fr-FR/api/core/definerequest), [`defineEventStream`](/fr-FR/api/core/defineeventstream), [`defineWebSocket`](/fr-FR/api/core/definewebsocket) et les [Structs](/fr-FR/api/struct). Les applications utilisent la [configuration du Client](/fr-FR/api/client) pour appeler ces opérations et les [Erreurs](/fr-FR/api/errors) pour traiter les résultats.

Les signatures sont le contrat. Suis le [démarrage rapide](/fr-FR/docs/start) et le [guide de publication de SDK](/fr-FR/recipes/publish-http-sdk) pour le parcours complet.

## Paquets

| Paquet                                                           | Ce que tu cherches                                                |
| ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| [`@defjs/core`](/fr-FR/api/client)                               | `createClient`, `defineRequest`, `struct`, HTTP / SSE / WebSocket |
| [`@defjs/vue`](/fr-FR/api/vue)                                   | `createClientPlugin`, `injectClient`, `HTTP_CLIENT`               |
| [`@defjs/react`](/fr-FR/api/react)                               | `ClientProvider`, `useClient`                                     |
| [`@defjs/opentelemetry-server`](/fr-FR/api/opentelemetry-server) | `withOpenTelemetryServer`, options par transport                  |
