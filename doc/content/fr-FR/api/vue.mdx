# Vue

Fournissez un client `@defjs/core` existant à une application Vue. Ce paquet ne crée pas, ne met pas en cache et ne dispose pas le client. Vue 3 ou plus récent est requis.

Voir le [guide Vue](/fr-FR/docs/integrations/vue).

## createClientPlugin()

<ApiSignature name="createClientPlugin" />

- **client** — Client renvoyé par `createClient`.
- **Renvoie** un plugin Vue pour `app.use(...)`. L’installer appelle `app.provide(HTTP_CLIENT, client)`.

## injectClient()

<ApiSignature name="injectClient" />

`injectClient(key)` lit le provider le plus proche pour cette clé ; omis ou `undefined`, il utilise `HTTP_CLIENT`. Appelez-le dans un contexte d'injection Vue valide : `setup()` synchrone ou `app.runWithContext()` (Vue 3.3+). Ce dernier ne fournit qu’un contexte synchrone au niveau de l’app, pas les surcharges de sous-arbre ni le contexte à travers un `await` ordinaire. Les contextes restaurés par le compilateur après un `await` de premier niveau dans `<script setup>` restent valides. Passez ce client à une opération. La valeur injectée est le [`DerivableClient`](/fr-FR/api/core/derivableclient-type) fourni ; appelez-le avec des options de requête là où l’opération s’exécute pour dériver une valeur `Client`. Ne l'utilisez pas comme source d’un `watch` ou d’un `computed`, car ceux-ci appellent une fonction. Une valeur `Client` dérivée n’est pas acceptée par le plugin ni par `injectClient`.

Pour une `InjectionKey<DerivableClient>` personnalisée, utilisez `app.provide(key, client)` ou le `provide(key, client)` d'un ancêtre. Partagez le même objet `Symbol` ; des descriptions identiques ne rendent pas les clés égales. `createClientPlugin(client)` ne prend toujours que le client et fournit `HTTP_CLIENT`.

- **Renvoie** le client exact fourni pour la clé sélectionnée.
- **Lève** une `Error` sans contexte d’injection actif ou sans client pour la clé sélectionnée. Une clé personnalisée absente ne retombe jamais sur `HTTP_CLIENT` ; installer le plugin seul n’établit pas de contexte d’injection.

## HTTP_CLIENT

<ApiSignature name="HTTP_CLIENT" />

Clé d'injection Vue. Préférez `injectClient()` à `inject(HTTP_CLIENT)`. Surchargez un sous-arbre avec `provide(HTTP_CLIENT, childClient)`.
