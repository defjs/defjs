# Client

L’application crée son `Client`, importe les endpoints du SDK et exécute leurs commandes. Le client porte l’URL de base, l’authentification, les intercepteurs et le transport propres à l’environnement ; le SDK fournit le contrat de l’API. Le même endpoint exporté peut ainsi être utilisé dans des tests, un navigateur ou un serveur avec des clients Defjs configurés différemment.

Le client exécute les commandes HTTP, SSE et WebSocket. Il ne met pas les résultats en cache, n’organise pas les tentatives de l’application et ne supervise pas les flux ouverts. Les résultats, l’annulation et le nettoyage restent à la charge de l’appelant qui lance le travail.

## Exécuter par transport

- HTTP → `[error, data, response]`
- SSE → `[error, stream, open]`. `open` est l’instantané du premier handshake réussi de la connexion du handle renvoyé pour les handles natifs Defjs ou les wrappers transmettant le même objet `open` live ; les handles custom ou wrappers qui redéfinissent `open` utilisent leur `open` public courant même après une reconnexion, tandis que `stream.open` reste live (voir [SSE](/fr-FR/docs/sse)).
- WebSocket → `[error, session, connection]`

L’execute WebSocket peut remplacer `beforeConnect`, `heartbeat`, `protocols` et `reconnect`. `timeout` doit être un entier sûr positif dans `1..2_147_483_647`.

Tu possèdes le nettoyage : abandonne HTTP, ferme SSE + `await stream.closed`, ferme WebSocket + `await session.closed`.

## Portée serveur vs navigateur

Sur un serveur, crée le client dans la frontière de la requête quand les options ou closures d’intercepteur capturent auth, cookies, utilisateurs ou tenants. L’identité du client n’est pas une frontière de sécurité à elle seule.

## Référence

| Helper                                                                                                        | Effet                                                                             |
| ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `withEndpoint(url)`                                                                                           | Endpoint de base absolu pour tous les transports                                  |
| `withHeaders(HeadersInit)`                                                                                    | En-têtes par défaut statiques pour HTTP/SSE ; les en-têtes de commande overrident |
| `withTimeout(ms)`                                                                                             | Timeout `execute` HTTP par défaut seulement (SSE/WS l’ignorent)                   |
| `withHTTPHandle(fetch)`                                                                                       | Remplace Fetch pour HTTP                                                          |
| `withSSEHandle(fetch)`                                                                                        | Remplace Fetch pour SSE                                                           |
| `withWebSocketHandle(WebSocket)`                                                                              | Remplace le constructeur WebSocket                                                |
| `withInterceptors(...items)`                                                                                  | Ajoute des intercepteurs mixtes en fin de chaîne                                  |
| `withQuerySerializer(fn)`                                                                                     | Encode un objet de query déjà aliasé en query string                              |
| `withCredentials(boolean)`                                                                                    | Fetch `credentials: 'include'` pour HTTP/SSE quand true                           |
| `withXSRF(options?)`                                                                                          | Cookie XSRF HTTP → en-tête                                                        |
| `withSSEReconnect` / `withSSEOnInvalidEvent`                                                                  | Réglages SSE                                                                      |
| `withWebSocketReconnect` / `withWebSocketHeartbeat` / `withWebSocketProtocols` / `withWebSocketBeforeConnect` | Réglages WebSocket                                                                |
