# Struct & schémas

`struct` déclare le contrat de données réseau partagé entre un SDK et ses consommateurs : entrées de l'appelant, sorties `2xx`, erreurs de service déclarées, événements SSE et trames WebSocket.

- **Inférence statique** : Dérivez les types TypeScript grâce à `Infer<typeof Schema>`.
- **Validation error-first** : Validez les valeurs à l'exécution via `struct.parse(Schema, value)` — renvoie `[null, data]` ou `[StructError, undefined]` sans jamais lever d'exception.

Les objets analysés ne conservent que les champs déclarés (les propriétés inconnues sont retirées) et adoptent un prototype `null`. Tout champ requis manquant, tout type primitif incorrect ou toute branche invalide génère un `StructError` sans aucune sortie partielle.

## 2. Champs requis, facultatifs et nullables

Defjs sépare strictement la **présence du champ** (`undefined`) de sa **nullabilité** (`null`). Chaque constructeur de struct est obligatoire et non-null par défaut :

| Déclaration                  | Manquant / `undefined`                  | `null`  | Valeur valide      |
| ---------------------------- | --------------------------------------- | ------- | ------------------ |
| `struct.string()`            | Rejet                                   | Rejet   | Accepte `string`   |
| `struct.string().optional()` | Accepte (omis lors de la sérialisation) | Rejet   | Accepte `string`   |
| `struct.string().null()`     | Rejet                                   | Accepte | Accepte `string`   |
| `struct.string().nullish()`  | Accepte (omis lors de la sérialisation) | Accepte | Accepte `string`   |
| `struct.null()`              | Rejet                                   | Accepte | Rejette non-`null` |

<include cwd lang="typescript">
  examples/struct/required-optional-null.ts#example
</include>

`struct.any()` et `struct.unknown()` rejettent également `null` et `undefined`, sauf s'ils sont combinés avec `.null()`, `.optional()` ou `.nullish()`.

## 3. Alias réseau bidirectionnels (`.alias()`)

Utilisez `.alias("wire_name")` lorsque le backend emploie du `snake_case` ou des noms d'en-têtes spécifiques alors que votre SDK TypeScript utilise le `camelCase`. Vous déclarez l'alias une fois sur le champ, et il fonctionne dans les deux sens :

| Frontière                                                               | Clé utilisée                                              |
| ----------------------------------------------------------------------- | --------------------------------------------------------- |
| `input` d'opération et `struct.parse(Schema, value)`                    | Nom logique (`customerName`)                              |
| Valeur struct typée renvoyée par `builder` (`body`, `query`, `headers`) | Alias réseau (`customer_name`)                            |
| Décodage de réponse JSON / événement SSE / trame WebSocket              | Alias réseau `customer_name` → nom logique `customerName` |
| Clé d'objet anonyme écrite directement dans `builder`                   | Clé littérale telle qu'écrite                             |

<include cwd lang="typescript">
  examples/struct/aliases.ts#example
</include>

Copier un objet typé avec la syntaxe de déploiement (spread) au sein du `builder` (`{ ...input.order, extra: 1 }`) préserve l'encodage du struct et ses alias. Déclarer à la fois la clé logique et son alias réseau sur le même objet échoue avec `REQ_BUILD_FAILED`.

## 4. Placement dans la requête et codecs de formulaire

`input` définit les paramètres ; `builder` les place dans `{ path, query, headers, body }`. Pour les corps encodés en formulaire, `struct.urlencoded(shape)` et `struct.formData(shape)` marquent l'objet racine afin que le transport le sérialise automatiquement en `URLSearchParams` ou `FormData` :

<include cwd lang="typescript">
  examples/struct/request-placement.ts#example
</include>

| Racine du corps renvoyée par le `builder`         | Format réseau     | `Content-Type` par défaut                         |
| ------------------------------------------------- | ----------------- | ------------------------------------------------- |
| Objet typé, tableau, nombre fini, booléen, `null` | Texte JSON        | `application/json`                                |
| Struct `string` ou `string` brute                 | Texte UTF-8       | `text/plain;charset=UTF-8`                        |
| `struct.urlencoded(shape)` à la racine du corps   | `URLSearchParams` | `application/x-www-form-urlencoded;charset=UTF-8` |
| `struct.formData(shape)` à la racine du corps     | `FormData`        | `multipart/form-data; boundary=...`               |
| `Blob` / `File` (`struct.file()`)                 | Binaire blob      | `blob.type` ou `application/octet-stream`         |
| `ArrayBuffer` / vue / `ReadableStream`            | Octets bruts      | `application/octet-stream`                        |

## 5. Traitement de `StructError` et des issues

`struct.parse(Schema, data, { aliases?, errorMap? })` renvoie `[StructError, undefined]` en cas d'échec. `StructError` hérite de la classe native `Error` et fournit `issues`, `format()`, `flatten()` et `prettify()` :

<include cwd lang="typescript">
  examples/struct/parse-failures.ts#example
</include>

Chaque `StructIssue` contient `code` (`invalid_type`, `missing_key`, `invalid_literal`, `invalid_enum`, `invalid_union`, `invalid_intersection` ou `custom`), `path`, `expected`, `received` et `message`. Les messages par défaut omettent la valeur reçue et n'indiquent que son _type_, mais les chemins conservent les clés dynamiques de record, qui peuvent contenir des valeurs sensibles. `String(error)` et `error.prettify()` ne constituent pas une frontière d'occultation ; utilisez une liste d'autorisation de champs sûrs pour les journaux, et traitez les valeurs brutes `received` ainsi que les messages personnalisés comme sensibles.

## 6. Référence des constructeurs

<include cwd lang="typescript">
  examples/struct/any.ts#example
</include>

| Constructeur                                               | Entrée acceptée                        | Sortie inférée                                                   |
| ---------------------------------------------------------- | -------------------------------------- | ---------------------------------------------------------------- |
| `struct.string()` / `struct.boolean()`                     | Primitive correspondante               | `string` / `boolean`                                             |
| `struct.number()`                                          | Tout `number` sauf `NaN`               | `number` (`NaN` rejeté ; `±Infinity` rejeté dans les corps JSON) |
| `struct.bigint()`                                          | `bigint` ou chaîne numérique           | `bigint`                                                         |
| `struct.date()`                                            | `Date` valide, timestamp ou chaîne ISO | `Date`                                                           |
| `struct.literal(value)`                                    | Littéral primitif exact                | Type littéral                                                    |
| `struct.enum(values)`                                      | Membre chaîne ou nombre déclaré        | Union de littéraux                                               |
| `struct.array(item)` / `struct.tuple(items)`               | Tableau / tuple de longueur fixe       | `T[]` / `[...]`                                                  |
| `struct.object(shape)` / `struct.record(val)`              | Objet simple                           | Objet typé / `Record<string, V>`                                 |
| `struct.discriminatedUnion(key, options)`                  | Objet avec discriminant littéral `key` | Union des branches d'objets                                      |
| `struct.or(branches)`                                      | Première branche correspondante        | Union des types des branches                                     |
| `struct.intersection(members)`                             | Valeur satisfaisant tous les membres   | Intersection fusionnée en profondeur                             |
| `struct.file()` / `struct.blob()` / `struct.arrayBuffer()` | `File` / `Blob` / `ArrayBuffer`        | Représentation binaire                                           |
