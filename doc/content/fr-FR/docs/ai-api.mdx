# llms.txt

Ce site publie du Markdown anglais destiné aux assistants. Ces adresses n’ont pas de préfixe de locale et ne sont pas des traductions des guides localisés.

## Index des pages [#llms-txt]

[llms.txt](/llms.txt) liste les pages anglaises et renvoie à leurs URL. C’est le point d’entrée lorsqu’un assistant doit d’abord trouver une page.

## Guides compilés [#llms-full]

[llms-full.txt](/llms-full.txt) réunit les guides anglais dans un seul fichier. Utilisez-le lorsqu'un assistant a besoin d’un contexte large dans un même document et que le budget de tokens le permet.

## Une page en Markdown [#page-markdown]

Chaque page anglaise est aussi disponible en Markdown à l’adresse `/llms.mdx/<path>/content.md`. Par exemple, [Quick start en Markdown](/llms.mdx/docs/start/content.md) est le texte anglais de la page Quick start.

## Vérifier la version [#version]

Ce site documente la branche par défaut ; le projet peut installer une autre version de `@defjs/core`. Vérifiez les API par rapport au paquet installé avant d'appliquer une suggestion. Supprimez les secrets et vérifiez les politiques du projet avant de partager du code ou du contexte avec un outil d’IA.
