# Annuler un appel HTTP

Combine le signal de l’appelant et une échéance sur `signal`. `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` est un seul signal. Un abort manuel se classe en `NET_ABORTED`. Une échéance se classe en `NET_TIMEOUT`.

Voir [HTTP](/fr-FR/docs/http#cancel-the-work) pour les détails.

<include cwd meta="cancel-report.ts">
  examples/recipes/cancel-http.ts#example
</include>

```txt
caller cancelled
```

L’annulation te dit ce que l’appelant a observé. Elle ne prouve pas qu’une écriture côté serveur a été annulée — garde les nouvelles tentatives de mutation derrière un contrat d’idempotence.
