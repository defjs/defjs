# Ouvrir une session WebSocket

Déclarez les structs `incoming` et `outgoing` sur `defineWebSocket`. Dans votre application, abonnez-vous à `session.onRuntimeError(...)`, consommez `session.receive`, et veillez systématiquement à vous désabonner, appeler `session.close(...)` et attendre `await session.closed` dans un bloc `finally` :

Avec un serveur répondant à `{ "type": "subscribe", "symbol": "ACME" }` par `{ "type": "tick", "symbol": "ACME", "price": 142.5 }`, le script affiche :

```txt
ACME 142.5
```

- La reconnexion (`withRetry`) et le heartbeat (`withWebSocketHeartbeat`) sont tous deux opt-in sur le client.
- Les WebSockets de navigateur ne peuvent pas envoyer d'en-têtes HTTP arbitraires lors du handshake d'upgrade ; utilisez des cookies, des sous-protocoles ou des jetons temporaires à la place. Consultez [Sessions WebSocket](/fr-FR/docs/web-socket).
