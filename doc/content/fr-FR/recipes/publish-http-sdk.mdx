# Publier un SDK HTTP sans cacher execute

Un SDK de méthodes qui avale `client.execute` rabaisse en général un `404` déclaré en exception non typée ou en « erreur API » partagée. Garde le contrat comme des endpoints plus un client explicite ; les appelants possèdent encore le branchement sur le statut.

Voir [Commandes](/fr-FR/docs/commands), [Client](/fr-FR/docs/client) et [Décisions de conception](/fr-FR/docs/design-decisions).
