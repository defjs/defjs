# Handle HTTP Undici Pool

Dans les BFF et services backend Node.js à fort débit, injectez un `undici.Pool` partagé via [`withHTTPHandle`](/fr-FR/api/core/withhttphandle) pour garder plusieurs connexions upstream actives et bornées tout en laissant vos définitions de SDK (`sdk/orders.ts`) totalement indépendantes de la plateforme. Pensez à appeler `await pool.close()` lors de l'arrêt.
