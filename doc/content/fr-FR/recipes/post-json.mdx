# POST JSON

Remets le corps typé au builder. Les noms de champs logiques restent dans TypeScript ; les alias wire du struct deviennent les clés JSON. Un corps objet est `application/json`.

Voir [HTTP](/fr-FR/docs/http) et [Client](/fr-FR/docs/client) pour les détails.

<include cwd meta="create-order.ts">
  examples/recipes/post-json.ts#example
</include>

`api.example.com` est un placeholder. Avec un serveur qui répond `201` et `{ "id": 1, "status": "paid", "customer_name": "Ada" }`, le snippet affiche :

```txt
Created paid → 201
```
