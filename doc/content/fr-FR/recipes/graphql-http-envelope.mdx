# Déballer une enveloppe GraphQL HTTP

Defjs n'intègre aucun client GraphQL ni politique `errorPolicy`. Modélisez GraphQL sur HTTP comme une opération `POST` standard dont le `builder` transmet `{ query, operationName, variables }`. Déclarez `data` comme `.nullish()` sur le Struct de l'enveloppe afin qu'une propriété `data` omise ou valant `null` satisfasse la validation structurelle, puis extrayez `errors[]` dans une fonction utilitaire applicative :

- Un code HTTP `200` signifie uniquement que l'enveloppe GraphQL a été reçue intacte. Les erreurs métier présentes dans `errors[]` (même accompagnées de `data: null`) sont des résultats applicatifs et non des faults `RES_STRUCT_MISMATCH`.
- Consultez [Architecture du cœur](/fr-FR/docs/design-decisions) pour comprendre pourquoi les enveloppes propres à un protocole sont confiées à des helpers applicatifs.
