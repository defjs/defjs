# Tester avec un handle Fetch local

`withHTTPHandle(...)` remplace Fetch pour ce client seulement. Tu obtiens quand même la construction d’URL, les intercepteurs, le dispatch par statut et le décodage Struct — sans DNS, TLS, ni vrai serveur.

Voir [Client](/fr-FR/docs/client) pour les détails.
