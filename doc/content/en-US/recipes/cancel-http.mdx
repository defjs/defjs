# Cancel an HTTP call

Combine the caller's signal with a deadline on `signal`. `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` is one signal. A manual abort classifies as `NET_ABORTED`. A deadline classifies as `NET_TIMEOUT`.

See [HTTP](/docs/http#cancel-the-work) for details.

```txt

```

Cancellation tells you what the caller observed. It does not prove a server-side write rolled back — keep mutation retries behind an idempotency contract.
