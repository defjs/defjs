# Unwrap a GraphQL HTTP envelope

Defjs does not implement GraphQL `errorPolicy`. Model the wire as an HTTP POST whose builder places the query document and variables. Declare envelope `data` as `.nullish()` so both missing `data` and `data: null` reach your helper, then unwrap `errors[]` before checking `data`.

See [Design Decisions](/docs/design-decisions).

HTTP success only means the envelope arrived. Application errors stay in `errors[]` until your unwrap throws or returns, including a response with `data: null`. The example handles both missing `data` and `data: null` with `errors[]` as application errors, not Struct mismatches.

`if (error) throw error` adapts a Defjs fault to that helper. HTTP 200 GraphQL failures stay application errors in `errors[]` and are thrown on their own.
