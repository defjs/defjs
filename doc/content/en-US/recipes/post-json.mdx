# POST JSON

Hand the typed body to the builder. Logical field names stay in TypeScript; wire aliases on the struct become JSON keys. An object body is `application/json`.

See [HTTP](/docs/http) and [Client](/docs/client) for details.

<include cwd meta="create-order.ts">
  examples/recipes/post-json.ts#example
</include>

`api.example.com` is a placeholder. With a server that answers `201` and `{ "id": 1, "status": "paid", "customer_name": "Ada" }`, the snippet prints:

```txt
Created paid → 201
```
