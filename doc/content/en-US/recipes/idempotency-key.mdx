# Idempotency keys

By default, `withRetry` retries only idempotent HTTP methods (`GET`, `HEAD`, `PUT`, `DELETE`, `OPTIONS`, `TRACE`). When enabling retries on `POST` or `PATCH` endpoints, pair `withRetry` with `idempotencyKeyHttpInterceptor()` so every retry attempt of the same logical call reuses `req.correlationId` as its `Idempotency-Key` header while subsequent calls receive fresh keys.
