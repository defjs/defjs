# Undici Pool HTTP handle

In high-throughput Node.js BFFs and backend services, inject a shared `undici.Pool` via [`withHTTPHandle`](/api/core/withhttphandle) so multiple upstream connections stay warm and bounded while SDK definitions (`sdk/orders.ts`) stay completely platform-neutral. Remember to call `await pool.close()` during shutdown.
