```ts
function withWebSocketHandle(WebSocketImpl: WebSocketHandleConstructor): ClientOption
```

Replaces the WebSocket constructor used for socket connections. The default is `globalThis.WebSocket`.

- **WebSocketImpl** is a [`WebSocketHandleConstructor`](/api/core/websockethandleconstructor-type) that returns a [`WebSocketHandle`](/api/core/websockethandle-type).
- If no constructor is available, executing a WebSocket command fails with an `ENV_UNSUPPORTED` fault.
