```ts
function createResolvedRequestUrl(baseEndpoint: string, path: string, queryString?: string): URL
```

- **baseEndpoint** — The client endpoint. Its query and hash are dropped, and a trailing slash is added to its pathname so that the base path is kept: `https://api.example.com/v1` with `/users` gives `https://api.example.com/v1/users`.
- **path** — A relative endpoint path. A single leading slash is removed.
- **queryString** — Query without a leading `?`. When non-empty it is set as the URL's search verbatim.
- **Returns** the resolved `URL`.

Throws `TypeError('Client endpoint must be a valid URL')` when `baseEndpoint` does not parse. Throws `Error` when `path` has a scheme or starts with `//` (`Endpoint path must not be an absolute URL`), or contains `?` or `#` (`Endpoint path must not include query or hash`).
