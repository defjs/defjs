---
title: 'ClientOptions'
description: 'Input-shaped client options that mirror what the option helpers configure.'
---

<ApiReference identity="@defjs/core:ClientOptions" />

```ts
interface ClientOptions extends HttpClientOptions {
  sse?: ClientSSEOptions
  webSocket?: ClientWebSocketOptions
}

// Non-exported base, shown inline.
interface HttpClientOptions {
  endpoint: string
  headers?: Headers
  http?: { handle?: FetchHandle }
  interceptors?: Interceptor[]
  querySerializer?: QuerySerializer
  timeout?: number
  withCredentials?: boolean
  xsrf?: {
    cookieName?: string
    headerName?: string
    tokenProvider?: (context: { request: HttpRequest }) => string | null | undefined
  }
}
```

The user-facing shape of the settings before defaults are applied. `createClient` does not accept this object; configure a client with option helpers such as `withEndpoint` and `withTimeout`. [`ClientConfig`](/api/core/clientconfig-type) is the resolved counterpart.
