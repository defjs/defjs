<ApiReference identity="@defjs/core:withEndpoint" />

```ts
function withEndpoint(endpoint: string): ClientOption
```

Sets the base URL prepended to relative request paths. The default is an empty string.

- **endpoint** — absolute or relative base endpoint.
- For WebSocket commands, an `http:` base becomes `ws:` and `https:` becomes `wss:`.
