```ts
interface FormattedStructError {
  _errors: string[]
  [key: string]: FormattedStructError | string[]
}
```

The result of `StructError.format()`. Leaf messages live under `_errors`; nested keys mirror the failing path. A path segment literally named `_errors` is stored as `\_errors`.
