---
title: 'withCredentials'
description: 'Client option that sends credentials with HTTP and SSE requests.'
---

<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

When `true`, Fetch uses `credentials: 'include'` for HTTP and SSE requests, so cookies and other credentials are sent with cross-origin requests. When it is `false` or never set, `credentials` is left unset and Fetch uses its default.

The WebSocket constructor does not receive this setting.
