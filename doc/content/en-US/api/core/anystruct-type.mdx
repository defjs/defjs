<ApiReference identity="@defjs/core:AnyStruct" />

```ts
type AnyStruct = Struct<any, any, boolean>
```

Broad constraint used by endpoint and client generics such as `defineRequest`, `Fault`, and
`HttpCommand`. Prefer a concrete `Struct<...>` when you need precise input and output inference.
