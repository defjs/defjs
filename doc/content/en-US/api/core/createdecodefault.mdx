<ApiReference identity="@defjs/core:createDecodeFault" />

```ts
function createDecodeFault(code: DecodeFaultCode, cause: unknown, response: HttpMeta): DecodeFault
```

- **code** — Which read step failed: `RES_DECODE_FAILED`, `RES_MEDIA_TYPE_INVALID`, or `RES_STRUCT_MISMATCH`.
- **cause** — The underlying parser or struct failure, kept as `cause`. Its message normally becomes the fault message (`String(cause)` when it is not an `Error`). For `RES_DECODE_FAILED` with an `Error` named `SyntaxError`, the message is `Response body could not be decoded`, keeping parser fragments out of `String(fault)`. Default Struct messages contain received kinds, not values; raw values and parser text remain on the cause.
- **response** — Metadata of the response that could not be read. `status` is copied from it.
- **Returns** a native `Error` named `DefjsFault` with no `body`.
