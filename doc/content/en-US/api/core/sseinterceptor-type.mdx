<ApiReference identity="@defjs/core:SSEInterceptor" />

```ts
interface SSEInterceptor {
  kind: 'sse'
  fn: SSEInterceptorFn
}
```

Created by `createSSEInterceptor(fn)`. The `kind` tag lets `withInterceptors` accept HTTP, SSE, and WebSocket interceptors in one list; only `kind: 'sse'` interceptors run for SSE commands.
