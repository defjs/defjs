<ApiReference identity="@defjs/core:fetchHandler" />

```ts
function fetchHandler(httpRequest: HttpRequest, fetchImpl?: FetchHandle): Promise<HttpResponse<unknown>>
```

- **httpRequest** — Normalized request (URL, headers, body, abort signal, progress hooks).
- **fetchImpl** — A [`FetchHandle`](/api/core/fetchhandle-type); defaults to the global `fetch`. A custom handle receives a `Request`, and its body is read chunk by chunk.

Default HTTP transport. The client always uses it; `withHTTPHandle` only replaces the `fetchImpl` it calls. It rejects — rather than resolving
with a synthetic response — when no response reached the client.
