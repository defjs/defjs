```ts
interface ClientSSEConfig extends ClientSSEOptions {

```

The type of `ClientConfig.sse`. It is [`ClientSSEOptions`](/api/core/clientsseoptions-type) with `handle` always present; the default wrapper resolves the current global `fetch` on each attempt, rather than capturing it at import time.
