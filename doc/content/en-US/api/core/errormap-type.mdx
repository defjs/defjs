---
title: 'ErrorMap'
description: 'Callback that rewrites the message of a struct issue.'
---

<ApiReference identity="@defjs/core:ErrorMap" />

```ts
type ErrorMap = (issue: StructIssue) => string | undefined
```

Passed as the `errorMap` option of `struct.parse`. It is called for each issue (`code`, `expected`, `message`, `path`, `received`) before the issue is recorded. Return a string to replace the default message, or `undefined` to keep it.
