<ApiReference identity="@defjs/core:UseRequestConfig" />

```ts
type UseRequestConfig = {
  onDownloadProgress?: HttpProgressFn
  onUploadProgress?: HttpProgressFn
} & ({ abort?: AbortSignal; timeout?: never } | { abort?: never; timeout?: number })
```

The HTTP-specific part of [`HttpExecuteOptions`](/api/core/httpexecuteoptions-type), which adds `signal`.

- `onDownloadProgress` and `onUploadProgress` are [`HttpProgressFn`](/api/core/httpprogressfn-type) callbacks. They receive an [`HttpProgressEvent`](/api/core/httpprogressevent-type) with `loaded`, `total`, and `lengthComputable`.
- Cancellation is either `abort` or `timeout`, never both. The type rejects both, and at runtime passing both fails with a `REQ_OPTIONS_INVALID` fault.
- `timeout` must be a positive safe integer no greater than `2_147_483_647`. It replaces the default set by [`withTimeout`](/api/core/withtimeout) for that call. `abort` combines with that default instead.
