```ts
function withHTTPHandle(fetchImpl: FetchHandle): ClientOption
```

Replaces the Fetch-compatible function used for HTTP requests. The default is the platform `fetch`.

- **fetchImpl** is a [`FetchHandle`](/api/core/fetchhandle-type), the `(input, init?) => Promise<Response>` call signature. It is not `typeof fetch`, so a test double does not need host extras such as `fetch.preconnect`.
- It only affects HTTP. SSE uses [`withSSEHandle`](/api/core/withssehandle).
