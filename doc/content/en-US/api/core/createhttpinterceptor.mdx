---
title: 'createHttpInterceptor'
description: 'Wraps an interceptor function as a tagged HTTP interceptor.'
---

<ApiReference identity="@defjs/core:createHttpInterceptor" />

```ts
function createHttpInterceptor(fn: InterceptorFn): HttpInterceptor

type InterceptorFn = (req: HttpRequest, next: HttpInterceptorNext) => Promise<HttpResponse<unknown>>
type HttpInterceptorNext = (req: HttpRequest) => Promise<HttpResponse<unknown>>
```

Returns `{ kind: 'http', fn }`. Call `next(req)` (optionally with a modified request) or short-circuit with `makeResponse`. `next` runs only the interceptors registered after this one and then the fetch handler. HTTP interceptors do not run for SSE or WebSocket commands.

A deterministic URL error from `next(req)` rejects the returned promise, so `.then` / `.catch` recovery runs; if it is not recovered, `client.execute` still reports `REQ_BUILD_FAILED`.
