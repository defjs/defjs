<ApiReference identity="@defjs/core:withInterceptors" />

```ts
function withInterceptors(...interceptors: Interceptor[]): ClientOption
```

Appends interceptors to the client interceptor chain. Calling it again appends more; it never replaces earlier ones.

- The first registered interceptor is the outermost layer.
- HTTP, SSE, and WebSocket interceptors can be mixed in one call. At execute time only the interceptors of the command's transport run, in their registration order.
