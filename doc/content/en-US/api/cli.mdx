# CLI (`@defjs/cli`)

Development-time CLI and programmatic generator converting Swagger 2.0 and OpenAPI 3.0–3.2 specifications into stateless ESM `@defjs/core` modules. See the [CLI integration guide](/docs/integrations/cli).
