# API Reference

<ApiIndex />

Use this reference while building or consuming a Defjs SDK. SDK authors start with [`defineRequest`](/api/core/definerequest), [`defineEventStream`](/api/core/defineeventstream), [`defineWebSocket`](/api/core/definewebsocket), and [Structs](/api/struct). Applications use [Client configuration](/api/client) to execute those definitions and [Errors](/api/errors) to handle results.

Signatures are the contract. Follow the [quick start](/docs/start) and [SDK publishing guide](/recipes/publish-http-sdk) for the complete workflow.
