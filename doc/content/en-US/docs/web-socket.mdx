# WebSocket sessions

`defineWebSocket` declares a bidirectional WebSocket contract in your SDK: the path template, optional `input` and `builder` (`path` and `query` only), `incoming` and `outgoing` message structs, queue bounds, and static subprotocols. The consuming application configures heartbeat, reconnect, and lifecycle cleanup on its client.

## 1. Define the contract and run a session

Model multiple frame types on `incoming` or `outgoing` using `struct.discriminatedUnion(...)`. Release the returned `WebSocketSession` with `await using` or explicit `session.close()` + `await session.closed`:

<Tabs items={["sdk/ticks-socket.ts", "app/session.ts", "Single-file quick look"]}>
<Tab value="sdk/ticks-socket.ts">

```ts
import { defineWebSocket, struct } from "@defjs/core";

export const TickFrame = struct.discriminatedUnion("type", [
  struct.object({
    type: struct.literal("tick"),
    symbol: struct.string(),
    price: struct.number(),
  }),
  struct.object({
    type: struct.literal("subscribed"),
    symbol: struct.string(),
  }),
]);

export const SubscribeCommand = struct.object({
  type: struct.literal("subscribe"),
  symbol: struct.string(),
});

export const openTicker = defineWebSocket({
  path: "/market/ws",
  operation: "market.ticker",
  incoming: TickFrame,
  outgoing: SubscribeCommand,
  maxIncomingQueueSize: 64,
});
```

</Tab>
<Tab value="app/session.ts">

```ts
import { createClient, withEndpoint } from "@defjs/core";
import { openTicker } from "../sdk/ticks-socket.ts";

const client = createClient(withEndpoint("https://api.example.com"));

async function main() {
  const [error, session] = await openTicker(client);
  if (error) {
    console.error(error.code);
    return;
  }

  await using active = session;
  active.send({ type: "subscribe", symbol: "ACME" });

  for await (const message of active.receive) {
    if (message.type === "tick") {
      console.log(message.symbol, message.price);
      break;
    }
  }
}

void main();
```

## 2. Message validation and direction rules

- **Incoming frames (`session.receive`)**: Text, `ArrayBuffer`, typed arrays, and `Blob` frames are decoded as UTF-8, parsed as JSON, and validated against `incoming`. Malformed JSON or schema mismatches are reported to `session.onRuntimeError` and dropped without closing the session. `session.receive` is single-consumer; requesting a second iterator throws `TypeError`.
- **Outgoing frames (`session.send(payload)`)**: Synchronously validates against `outgoing`, applies `.alias()` and codecs, and serializes with `JSON.stringify`. Sends immediately when `open`, queues during `reconnecting` (if `maxOutgoingQueueSize > 0`), and throws synchronously if the payload is invalid, the queue is full/disabled, or the session is closed.

## 3. Session state and observers

| Member               | Description                                                                                           |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| `state`              | `'idle' \| 'connecting' \| 'open' \| 'reconnecting' \| 'closing' \| 'closed' \| 'aborted' \| 'error'` |
| `connection`         | Live snapshot of the latest physical socket (`generation`, `url`, `protocol`, `extensions`)           |
| `bufferedAmount`     | Unsent byte count on the active physical socket (`0` when disconnected)                               |
| `receive`            | Single-consumer async iterable of validated `incoming` messages                                       |
| `onStateChange(fn)`  | Subscribes to state transitions; returns an `unsubscribe` function                                    |
| `onRuntimeError(fn)` | Subscribes to non-startup frame/parse errors; returns an `unsubscribe` function                       |
| `closed`             | Promise resolving to the terminal outcome (`kind: 'closed' \| 'aborted' \| 'error'`)                  |

## 4. Reconnect, heartbeat, and queues

Both reconnection and heartbeat are opt-in via client options (`withWebSocketReconnect`, `withWebSocketHeartbeat`) or per-call derived client options (`client({ reconnect, heartbeat })`):

- **Reconnect**: Defaults when enabled are `attempts: 3`, `delayMs: 1000`, `factor: 2`, `maxDelayMs: 30000`, `jitter: 0`. Each physical `open` resets the outage budget. `beforeConnect({ attempt, signal })` runs before initial connect and every reconnect attempt.
- **Handshake timeout (`connectTimeoutMs`)**: When provided, it must be finite, positive, and no greater than 2147483647 (the timer limit); otherwise the operation returns `REQ_OPTIONS_INVALID`. It bounds construction to `open` and is cleared after the handshake.
- **Heartbeat**: Periodically sends `message()` through the `outgoing` struct and waits up to `timeoutMs` for a frame matching `isAck(msg)`. Matching ack frames are consumed by the heartbeat monitor and not forwarded to `session.receive`. A missed ack is fatal to the session.
- **Queue bounds**:
  - `maxIncomingQueueSize` (required positive integer): Overflow terminates the session with `CAP_QUEUE_OVERFLOW`. Keep consuming `session.receive` while the session is open.
  - `maxOutgoingQueueSize` (optional non-negative integer, default `0`): Buffers `session.send()` calls only while `state === 'reconnecting'` and flushes them before publishing the next `open`.

## 5. Subprotocols and authentication [#protocols-and-authentication]

Browser WebSockets do not support arbitrary handshake headers, so WebSocket `builder` functions return only `{ path?, query? }`.

- **Subprotocol precedence**: `client({ protocols })` overrides `withWebSocketProtocols(...)`, which overrides `defineWebSocket({ protocols })`.
- **URL conversion**: Defjs automatically converts `http:` → `ws:` and `https:` → `wss:` on the resolved endpoint.
- **Credentials**: `withCredentials(true)` applies to Fetch (HTTP/SSE) only. Authenticate WebSockets using cookies/session policies, subprotocols, or short-lived connection tickets—avoid placing long-lived secrets in query strings.

## 6. Closure and ownership
