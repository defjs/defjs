# Integrations overview

An integration extends the application's own `Client` at a defined extension point without modifying `@defjs/core` or coupling an SDK definition to a framework or telemetry stack. Your SDK definitions remain pure `@defjs/core` modules; the consuming application chooses which integrations to install.

Every Defjs plugin obeys the **thin plugin contract**:

- **No hidden caching or state**: plugins never store responses, retry requests, or manage query state.
- **No transport replacement**: plugins never wrap or replace the underlying HTTP, SSE, or WebSocket transport.
- **Caller-owned lifecycle**: unmounting a UI provider or shutting down a telemetry SDK does not automatically cancel in-flight requests or close active streams.

## Two plugin architectures

### 1. Framework plugins (`@defjs/react`, `@defjs/vue`)

A framework plugin passes an existing [`DerivableClient`](/api/core/derivableclient-type) down the component tree via native dependency injection (React Context or Vue `provide` / `inject`):

<Tabs items={["sdk/orders.ts", "app/main.tsx", "app/OrderCard.tsx"]}>
  <Tab value="sdk/orders.ts">
```ts
import { defineRequest, struct } from "@defjs/core";

export const Order = struct.object({
  id: struct.number(),
  status: struct.string(),
});

export const getOrder = defineRequest({
  method: "GET",
  path: "/orders/:id",
  input: struct.object({ id: struct.number() }),
  builder: (input) => ({ path: { id: input.id } }),
  output: Order,
});
```
  </Tab>
  <Tab value="app/main.tsx">
```tsx
import { createClient, withEndpoint } from "@defjs/core";
import { ClientProvider } from "@defjs/react";
import { OrderCard } from "./OrderCard.tsx";

const client = createClient(withEndpoint("https://api.example.com"));

export function App() {
  return (
    <ClientProvider client={client}>
      <OrderCard id={42} />
    </ClientProvider>
  );
}
```
  </Tab>
  <Tab value="app/OrderCard.tsx">
```tsx
import { useClient } from "@defjs/react";
import { getOrder } from "../sdk/orders.ts";

export function OrderCard({ id }: { id: number }) {
  const client = useClient();
  // Pass `client` or `client({ signal })` into `getOrder(...)` inside an effect or query hook
  void id;
  void getOrder;
  void client;
  return null;
}
```
  </Tab>
</Tabs>

### 2. Middleware plugins (`@defjs/opentelemetry-server`)

A middleware plugin is a factory that returns a [`ClientOption`](/api/core/clientoption-type). When passed to `createClient(...)`, it appends HTTP, SSE, and/or WebSocket interceptors through `withInterceptors`:

import { createClient, withEndpoint } from "@defjs/core";
import { withRequestIdHeader } from "../plugins/request-id.ts";

export const client = createClient(
  withEndpoint("https://api.example.com"),
  withRequestIdHeader(),
