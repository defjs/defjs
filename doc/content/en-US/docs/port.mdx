# Port transport (`@defjs/core/port`)

`@defjs/core/port` lets an isolated context (`SharedWorker`, Dedicated Worker, sandboxed `iframe`, Electron renderer, or a WebExtension Popup / Side Panel / Content Script) execute pure `@defjs/core` SDK definitions over a single multiplexed port without coupling definitions to the proxy transport.

- Zero runtime dependencies; ships as optional `@defjs/core/port` and `@defjs/core/port/webext` subpath exports with zero bundle overhead unless imported
- Shares one port concurrently across HTTP (including `ReadableStream` uploads/downloads), SSE (`text/event-stream`), and WebSocket connections
- **Fail-closed security by default**: `attachPortHost` refuses all traffic unless the host specifies `allowedOrigins`, `allowRequest`, or explicit `allowAnyOrigin: true`

```bash
bun add @defjs/core
```

## MV3 WebExtension proxy (`@defjs/core/port/webext`)

WebExtension `runtime.Port` cannot transfer `ArrayBuffer` objects directly across Chromium/Firefox/Safari extension boundaries and disconnects whenever a Manifest V3 Service Worker suspends. `@defjs/core/port/webext` provides a zero-dependency structural adapter `fromWebExtPort` (requiring no `@types/chrome`) that uses `"json"` chunked Base64 framing and supports lazy connector functions for automatic reconnect after Service Worker hibernation:
