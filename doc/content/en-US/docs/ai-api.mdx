The documentation site publishes English Markdown generated for assistants. These addresses have no locale prefix and are not translations of the localized guides.

## Page index [#llms-txt]

[llms.txt](/llms.txt) lists the English pages and links to their website URLs. It is the entry point when an assistant needs to find a page first.

## Compiled guides [#llms-full]

[llms-full.txt](/llms-full.txt) joins the English guides into one file. Use it when the assistant needs broad context in a single document and the token budget allows it.

## One page as Markdown [#page-markdown]

Every English page is also available as Markdown at `/llms.mdx/<path>/content.md`. For example, [Quick start as Markdown](/llms.mdx/docs/start/content.md) is the English text of the Quick start page.

## Check the version [#version]

The site documents the default branch; the project may install a different `@defjs/core` version. Verify APIs against the installed package before applying a suggestion. Remove secrets and check the project's policies before sharing code or context with an AI tool.
