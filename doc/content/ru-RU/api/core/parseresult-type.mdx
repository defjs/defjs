<ApiReference identity="@defjs/core:ParseResult" />

```ts
type ParseResult<O> = [error: null, value: O] | [error: StructError, value: undefined]
```

При успехе error равен `null`, а `value` — распарсенный output `O`. При сбое error — это `StructError`, а `value` всегда `undefined`.
