<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

Если `true`, Fetch использует `credentials: 'include'` для запросов HTTP и SSE, поэтому cookie и другие credentials уходят и с cross-origin запросами. Если `false` или опция не задана, `credentials` не выставляется и Fetch использует своё значение по умолчанию.

Конструктор WebSocket эту настройку не получает.
