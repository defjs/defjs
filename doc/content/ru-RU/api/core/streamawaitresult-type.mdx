```ts
type StreamAwaitResult<TEvent, TError extends AnyStruct | undefined = undefined> =
  | [error: null, stream: EventStreamHandle<TEvent>, open: EventStreamOpenInfo]
  | [error: Fault<TError>, stream: undefined, open: EventStreamOpenInfo | undefined]
```

Результат `client.execute` для SSE-команды.

- При успехе: `[null, stream, open]`. `open` — снимок, сделанный при открытии потока; `stream.open` может измениться после reconnect.
- При сбое: `[fault, undefined, open]`. `open` несёт снимок response, если сбой случился после получения response, например при не-2xx handshake, и равен `undefined` в остальных случаях.
- `TError` — объявленный struct `error`. Он типизирует декодированное тело ошибки в fault.
