---
title: 'StructInput'
description: 'Вспомогательный тип, который извлекает принимаемый input-тип struct.'
---

<ApiReference identity="@defjs/core:StructInput" />

```ts
type StructInput<T> = T extends { readonly _struct: { readonly input: unknown } } ? T['_struct']['input'] : never
```

Тип, который принимает struct, в отличие от [`Infer`](/ru-RU/api/core/infer-type), то есть того, что возвращает успешный parse. `T` — struct или любой [`StructLike`](/ru-RU/api/core/structlike-type). Всё остальное даёт `never`.

Они различаются, когда struct преобразует свой input:

```ts
const Created = struct.date()

type In = StructInput<typeof Created> // Date | number | string
type Out = Infer<typeof Created> // Date
```
