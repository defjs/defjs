<ApiReference identity="@defjs/core:UseWebSocketConfig" />

```ts
type UseWebSocketConfig<TIncoming = unknown, TOutgoing = unknown> = {
  beforeConnect?: ClientWebSocketOptions['beforeConnect']
  heartbeat?: WebSocketHeartbeatConfig<TIncoming, TOutgoing>
  protocols?: readonly string[]
  reconnect?: ClientWebSocketOptions['reconnect']
} & ({ abort?: AbortSignal; timeout?: never } | { abort?: never; timeout?: number })
```

WebSocket-часть [`WebSocketExecuteOptions`](/ru-RU/api/core/websocketexecuteoptions-type), к которой тот добавляет `signal`.

- `beforeConnect`, `heartbeat`, `protocols` и `reconnect` переопределяют опции уровня клиента только для одного вызова.
- Отмена — это либо `abort`, либо `timeout`, но не оба. Тип отвергает оба сразу, а если передать оба в рантайме, вызов завершится fault’ом `REQ_OPTIONS_INVALID`.
