---
title: 'struct.parse'
description: 'Разбирает unknown-значение через struct и возвращает error-first кортеж.'
---

<ApiReference identity="@defjs/core:struct.parse" />

```ts
function parse<S extends StructLike<unknown, unknown, boolean>>(
  struct: S,
  value: unknown,
  options?: { aliases?: boolean; errorMap?: ErrorMap },
): ParseResult<S['_struct']['output']>
```

- **struct** — struct, которым разбирается значение. Значение, не являющееся struct, бросает `TypeError`.
- **value** — входное значение неизвестного типа.
- **options.aliases** по умолчанию `false`: ключи объекта читаются по **логическим** именам (`displayName`). При `true` они читаются по wire-именам (`display_name`), как их читают кодеки HTTP/JSON. Output всегда использует логические имена.
- **options.errorMap** — [`ErrorMap`](/ru-RU/api/core/errormap-type), который переписывает сообщения issue только для этого вызова, включая ошибки преобразования bigint/date при использовании struct, созданного другой копией Core. Любая строка, включая `''`, заменяет сообщение; только `undefined` сохраняет текст по умолчанию. Пользовательский текст используется дословно.
- **Возвращает** `[null, output]` или `[StructError, undefined]`. Ошибки валидации не приводят к исключениям. Исключения из предоставленных вызывающей стороной геттеров и колбэков `errorMap` распространяются без изменений.
- Разбор fail-fast: он останавливается на первом сбое, поэтому в error один issue. Неизвестные ключи объекта отбрасываются из output, а input не изменяется.
- На одном пути посещается не более **256 вложенных контейнеров** (`object`, `array`, `record` или `tuple`), причём корневой контейнер считается первым. Для следующего контейнера возвращается `invalid_type` с его логическим путём и `expected: 'value nested at most 256 levels deep'`. В объединении последующие кандидаты ещё могут успешно пройти проверку; если ни один не подходит, объединение сообщает `invalid_union`. Циклы через объявленные поля контейнеров тоже достигают этого предела; общие нециклические дочерние узлы разрешены. Ветви объединений и пересечений не добавляют уровень контейнера, а значения `any`/`unknown` остаются непрозрачными и не обходятся.

```ts
const [error, user] = struct.parse(User, { id: 1, displayName: 'Ada' })
if (error) return console.error(error.prettify())
```

`any` и `unknown` не обходят свои значения, но пересечение может рекурсивно объединять два разных объекта или массива, возвращённых этими листовыми узлами. Это объединение использует общий с охватывающим логическим путём лимит в 256 контейнеров. При его превышении возвращается `invalid_intersection` с логическим путём отклонённого контейнера. Идентичные ссылки сохраняются без обхода, в том числе для совместно используемого циклического значения.

См. [`ParseResult`](/ru-RU/api/core/parseresult-type) и [`StructError`](/ru-RU/api/core/structerror-type).
