Тип `ClientConfig.sse`. Это [`ClientSSEOptions`](/ru-RU/api/core/clientsseoptions-type), у которого `handle` присутствует всегда; обёртка по умолчанию обращается к текущему глобальному `fetch` при каждой попытке, а не сохраняет его при импорте.
