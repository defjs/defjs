<ApiReference identity="@defjs/core:WebSocketOutgoingData" />

```ts
type WebSocketOutgoingData<TOutgoing extends AnyStruct | undefined> = TOutgoing extends AnyStruct ? StructInput<TOutgoing> : never
```

Тип, который принимает `session.send`: [`StructInput`](/ru-RU/api/core/structinput-type) для struct `outgoing` эндпоинта или `never`, если эндпоинт его не объявил, — тогда `send` нельзя вызвать со значением.
