---

<ApiReference identity="@defjs/core:struct.file" />

```ts
function file(): Struct<File, File>
```

- Принимает только `File`; обычный `Blob` даёт `invalid_type`.
- Используй его для поля [`struct.formData()`](/ru-RU/api/core/struct-formdata) или для сырого file body.
- Как struct `output` или `error` заставляет читать тело ответа как blob.
