```ts
function fetchHandler(httpRequest: HttpRequest, fetchImpl?: FetchHandle): Promise<HttpResponse<unknown>>
```

- **httpRequest** — нормализованный request (URL, заголовки, body, abort signal, progress hook’и).
- **fetchImpl** — [`FetchHandle`](/ru-RU/api/core/fetchhandle-type); по умолчанию глобальный `fetch`, который определяется в момент отправки. Неизменённый платформенный Fetch получает `(url, init)`; заменённый глобальный Fetch или пользовательский обработчик получает `Request`, а тело его ответа читается по частям. Тело платформенного ответа без наблюдения за прогрессом читается целиком; при отслеживании прогресса загрузки оно читается по частям.

HTTP-транспорт по умолчанию. Клиент всегда использует его; `withHTTPHandle` заменяет лишь `fetchImpl`, который он вызывает. Если до клиента не дошёл никакой ответ, он отклоняется, а не разрешается синтетическим ответом.
