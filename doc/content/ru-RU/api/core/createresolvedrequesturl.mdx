```ts
function createResolvedRequestUrl(baseEndpoint: string, path: string, queryString?: string): URL
```

- **baseEndpoint** — endpoint клиента. Его query и hash отбрасываются, а к pathname добавляется завершающий слэш, чтобы сохранить базовый путь: `https://api.example.com/v1` и `/users` дают `https://api.example.com/v1/users`.
- **path** — относительный путь эндпоинта. Один ведущий слэш удаляется.
- **queryString** — query без ведущего `?`. Если строка не пуста, она записывается в search URL как есть.
- **Возвращает** разрешённый `URL`.

Бросает `TypeError('Client endpoint must be a valid URL')`, если `baseEndpoint` не разбирается. Бросает `Error`, если `path` содержит схему или начинается с `//` (`Endpoint path must not be an absolute URL`), либо содержит `?` или `#` (`Endpoint path must not include query or hash`).
