description: 'HTTP interceptor, который задаёт заголовок Basic Authorization по учётным данным.'
---

<ApiReference identity="@defjs/core:basicAuthHttpInterceptor" />

```ts
function basicAuthHttpInterceptor(fn: () => { username: string; password: string }, options?: BasicAuthInterceptorOptions): HttpInterceptor
```

- **fn** — вызывается на каждый request и возвращает учётные данные.
- **options** — необязательные [`BasicAuthInterceptorOptions`](/ru-RU/api/core/basicauthinterceptoroptions-type) с собственным `encode`.
- **Возвращает** `HttpInterceptor`, который задаёт `Authorization: Basic <encoded>` на копии заголовков request’а и заменяет любой существующий заголовок `Authorization`.

Кодировщик по умолчанию — ``btoa(`${username}:${password}`)``, поэтому учётные данные должны быть в Latin-1. Без `encode` вызов `basicAuthHttpInterceptor` бросает `Error: BasicAuthInterceptor is not supported in this environment`, если в runtime нет `btoa`. Для SSE-команд используй [`basicAuthSSEInterceptor`](/ru-RU/api/core/basicauthsseinterceptor).

См. [гайд Interceptors](/ru-RU/docs/interceptors).
