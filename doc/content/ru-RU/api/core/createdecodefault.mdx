<ApiReference identity="@defjs/core:createDecodeFault" />

```ts
function createDecodeFault(code: DecodeFaultCode, cause: unknown, response: HttpMeta): DecodeFault
```

- **code** — какой шаг чтения не удался: `RES_DECODE_FAILED`, `RES_MEDIA_TYPE_INVALID` или `RES_STRUCT_MISMATCH`.
- **cause** — исходный сбой парсера или struct, сохранённый в `cause`. Обычно его сообщение становится сообщением fault’а (`String(cause)`, если это не `Error`). Для `RES_DECODE_FAILED` с `Error`, у которого имя `SyntaxError`, используется сообщение `Response body could not be decoded`, чтобы фрагменты из сообщения парсера не попадали в `String(fault)`. Сообщения Struct по умолчанию содержат виды полученных значений, а не сами значения; исходные значения и текст ошибки парсера остаются в причине.
- **response** — метаданные ответа, который не удалось прочитать. `status` копируется из них.
- **Возвращает** нативный `Error` с именем `DefjsFault` без `body`.
