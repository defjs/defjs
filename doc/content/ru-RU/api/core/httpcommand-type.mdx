```ts
interface HttpCommand<
  TInput extends AnyStruct | undefined,
  TOutput extends AnyStruct | undefined,
  TError extends AnyStruct | undefined = undefined,
> {
  readonly definition: RequestDefinition<TInput, TOutput, TError>
  readonly input: EndpointInput<TInput> | undefined
  // plus internal symbol-keyed members that identify and run the command
}
```

Создаётся вызовом `RequestEndpoint` с input. Считай её непрозрачной и передавай в `client.execute`.
