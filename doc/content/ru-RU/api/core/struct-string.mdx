<ApiReference identity="@defjs/core:struct.string" />

```ts
function string(): Struct<string, string>
```

- Принимает только значения `string`; всё остальное даёт `invalid_type`.
- Как корень тела или как входящий struct `output` / `error` байты остаются текстом и не разбираются как JSON.
