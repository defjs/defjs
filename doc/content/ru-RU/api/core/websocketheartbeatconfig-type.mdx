<ApiReference identity="@defjs/core:WebSocketHeartbeatConfig" />

```ts
interface WebSocketHeartbeatConfig<TIncoming = unknown, TOutgoing = unknown> {
  intervalMs: number
  isAck?: (message: TIncoming) => boolean
  message?: () => TOutgoing
  timeoutMs?: number
}
```

- `intervalMs` — задержка между heartbeat-сообщениями.
- `message()` строит payload. Он отправляется через struct `outgoing`. Если `message` опущен или возвращает `undefined`, ничего не отправляется.
- После кодирования struct значения, непредставимые в JSON, приводят к `TypeError` в том же сериализаторе, что использует `session.send`; такой сбой heartbeat завершает логическую сессию без переподключения.
- `isAck(message)` получает каждое декодированное входящее сообщение. Если возвращает `true`, сообщение считается подтверждением и в `receive` не доставляется.
- `timeoutMs` — сколько ждать подтверждения после heartbeat. Если оно не пришло, сессия завершается ошибкой.
- `intervalMs` и `timeoutMs` должны быть положительными, конечными и не больше `2_147_483_647`.

Задаётся через [`withWebSocketHeartbeat`](/ru-RU/api/core/withwebsocketheartbeat) или execute-опцию `heartbeat`.
