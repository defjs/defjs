<ApiReference identity="@defjs/core:UseRequestConfig" />

```ts
type UseRequestConfig = {
  onDownloadProgress?: HttpProgressFn
  onUploadProgress?: HttpProgressFn
} & ({ abort?: AbortSignal; timeout?: never } | { abort?: never; timeout?: number })
```

HTTP-часть [`HttpExecuteOptions`](/ru-RU/api/core/httpexecuteoptions-type), к которой тот добавляет `signal`.

- `onDownloadProgress` и `onUploadProgress` — колбэки [`HttpProgressFn`](/ru-RU/api/core/httpprogressfn-type). Они получают [`HttpProgressEvent`](/ru-RU/api/core/httpprogressevent-type) с `loaded`, `total` и `lengthComputable`.
- Отмена — это либо `abort`, либо `timeout`, но не оба. Тип отвергает оба сразу, а если передать оба в рантайме, вызов завершится fault’ом `REQ_OPTIONS_INVALID`.
- `timeout` должен быть положительным safe integer не больше `2_147_483_647`. Он заменяет значение по умолчанию, заданное [`withTimeout`](/ru-RU/api/core/withtimeout), только для этого вызова. `abort` же сочетается с этим значением.
