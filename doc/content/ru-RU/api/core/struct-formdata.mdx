title: 'struct.formData'
description: 'Object struct, который кодируется как multipart FormData, когда он является телом запроса.'
---

<ApiReference identity="@defjs/core:struct.formData" />

```ts
function formData<T extends ObjectShape>(shape: T): ObjectStruct<T>
```

Разбирает как [`struct.object()`](/ru-RU/api/core/struct-object) и несёт тег кодека `formData`.

- Тег применяется, только когда значение этого struct — корень тела запроса. Тогда тело уходит как `FormData` с разделителем multipart, который задаёт платформа.
- Массивы повторяют имя поля, поля со значением `undefined` пропускаются, а значения `Blob` / `File` добавляются как файлы. Вложенный объект приводит к сбою запроса с `REQ_BUILD_FAILED`.
- `struct.parse` игнорирует тег. Он не принимает экземпляр `FormData`, только plain object.
