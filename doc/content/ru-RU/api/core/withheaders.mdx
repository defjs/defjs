<ApiReference identity="@defjs/core:withHeaders" />

```ts
function withHeaders(headers: HeadersInit): ClientOption
```

Задаёт статические заголовки по умолчанию для запросов HTTP и SSE, которые строит этот клиент. Соединения WebSocket их не используют.

- `HeadersInit` копируется в объект `Headers` в момент применения опции. Более поздний вызов заменяет прежние заголовки, а не сливается с ними.
- Заголовки, которые вернул builder запроса, заменяют одноимённый заголовок по умолчанию, если значение — скаляр или экземпляр `Headers`. Значения-массивы (запись record с массивом или `HeadersInit` в виде массива кортежей) добавляются к значению по умолчанию.
- Credentials, которые вычисляются или меняются от запроса к запросу, — например, обновлённый Bearer-токен или HMAC-подпись, — относятся к [interceptor’у](/ru-RU/api/interceptors), потому что им нужно итоговое тело или свежее значение.
