```ts
function withEndpoint(endpoint: string): ClientOption
```

Задаёт корректный абсолютный базовый URL, который добавляется перед относительными путями запроса. По умолчанию — пустая строка, поэтому для выполнения нужен явно заданный endpoint.

- **endpoint** — корректный абсолютный базовый endpoint. Его pathname сохраняется как каталог; query и hash отбрасываются.
- Для команд WebSocket базовый `http:` становится `ws:`, а `https:` — `wss:`.

Отсутствующий, относительный или некорректный endpoint либо недопустимый путь запроса приводят к `REQ_BUILD_FAILED` на этапе построения, до запуска любого interceptor’а или транспорта, даже если interceptor мог бы вернуть результат без обращения к транспорту. Это правило общее для HTTP, SSE и WebSocket. Построенный URL запроса должен сохранять origin базового URL и оставаться внутри его каталога; управляющие символы C0 (включая табуляцию, CR и LF), обратные косые черты, `?`, `#` и выход за пределы каталога в пути отвергаются. Похожие на схему и протокольно-относительные формы отклоняются даже с ведущими пробелами; обычный пробел внутри пути разрешён и отправляется как `%20`. Итоговый `req.endpoint` interceptor’а проверяется относительно его итогового `req.baseEndpoint` по тому же правилу, но interceptor может намеренно заменить базовый URL другим корректным абсолютным URL. Повторные попытки при детерминированных ошибках URL никогда не выполняются.
