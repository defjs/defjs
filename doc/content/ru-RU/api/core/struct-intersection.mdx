<ApiReference identity="@defjs/core:struct.intersection" />

```ts
function intersection<const T extends readonly [StructLike, ...StructLike[]]>(...structs: T): IntersectionStruct<T>
```

`struct.intersection` принимает переменное число аргументов: передавай каждый struct отдельным аргументом.

- Разбирает input каждым struct и сливает результаты.
- Когда каждый struct — object struct, output — один объект с полями всех. Ключи, которые не объявляет ни один из них, удаляются.
- Если два struct выдают несовместимые значения для одного ключа, результат — `invalid_intersection`.
- Единственный struct возвращается без изменений. Вызов без struct бросает `TypeError`, как и аргумент, не являющийся struct.

`IntersectionStruct<T>` не экспортируется. Это `Struct`, чьи input и output — пересечения типов членов.
