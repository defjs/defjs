<ApiReference identity="@defjs/core:FetchHandle" />

```ts
type FetchHandle = (input: RequestInfo | URL, init?: RequestInit) => Promise<Response>
```

Сигнатура вызова `(input, init?) => Promise<Response>`, которую вызывает Defjs. Это намеренно не `typeof fetch`, чтобы моку не требовались расширения хоста вроде `preconnect`. Пользовательский handle вызывается с `Request`; только библиотечное значение по умолчанию (глобальный `fetch`) вызывается как `(url, init)`.

Принимается в `withHTTPHandle`, `withSSEHandle` и `fetchHandler`.
