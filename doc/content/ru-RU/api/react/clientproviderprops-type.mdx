description: 'Props у ClientProvider: обязательный client и необязательные children.'
---

<ApiReference identity="@defjs/react:ClientProviderProps" />

```ts
interface ClientProviderProps {
  client: Client
  children?: ReactNode
}
```

- `client` — обязателен. Клиент Defjs, которым владеет приложение.
- `children` — необязателен. React-дерево, которое может вызывать `useClient`.
