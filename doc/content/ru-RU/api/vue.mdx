# Vue

Отдай существующий `@defjs/core` client Vue-приложению. Этот пакет не создаёт, не кэширует и не dispose’ит client. Нужен Vue 3 или новее.

См. [гайд Vue](/ru-RU/docs/integrations/vue).

## createClientPlugin()

```ts
function createClientPlugin(client: Client): Plugin
```

- **client** — Экземпляр из `createClient`.
- **Возвращает** Vue-плагин для `app.use(...)`. Установка вызывает `app.provide(HTTP_CLIENT, client)`.

## injectClient()

```ts
function injectClient(): Client
```

Читает ближайший `HTTP_CLIENT` provider. Вызывай там, где разрешён `inject`, например в `setup()`.

- **Возвращает** внедрённый client.
- **Бросает** `Error`, если client не был предоставлен, например когда плагин не поставили.

## HTTP_CLIENT

```ts
const HTTP_CLIENT: InjectionKey<Client>
```

Ключ внедрения зависимостей Vue. Бери `injectClient()`, а не `inject(HTTP_CLIENT)`. Переопредели клиент для поддерева через `provide(HTTP_CLIENT, childClient)`.
