# Vue

Передайте существующий клиент `@defjs/core` Vue-приложению. Этот пакет не создаёт, не кэширует и не освобождает клиент. Нужен Vue 3 или новее.

См. [руководство по Vue](/ru-RU/docs/integrations/vue).

## createClientPlugin()

<ApiSignature name="createClientPlugin" />

- **client** — Экземпляр из `createClient`.
- **Возвращает** Vue-плагин для `app.use(...)`. Установка вызывает `app.provide(HTTP_CLIENT, client)`.

## injectClient()

<ApiSignature name="injectClient" />

`injectClient(key)` читает ближайший провайдер для этого ключа; без аргумента или с `undefined` использует `HTTP_CLIENT`. Вызывайте в действующем контексте внедрения Vue: синхронном `setup()` или `app.runWithContext()` (Vue 3.3+). Последний даёт только синхронный контекст приложения, без переопределений поддерева и без сохранения через обычный `await`. Контекст, восстановленный компилятором после верхнеуровневого `await` в `<script setup>`, по-прежнему подходит. Передайте этот клиент в операцию. Внедрённое значение — предоставленный [`DerivableClient`](/ru-RU/api/core/derivableclient-type); вызовите его с опциями запроса там, где выполняется операция, чтобы получить значение `Client`. Не используйте его как источник `watch` или `computed`, потому что они вызывают функцию. Выведенное значение `Client` не принимается ни плагином, ни `injectClient`.

Для своего `InjectionKey<DerivableClient>` используйте `app.provide(key, client)` или `provide(key, client)` в компоненте-предке. Обе стороны должны разделять один и тот же объект `Symbol`; одинаковые описания не делают ключи равными. `createClientPlugin(client)` по-прежнему принимает только клиент и предоставляет только `HTTP_CLIENT`.

- **Возвращает** тот же клиент, который предоставлен по выбранному ключу.
- **Бросает** `Error`, если нет активного контекста внедрения или клиента по выбранному ключу. Отсутствующий свой ключ не приводит к откату на `HTTP_CLIENT`; одна установка плагина не создаёт контекст внедрения.

## HTTP_CLIENT

<ApiSignature name="HTTP_CLIENT" />

Ключ внедрения зависимостей Vue. Предпочитайте `injectClient()` вместо `inject(HTTP_CLIENT)`. Переопределите клиент для поддерева через `provide(HTTP_CLIENT, childClient)`.
