# Справка API

<ApiIndex />

Пользуйтесь этой справкой при создании и использовании SDK Defjs. Авторы SDK начинают с [`defineRequest`](/ru-RU/api/core/definerequest), [`defineEventStream`](/ru-RU/api/core/defineeventstream), [`defineWebSocket`](/ru-RU/api/core/definewebsocket) и [Structs](/ru-RU/api/struct). Приложения используют [настройку клиента](/ru-RU/api/client), чтобы вызывать эти операции, и [ошибки](/ru-RU/api/errors), чтобы обрабатывать результаты.

Сигнатуры — это контракт. Полный процесс описан в [быстром старте](/ru-RU/docs/start) и [руководстве по публикации SDK](/ru-RU/recipes/publish-http-sdk).
