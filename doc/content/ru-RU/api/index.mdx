# Справка API

<ApiIndex />

Справочник описывает публичные компоненты для авторов SDK и приложений. Сигнатуры задают контракт; [руководство](/ru-RU/docs/start) и [рецепт публикации](/ru-RU/recipes/publish-http-sdk) показывают их совместное использование.

- **Создание SDK:** начни со [`struct`](/ru-RU/api/struct), [`defineRequest`](/ru-RU/api/http), [`defineEventStream`](/ru-RU/api/sse) или [`defineWebSocket`](/ru-RU/api/web-socket) и экспортируй полученные эндпоинты.
- **Использование SDK:** настрой [`createClient` и `with*`](/ru-RU/api/client), выполняй импортированные эндпоинты, обрабатывай [ошибки](/ru-RU/api/errors) и управляй транспортными ресурсами.
- **Интеграция приложения:** подключи [перехватчики](/ru-RU/api/interceptors), [React](/ru-RU/api/react), [Vue](/ru-RU/api/vue) или [OpenTelemetry](/ru-RU/api/opentelemetry-server) к клиенту приложения.

## Пакеты

| Пакет                                                            | Что ищешь                                                         |
| ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| [`@defjs/core`](/ru-RU/api/client)                               | `createClient`, `defineRequest`, `struct`, HTTP / SSE / WebSocket |
| [`@defjs/vue`](/ru-RU/api/vue)                                   | `createClientPlugin`, `injectClient`, `HTTP_CLIENT`               |
| [`@defjs/react`](/ru-RU/api/react)                               | `ClientProvider`, `useClient`                                     |
| [`@defjs/opentelemetry-server`](/ru-RU/api/opentelemetry-server) | `withOpenTelemetryServer`, опции по транспортам                   |
