<ApiReference identity="@defjs/vue:createClientPlugin" />

```ts
function createClientPlugin(client: Client): Plugin
```

- **client** — экземпляр из `createClient`. Плагин не создаёт, не кэширует и не dispose’ит его.
- **Возвращает** Vue-плагин для `app.use(...)`. Установка вызывает `app.provide(HTTP_CLIENT, client)`, поэтому компоненты читают клиент через `injectClient()`.
