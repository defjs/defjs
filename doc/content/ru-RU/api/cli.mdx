# CLI (`@defjs/cli`)

CLI для этапа разработки и программный генератор, преобразующий спецификации Swagger 2.0 и OpenAPI 3.0–3.2 в stateless ESM-модули `@defjs/core`. Смотрите [руководство по интеграции CLI](/ru-RU/docs/integrations/cli).
