# Создание и публикация SDK [#publish-an-http-sdk-without-hiding-execute]

SDK на базе Defjs экспортирует чистые определения операций и схемы Struct в виде npm-пакета, оставляя `createClient(...)`, эндпоинты, учётные данные и перехватчики на стороне использующего приложения.

---

## 1. Описание пакета SDK

Храните определения операций, реэкспорты, `package.json` и `tsconfig.json` в отдельной директории пакета с объявлением `@defjs/core` в качестве `peerDependency`:

- Пакет `@defjs/core` остаётся внешней runtime-зависимостью (`peerDependency`), разделяемой с использующим приложением.
- Поле `"sideEffects": false` позволяет бандлерам удалять неиспользуемые операции с помощью tree-shaking, если приложение импортирует только часть из них.

## 2. Сборка и проверка tarball-архива

Соберите `dist/index.js` и `dist/index.d.ts` с помощью `tsdown`, затем проверьте содержимое пакета перед публикацией:

```sh
bun install
bun run build
bun pm pack --dry-run
bun pm pack
```

Убедитесь, что файлы `dist/index.js` и `dist/index.d.ts` включены в tarball-архив.

---

## 3. Использование SDK в приложении

Установите ваш SDK вместе с `@defjs/core`:

```sh
bun add @company/orders-sdk @defjs/core@^0.7.0
```

Приложение создаёт собственный экземпляр `Client` и передаёт его в импортированную операцию:


В продакшен-коде замените относительный импорт `./src/orders.ts` на `@company/orders-sdk` и удалите вызов `withHTTPHandle(...)`, чтобы использовать платформенный `fetch`.

---

## 4. Тестирование и публикация

Проверьте экспортированные определения с помощью [тестов с хэндлами в памяти](/ru-RU/recipes/test-with-handle), охватывающих маппинг запроса, декодирование `output`, объявленные сбои `HTTP_STATUS` и отмену. После успешной проверки опубликуйте пакет:

```sh
bun publish --access public
```

См. разделы [HTTP-операции](/ru-RU/docs/http), [Клиент](/ru-RU/docs/client), [Тестирование](/ru-RU/docs/testing) и [Архитектура ядра](/ru-RU/docs/design-decisions).
