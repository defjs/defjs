# POST JSON

Отдай типизированное тело builder’у. Логические имена полей остаются в TypeScript; wire-алиасы на struct становятся JSON-ключами. Тело-объект — это `application/json`.

Подробности — в [HTTP](/ru-RU/docs/http) и [Клиент](/ru-RU/docs/client).

</include>

`api.example.com` — placeholder. Если сервер отвечает `201` и `{ "id": 1, "name": "Ada", "email": "ada@example.com" }`, сниппет выведет:

```txt
Created Ada → 201
```
