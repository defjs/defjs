# POST JSON

Передайте типизированный объект параметров в `builder` и верните `{ body: input }`. Вызов `.alias("customer_name")` сохраняет свойство `customerName` в TypeScript, отправляя `"customer_name"` по сети и декодируя его обратно из ответа `201`.

Если сервер отвечает статусом `201` и телом `{ "id": 1, "status": "paid", "customer_name": "Ada" }`, скрипт выведет:

```txt
Created paid → 201
```

Подробности см. в разделах [HTTP-операции](/ru-RU/docs/http) и [Struct и схемы](/ru-RU/docs/struct).
