# GET с объявленным 404

Объявите и `output` (для ответов 2xx), и `error` (для ответов вне диапазона 2xx) в `defineRequest`. В месте вызова проверяйте условие `error?.code === "HTTP_STATUS" && error.status === 404`, чтобы прочитать типизированную полезную нагрузку `error.data`.

<Tabs items={["sdk/orders.ts", "app/main.ts", "get-order.ts"]}>
  <Tab value="sdk/orders.ts">
```ts
import { defineRequest, struct } from "@defjs/core";

export const getOrder = defineRequest({
  method: "GET",
  path: "/orders/:id",
  input: struct.object({ id: struct.number() }),
  builder: (input) => ({ path: { id: input.id } }),
  output: struct.object({ id: struct.number(), status: struct.string() }),
  error: struct.object({ message: struct.string() }),
});
```
  </Tab>
  <Tab value="app/main.ts">
```ts
import { createClient, withEndpoint } from "@defjs/core";
import { getOrder } from "../sdk/orders.ts";

const client = createClient(withEndpoint("https://api.example.com"));

async function main() {
const [error, order, response] = await getOrder(client, { id: 7 });
if (error?.code === "HTTP_STATUS" && error.status === 404) {
console.log(error.data.message);
return;
}
if (error) {
console.error(error.code);
return;
}
console.log(`Loaded ${order.status} from ${response.status}`);
}

void main();

````

Если сервер отвечает на `GET /orders/7` статусом `200` и телом `{ "id": 7, "status": "paid" }`, скрипт выведет:

```txt
Loaded paid from 200
````

- Каждый статус вне 2xx формирует ошибку `HTTP_STATUS`. Объявление `error` декодирует и валидирует тело ошибки в `error.data`; если `error` не объявлен, `error.data` остаётся `undefined`, а тело вообще не читается.
- Если объявленное тело `error` имеет неподдерживаемый тип медиа, содержит невалидный JSON или нарушает схему Struct, операция возвращает ошибку класса `RES_*`. Поскольку одна структура `error` покрывает все статусы вне диапазона 2xx, используйте `struct.or(...)`, если разные статусы ошибок имеют разную структуру.

См. разделы [HTTP-операции](/ru-RU/docs/http) и [Обработка ошибок](/ru-RU/docs/errors).
