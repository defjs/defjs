# HTTP-хэндл на Undici Pool

В высоконагруженных BFF и серверных приложениях Node.js передавайте общий `undici.Pool` через [`withHTTPHandle`](/ru-RU/api/core/withhttphandle), чтобы пул соединений к апстримам оставался прогретым и ограниченным, пока определения SDK (`sdk/orders.ts`) сохраняют полную независимость от платформы. Не забывайте вызывать `await pool.close()` при завершении работы сервиса.
