# Открытие WebSocket-сессии

Объявите структуры `incoming` и `outgoing` в `defineWebSocket` вместе с ограничением `maxIncomingQueueSize`. В приложении подпишитесь на `session.onRuntimeError(...)`, читайте `session.receive` и всегда отписывайтесь, вызывайте `session.close(...)` и дожидайтесь `await session.closed` в блоке `finally`:

<Tabs items={["sdk/quotes.ts", "app/main.ts", "quotes.ts"]}>
  <Tab value="sdk/quotes.ts">
```ts
import { defineWebSocket, struct } from "@defjs/core";

export const quotes = defineWebSocket({
  maxIncomingQueueSize: 100,
  path: "/quotes",
  incoming: struct.object({
    type: struct.literal("tick"),
    symbol: struct.string(),
    price: struct.number(),
  }),
  outgoing: struct.object({
    type: struct.literal("subscribe"),
    symbol: struct.string(),
  }),
});
```
  </Tab>
  <Tab value="app/main.ts">
```ts
import { createClient, withEndpoint } from "@defjs/core";
import { quotes } from "../sdk/quotes.ts";

const client = createClient(withEndpoint("https://quotes.example.com"));

async function main() {
const [error, session] = await quotes(client);
if (error) {
console.error(error.code);
return;
}
const unsubscribe = session.onRuntimeError((cause) =>
console.error("runtime", cause),
);
try {
session.send({ type: "subscribe", symbol: "ACME" });
for await (const message of session.receive) {
console.log(message.symbol, message.price);
break;
}
} finally {
unsubscribe();
session.close(1000, "consumer-finished");
await session.closed;
}
}

void main();

````

Если сервер отвечает на `{ "type": "subscribe", "symbol": "ACME" }` сообщением `{ "type": "tick", "symbol": "ACME", "price": 142.5 }`, скрипт выведет:

```txt
ACME 142.5
````

- И переподключение (`withWebSocketReconnect`), и heartbeat (`withWebSocketHeartbeat`) подключаются на клиенте опционально.
- Браузерные WebSocket не могут отправлять произвольные HTTP-заголовки во время хэндшейка обновления протокола; используйте cookies, субпротоколы или короткоживущие тикеты подключения. См. раздел [Сессии WebSocket](/ru-RU/docs/web-socket).
