# Открыть WebSocket-сессию

Каждое направление — один struct. Отмена подписок, `close` и `await session.closed` — на тебе. Невалидные кадры идут в `onRuntimeError`.

Подробности — в [WebSocket](/ru-RU/docs/web-socket).

`quotes.example.com` — placeholder. Если сервер на `{ "type": "subscribe", "symbol": "ACME" }` отвечает `{ "type": "tick", "symbol": "ACME", "price": 142.5 }`, сниппет выведет:

```txt
ACME 142.5
```

Переподключение включается явно (`withWebSocketReconnect`), как и heartbeat. Браузерные WebSocket’ы не принимают произвольные заголовки при установлении соединения — используй cookies, подпротоколы или билет с коротким сроком действия.
