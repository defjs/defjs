# Ключи идемпотентности

По умолчанию `withRetry` повторяет только идемпотентные HTTP-методы (`GET`, `HEAD`, `PUT`, `DELETE`, `OPTIONS`, `TRACE`). Когда нужно разрешить повторы для эндпоинтов `POST` или `PATCH`, сочетайте `withRetry` с `idempotencyKeyHttpInterceptor()`, чтобы каждая повторная попытка одного и того же логического вызова использовала `req.correlationId` в заголовке `Idempotency-Key`, а последующие вызовы получали свежие ключи.
