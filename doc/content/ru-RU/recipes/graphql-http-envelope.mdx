# Разбор HTTP-ответа GraphQL

В Defjs нет встроенного клиента GraphQL или встроенной политики `errorPolicy`. Моделируйте GraphQL поверх HTTP как стандартную операцию `POST`, чей `builder` отправляет `{ query, operationName, variables }`. Пометьте `data` как `.nullish()` в Struct-оболочке, чтобы как пропущенное `data`, так и `data: null` успешно проходили структурную валидацию, а затем распаковывайте `errors[]` в прикладной функции-хелпере:

<Tabs items={["sdk/viewer.ts", "app/load-viewer.ts", "graphql-viewer.ts"]}>
  <Tab value="sdk/viewer.ts">
```ts
import { defineRequest, struct } from "@defjs/core";

const VIEWER_QUERY = "query Viewer { viewer { id login } }" as const;

export const runViewer = defineRequest({
  method: "POST",
  path: "/graphql",
  builder: () => ({
    body: { query: VIEWER_QUERY, operationName: "Viewer" },
  }),
  output: struct.object({
    data: struct
      .object({
        viewer: struct
          .object({ id: struct.string(), login: struct.string() })
          .null(),
      })
      .nullish(),
    errors: struct
      .array(struct.object({ message: struct.string() }))
      .optional(),
  }),
});
```
  </Tab>
  <Tab value="app/load-viewer.ts">
```ts
import type { Client } from "@defjs/core";
import { runViewer } from "../sdk/viewer.ts";

export async function loadViewer(client: Client) {
  const [error, result] = await runViewer(client);
  if (error) throw error;
  if (result.errors?.length) {
    throw new Error(result.errors.map((item) => item.message).join("; "));
  }
  if (!result.data) {
    throw new Error("GraphQL response contained neither data nor errors");
  }
  return result.data.viewer;
}
```

- Статус HTTP `200` означает лишь то, что конверт GraphQL успешно доставлен. Доменные ошибки внутри `errors[]` (даже в сочетании с `data: null`) являются результатами уровня приложения, а не ошибками `RES_STRUCT_MISMATCH`.
- См. раздел [Архитектура ядра](/ru-RU/docs/design-decisions), где объясняется, почему протокольные конверты распаковываются во вспомогательных функциях приложения.
