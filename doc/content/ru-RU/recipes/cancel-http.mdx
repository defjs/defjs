# Отменить HTTP-вызов

Объедините `AbortController` вызывающего кода с дедлайном с помощью `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` и передайте полученный сигнал через `client({ signal })`. Defjs классифицирует ручную отмену вызывающим кодом как `NET_ABORTED`, а завершение по таймауту — как `NET_TIMEOUT`.

Отмена лишь фиксирует то, что наблюдал клиент, — она не гарантирует откат мутации на стороне сервера. Защищайте повторы мутирующих запросов ключом идемпотентности. См. раздел [Отмена работы и установка дедлайнов](/ru-RU/docs/http#cancel-the-work).
