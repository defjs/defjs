# Отменить HTTP-вызов

Объедини сигнал вызывающего с дедлайном в `signal`. `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` — один сигнал. Ручной abort классифицируется как `NET_ABORTED`. Дедлайн классифицируется как `NET_TIMEOUT`.

Подробности — в [HTTP](/ru-RU/docs/http#cancel-the-work).

<include cwd meta="cancel-report.ts">
  examples/recipes/cancel-http.ts#example
</include>

```txt
caller cancelled
```

Отмена говорит, что увидел вызывающий. Она не доказывает, что серверная запись откатилась — держи ретраи мутаций за контрактом идемпотентности.
