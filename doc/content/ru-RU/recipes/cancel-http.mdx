# Отменить HTTP-вызов

Объедините `AbortController` вызывающего кода с дедлайном с помощью `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` и передайте полученный сигнал через `client({ signal })`. Defjs классифицирует ручную отмену пользователем как `NET_ABORTED`, а завершение по таймауту — как `NET_TIMEOUT`.

<Tabs items={["sdk/reports.ts", "app/main.ts", "cancel-report.ts"]}>
  <Tab value="sdk/reports.ts">
```ts
import { defineRequest } from "@defjs/core";

export const getReport = defineRequest({
  method: "GET",
  path: "/report",
});
```
  </Tab>
  <Tab value="app/main.ts">
```ts
import { createClient, withEndpoint } from "@defjs/core";
import { getReport } from "../sdk/reports.ts";

const client = createClient(withEndpoint("https://api.example.com"));

const controller = new AbortController();
const pending = getReport(
client({
signal: AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)]),
}),
);

controller.abort("screen closed");

async function main() {
const [error] = await pending;
if (error?.code === "NET_ABORTED") {
console.log("caller cancelled");
return;
}
if (error?.code === "NET_TIMEOUT") {
console.log("timed out");
return;
}
if (error) {
console.error(error.code);
return;
}
console.log("got the report");
}

void main();

````

Отмена лишь фиксирует то, что наблюдал клиент, — она не гарантирует откат мутации на стороне сервера. Защищайте повторы мутирующих запросов ключом идемпотентности. См. раздел [Отмена работы и установка дедлайнов](/ru-RU/docs/http#cancel-the-work).
