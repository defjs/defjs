# Курсорная пагинация

Держите пагинированную операцию внутри модуля SDK (`listOrders`), а продолжение по курсору вынесите в чистый вспомогательный генератор приложения (`listAllOrders`), который отдаёт Go-кортежи `[err, item]` и немедленно останавливается при сбое или отмене вызывающим кодом.
