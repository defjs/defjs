# Skill

Skill Defjs передаёт ассистенту контракт между определением SDK и выполнением в приложении. Поддерживающий ассистент может загрузить его для подходящей задачи; автоматическая активация зависит от инструмента.

## Установка skill [#install]

Запустите команду в нужном проекте. По умолчанию CLI устанавливает skill в текущий проект и может определить текущего агента или предложить выбор; используйте `-a`, чтобы указать агента явно.

```sh
bunx skills add defjs/defjs --skill defjs
```

После публикации инструкции skill можно прочитать в [skills/defjs/SKILL.md](https://github.com/defjs/defjs/blob/main/skills/defjs/SKILL.md). Исходный код на GitHub — это ветка по умолчанию, и она может не совпадать с версией `@defjs/core`, установленной в проекте.

## Запрос одной операции [#prompt]

Дайте помощнику одну задачу. Этот запрос просит типизированный `GET /orders/:id`, клиент которого остаётся в приложении:

```txt
Use @defjs/core to define GET /orders/:id.
The input is { id: number }; a successful response is { id: number, status: string }.
Keep the SDK definition and application client in separate modules,
and verify the result with the project’s existing tests.
```

## Проверка результата [#verify]

Читайте определение и приложение отдельно. Определение экспортирует операцию и не создаёт клиент. Приложение создаёт клиент и вызывает операцию, например `getOrder(client, { id: 1 })`. Если объявлен `input`, `builder` — явная синхронная чистая функция. Успешное значение используется только когда слот ошибки пуст.

Затем запустите проверку типов этого проекта и тесты, покрывающие контракт. Установка зависимостей и правила CI остаются в том проекте.
