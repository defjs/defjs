Сайт публикует английский Markdown для ассистентов. У этих адресов нет префикса локали, и они не являются переводами локализованных руководств.

## Индекс страниц [#llms-txt]

[llms.txt](/llms.txt) перечисляет английские страницы и ссылается на их веб-адреса. Это точка входа, когда ассистенту сначала нужно найти страницу.

## Сводные руководства [#llms-full]

[llms-full.txt](/llms-full.txt) объединяет английские руководства в один файл. Используйте его, когда ассистенту нужен широкий контекст в одном документе и позволяет бюджет токенов.

## Одна страница как Markdown [#page-markdown]

Каждая английская страница также доступна как Markdown по адресу `/llms.mdx/<path>/content.md`. Например, [Quick start как Markdown](/llms.mdx/docs/start/content.md) — это английский текст страницы Quick start.

## Проверка версии [#version]

Сайт описывает ветку по умолчанию; в проекте может быть установлена другая версия `@defjs/core`. Перед применением предложения проверьте API по установленному пакету. Удаляйте секреты и проверяйте политики проекта, прежде чем передавать код или контекст инструменту ИИ.
