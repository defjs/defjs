# Клиент

`Client` — это настройка выполнения приложения-потребителя, и это функция. `createClient(...)` возвращает эту функцию. Импортируй операции из SDK, выбери адрес сервиса, учётные данные, перехватчики и транспорт, затем вызови операцию с клиентом. `getUser(client({ abort }), { id: 1 })` начинает вызов, у которого объявлен input. `health(client)` начинает вызов без input. Когда весь входной struct необязателен, допустимы и `search(client)`, и `search(client, input)`. Третьего аргумента с опциями нет. Вызов операции её начинает. `await` только ждёт кортеж error-first.

Определения SDK не привязаны к этому экземпляру. Браузер, серверный запрос и локальный тест могут использовать одну экспортированную операцию с разными клиентами. Все по-прежнему следуют одному контракту Defjs и совместимым версиям Core. Настрой адрес сервиса каждого клиента для операций, которые через него вызываешь.

Одно и то же значение клиента можно передать многим операциям. Кеш и политику повторов выбирает приложение, и оно владеет работой, которую начинает. HTTP автоматически не повторяется. Переподключение потока включается явно.

Поскольку `Client` — функция, не передавай его в setter состояния React: `setState(client)` вызовет его как updater. Не используй его как источник Vue `watch` или `computed`: они вызывают функцию.

## Выведи клиент

`client(options?)` возвращает новый клиент. При вызове `client(options)` семь известных полей копируются из объекта аргумента: снимок верхнего уровня в новый объект опций, наложенный на текущие опции. Более позднее поле побеждает. Поле со значением `undefined` считается не заданным и сохраняет значение родителя. Выведенный клиент не может сбросить настройку, которая есть у родителя. Чтобы снова оказаться без настройки, выведи ещё раз из клиента, у которого её не было (корневой клиент сохрани). Вложенные значения `heartbeat`, `protocols` и `reconnect` хранятся по ссылке, не клонируются, и заменяют значение родителя целиком, а не сливаются. WebSocket читает их, когда выполняется операция (в этот момент копирует поля heartbeat и список protocols), поэтому изменение этих объектов после вывода всё ещё может повлиять на последующий вызов. Приложение должно считать их неизменяемыми после передачи. Вывод не делает I/O. Исходный клиент никогда не мутируется. `client()`, `client(undefined)` и `client({})` копируют текущие опции.

`abort` не объединяется. Более поздний `abort` заменяет предыдущий сигнал. Объединяй сигналы через `AbortSignal.any` в коде приложения.

Базовая конфигурация из `createClient` общая для каждого выведенного клиента и во время выполнения не заморожена. Она фиксирована по соглашению: библиотека её не меняет, и приложению тоже не следует. ## Опции запроса

У [`RequestOptions`](/ru-RU/api/core/requestoptions-type) семь плоских полей. Каждый протокол читает только известные ему поля и игнорирует остальные. Передать `heartbeat` в HTTP-операцию — значит, что поле игнорируется, а не что это fault. SSE читает из опций запроса только `abort`. Переподключение SSE берётся из конфигурации клиента (`withSSEReconnect`), поэтому `client({ reconnect })` влияет только на WebSocket. Фильтра протокола на этапе компиляции нет.

| Поле                 | Кто использует       | Правило                                                                                                        |
| -------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------- |
| `abort`              | HTTP, SSE, WebSocket | Заменяет предыдущий сигнал. Дедлайн — `AbortSignal.timeout(ms)` (`NET_TIMEOUT`). Ручной abort — `NET_ABORTED`. |
| `onUploadProgress`   | HTTP                 | SSE и WebSocket игнорируют.                                                                                    |
| `onDownloadProgress` | HTTP                 | SSE и WebSocket игнорируют.                                                                                    |
| `beforeConnect`      | WebSocket            | Заменяет настройку клиента для этого вызова.                                                                   |
| `protocols`          | WebSocket            | Заменяет список клиента. Он не дописывается.                                                                   |
| `heartbeat`          | WebSocket            | Заменяется целиком. `timeoutMs` — ожидание подтверждения heartbeat, а не дедлайн запроса.                      |
| `reconnect`          | WebSocket            | Заменяется целиком.                                                                                            |

Поля `timeout` нет, поля `signal` нет, и дедлайна по умолчанию на уровне клиента нет. Для SSE и WebSocket `abort` покрывает всё соединение, в том числе после открытия. Дедлайна только на старт нет. Приложение, которому он нужен, создаёт свой `AbortController`, прерывает его через `new DOMException("...", "TimeoutError")` из таймера и сбрасывает таймер после того, как `await` вернулся. См. [SSE](/ru-RU/docs/sse#close-and-dispose).

`HttpExecuteOptions` — срез HTTP: `abort` плюс колбэки прогресса. `EventStreamExecuteOptions` — это `{ abort? }`. `WebSocketExecuteOptions` — срез WebSocket плюс `abort`.

## Результаты по транспорту

- HTTP → `[error, data, response]`
- SSE → `[error, stream, open]`. `open` — снимок первого успешного handshake возвращённого соединения для нативных handle Defjs или обёрток, передающих тот же живой объект `open`; пользовательские handle или обёртки, переопределяющие `open`, используют свой текущий публичный `open` даже после переподключения, а `stream.open` остаётся живым (см. [SSE](/ru-RU/docs/sse)).
- WebSocket → `[error, session, connection]`

Вернись до использования успешного значения, если задан `error`.

Очистка на тебе: abort HTTP, close SSE + `await stream.closed`, close WebSocket + `await session.closed`.

## Scope на сервере и в браузере

На сервере создавай клиент внутри границы запроса, когда опции или замыкания interceptor’ов захватывают auth, cookies, пользователей или tenants. Идентичность клиента сама по себе — не security boundary.

## Миграция

| Было                                      | Стало                                                     |
| ----------------------------------------- | --------------------------------------------------------- |
| `client.execute(getUser(input), options)` | `getUser(client(options), input)`                         |
| `execute(cmd, { timeout: 5000 })`         | `client({ abort: AbortSignal.timeout(5000) })`            |
| `execute(cmd, { signal })`                | `client({ abort: signal })`                               |
| `createClient(withTimeout(5000), ...)`    | передавай `abort` на вызове или оберни функцию приложения |
