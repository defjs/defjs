## Читай fault до значения [#fault-first]

Каждая операция возвращает `[error, data, response]`. Значение успеха имеет смысл, только когда первый элемент — `null`.

Предпочитай:

```ts
const [error, order] = await getOrder(client, { id: 1 });
if (error) return handleOrderFault(error);
console.log(order.status);
```

Избегай:

```ts
const [, order] = await getOrder(client, { id: 1 });
console.log(order.status); // order is undefined when the call failed
```

## Сужай по code, затем по data [#narrow]

`fault.code` выбирает класс провала. Читай `status` для `HTTP_STATUS`, `data` для декодированного тела ошибки и `response` для метаданных. `cause` хранит нижележащий провал парсера или транспорта; не заменяй его общим сообщением.

```ts
if (error.code === "HTTP_STATUS" && error.status === 404) {
  console.log(error.data?.message);
}
```

Коды `RES_*` означают, что ответ не удалось прочитать так, как объявлено. Коды `NET_*` означают, что запрос не дал пригодного ответа. Не повторяй провал декодирования или контракта так, будто это сетевой сбой.

## Логируй один раз, на границе, которой принадлежит исход [#logging]

Логируй на слое, который решает, что будет дальше: в обработчике запроса, в исполнителе задач или на границе UI. Для телеметрии используй плагин OpenTelemetry или интерцептор; определение остаётся свободным от логирования. Редактируй URL, query-строки, заголовки и тела до того, как они попадут в лог.

## Повторяй только то, что безопасно воспроизвести [#retry]

Defjs не повторяет HTTP сам по себе. Повтор принадлежит приложению или явной политике failover эндпоинтов. Повторяй безопасный метод или операцию, которую сервис документирует как идемпотентную. POST, который мог запустить оплачиваемую работу, небезопасно повторять без контракта воспроизведения.

## Не проглатывай ошибки [#no-swallow]

Возврат успеха после ошибки скрывает сломанный контракт. Преобразуй fault в результат приложения, перебрось ошибку программирования или заверши операцию типизированным провалом. Не лови fault только ради записи в лог, чтобы продолжить с неопределённым значением.
