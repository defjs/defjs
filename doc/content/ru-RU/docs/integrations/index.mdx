# Обзор интеграций

Интеграция расширяет собственный `Client` приложения в строго определённой точке расширения без модификации `@defjs/core` и без связывания определений SDK с конкретным фреймворком или стеком телеметрии. Определения вашего SDK остаются чистыми модулями `@defjs/core`, а использующее приложение само решает, какие интеграции подключать.

Каждый плагин Defjs строго следует **контракту тонкого плагина (thin plugin)**:

- **Никакого скрытого кэширования или состояния**: плагины никогда не кэшируют ответы, не повторяют запросы и не управляют состоянием данных запросов.
- **Никакой подмены транспорта**: плагины никогда не оборачивают и не подменяют базовые транспорты HTTP, SSE или WebSocket.
- **Жизненным циклом владеет вызывающий код**: размонтирование UI-провайдера или завершение работы SDK телеметрии не отменяет выполняемые запросы и не закрывает активные потоки автоматически.

## Опубликованные интеграции и инструменты

| Область                                                                   | Пакет / Ресурс                    | Категория         | Что предоставляет                                                                                              | Что остаётся в приложении                                                               |
| ------------------------------------------------------------------------- | --------------------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| [React](/ru-RU/docs/integrations/react)                                   | `@defjs/react`                    | Плагин фреймворка | `ClientProvider` и `useClient(overrideClient?)` для React 18+                                                  | Создание клиента, отмена через `AbortController`, кэширование запросов (TanStack Query) |
| [Vue](/ru-RU/docs/integrations/vue)                                       | `@defjs/vue`                      | Плагин фреймворка | `createClientPlugin`, `HTTP_CLIENT` и `injectClient(key?)` для Vue 3.2+                                        | Создание клиента, отмена в `onCleanup` / `onScopeDispose`, состояние запросов           |
| [OpenTelemetry на сервере](/ru-RU/docs/integrations/opentelemetry-server) | `@defjs/opentelemetry-server`     | Middleware-плагин | Опция `ClientOption` `withOpenTelemetryServer(...)` для исходящих спанов, метрик и логов HTTP, SSE и WebSocket | Инициализация OpenTelemetry SDK, экспортёры, сэмплирование, маскирование данных         |
| [ИИ-навык](/ru-RU/docs/ai) и [llms.txt](/ru-RU/docs/ai-api)               | Навык `defjs/defjs` и `/llms.txt` | Инструменты ИИ    | Навык агента (`SKILL.md`) и машиночитаемая Markdown-документация                                               | Проверка на соответствие установленной в проекте версии `@defjs/core` и набору тестов   |
