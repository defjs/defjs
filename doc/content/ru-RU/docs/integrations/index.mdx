# Плагины

Плагины — необязательные пакеты, которые приложение-потребитель ставит на свой клиент Defjs. `@defjs/core` их не импортирует, определения SDK тоже. Клиент, endpoint, учётные данные и выбор плагинов принадлежат приложению.

Плагины бывают двух видов. **Плагины фреймворка** передают существующий `Client` дереву фреймворка. **Middleware-плагин** — это форма плагина для цепочки перехватчиков: он дописывает перехватчики в клиент приложения. См. [Перехватчики](/ru-RU/docs/interceptors).

| Плагин                                                                                 | Пакет                         | Что добавляет                                                                                        | Чего не делает                                                                                       |
| -------------------------------------------------------------------------------------- | ----------------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| [React](/ru-RU/docs/integrations/react) · фреймворк                                    | `@defjs/react`                | `ClientProvider` и `useClient()` для существующего клиента                                           | Не создаёт, не кэширует, не повторяет и не освобождает клиент. Это не библиотека query или состояния |
| [Vue](/ru-RU/docs/integrations/vue) · фреймворк                                        | `@defjs/vue`                  | Vue-плагин, `HTTP_CLIENT` и `injectClient()`                                                         | Не создаёт, не кэширует и не повторяет. Не закрывает транспорт при unmount. Это не библиотека query  |
| [OpenTelemetry на сервере](/ru-RU/docs/integrations/opentelemetry-server) · middleware | `@defjs/opentelemetry-server` | `withOpenTelemetryServer(...)`, опция клиента, которая дописывает перехватчики HTTP, SSE и WebSocket | Не инициализирует OpenTelemetry SDK и не инструментирует входящие серверные запросы                  |

React и Vue передают существующий `Client` дереву фреймворка. Приложение создаёт этот клиент через `createClient` из `@defjs/core`. Плагин React отдаёт его через Context. Плагин Vue отдаёт его через `app.use(createClientPlugin(client))`. Ни один из пакетов не начинает запрос.

Серверный middleware-плагин OpenTelemetry — это `ClientOption`. Передай `withOpenTelemetryServer(...)` в `createClient`. Он дописывает по одному перехватчику на каждый включённый транспорт, в порядке HTTP, SSE, WebSocket. См. [Перехватчики](/ru-RU/docs/interceptors). Пакет не инициализирует OpenTelemetry SDK.
