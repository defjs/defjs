# Обзор интеграций

Интеграция расширяет собственный `Client` приложения в строго определённой точке расширения без модификации `@defjs/core` и без связывания определений SDK с конкретным фреймворком или стеком телеметрии. Определения вашего SDK остаются чистыми модулями `@defjs/core`, а использующее приложение само решает, какие интеграции подключать.

Каждый плагин Defjs строго следует **контракту тонкого плагина (thin plugin)**:

- **Никакого скрытого кэширования или состояния**: плагины никогда не кэшируют ответы, не повторяют запросы и не управляют состоянием данных запросов.
- **Никакой подмены транспорта**: плагины никогда не оборачивают и не подменяют базовые транспорты HTTP, SSE или WebSocket.
- **Жизненным циклом владеет вызывающий код**: размонтирование UI-провайдера или завершение работы SDK телеметрии не отменяет выполняемые запросы и не закрывает активные потоки автоматически.

## Две архитектуры плагинов

### 1. Плагины для фреймворков (`@defjs/react`, `@defjs/vue`)

Плагин фреймворка передаёт существующий [`DerivableClient`](/ru-RU/api/core/derivableclient-type) вниз по дереву компонентов с помощью стандартного механизма внедрения зависимостей (React Context или Vue `provide` / `inject`):

<Tabs items={["sdk/orders.ts", "app/main.tsx", "app/OrderCard.tsx"]}>
<Tab value="sdk/orders.ts">

```ts
import { defineRequest, struct } from "@defjs/core";

export const Order = struct.object({
  id: struct.number(),
  status: struct.string(),
});

export const getOrder = defineRequest({
  method: "GET",
  path: "/orders/:id",
  input: struct.object({ id: struct.number() }),
  builder: (input) => ({ path: { id: input.id } }),
  output: Order,
});
```

</Tab>
<Tab value="app/main.tsx">

```tsx
import { createClient, withEndpoint } from "@defjs/core";
import { ClientProvider } from "@defjs/react";
import { OrderCard } from "./OrderCard.tsx";

const client = createClient(withEndpoint("https://api.example.com"));

export function App() {
  return (
    <ClientProvider client={client}>
      <OrderCard id={42} />
    </ClientProvider>
  );
}
```

</Tab>
<Tab value="app/OrderCard.tsx">

```tsx
import { useClient } from "@defjs/react";
import { getOrder } from "../sdk/orders.ts";

export function OrderCard({ id }: { id: number }) {
  const client = useClient();
  // Передавайте `client` или `client({ signal })` в `getOrder(...)` внутри эффекта или query-хука
  void id;
  void getOrder;
  void client;
  return null;
}
```

</Tab>
</Tabs>

### 2. Middleware-плагины (`@defjs/opentelemetry-server`)

Middleware-плагин представляет собой фабрику, возвращающую [`ClientOption`](/ru-RU/api/core/clientoption-type). При передаче в `createClient(...)` он добавляет перехватчики HTTP, SSE и/или WebSocket через `withInterceptors`:

<Tab value="plugins/request-id.ts">

```ts
import { createClient, withEndpoint } from "@defjs/core";
import { withRequestIdHeader } from "../plugins/request-id.ts";

export const client = createClient(
  withEndpoint("https://api.example.com"),
  withRequestIdHeader(),
);
```
