# Транспорт Port (`@defjs/core/port`)

`@defjs/core/port` позволяет изолированному контексту (`SharedWorker`, Dedicated Worker, изолированному в sandbox `iframe`, Electron renderer или Popup / Side Panel / Content Script в WebExtension) выполнять чистые SDK-определения `@defjs/core` поверх одного мультиплексированного порта без привязки определений к прокси-транспорту.

- Ноль runtime-зависимостей; поставляется как опциональные subpath-экспорты `@defjs/core/port` и `@defjs/core/port/webext` с нулевыми накладными расходами на бандл без явного импорта
- Делит один порт одновременно между HTTP (включая загрузки и скачивания через `ReadableStream`), SSE (`text/event-stream`) и WebSocket-соединениями
- **Отказобезопасный режим по умолчанию (fail-closed)**: `attachPortHost` отклоняет весь трафик, пока хост явно не укажет `allowedOrigins`, `allowRequest` или `allowAnyOrigin: true`

```bash
bun add @defjs/core
```

## Прокси MV3 WebExtension (`@defjs/core/port/webext`)

WebExtension `runtime.Port` не умеет передавать объекты `ArrayBuffer` напрямую через границы расширений Chromium/Firefox/Safari и разрывает соединение каждый раз, когда Service Worker Manifest V3 уходит в спящий режим. Модуль `@defjs/core/port/webext` предоставляет структурный адаптер без зависимостей `fromWebExtPort` (не требующий `@types/chrome`), который использует чанковую Base64-упаковку `"json"` и поддерживает ленивые функции подключения для автоматического переподключения после гибернации Service Worker:
