Defjs помогает пройти путь от контракта API до опубликованного SDK. Начни с [быстрого старта](/ru-RU/docs/start), затем изучи [команды](/ru-RU/docs/commands) и [клиент](/ru-RU/docs/client): SDK экспортирует эндпоинты, а приложение настраивает их выполнение. [Struct](/ru-RU/docs/struct) описывает общие контракты данных; [проектные решения](/ru-RU/docs/design-decisions) объясняют границы.

Когда первый эндпоинт работает, переходи к [локальным тестам](/ru-RU/recipes/test-with-handle) и [публикации в npm](/ru-RU/recipes/publish-http-sdk). Руководства по транспортам и плагинам подробнее раскрывают контракт SDK и обязанности приложения.
