# Defjs

**Опишите контракт API один раз. Настраивайте выполнение под каждое приложение.**

Defjs разделяет две стороны TypeScript SDK:

- **Определение SDK (`@defjs/core`)** — авторы SDK объявляют типизированные операции HTTP, SSE и WebSocket вместе со схемами `struct`. Определение — это чистые данные: его импорт не запускает сетевой запрос и не привязывает глобальный клиент.
- **Выполнение в приложении** — использующие приложения создают собственный `Client` (`createClient(withEndpoint(...))`), подключают учётные данные, перехватчики и балансировщики нагрузки и передают этот клиент при вызове операции.

## Зачем разделять определения и клиенты?

| Зона ответственности | Автор SDK (определение)                                                                                 | Приложение (выполнение)                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Чем владеет**      | Метод, шаблон пути, схемы `input` / `output` / `error`, маппинг `builder` и статическое имя `operation` | Базовые URL, учётные данные, перехватчики авторизации, балансировка нагрузки, таймауты и освобождение ресурсов |
| **Что поставляет**   | Переиспользуемые ESM-модули и декларации `.d.ts`                                                        | Конфигурация для браузера, сервера или тестового окружения                                                     |
| **Преимущество**     | Полная отвязка от среды выполнения; работает в браузере, SSR и тестах                                   | Полный контроль над повторными попытками, отказоустойчивостью, телеметрией и жизненным циклом                  |

## Выберите свой путь

1. **[Быстрый старт](/ru-RU/docs/start)** — опишите операцию, протестируйте её офлайн с локальным Fetch-хэндлом и направьте на реальный сервис.
2. **[Архитектура ядра](/ru-RU/docs/design-decisions)** — разберитесь в шести правилах декодирования ответов, error-first кортежах и владении ресурсами.
3. **[Определение SDK](/ru-RU/docs/struct)** — объявляйте сетевые контракты с помощью [Struct](/ru-RU/docs/struct) и экспортируйте операции [HTTP](/ru-RU/docs/http), [SSE](/ru-RU/docs/sse) и [WebSocket](/ru-RU/docs/web-socket).
4. **[Клиент и выполнение](/ru-RU/docs/client)** — настраивайте [клиенты](/ru-RU/docs/client), обрабатывайте типизированные [ошибки](/ru-RU/docs/errors), подключайте [перехватчики](/ru-RU/docs/interceptors), настраивайте [балансировку нагрузки и отказоустойчивость](/ru-RU/docs/load-balancing) и запускайте детерминированные [тесты](/ru-RU/docs/testing).

## Поддерживаемые транспорты и кортежи результатов

Каждая операция возвращает error-first кортеж из трёх элементов, адаптированный под жизненный цикл своего транспорта:

| Транспорт                               | Точка входа         | Форма кортежа                  | Управление жизненным циклом                                                     |
| --------------------------------------- | ------------------- | ------------------------------ | ------------------------------------------------------------------------------- |
| **[HTTP](/ru-RU/docs/http)**            | `defineRequest`     | `[error, data, response]`      | Отмена выполняемого запроса через `client({ signal })`                          |
| **[SSE](/ru-RU/docs/sse)**              | `defineEventStream` | `[error, stream, open]`        | Освобождение через `await using` или `stream.close()` + `await stream.closed`   |
| **[WebSocket](/ru-RU/docs/web-socket)** | `defineWebSocket`   | `[error, session, connection]` | Освобождение через `await using` или `session.close()` + `await session.closed` |

При сбое HTTP кортеж принимает вид `[error, undefined, undefined]`, поскольку `error` уже содержит метаданные ответа `HttpMeta`. Для SSE и WebSocket третий слот хранит снимок старта, если он успел сформироваться до ошибки.

## Официальные пакеты

| Пакет                         | Роль                                                                       | Руководство                                                           |
| ----------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `@defjs/core`                 | Определения SDK без зависимостей, `struct`, клиент и перехватчики          | [Быстрый старт](/ru-RU/docs/start)                                    |
| `@defjs/react`                | `ClientProvider` и контекстное внедрение `useClient()` для React 18+       | [Интеграция с React](/ru-RU/docs/integrations/react)                  |

| `@defjs/opentelemetry-server` | Исходящие серверные спаны, метрики и диагностические логи                  | [OpenTelemetry Server](/ru-RU/docs/integrations/opentelemetry-server) |
