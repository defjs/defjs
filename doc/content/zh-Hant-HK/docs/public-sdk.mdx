# 公開 SDK 設計 [#public-sdk-design]

當你間公司或者平台團隊要為外部開發者發佈官方 TypeScript SDK（例如物件儲存 SDK、支付網關 SDK 或 SaaS 平台 SDK）時，SDK 套件嘅核心職責係**定義網絡契約，同時唔強加執行環境同 Client 策略**。

呢篇指南會用**兼容 Amazon S3 嘅物件儲存 SDK（`@company/s3-sdk`）**作為具體藍本，示範點樣用 `models/` 同純函數 `services/` 設計多模組嘅公開 SDK。

---

## 1. 點解公開 SDK 會受惠於 Defjs 嘅職責分離？

傳統 SDK 往往將厚重嘅 client 類別（例如 `new S3Client({ region, credentials })`）同 command 類別或者靜態 service 類別綁死埋一齊。用 `@defjs/core` 編寫公開 SDK 可以為外部用戶解決四個常見痛點：

1. **多環境同沙盒靈活切換**：因為 `@company/s3-sdk` 唔綁定任何 endpoint 或 client，客戶可以將完全相同嘅操作定義指向正式環境（`https://s3.us-east-1.amazonaws.com`）、測試沙盒、Cloudflare R2，或者 CI 測試入面嘅本地 MinIO 容器。
2. **100% 打包工具 Tree-shaking**：匯出獨立嘅純函數（`listBuckets`、`listObjectsV2`、`getObject`、`putObject`、`deleteObject`）並加上 `"sideEffects": false`，可以確保只呼叫 `getObject` 同 `putObject` 嘅瀏覽器 bundle 自動剔除晒所有其他 endpoint 同模型。
3. **Runtime 驗證與靜態型別同源**：外部使用方由同一個來源就可以同時攞到編譯期 TypeScript 型別（`Infer<typeof ...>`）同 runtime 回應／錯誤驗證（`struct`），防範非預期嘅網絡 payload，並自動轉換 `snake_case` 欄位或 ISO 日期字串。
4. **完全掌握認證、重試同觀測**：客戶可以喺自己嘅 `Client` 上面自由掛載憑證輪換攔截器、`withRetry(...)` 策略、跨區域負載平衡器（`withBalancer(...)`），或者伺服器端 OpenTelemetry（`@defjs/opentelemetry-server`）。

## 2. 套件目錄結構

將 SDK 套件分成 `src/models/`（資料結構）同 `src/services/`（按資源領域分組嘅純函數操作定義），並透過扁平入口 `src/index.ts` 統一匯出：

```text
@company/s3-sdk/
├── src/
│   ├── models/                 # 1. 共用 struct schema 同 Infer<typeof ...> 型別
│   │   ├── common.ts           #    StorageClass, S3Error
│   │   ├── bucket.ts           #    Bucket, ListBucketsOutput
│   │   └── object.ts           #    ObjectSummary, ListObjectsOutput
│   ├── services/               # 2. 按資源領域劃分嘅純 defineRequest 函數
│   │   ├── buckets.ts          #    BucketInput, listBuckets, headBucket, deleteBucket
│   │   └── objects.ts          #    listObjectsV2, headObject, getObject, putObject, deleteObject
│   └── index.ts                # 3. 供根路徑 import 同 tree-shaking 使用嘅匯出入口
├── package.json                # sideEffects: false, peerDependencies: { "@defjs/core": "^0.8.0" }
└── tsconfig.json
```

### 設計順手易用嘅操作契約

- **扁平化呼叫端輸入，並喺 `builder` 入面路由**：喺 `putObject` 入面，呼叫端只需要傳入一個扁平物件（`{ bucket, key, body, contentType, storageClass }`），再由同步 `builder` 將輸入拆去 `path`（`:bucket/:key`）、`headers`（`content-type`、`x-amz-storage-class`）同二進制 `body`（`Blob`）。喺 `listObjectsV2` 入面，`builder` 會將 `continuationToken` 同 `maxKeys` 映射到 S3 嘅 `continuation-token` 同 `max-keys` 查詢參數，並自動帶上 `list-type: 2`。
- **將 `output` 對齊實際嘅網絡 payload**：
  - **結構化 JSON（`listBuckets`、`listObjectsV2`）**：宣告帶有 `.alias()` 映射同 `struct.date()` 欄位嘅 `struct.object(...)`。
  - **二進制 payload（`getObject`）**：宣告 `output: struct.blob()`（或者 `struct.arrayBuffer()`）。
  - **空回應 body（`headBucket`、`headObject`、`putObject`、`deleteObject`）**：省略 `output`，令零 byte 嘅 `HEAD`、`200` 同 `204` 回應直接成功而唔嘗試做 JSON 解碼，同時呼叫端仍然可以由回傳 tuple 嘅第三格讀取回應 header（`response.headers.get("etag")`）。

## 4. 外部開發者點樣使用你嘅 SDK

外部應用程式只需要安裝 `@company/s3-sdk` 同 `@defjs/core`，用自己嘅 endpoint 同簽名攔截器設定好 `Client`，就可以直接當純函數咁呼叫你匯出嘅操作。呢個例子跟 Go 風格處理錯誤：`syncReport` 有三個呼叫，所以按步驟命名每個錯誤（`putErr`、`listErr`、`getErr`），回傳 error-first tuple，並用 `new Error("put object", { cause: putErr })` 包裝失敗嘅步驟，就好似 Go 嘅 `fmt.Errorf("put object: %w", err)`。只有程式頂層嘅 `main` 會記錄個錯誤：
