# Vue

`@defjs/vue` 透過 `createClientPlugin(client)`、`HTTP_CLIENT` 同 `injectClient()`，將應用程式自設嘅 `@defjs/core` client 接駁到 Vue 3.2+ 應用程式入面。你嘅 SDK 定義依然保持純粹嘅 `@defjs/core` 模組，完全零 Vue 依賴。

```sh
bun add @defjs/core @defjs/vue vue
```

## `@defjs/vue` 負責乜嘢 vs. 你負責乜嘢

- **`@defjs/vue` 提供**：`createClientPlugin(client)`、`HTTP_CLIENT`（`InjectionKey<Client>`）以及 `injectClient(key?)`。
- **由你嘅應用程式負責**：建立 [`DerivableClient`](/zh-Hant-HK/api/core/derivableclient-type)、喺 watcher（`onCleanup`）或 composable（`onScopeDispose`）入面中斷進行中嘅請求、關閉 SSE/WebSocket handles，以及整合各類查詢狀態庫（例如 Vue Query）。
- **重要提醒**：`injectClient()` 回傳嘅係一個可呼叫嘅 `DerivableClient` 函式物件。請喺具體執行操作嘅地方使用 `client({ signal })`（例如 `getOrder(client({ signal }), input)`）。切忌直接將 `client` 作為第一個參數傳入 `watch(client, ...)` 或 `computed(client)`，因為 Vue 會將函式參數當成響應式 getter 執行。

## 2. 喺子樹中注入與覆寫

`injectClient(key?)` 會向上尋找距離最近嘅 `key` 提供者（預設為 `HTTP_CLIENT`）。如果喺活躍嘅 Vue 注入上下文（`setup()` 或 `app.runWithContext()`）之外呼叫，或者根本冇為該 key 提供 client，就會拋出 `Error`。

- 後代元件會接收到 `childClient`，而平級嘅同輩子樹則繼續保留根 client。
- 如果某個輔助函式接受可選嘅顯式 client（`explicitClient ?? injectClient()`），就只有 fallback 分支需要處於活躍嘅 Vue 注入上下文。請務必喺 `setup()` 執行期間、任何 `await` 之前同步捕獲 client。

對於喺 composable 或元件內部、watcher 之外啟動嘅工作，可以結合 `AbortController` 與 `onScopeDispose`。先中斷啟動流程、關閉 disposal 之後先 resolve 出嚟嘅 handle、消費其單一 async iterator，並等待 `.closed`：

<include cwd>examples/vue/realtime-scope.vue#example</include>

- Tuple 嘅錯誤分支會顯示初始握手失敗（包括 HTTP 503）。Iterator 嘅 `catch` 會顯示啟動後嘅失敗；`finally` 區塊仍然會關閉並等 stream 結束。

- 停止 scope 會令 SSE 嘅 `for await` 迴圈正常結束。
- 中斷 WebSocket 會話會將其狀態置為 `aborted`，並以 `AbortError` reject `session.receive`，因此請喺銷毀後保護好 `catch` 區塊，並喺 `finally` 入面取消訂閱 `onStateChange` / `onRuntimeError` 監聽器。

## 4. SSR 與應用程式作用域

- **瀏覽器端**：當端點同中介層與請求無關時，每個 Vue app 共用單一 client 實例。
- **SSR 伺服器端**：只要 headers、cookies、租戶或身分憑證隨請求變動，就一定要為每個 SSR 請求建立並安裝全新嘅 client。
- Unmount Vue app 或銷毀元件 scope **唔會**自動中斷 HTTP 請求、唔會關閉 SSE/WebSocket 串流，亦唔會銷毀核心 client。
