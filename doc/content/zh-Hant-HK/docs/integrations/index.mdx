# 整合概覽

整合機制允許應用程式喺已定義嘅擴充點上擴充自己嘅 `Client`，完全唔使改動 `@defjs/core`，亦唔會將 SDK 定義同任何前端框架或遙測工具庫綁死。你嘅 SDK 定義始終係純粹嘅 `@defjs/core` 模組；由使用方應用程式自由決定要安裝邊啲整合。

每個 Defjs 外掛都嚴格遵守**輕量外掛契約（Thin plugin contract）**：

- **絕無隱藏快取或狀態**：外掛永遠唔會自行快取回應、重試請求，或擅自管理 query 狀態。
- **絕唔替換傳輸層**：外掛永遠唔會包裝或替換底層嘅 HTTP、SSE 或 WebSocket 傳輸層。
- **由呼叫端掌控生命週期**：Unmount UI 提供者或關閉遙測 SDK，都唔會自動取消進行中嘅請求或者關閉活躍嘅串流。

## 兩種外掛架構

### 1. 框架外掛（`@defjs/react`、`@defjs/vue`）

框架外掛透過原生依賴注入（React Context 或 Vue `provide` / `inject`），將現有嘅 [`DerivableClient`](/zh-Hant-HK/api/core/derivableclient-type) 傳遞畀元件樹下層：

<Tabs items={["sdk/orders.ts", "app/main.tsx", "app/OrderCard.tsx"]}>
  <Tab value="sdk/orders.ts">
```ts
import { defineRequest, struct } from "@defjs/core";

export const Order = struct.object({
  id: struct.number(),
  status: struct.string(),
});

export const getOrder = defineRequest({
  method: "GET",
  path: "/orders/:id",
  input: struct.object({ id: struct.number() }),
  builder: (input) => ({ path: { id: input.id } }),
  output: Order,
});
```
  </Tab>
  <Tab value="app/main.tsx">
```tsx
import { createClient, withEndpoint } from "@defjs/core";
import { ClientProvider } from "@defjs/react";
import { OrderCard } from "./OrderCard.tsx";

const client = createClient(withEndpoint("https://api.example.com"));

export function App() {
  return (
    <ClientProvider client={client}>
      <OrderCard id={42} />
    </ClientProvider>
  );
}
```
  </Tab>
  <Tab value="app/OrderCard.tsx">
```tsx
import { useClient } from "@defjs/react";
import { getOrder } from "../sdk/orders.ts";

export function OrderCard({ id }: { id: number }) {
  const client = useClient();
  // 喺 effect 或 query hook 入面將 `client` 或 `client({ signal })` 傳入 `getOrder(...)`
  void id;
  void getOrder;
  void client;
  return null;
}
```
  </Tab>
</Tabs>

### 2. 中介層外掛（`@defjs/opentelemetry-server`）

中介層外掛係一個回傳 [`ClientOption`](/zh-Hant-HK/api/core/clientoption-type) 嘅工廠函式。當傳入 `createClient(...)` 時，佢會透過 `withInterceptors` 追加 HTTP、SSE 及／或 WebSocket 中介層：
