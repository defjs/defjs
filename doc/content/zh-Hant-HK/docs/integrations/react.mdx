# React

應用程式建立 `@defjs/core` Client，再透過 `@defjs/react` 框架插件的 Context 及 `useClient()` 將它接入 React 樹。組件或資料請求函式庫可以匯入 SDK 端點，並用這個 Client 執行 command；SDK 定義不依賴 React。

呢啲 plugins 只係設定同取得現有 `Client` 嘅可選輔助。你可以直接 import 應用固定嘅 Client、將明確 Client 傳俾可重用邏輯、用框架注入提供組件樹預設值同 subtree override，或者用應用自己嘅組織方式；SDK 定義唔要求經 plugin 執行。

這個套件不會建立 Client、快取結果、重試 command 或釋放傳輸資源。啟動工作的組件、effect 或資料請求函式庫負責取消、關閉及其他生命週期處理。

## 用 `useClient` 讀

`useClient(overrideClient)` 優先 return 明確傳入嘅 Client；省略參數或者傳入 `undefined` 就讀最近嘅 `ClientProvider`。兩個來源都冇 Client 先會 throw `Error`，原本嘅 `useClient()` call 仍然有效。

無論有冇明確 Client，都要喺組件或者 custom Hook 頂層 call `useClient(explicitClient)`，唔可以喺普通 function 或者 event callback 入面 call。唔好寫 `explicitClient ?? useClient()`，因為佢會有條件咁 call Hook。明確值唔會寫入 Context，亦唔會建立 Provider；Hook 仍然會 subscribe Context。

<include cwd>examples/react/read-with-use-client.tsx#example</include>

Hook 淨係供應 client。佢唔會開始工作、subscribe transport，或者將 error-first tuple 變做 exception。

## 由 query library own 嘅工作

Query library 可以 own caching、retries、stale-result suppression 同 cancellation。將佢提供嘅 signal 傳過去。List pages 用 TanStack Query（或者類似嘅）包住 `client.execute(...)`——`@defjs/react` 只做 DI，**唔會** ship `useRequest`。

<include cwd>examples/react/own-query-work.tsx#example</include>

呢度嘅 `throw error` 係 query function 嘅拒絕通道，唔係 Defjs 嘅預設呼叫方式。先檢查 tuple，只有呢個 adapter 先會 reject，等 query library 記錄呢次失敗。

唔好將同一個 command wrap 入第二個 effect — 兩個 owners 會令 cancel 同 stale-result handling 變模糊。

## 自己 own realtime 工作

SSE 同 WebSocket handles 會 outlive `client.execute(...)`。Await startup 之前先 register cleanup，dispose 之後先到嘅 handle 要 close，consume 佢唯一個 iterator，await terminal promise：

<include cwd>examples/react/own-realtime-work.tsx#example</include>

傳俾 `execute` 嘅 `signal` 會繼續管住已經 open 嘅 session。喺 cleanup abort 佢，session 會以 `aborted` 完結，`receive` 以 `AbortError` reject，所以上面個 `catch` 喺 effect dispose 之後會忽略 errors，只報真正嘅失敗（queue overflow、heartbeat timeout）。Abort 咗嘅 SSE stream 就反過來，iterator 會正常完結。冇呢個 `catch` 嘅話，loop 嘅 rejection 就會變成 unhandled promise rejection。

`EventStreamHandle` 同一條規則：喺 `finally` close，await `stream.closed`。WebSocket consumers 亦要 unsubscribe state/runtime-error listeners，同保持讀 `session.receive` — unread bounded queue 可以 overflow。

## SSR 同 client scope

Package entry 係 Client Component boundary。Browser app 可以 share module-scoped client，當 endpoint、interceptors 同 captured state 係 browser-safe 同 request-independent。SSR 時，當 headers、cookies、users、tenants 或者 credentials 唔同時，喺每個 request boundary 入面 create 分開嘅 client。

Provider unmount **唔會** abort HTTP、close SSE/WebSocket、unsubscribe listeners，或者 call `dispose`。`@defjs/react` 冇呢類 lifecycle API。開始每次 operation 嘅 code 一定要 finish 或者 cancel 佢。

## 參考

`@defjs/react` 嘅 public exports：

- `ClientProvider` — 接受 `ClientProviderProps`，provide 傳入嘅 client
- `useClient` — 明確 Client 優先，否則讀最近提供嘅 Client；兩者都冇先 throw
- `ClientProviderProps` — `{ client: Client; children?: ReactNode }`
