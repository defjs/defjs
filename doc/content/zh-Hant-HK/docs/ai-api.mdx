本站發佈面向助手嘅英文 Markdown。呢啲地址冇語言前綴，亦唔係本地化指南嘅譯文。

## 頁面索引 [#llms-txt]

[llms.txt](/llms.txt) 列出英文頁面，並連去對應網頁。助手需要先搵到頁面時，由呢度開始。

## 彙編指南 [#llms-full]

[llms-full.txt](/llms-full.txt) 將英文指南合成一個檔案。需要喺一次上下文提供較廣背景，而 token 預算夠一份大文件時用。

## 單頁 Markdown [#page-markdown]

每個英文頁面亦可以透過 `/llms.mdx/<path>/content.md` 取得 Markdown。例如，[快速開始嘅 Markdown](/llms.mdx/docs/start/content.md) 就係快速開始頁嘅英文正文。

## 核對版本 [#version]

本站記錄預設分支；項目安裝嘅 `@defjs/core` 版本可能唔同。採用建議之前，先按已安裝嘅套件核對 API。向 AI 工具提供程式碼或上下文之前，先移除密鑰並確認項目嘅資料使用政策。
