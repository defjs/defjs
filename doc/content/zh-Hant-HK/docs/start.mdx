# 快速開始：你嘅第一個 SDK 操作 [#getting-started-one-http-request]

喺呢篇指南入面，你會建立一個定義咗 `GET /orders/:id` 嘅 SDK 模組，然後由兩個獨立嘅應用程式模組呼叫佢：一個用離線 mock 傳輸層，另一個直接對接真實嘅線上 API。

## 1. 安裝 `@defjs/core`

`@defjs/core` 係一個零依賴嘅純 ESM 套件，支援瀏覽器、Bun 同埋 Node.js（22.18+ 或 24+ 可以直接執行 `.ts` 檔案）。記得喺你嘅 `package.json` 入面設定 `"type": "module"`。

```sh
bun add @defjs/core
```

## 2. 定義 SDK 並喺應用程式入面呼叫

將操作定義保留喺佢專屬嘅 SDK 模組（`src/define-request.ts`），然後喺你嘅應用程式入面建立 client（`src/execute-locally.ts` 或 `src/real-api.ts`）：

### 呢三個檔案點樣協同運作

1. **`src/define-request.ts`（SDK 定義）**：
   - 用 `struct` 宣告 `input`、`output`（對應 `2xx` 成功回應）同埋 `error`（對應非 `2xx` 回應）。
   - 提供一個同步嘅純函式 `builder`，將 `input` 映射成 `{ path }`。只要宣告咗 `input`，就必須提供明確嘅 `builder`。
   - 匯出 `getOrder`，過程完全唔會建立或者綁死任何 client。
2. **`src/execute-locally.ts`（離線測試執行）**：
   - 用 `withHTTPHandle(...)` 設定 client，唔使連上真實網絡，都可以跑齊完整嘅 Defjs 流程（input 驗證、URL 解析、狀態碼分發，以及 response struct 解析）。
3. **`src/real-api.ts`（生產環境執行）**：
   - 匯入完全同一個 `getOrder` 操作，並透過 `withEndpoint(...)` 設定真實嘅 base URL 嚟呼叫線上服務。

## 3. 執行本地範例

用 Bun 執行 `src/execute-locally.ts`：

```sh
bun src/execute-locally.ts
```

```txt
Loaded paid from 200
```

如果你將 input 由 `{ id: 7 }` 改做 `{ id: 8 }`，mock 會回傳 `404`，Defjs 就會將宣告好嘅 `error` struct 解碼並放落 `error.data`：

```txt
Order not found
```

## 4. 理解 error-first tuple

每次 HTTP 呼叫都會 resolve 出 `[error, data, response]`：

- **`2xx` 成功**：`error` 係 `null`，`data` 係通過驗證嘅 `output` 值（`Order`），而 `response` 就係 `DecodedResponse<Order>`。
- **宣告過嘅非 `2xx` 狀態碼**：`error.code` 係 `'HTTP_STATUS'`，`error.status` 係數字狀態碼（`404`），而 `error.data` 係通過驗證嘅 `error` struct（`NotFound`）。
- **Input、解碼或網絡錯誤**：`error.code` 會標明具體喺邊個階段出事：
  - `REQ_INPUT_INVALID` / `REQ_BUILD_FAILED` — 呼叫端傳入嘅 input 無效，或者 `builder` 拋出例外
  - `RES_MEDIA_TYPE_INVALID` — 宣告咗 JSON body 但伺服器回傳咗非 JSON 嘅 `Content-Type`（喺讀取 body 前就會拒絕）
  - `RES_DECODE_FAILED` / `RES_STRUCT_MISMATCH` — 無法讀取 body 或 schema 結構唔吻合
  - `NET_UNREACHABLE` / `NET_ABORTED` / `NET_TIMEOUT` — 傳輸層錯誤、手動中斷，或者 `AbortSignal.timeout(ms)` 逾時

如果要設定單次呼叫嘅截止時間或中斷信號，只要衍生出單次使用嘅 client 即可：`getOrder(client({ signal: AbortSignal.timeout(5_000) }), { id: 7 })`。
