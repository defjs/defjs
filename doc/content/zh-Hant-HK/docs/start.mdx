# 快速開始：一個 HTTP request

這次先以 SDK 作者的身份定義並匯出 `GET /users/:id`，再以應用程式開發者的身份匯入它、建立 Client 並執行。兩個檔案分別負責契約與呼叫，`200` 及已聲明的 `404` 都保留類型。本地 handle 讓第一次執行可以離線完成；連接真實服務時繼續使用同一個定義。

## 最佳實踐

Definition 同 client 係分開嘅。Call definition 只會建立 command。先畀呢個 command 一個名，再將個名交畀應用程式自己嘅 client 去 `client.execute`。服務地址同 credentials 都歸應用程式所有。先檢查 error-first tuple。`error` 有值時，報告 `error.code`，喺 function 入面 return，然後先讀成功值。

## Step 1 — 安裝

## Step 2 — Define 個 request

建立 `src/define-request.ts`，匯出 SDK 的 `getUser` 端點。Input Struct 描述呼叫方提供的值，`builder` 決定值在請求中的位置。這裏整個 input 就是 path 物件，沒有 alias 的純量欄位會填入 `:id`。定義檔案不建立 Client，也不發出請求。

<include cwd meta="define-request.ts">
  examples/start/define-request.ts#example
</include>

`output` 係 2xx body。`error` 係其餘每個 status。一邊一個 struct。Bodies 唔同就用 `struct.or(...)` 或者 discriminated union。

`defineRequest(...)` return 嘅係 endpoint。Call `getUser(...)` 會 build 出你之後傳去 `client.execute(...)` 嘅 opaque command。上面嗰個 `builder` 係擺放 input 嘅 function；佢唔係 endpoint。

## Step 3 — 喺本機 execute

建立 `src/execute-locally.ts`，從 `./define-request.ts` 匯入 `getUser`。應用程式擁有 Client，並為它設定服務地址及本地 Fetch handle；不需網絡也能完成輸入驗證、`Request` 建立、狀態分派及 body 解析。

Success 時：`error` 係 `null`，`user` 係 `200` Struct output，`response` 係 `DecodedResponse<User>`。Declared `404`：`error.code` 係 `'HTTP_STATUS'`，`error.status` 係 `404`，`error.data` 有 typed `NotFound`。失敗時 tuple 第二項係 `undefined`。

## Result 唔同時

- 壞 input → `REQ_INPUT_INVALID`；撞咗嘅 cancel options → `REQ_OPTIONS_INVALID`；失敗嘅 `builder` → `REQ_BUILD_FAILED`
- 非 2xx status → `HTTP_STATUS`；如果聲明過 `error` 而且 body 解碼成功，`error.data` 就有 type
- 已聲明嘅 JSON body 用另一種 media type → `RES_MEDIA_TYPE_INVALID`，讀 body 之前就報
- 已聲明嘅 body（2xx 係 `output`，其餘係 `error`）解唔出 → `RES_DECODE_FAILED` 或者 `RES_STRUCT_MISMATCH`，唔理 status 係咩
- Fetch fail / cancel / timeout → `NET_UNREACHABLE` / `NET_ABORTED` / `NET_TIMEOUT`

`timeout` 一定要係 `1..2_147_483_647` 入面嘅 positive safe integer。合法嘅 cancel 形狀：`{ signal }`、`{ timeout }`、`{ abort }`，或者 `{ signal, timeout }` / `{ signal, abort }`。`{ abort, timeout }` 一齊係 invalid。Cancellation 淨係話你 caller 見到咩 — 唔證明 server write 有冇 commit。
