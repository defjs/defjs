# 快速開始：你嘅第一個 SDK 操作 [#getting-started-one-http-request]

你會寫兩個檔案：一個 SDK 模組匯出 `GET /users/:id`，一個應用程式匯入佢並擁有 client。本地 Fetch handle 令第一次執行可以離線。同一份 API 定義之後可以用一個指向你服務嘅 client。

## 最佳實踐

定義同 client 係分開嘅。用應用程式嘅 client 呼叫操作，好似 `getUser(client, { id: 7 })`。冇第三個 options 參數。呼叫操作就開始佢；`await` 只係等。服務地址同 credentials 都歸應用程式所有。先檢查 error-first tuple。`error` 有值時，報告 `error.code`，喺 function 入面 return，然後先讀成功值。

## Step 1 — 安裝

`@defjs/core` 係 ESM，可以喺 Node.js 或 Bun 上面行。Node.js 22.18+（或 24+）透過 type stripping 直接 run `.ts`；舊啲嘅 22.x 要加 `--experimental-strip-types`。package.json 要保持 `"type": "module"`。Browser 仍然要你自己嘅 bundler 同 Fetch。

```sh
bun add @defjs/core
```

## Step 2 — Define 個 request

建立 `src/define-request.ts`，匯出 SDK 的 `getUser` 端點。Input Struct 描述呼叫方提供的值，`builder` 決定值在請求中的位置。這裏整個 input 就是 path 物件，沒有 alias 的純量欄位會填入 `:id`。定義檔案不建立 Client，也不發出請求。

<include cwd meta="define-request.ts">
  examples/start/define-request.ts#example
</include>

`output` 係 2xx body。`error` 係其餘每個 status。一邊一個 struct。Bodies 唔同就用 `struct.or(...)` 或者 discriminated union。

`defineRequest(...)` return 一個操作。Call `getUser(client, input)` 就開始請求。上面嗰個 `builder` 係擺放 input 嘅 function；佢唔係操作。聲明咗 `input` 時，`builder` 必須有，而且係同步純函數。

## Step 3 — 喺本地呼叫

建立 `src/execute-locally.ts`，從 `./define-request.ts` 匯入 `getUser`。應用程式擁有 Client，並為它設定服務地址及本地 Fetch handle；不需網絡也能完成輸入驗證、`Request` 建立、狀態分派及 body 解析。

<include cwd meta="execute-locally.ts">
  examples/start/execute-locally.ts#example
</include>

Run 佢：

```sh
bun src/execute-locally.ts
```

```txt
Loaded Ada from 200
```

試吓 missing user — 將 path id 改做 `8`，再 run 一次：

```txt
User not found
```

Success 時：`error` 係 `null`，`user` 係 `200` Struct output，`response` 係 `DecodedResponse<User>`。Declared `404`：`error.code` 係 `'HTTP_STATUS'`，`error.status` 係 `404`，`error.data` 有 typed `NotFound`。失敗時 tuple 第二項係 `undefined`。

## Step 4 — 指去真實 API

喺 `src/real-api.ts` 匯入同一個 `getUser`，用你服務嘅 base URL 建立 client。將例子入面嘅地址換成實作 `GET /v1/users/:id`、而且 body 符合嗰啲形狀嘅服務之後，先至跑呢個版本。

<include cwd>examples/start/real-api.ts#example</include>

API 定義留喺 SDK 模組。服務地址、認證、攔截器同執行壽命留喺應用程式。兩個 client 用同一份 Defjs 端點契約。

## 發佈定義

更多應用程式需要呢份定義時，將佢搬入 SDK 套件。匯出 `getUser`，帶埋 TypeScript declarations，並聲明兼容嘅 Core 版本。使用方之後由套件匯入，而唔係 `./define-request.ts`；佢哋嘅 client 設定仍然係自己嘅。完整套件設定跟[建置並發佈 SDK](/zh-Hant-HK/recipes/publish-http-sdk)。

## Result 唔同時

- 壞 input → `REQ_INPUT_INVALID`；失敗嘅 `builder` → `REQ_BUILD_FAILED`
- 非 2xx status → `HTTP_STATUS`；如果聲明過 `error` 而且 body 解碼成功，`error.data` 就有 type
- 已聲明嘅 JSON body 用另一種 media type → `RES_MEDIA_TYPE_INVALID`，讀 body 之前就報
- 已聲明嘅 body（2xx 係 `output`，其餘係 `error`）解唔出 → `RES_DECODE_FAILED` 或者 `RES_STRUCT_MISMATCH`，唔理 status 係咩
- Fetch fail / cancel / deadline → `NET_UNREACHABLE` / `NET_ABORTED` / `NET_TIMEOUT`

Deadline 係 `client({ signal: AbortSignal.timeout(ms) })`，分類為 `NET_TIMEOUT`。手動 abort 係 `NET_ABORTED`。冇 client 層級嘅預設 deadline。某次呼叫要自己嘅 `signal` 時，派生一個 client；睇 [Client](/zh-Hant-HK/docs/client)。Cancellation 淨係話你 caller 見到咩 — 唔證明 server write 有冇 commit。
