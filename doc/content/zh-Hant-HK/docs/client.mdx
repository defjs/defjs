# Client

`Client` 負責持有使用方應用程式嘅執行設定：包括 base URL、預設 headers、認證憑證、攔截器、query 序列化函式同埋傳輸層 handle。

呼叫 `createClient(...options)` 會回傳一個 [`DerivableClient`](/zh-Hant-HK/api/core/derivableclient-type)：

- 如果唔需要單次呼叫自訂選項，可以直接將 `client` 傳入操作（例如 `getOrder(client, { id: 1 })`）。
- 呼叫 `client(requestOptions)` 可以衍生出單次呼叫用嘅 client 值（例如 `getOrder(client({ signal }), { id: 1 })`）。衍生過程唔會進行任何 I/O，而衍生出嚟嘅值係一個普通物件（唔可以當函式咁呼叫）。

### 選項組合規則

- 所有選項按**由左至右**嘅順序套用。
- 單值設定函式（`withEndpoint`、`withHeaders`、`withQuerySerializer`、`withCredentials`，以及來自 `@defjs/core/xsrf` 嘅 `withXSRF`）會**覆寫**前面設定嘅舊值。
- `withInterceptors(...items)` 會將新項目**追加**到現有嘅攔截器清單尾部，並喺執行具體操作時自動按傳輸層（`http`、`sse`、`web-socket`）過濾。

### 單次呼叫 `RequestOptions` 參考

`RequestOptions` 包含七個扁平欄位。每種傳輸層只會讀取適用於自己嘅欄位，並自動忽略其餘部分：

| 欄位                 | 適用傳輸             | 行為描述                                                                              |
| -------------------- | -------------------- | ------------------------------------------------------------------------------------- |
| `signal`             | HTTP、SSE、WebSocket | 中斷當前呼叫（`AbortSignal.timeout(ms)` → `NET_TIMEOUT`；手動中斷 → `NET_ABORTED`）。 |
| `onUploadProgress`   | HTTP                 | 回報串流 request body 嘅上傳進度。                                                    |
| `onDownloadProgress` | HTTP                 | 回報宣告過嘅 response body 嘅下載進度。                                               |
| `beforeConnect`      | WebSocket            | 喺呢次會話入面替換 client 層級嘅 `beforeConnect` hook。                               |
| `protocols`          | WebSocket            | 喺呢次會話入面替換 client 層級嘅子協議清單。                                          |
| `heartbeat`          | WebSocket            | 喺呢次會話入面替換 client 層級嘅心跳偵測設定。                                        |
| `retry`              | HTTP、SSE、WebSocket | 喺呢次呼叫入面替換 client 層級嘅重試策略。HTTP 嘅 `budget` 仍然留喺 client。          |

## 3. 瀏覽器單例 vs. 伺服器請求作用域

- **瀏覽器應用程式**：當 endpoint、攔截器同憑證屬於整個前端共用嗰陣，喺模組頂層共用一個 `DerivableClient` 單例即可。
- **伺服器 / SSR 應用程式**：只要 headers、cookies、認證 token 或租戶 context 係隨請求變動，就一定要**喺每個傳入請求嘅處理範圍內**建立獨立嘅 client。絕唔好喺整個 process 共用嘅全域 client 上面存放個別用戶嘅身分憑證。

## 4. 多端點與負載平衡 [#multiple-endpoints]

`withEndpoint(...urls)` 接受傳入一個或多個候選 base URL。預設情況下：

- 每個 client 預設使用 [`pickFirstBalancer`](/zh-Hant-HK/api/core/pickfirstbalancer)，停喺第一個 URL，直至遇到 `NET_UNREACHABLE` 或 `NET_UNAVAILABLE`（HTTP 502、503 或 504）先至前進。
- **重試預設關閉。** 每次呼叫只試一次。`withRetry()` 等同 `withRetry({})`：HTTP、SSE 同 WebSocket 都一樣，最多三次帶 backoff 嘅重試。每次失敗之後 balancer 會由所有端點再揀一次，所以連線被拒絕之後嘅重試，喺 pick-first 下面會去到下一個端點，而單一端點會喺延遲之後再試一次。HTTP 嘅 Finagle 重試預算屬於 client 配置，由佢派生出嚟嘅 client 共享，同 balancer 嘅 identity 無關。

<include cwd lang="typescript">
  examples/client/multiple-endpoints.ts#example
</include>

`attemptTimeoutMs` 限制一次嘗試：HTTP 計到 response body 結束，SSE 計到 response headers，WebSocket 計到 `open`。想有時間上限但唔重試，就寫 `withRetry({ maxRetries: 0, attemptTimeoutMs })`。重試選項唔會喺 runtime 驗證。決策順序，以及由 `withSSEReconnect` 同 `withWebSocketReconnect` 遷移過嚟，請睇[負載平衡與故障轉移](/zh-Hant-HK/docs/load-balancing#retries)。

### 健康檢查過濾與 P2C [#health-filtering-and-p2c]

對於對等伺服器節點，[`roundRobinBalancer`](/zh-Hant-HK/api/core/roundrobinbalancer) 同 [`p2cBalancer`](/zh-Hant-HK/api/core/p2cbalancer)（結合 PeakEwma RTT 與進行中請求負載）可以接受 `outlierDetection` 選項；除非你傳入一個物件（`{}` 即用預設值），否則佢係關閉嘅。佢會計失敗並將端點剔除一段時間，亦會跳過你自己嘅 `isHealthy` 函式拒絕嘅端點；Defjs 唔會決定健康係點解。預設情況下每個帶錯誤碼嘅結果都計為失敗（包括 `NET_TIMEOUT` 同 `NET_BODY_INCOMPLETE`），你可以用 `isFailure` 替換呢條規則；原始 response `status` 只供自訂 balancer 使用。

關於重試預算、失敗剔除同你自己嘅健康函式、P2C 負載估算以及自訂 balancer 嘅完整細節，請參閱[負載平衡與故障轉移](/zh-Hant-HK/docs/load-balancing)指南。

## 6. Client 選項輔助函式參考

| 輔助函式                                                                           | 用途                                                                                                                                                                                                                                                     |
| ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `withEndpoint(...urls)`                                                            | 設定一個或多個候選 base URL（會覆寫先前嘅清單）。                                                                                                                                                                                                        |
| `withHeaders(HeadersInit)`                                                         | 為 HTTP 同 SSE 設定靜態預設 headers（會被 builder headers 覆寫）。                                                                                                                                                                                       |
| `withInterceptors(...items)`                                                       | 以洋蔥模型順序追加 HTTP、SSE 同 WebSocket 攔截器。                                                                                                                                                                                                       |
| `withQuerySerializer(fn)`                                                          | 將已套用別名嘅 query 物件序列化成 query string。                                                                                                                                                                                                         |
| `withCredentials(boolean)`                                                         | 設為 `true` 時，為 HTTP 同 SSE 請求設定 Fetch 嘅 `credentials: "include"`。                                                                                                                                                                              |
| `withXSRF(options?)`                                                               | 來自 `@defjs/core/xsrf`。喺瀏覽器入面，於同源嘅變更類 HTTP 請求中，自動將 XSRF cookie 複製到 header。呼叫 `withXSRF()` 時，如果缺少 `location` 或者 `document`（包括 Worker）會拋錯。同構程式只喺瀏覽器入面加呢個 option。令牌嚟自別處時，用攔截器設定。 |
| `withBalancer(balancer)`                                                           | 替換端點選取策略（`pickFirstBalancer`、`roundRobinBalancer`、`p2cBalancer`）。                                                                                                                                                                           |
| `withRetry(options?)`                                                              | 設定可選啟用嘅 HTTP、SSE 同 WebSocket 重試：重試次數、backoff、方法、單次 attempt 逾時、`shouldRetry` 函式，以及 HTTP 歸 client 所有嘅 budget。                                                                                                          |
| `withSSEOnInvalidEvent`                                                            | 觀察冇 struct 或者驗證失敗嘅 SSE 事件。                                                                                                                                                                                                                  |
| `withWebSocketHeartbeat` / `withWebSocketProtocols` / `withWebSocketBeforeConnect` | 設定 WebSocket 會話嘅各項預設參數。                                                                                                                                                                                                                      |
| `withHTTPHandle` / `withSSEHandle` / `withWebSocketHandle`                         | 注入自訂或 mock 傳輸實作。                                                                                                                                                                                                                               |
