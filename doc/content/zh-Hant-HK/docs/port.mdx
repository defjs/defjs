# Port 傳輸層（`@defjs/core/port`）

`@defjs/core/port` 令隔離執行環境（`SharedWorker`、Dedicated Worker、沙盒化 `iframe`、Electron renderer，或者 WebExtension Popup / Side Panel / Content Script）可以透過單一多工 port 執行純粹嘅 `@defjs/core` SDK 定義，而唔會將定義耦合到代理傳輸層。

- 零執行期依賴；作為可選子路徑 `@defjs/core/port` 同 `@defjs/core/port/webext` 提供，唔匯入時零打包體積開銷
- 透過同一個 port 並發共用 HTTP（包括 `ReadableStream` 上傳／下載）、SSE（`text/event-stream`）同 WebSocket 連線
- **預設 fail-closed 安全性**：除非 host 明確指定 `allowedOrigins`、`allowRequest` 或明確設定 `allowAnyOrigin: true`，否則 `attachPortHost` 會拒絕所有流量

```bash
bun add @defjs/core
```

## MV3 WebExtension 代理（`@defjs/core/port/webext`）

WebExtension 嘅 `runtime.Port` 無法跨 Chromium／Firefox／Safari 擴充功能邊界直接傳輸 `ArrayBuffer` 物件，而且只要 Manifest V3 Service Worker 休眠就會斷線。`@defjs/core/port/webext` 提供零依賴嘅結構性適配器 `fromWebExtPort`（唔需要 `@types/chrome`），採用 `"json"` 分塊 Base64 封裝格式，並支援延遲連接函式，方便喺 Service Worker 休眠喚醒後自動重連：
