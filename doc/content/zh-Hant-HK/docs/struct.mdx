# Struct 與 Schema

`struct` 用嚟宣告 SDK 同使用方之間共享嘅網絡資料契約：包括呼叫端嘅 input、`2xx` 輸出、宣告過嘅服務錯誤、SSE 事件，以及 WebSocket frame。

- **靜態型別推斷**：透過 `Infer<typeof Schema>` 推斷 TypeScript 型別。
- **Error-first 執行時驗證**：用 `struct.parse(Schema, value)` 喺執行時驗證值 — 回傳 `[null, data]` 或 `[StructError, undefined]`，唔會拋出例外。

解析出嚟嘅物件只會保留宣告過嘅欄位（未宣告嘅未知屬性會自動被剔除），並且採用 `null` prototype。只要缺少必要 key、基本型別唔啱，或者分支無效，就會直接產生 `StructError`，唔會產出部分結果。

## 2. 必填、可選與 Nullable 欄位

Defjs 將**欄位存在與否**（`undefined`）同**空值**（`null`）分得清清楚楚。預設情況下，每個 struct 建構子都係嚴格必填而且唔接受 null：

| 宣告方式                     | 缺少 / `undefined`       | `null` | 有效值        |
| ---------------------------- | ------------------------ | ------ | ------------- |
| `struct.string()`            | 拒絕                     | 拒絕   | 接受 `string` |
| `struct.string().optional()` | 接受（物件序列化時省略） | 拒絕   | 接受 `string` |
| `struct.string().null()`     | 拒絕                     | 接受   | 接受 `string` |
| `struct.string().nullish()`  | 接受（物件序列化時省略） | 接受   | 接受 `string` |
| `struct.null()`              | 拒絕                     | 接受   | 拒絕非 `null` |

<include cwd lang="typescript">
  examples/struct/required-optional-null.ts#example
</include>

`struct.any()` 同 `struct.unknown()` 亦都會預設拒絕 `null` 同 `undefined`，除非你後面鏈式呼叫 `.null()`、`.optional()` 或 `.nullish()`。

## 3. 雙向網絡別名（`.alias()`）

當後端用 `snake_case` 或者特定 header 名稱，而你嘅 TypeScript SDK 用 `camelCase` 嗰陣，就可以用 `.alias("wire_name")`。你只需喺欄位宣告一次 alias，佢就可以喺兩個方向自動轉換：

| 邊界                                                           | 使用嘅 Key 名稱                            |
| -------------------------------------------------------------- | ------------------------------------------ |
| 操作 `input` 與 `struct.parse(Schema, value)`                  | 邏輯名稱（`customerName`）                 |
| `builder` 回傳嘅帶型別 struct 值（`body`、`query`、`headers`） | 網絡 alias（`customer_name`）              |
| 解碼 JSON 回應 / SSE 事件 / WebSocket frame                    | 網絡 `customer_name` → 邏輯 `customerName` |
| 喺 `builder` 入面直接手寫嘅匿名物件 key                        | 照寫入嘅字面 key                           |

<include cwd lang="typescript">
  examples/struct/aliases.ts#example
</include>

喺 `builder` 入面展開帶型別嘅物件（例如 `{ ...input.order, extra: 1 }`）會保留佢嘅 struct 編碼同別名設定。但如果你喺同一個物件同時寫入邏輯 key 同網絡 alias，呼叫就會以 `REQ_BUILD_FAILED` 失敗。

## 4. 請求放置與表單編碼

`input` 負責定義參數；`builder` 則負責將佢哋放到 `{ path, query, headers, body }`。針對表單編碼嘅 body，`struct.urlencoded(shape)` 同 `struct.formData(shape)` 會標記根物件，等傳輸層自動將佢序列化做 `URLSearchParams` 或者 `FormData`：

<include cwd lang="typescript">
  examples/struct/request-placement.ts#example
</include>

| `builder` 回傳嘅 Body 根值                  | 網絡傳輸格式      | 預設 `Content-Type`                               |
| ------------------------------------------- | ----------------- | ------------------------------------------------- |
| 帶型別物件、陣列、有限數值、boolean、`null` | JSON 字串         | `application/json`                                |
| `string` struct 或原生 `string`             | UTF-8 純文字      | `text/plain;charset=UTF-8`                        |
| 位於 body 根部嘅 `struct.urlencoded(shape)` | `URLSearchParams` | `application/x-www-form-urlencoded;charset=UTF-8` |
| 位於 body 根部嘅 `struct.formData(shape)`   | `FormData`        | `multipart/form-data; boundary=...`               |
| `Blob` / `File` (`struct.file()`)           | 二進制 blob       | `blob.type` 或 `application/octet-stream`         |
| `ArrayBuffer` / view / `ReadableStream`     | 原始位元組串流    | `application/octet-stream`                        |

## 5. 處理 `StructError` 與錯誤細項

當驗證失敗時，`struct.parse(Schema, data, { aliases?, errorMap? })` 會回傳 `[StructError, undefined]`。`StructError` 繼承自原生 `Error`，並提供 `issues`、`format()`、`flatten()` 同 `prettify()`：

<include cwd lang="typescript">
  examples/struct/parse-failures.ts#example
</include>

每個 `StructIssue` 都包含 `code`（`invalid_type`、`missing_key`、`invalid_literal`、`invalid_enum`、`invalid_union`、`invalid_intersection` 或 `custom`）、`path`、`expected`、`received` 同埋 `message`。預設訊息會省略收到嘅值，只報告佢嘅*型別*，但 path 會保留動態 record 嘅 key，入面可能有敏感值。`String(err)` 同 `err.prettify()` 唔係脫敏邊界；寫 log 時請用安全欄位嘅 allowlist，並將原始 `received` 值同自訂訊息當作敏感資料。

## 6. 建構函式參考

| 建構函式                                                   | 接受嘅輸入                         | 推斷出嘅輸出型別                                      |
| ---------------------------------------------------------- | ---------------------------------- | ----------------------------------------------------- |
| `struct.string()` / `struct.boolean()`                     | 吻合嘅基本型別                     | `string` / `boolean`                                  |
| `struct.number()`                                          | 除咗 `NaN` 以外嘅任何 `number`     | `number`（拒絕 `NaN`；喺 JSON body 拒絕 `±Infinity`） |
| `struct.bigint()`                                          | `bigint` 或數字字串                | `bigint`                                              |
| `struct.date()`                                            | 有效 `Date`、timestamp 或 ISO 字串 | `Date`                                                |
| `struct.literal(value)`                                    | 完全精確嘅基本型別字面值           | 字面值型別                                            |
| `struct.enum(values)`                                      | 宣告過嘅字串或數字成員             | 字面值嘅 Union                                        |
| `struct.array(item)` / `struct.tuple(items)`               | 陣列 / 固定長度 tuple              | `T[]` / `[...]`                                       |
| `struct.object(shape)` / `struct.record(val)`              | 純物件                             | 帶型別物件 / `Record<string, V>`                      |
| `struct.discriminatedUnion(key, options)`                  | 帶有字面值 `key` 判別器嘅物件      | 各物件分支嘅 Union                                    |
| `struct.or(branches)`                                      | 第一個吻合嘅分支                   | 各分支型別嘅 Union                                    |
| `struct.intersection(members)`                             | 同時滿足所有成員嘅值               | 深度合併嘅 Intersection                               |
| `struct.file()` / `struct.blob()` / `struct.arrayBuffer()` | `File` / `Blob` / `ArrayBuffer`    | 二進制表示                                            |

### 遞迴 struct

自我參照嘅型別透過 shape 上面嘅 getter 屬性讀取自己。getter 唔係喺定義常數嗰陣執行，而係喺物件 struct 第一次被使用時執行一次，所以常數可以引用自己。請用 `Struct<T>` 標註該常數：TypeScript 推斷唔到參照自己嘅型別。

### `struct` 唔做嘅嘢

- `struct` 只係宣告結構。字串長度、正規表示式、數值範圍同業務規則應該喺解析之後由應用程式碼處理。
- 解析會喺第一個無效欄位停低。佢從來唔會用零值填補缺少嘅欄位，亦從來唔會回傳部分輸出。
