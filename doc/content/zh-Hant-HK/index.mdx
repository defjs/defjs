# Defjs

**為更好嘅 SDK 而設計。**

Defjs 幫團隊將自己嘅 API 變成可重用嘅 TypeScript SDK。`def` 即係 `define`：描述服務提供嘅操作，由模組或 npm 套件匯出，再由每個應用程式設定自己嘅 client 去呼叫。

## 定義 SDK，設定應用程式

| SDK 作者                                  | SDK 使用方                         |
| ----------------------------------------- | ---------------------------------- |
| 定義操作、input、request 映射、回應同錯誤 | 揀服務地址、認證、攔截器同傳輸     |
| 匯出帶類型嘅 HTTP、SSE 同 WebSocket 端點  | 匯入呢啲端點，用 Defjs client 呼叫 |
| 維護並發佈 API 契約                       | 處理結果，並擁有取消、串流同會話   |

SDK 定義唔會捕獲應用程式嘅 client。同一個匯出端點可以用喺瀏覽器應用程式、伺服器，或者用唔同 client 設定做本地測試。兩邊仍然用 Defjs 嘅執行契約同兼容嘅 Core 版本。

SDK 匯出一個操作：

<include cwd meta="get-health.ts">
  examples/home/get-health.ts#example
</include>

應用程式匯入佢，並擁有執行：

<include cwd meta="app.ts">
  examples/home/app.ts#example
</include>

呼叫 `getHealth(client)` 就開始請求。發佈定義之後，使用方由你嘅 SDK 套件匯入，而唔係本地檔案。

## 最佳實踐

定義同 client 係分開嘅。應用程式嘅 client 做第一個參數傳入，好似 `getHealth(client)`。服務地址同認證都歸應用程式所有。先檢查 error-first tuple。`error` 有值時，報告 `error.code`，喺 function 入面 return，然後先讀成功值。

## 建立你嘅 SDK

1. 喺分開嘅 SDK 同應用程式檔案入面[定義並執行你嘅第一個操作](/zh-Hant-HK/docs/start)。
2. 描述 SDK 匯出嘅[資料契約](/zh-Hant-HK/docs/struct)同 [HTTP 操作](/zh-Hant-HK/docs/http)。
3. [測試並發佈一個 SDK 套件](/zh-Hant-HK/recipes/publish-http-sdk)，包含 JavaScript、declarations，同兼容嘅 Core dependency。
4. 設定使用方應用程式嘅 [Client](/zh-Hant-HK/docs/client)，再按需要加框架或可觀測性整合。

[設計決策](/zh-Hant-HK/docs/design-decisions)解釋點解 API 定義同執行有各自嘅擁有者。發佈套件之前，你可以喺同一個應用程式入面用呢個結構。

## 揀傳輸方式

| 你需要                            | 由呢度開始                               | 成功時嘅 result                                                   |
| --------------------------------- | ---------------------------------------- | ----------------------------------------------------------------- |
| Request + 按 status 分嘅 response | [HTTP](/zh-Hant-HK/docs/http)            | Decoded data + `DecodedResponse`（冇聲明 output 時係 `HttpMeta`） |
| 長駐嘅 server event feed          | [SSE](/zh-Hant-HK/docs/sse)              | 一條 stream + startup `open` snapshot                             |
| Bidirectional session             | [WebSocket](/zh-Hant-HK/docs/web-socket) | 一個 session + startup `connection` snapshot                      |

三種傳輸都係同一條次序：先定義操作，再用應用程式嘅 client 同呼叫方嘅 input 去呼叫。

## 揀 package

| Package                       | 幾時用                                                                                                          |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `@defjs/core`                 | 定義 SDK 操作同契約；建立 client，並呼叫 HTTP、SSE 同 WebSocket 操作                                            |
| `@defjs/react`                | `ClientProvider` / `useClient` — 睇 [React](/zh-Hant-HK/docs/integrations/react)                                |
| `@defjs/vue`                  | Plugin + `injectClient` — 睇 [Vue](/zh-Hant-HK/docs/integrations/vue)                                           |
| `@defjs/opentelemetry-server` | Outbound spans、metrics 同 logs — 睇 [OpenTelemetry Server](/zh-Hant-HK/docs/integrations/opentelemetry-server) |

## Result 形狀

三種傳輸都 return error-first 三項 tuple。位置一樣；意思唔一樣：

- HTTP → `[error, data, response]`
- SSE → `[error, stream, open]`
- WebSocket → `[error, session, connection]`

失敗時第二項係 `undefined`。HTTP 嘅第三項亦係 `undefined`，因為 fault 已經帶住 response metadata。SSE 同 WebSocket 嘅第三項，係失敗之前已經 capture 到嘅 startup snapshot（如果有）。詳情睇 [Errors](/zh-Hant-HK/docs/errors)。

## Ownership 一句講晒

HTTP stale 就 abort。SSE close 完之後 `await stream.closed`。WebSocket close 完之後 `await session.closed`。喺 server 上面，如果 options 會 capture cookies、auth 或 tenant data，就喺 request boundary 入面 create client。Log 之前先 redact URLs、headers 同 bodies。

Defjs 提供定義、驗證同執行。應用程式自己揀快取同重試策略；串流重連係 opt-in。而家支援手寫 SDK 套件。CLI tooling 同 OpenAPI/SDK generation 仍然係計劃中。
