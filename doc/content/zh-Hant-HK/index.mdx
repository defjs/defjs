# Defjs

**定義一次 API 契約。按應用程式設定執行環境。**

Defjs 將 TypeScript SDK 拆開做兩邊：

- **SDK 定義 (`@defjs/core`)** — SDK 作者用 `struct` schema 宣告帶型別嘅 HTTP、SSE 同 WebSocket 操作。定義純粹係資料：淨係 import 佢唔會發起任何網絡請求，亦唔會綁死全域 client。
- **應用程式執行** — 使用方應用程式建立自己嘅 `Client`（`createClient(withEndpoint(...))`），掛上憑證、中介層（interceptor）同負載平衡器，然後喺呼叫操作嗰陣將個 client 傳入去。

## 點解要將定義同 Client 分開？

| 職責     | SDK 作者（定義）                                                                                 | 應用程式（執行）                                                |
| -------- | ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| **擁有** | Method、路徑模板、`input` / `output` / `error` schema、`builder` 映射，以及靜態 `operation` 名稱 | Base URL、憑證、認證中介層、負載平衡、逾時設定同資源釋放        |
| **發佈** | 可重用嘅 ESM 模組同 `.d.ts` 宣告                                                                 | 瀏覽器、伺服器或測試環境嘅 runtime 設定                         |
| **好處** | 完全零環境耦合；無論喺瀏覽器、SSR 定係測試環境都通用                                             | 完全掌控重試、故障轉移（failover）、遙測（telemetry）同生命週期 |

## 支援嘅傳輸協議與回傳 Tuple

每個操作都會回傳一個三項式 error-first tuple，切合相應傳輸嘅生命週期：

| 傳輸協議                                     | 入口函式            | Tuple 形狀                     | 生命週期擁有權                                                            |
| -------------------------------------------- | ------------------- | ------------------------------ | ------------------------------------------------------------------------- |
| **[HTTP](/zh-Hant-HK/docs/http)**            | `defineRequest`     | `[error, data, response]`      | 透過 `client({ signal })` 取消進行中嘅請求                                |
| **[SSE](/zh-Hant-HK/docs/sse)**              | `defineEventStream` | `[error, stream, open]`        | 透過 `await using` 或 `stream.close()` + `await stream.closed` 釋放資源   |
| **[WebSocket](/zh-Hant-HK/docs/web-socket)** | `defineWebSocket`   | `[error, session, connection]` | 透過 `await using` 或 `session.close()` + `await session.closed` 釋放資源 |

喺 HTTP 失敗嗰陣，tuple 會係 `[error, undefined, undefined]`，因為 `error` 本身已經包含咗 `HttpMeta` 回應元數據。至於 SSE 同 WebSocket，只要喺失敗前已經捕獲到啟動 snapshot，第三個位就會保留佢。
