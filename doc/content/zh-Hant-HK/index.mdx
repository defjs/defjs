# Defjs

**TypeScript SDK 與高韌性 Client 工具組 — 寫一次 API 契約定義，按每個應用程式分別配置執行細節。**

Defjs 將 TypeScript SDK 嘅兩面清楚拆開：

- **SDK 定義 (`@defjs/core`, `@defjs/cli`)** — 宣告帶型別嘅 HTTP、SSE 同 WebSocket 操作，並配合其 `struct` schema（可以手寫，亦可以由 OpenAPI 2.0/3.0/3.1/3.2 規格生成無狀態 ESM）。定義純粹係資料：只 import 佢唔會發起網絡呼叫，亦唔會綁死全域 client。
- **高韌性應用程式執行 (`@defjs/core`)** — 應用程式建立自己嘅 `Client`（`createClient(withEndpoint(...))`），掛上憑證同攔截器（`basicAuth*`、`idempotencyKeyHttpInterceptor`、`concurrencyLimitHttpInterceptor`），配置 P2C 負載平衡與 `outlierDetection`（`halfOpen`、`maxEjectionPercent`），啟用 `429`/`Retry-After` 重試，透過 `@defjs/core/concurrent` 扇出並行呼叫，或者用 `@defjs/core/port` 橋接 worker 同瀏覽器擴充功能。

## 點解要將定義同 Client 分開？

| 職責     | SDK 作者（定義）                                                                             | 應用程式（執行）                                                |
| -------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **擁有** | Method、路徑模板、`input` / `output` / `error` schema、`builder` 映射，以及可選嘅自訂 `meta` | Base URL、憑證、認證攔截器、負載平衡、逾時設定同資源釋放        |
| **交付** | 可重用嘅 ESM 模組同 `.d.ts` 宣告                                                             | 瀏覽器、伺服器或測試環境嘅 runtime 設定                         |
| **好處** | 零環境耦合；喺瀏覽器、SSR 同測試之間通用                                                     | 完全掌控重試、故障轉移（failover）、遙測（telemetry）同生命週期 |

## 支援嘅傳輸層與結果 tuple

每個操作都會回傳一個三項式 error-first tuple，配合相應傳輸層嘅生命週期：

| 傳輸層                                       | 入口函式            | Tuple 形狀                   | 生命週期擁有權                                                            |
| -------------------------------------------- | ------------------- | ---------------------------- | ------------------------------------------------------------------------- |
| **[HTTP](/zh-Hant-HK/docs/http)**            | `defineRequest`     | `[err, data, response]`      | 透過 `client({ signal })` 取消進行中嘅請求                                |
| **[SSE](/zh-Hant-HK/docs/sse)**              | `defineEventStream` | `[err, stream, open]`        | 透過 `await using` 或 `stream.close()` + `await stream.closed` 釋放資源   |
| **[WebSocket](/zh-Hant-HK/docs/web-socket)** | `defineWebSocket`   | `[err, session, connection]` | 透過 `await using` 或 `session.close()` + `await session.closed` 釋放資源 |

喺 HTTP 失敗嗰陣，tuple 會係 `[err, undefined, undefined]`，因為 `err` 本身已經包含咗任何 `HttpMeta` 回應元數據。至於 SSE 同 WebSocket，只要喺失敗前已經捕獲到啟動 snapshot，第三個位就會保留佢。
