# Defjs

**寫一次 API 契約定義，執行細節按每個應用程式自己設定。**

無論你係要發佈獨立嘅 npm SDK，定係想將項目內部前後端介面層整理得好啲，Defjs 都將兩邊職責清楚拆開：

- **介面契約定義 (`@defjs/core`)** — 用 `defineRequest`、`defineEventStream` 同 `defineWebSocket` 宣告帶型別嘅 HTTP、SSE 同 WebSocket 操作，配合 `struct` 定義資料結構。定義純粹係資料：只 import 佢唔會發起網絡請求，亦唔會綁死全域 client。
- **應用程式執行** — 業務應用程式建立自己嘅 `Client`（`createClient(withEndpoint(...))`），掛上憑證同攔截器、配置負載平衡，然後喺呼叫操作嗰陣傳入該 client。

## 點解要將定義同 Client 分開？

| 職責     | 介面定義（專案 `src/api/` 或公開 SDK）                                                       | 應用程式（執行時期）                                            |
| -------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **擁有** | Method、路徑模板、`input` / `output` / `error` schema、`builder` 映射，以及可選嘅自訂 `meta` | Base URL、憑證、認證攔截器、負載平衡、逾時設定同資源釋放        |
| **交付** | 可重用嘅 ESM 模組同 `.d.ts` 宣告                                                             | 瀏覽器、伺服器或測試環境嘅 runtime 設定                         |
| **好處** | 完全零環境耦合；同一份定義唔使改寫就喺瀏覽器、SSR 同本機測試通用                             | 完全掌控重試、故障轉移（failover）、遙測（telemetry）同生命週期 |

## 支援嘅傳輸層與結果 tuple

每個操作都會回傳一個三項式 error-first tuple，配合相應傳輸嘅生命週期：

| 傳輸層                                       | 入口函式            | tuple 形狀                   | 點樣取消或釋放資源                                                        |
| -------------------------------------------- | ------------------- | ---------------------------- | ------------------------------------------------------------------------- |
| **[HTTP](/zh-Hant-HK/docs/http)**            | `defineRequest`     | `[err, data, response]`      | 透過 `client({ signal })` 取消進行中嘅請求                                |
| **[SSE](/zh-Hant-HK/docs/sse)**              | `defineEventStream` | `[err, stream, open]`        | 透過 `await using` 或 `stream.close()` + `await stream.closed` 釋放資源   |
| **[WebSocket](/zh-Hant-HK/docs/web-socket)** | `defineWebSocket`   | `[err, session, connection]` | 透過 `await using` 或 `session.close()` + `await session.closed` 釋放資源 |

喺 HTTP 失敗嗰陣，tuple 會係 `[err, undefined, undefined]`，因為 `err` 本身已經包含咗 `HttpMeta` 回應元數據。至於 SSE 同 WebSocket，只要喺失敗前已經捕獲到啟動 snapshot，第三個位就會保留佢。
