# SSE

Declare 一條 event stream，execute 佢，iterate events，之後 close。

## defineEventStream()

```ts
function defineEventStream(definition: EventStreamDefinition): EventStreamEndpoint
```

- **definition** — `path`、`events` map，以及必填、為正整數嘅上限 `maxBufferSize` 同 `maxQueueSize`；可選 `method`（default `'GET'`）、`operation`、`input` 同 `error`。只要聲明咗 `input`，就必須明確提供 `builder`，即使 input 已經係 request shape 都一樣。只有冇 `input` 嘅定義先可以省略 `builder`。
- **Returns** 一個 endpoint。用 input call 佢，就會得到 `EventStreamCommand`。

## executeEventStreamCommand()

```ts
function executeEventStreamCommand(
  clientConfig: ClientConfig,
  command: EventStreamCommand,
  options?: EventStreamExecuteOptions,
): Promise<StreamAwaitResult>
```

`client.execute` 嘅 low-level entry。Application code prefer 用 client。

- **Returns** `[null, stream, open]` 或者 `[error, undefined, open?]`。聲明過 `error` 嘅時候，fault 係嗰個 struct 嘅 `Fault`；否則就係 `Fault<undefined>`。

## 執行 options

## EventStreamExecuteOptions

```ts
type EventStreamExecuteOptions = ({ abort?: AbortSignal; timeout?: never } | { abort?: never; timeout?: number }) & {
  signal?: AbortSignal
}
```

Cancellation 規則同 HTTP 一樣：`abort` 或者 `timeout`，唔可以兩個一齊（type 會拒絕兩者並存，runtime 時兩者都傳會以 `REQ_OPTIONS_INVALID` 失敗）；`signal` 可以同其中一個合併使用。`timeout` 係啟動 deadline：涵蓋 input 解析、builder、interceptors 同 handshake，唔會 abort 已經開啟嘅 stream。`withTimeout` 唔適用於 SSE。

## EventStreamHandle

```ts
interface EventStreamHandle<TEvent> extends AsyncIterable<TEvent>, AsyncDisposable {
  readonly open: EventStreamOpenInfo
  readonly closed: Promise<EventStreamCloseInfo>
  close(reason?: unknown): void
  [Symbol.asyncDispose](): PromiseLike<void>
}
```

Tuple 第三項係 `open` 嘅 startup snapshot；reconnect 之後，`stream.open` 會跟住最新嘅連線。自己 own 嘅 scope 優先用 `await using stream = handle` cleanup。Disposer 會停低 Defjs 嘅 read 同 reconnect work，再等 reader lock release；但唔保證由 provider 控制兼卡死咗嘅 `ReadableStream.cancel()` promise 一定完成。Manual `close()` / `closed` 仍然用得。

```ts
async function consume(handle: EventStreamHandle<unknown>): Promise<void> {
  await using stream = handle
  for await (const event of stream) console.log(event)
}
```

自己 structural implement `EventStreamHandle` 嘅 code，而家必須 implement `[Symbol.asyncDispose]()`，並 return 同一條 owned teardown path。對 custom handle implementer 嚟講係 compile-time breaking change；淨係接收 Defjs handle 嘅 code 唔使加新 runtime call。

### EventStreamOpenInfo

```ts
interface EventStreamOpenInfo {
  response: HttpResponse<unknown>
  url: string
}
```

### EventStreamCloseInfo

```ts
type EventStreamCloseInfo =
  | { kind: 'eof'; reason?: string; cause?: unknown }
  | { kind: 'aborted'; reason?: string; cause?: unknown }
  | { kind: 'error'; code: EventStreamFaultCode; reason?: string; cause?: unknown }
```

`EventStreamFaultCode`：`'CAP_BUFFER_EXCEEDED' | 'CAP_QUEUE_OVERFLOW' | 'EXT_HOOK_FAILED' | 'EXT_OBSERVER_FAILED' | 'NET_TIMEOUT' | 'NET_UNREACHABLE' | 'RES_DECODE_FAILED' | 'RES_MEDIA_TYPE_INVALID'`。

## 事件 map

## EventStructs

```ts
type EventStructs = { [eventName: string]: AnyStruct }
```

Key 係 SSE event 名稱；冇 `event:` 欄位嘅訊息名為 `message`。冇 key 配得上嗰陣，就用 `default` struct。`string` event struct 會保留 raw `data` text。其他 kind 都係 JSON text：先 `JSON.parse`，再過 struct。所以 bare `struct.literal` 要 JSON text，唔係冇引號嘅 token。Handshake `error` bodies 用同 HTTP 一樣嘅 kind rule：`string` 係 text，`blob` / `file` 係 blobs，`arrayBuffer` 係 bytes，其他就係 JSON。

Reconnect 住喺 client（`withSSEReconnect`）。SSE `jitter` 係 **0–1 multiplicative factor**，同 WebSocket 一樣。

睇 [SSE guide](/zh-Hant-HK/docs/sse) 同 [Consume an SSE stream](/zh-Hant-HK/recipes/consume-sse)。

## EventStreamDefinition

`path`、`events`、必填嘅 `maxBufferSize` 同 `maxQueueSize`，可選 `method` / `operation` / `input` / `error`。Request shape 同 HTTP 一樣，包括 `body`。`GET` 同 `HEAD` 唔可以 return body。只要聲明咗 `input`，就必須明確提供 `builder`，即使 input 已經係 request shape 都一樣。只有冇 `input` 嘅定義先可以省略 `builder`。

## EventStreamEndpoint

`defineEventStream` 嘅回傳。用 input call 一次就攞到 `EventStreamCommand`。

## EventStreamRequestShape

Fields 同條 stream 嘅 method 同 path 對應嘅 `HttpRequestShape` 一樣。

## EventStreamCommand

Opaque SSE command。交畀 `client.execute`。

## StreamAwaitResult

`[null, stream, open]` 或者 `[error, undefined, open?]`。

## EventStreamData

由 `EventStructs` map infer 出嚟、parse 完嘅 event payload。
