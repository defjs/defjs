# API 參考

<ApiIndex />

建置或使用 Defjs SDK 時可以查閱呢份參考。SDK 作者會由 [`defineRequest`](/zh-Hant-HK/api/core/definerequest)、[`defineEventStream`](/zh-Hant-HK/api/core/defineeventstream)、[`defineWebSocket`](/zh-Hant-HK/api/core/definewebsocket) 同 [Structs](/zh-Hant-HK/api/struct) 開始；應用程式則用 [Client 設定](/zh-Hant-HK/api/client) 呼叫呢啲操作，並用 [Errors](/zh-Hant-HK/api/errors) 處理結果。

簽章即係契約。完整工作流程請參閱[快速開始](/zh-Hant-HK/docs/start)同[SDK 發佈指南](/zh-Hant-HK/recipes/publish-http-sdk)。
