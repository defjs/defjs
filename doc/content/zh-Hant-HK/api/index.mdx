# API 參考

按職責選擇入口：SDK 作者使用 [`defineRequest`](/zh-Hant-HK/api/core/definerequest)、[`defineEventStream`](/zh-Hant-HK/api/core/defineeventstream)、[`defineWebSocket`](/zh-Hant-HK/api/core/definewebsocket) 同 [Structs](/zh-Hant-HK/api/struct) 定義並匯出契約；應用程式用 [Client 設定](/zh-Hant-HK/api/client) 呼叫呢啲操作，再用 [Errors](/zh-Hant-HK/api/errors) 處理結果。

以下簽章描述 Defjs 嘅執行時契約。完整開發流程見[快速開始](/zh-Hant-HK/docs/start)同[建置並發佈 SDK](/zh-Hant-HK/recipes/publish-http-sdk)。
