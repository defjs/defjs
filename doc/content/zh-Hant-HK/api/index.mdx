# API 參考

按職責選擇入口：SDK 作者使用 `defineRequest`、`defineEventStream`、`defineWebSocket` 及 `struct.*` 定義並匯出契約；應用程式使用 `createClient`、`with*` 設定及 `client.execute(...)` 執行這些定義建立的 command。

以下簽章描述 Defjs 的執行時契約。完整開發流程見[快速開始](/zh-Hant-HK/docs/start)及[建置並發佈 SDK](/zh-Hant-HK/recipes/publish-http-sdk)。
