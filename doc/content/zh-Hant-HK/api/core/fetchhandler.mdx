```ts
function fetchHandler(httpRequest: HttpRequest, fetchImpl?: FetchHandle): Promise<HttpResponse<unknown>>
```

- **httpRequest** — 正規化咗嘅 request（URL、headers、body、abort signal、progress hooks）。
- **fetchImpl** — [`FetchHandle`](/zh-Hant-HK/api/core/fetchhandle-type)；預設係 global `fetch`。自訂 handle 會收到 `Request`，而且 body 係逐 chunk 讀取。

Default HTTP transport。Client 一定會用佢；`withHTTPHandle` 只係取代佢 call 嘅 `fetchImpl`。當冇任何 response 去到 client 時，佢會 reject，而唔係 resolve 一個合成 response。
