<ApiReference identity="@defjs/core:FaultOf" />

```ts
type FaultOf<TData = undefined> = DecodeFault | HttpStatusFaultOf<TData> | PreflightFault
```

`TData` 係解碼後嘅 `error` body，冇聲明 error struct 時係 `undefined`。`Fault<TErr>` 係將 `FaultOf` 套用喺 `Infer<TErr>` 上，而 `HttpAwaitResult` 用 `FaultOf<TErrorData>`。傳入嘅要係解碼後嘅 type，唔係 struct：寫 `FaultOf<Infer<typeof errorStruct>>`，或者用 `Fault<typeof errorStruct>`。
