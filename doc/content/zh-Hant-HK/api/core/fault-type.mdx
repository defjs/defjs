<ApiReference identity="@defjs/core:Fault" />

```ts
type Fault<TErr extends AnyStruct | undefined = undefined> = FaultOf<[TErr] extends [undefined] ? undefined : Infer<TErr>>
```

`TErr` 係 endpoint 聲明嘅 `error` struct，冇聲明就係 `undefined`。`Fault<TErr>` 係將 [`FaultOf`](/zh-Hant-HK/api/core/faultof-type) 套用喺解碼後嘅 body type 上，所以佢係三個變體嘅 union：[`DecodeFault`](/zh-Hant-HK/api/core/decodefault-type)、[`HttpStatusFault<TErr>`](/zh-Hant-HK/api/core/httpstatusfault-type) 同 [`PreflightFault`](/zh-Hant-HK/api/core/preflightfault-type)。對 `fault.code` 做 switch。

每個變體都係名為 `DefjsFault` 嘅原生 `Error`，所以 `String(fault)` 直接俾出可以寫 log 嘅 `DefjsFault: <message>`。`code` 同各變體 metadata——`status`、`response`、`data`——都係可枚舉嘅自有屬性。原生 `cause` chain 唔可枚舉。
