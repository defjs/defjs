---

<ApiReference identity="@defjs/core:WebSocketInterceptor" />

```ts
interface WebSocketInterceptor {
  kind: 'web-socket'
  fn: WebSocketInterceptorFn
}
```

由 `createWebSocketInterceptor(fn)` 建立。`kind` tag 令 `withInterceptors` 可以喺同一個 list 入面接受 HTTP、SSE 同 WebSocket interceptors；執行 WebSocket commands 時，只有 `kind: 'web-socket'` 嘅 interceptors 會運行。
