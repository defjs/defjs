<ApiReference identity="@defjs/core:HttpProgressFn" />

```ts
type HttpProgressFn = (event: HttpProgressEvent) => Promise<void> | void
```

喺 `HttpExecuteOptions` 入面作為 `onDownloadProgress` 或 `onUploadProgress` 傳入。Callbacks 可以係 async，而且會喺處理下一個 chunk 之前被 await。如果 callback 拋出錯誤或者 reject，call 就會以 `EXT_OBSERVER_FAILED` 失敗，拋出嘅值會成為 `cause`，download 同 upload 都一樣。Caller 取消操作同 `timeout` 仍然優先，分別會報 `NET_ABORTED` 同 `NET_TIMEOUT`。只有 runtime 支援以 stream 方式送出 request body，先會回報 upload progress（Bun、Node、Deno）。喺 browser，`Blob` / `File`、`ArrayBuffer` 或者 `FormData` body 會原樣送出，而且唔會 call `onUploadProgress`；`onDownloadProgress` 唔受影響。
