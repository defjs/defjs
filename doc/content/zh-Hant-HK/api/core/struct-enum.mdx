---
title: 'struct.enum'
description: '接受字串 list 其中一個值，或者 object 其中一個 value 嘅 struct。'
---

<ApiReference identity="@defjs/core:struct.enum" />

```ts
function enum<const T extends readonly [string, ...string[]]>(value: T): Struct<T[number], T[number]>
function enum<const T extends { [key: string]: number | string }>(value: T): Struct<T[keyof T], T[keyof T]>
```

- 傳入非空字串 array 嗰陣，接受嘅值就係 array 入面嘅項目。
- 傳入 object 嗰陣，接受嘅值係 object 嘅字串同數字 **value**，唔係 key。`{ A: 'a', B: 2 }` 接受 `'a'` 同 `2`。
- TypeScript 數字 `enum` object 亦接受佢嘅成員名稱，因為反向映射本身就屬於佢嘅 values。
- 集合以外嘅值會以 `invalid_enum` 失敗。如果 object 冇任何字串或者數字 value，建立 struct 嗰陣會 throw `TypeError`。
