```ts
function createNetworkFault(cause: unknown, response?: HttpMeta): PreflightFault
```

- **cause** — 底層嘅 cancellation、timeout 或 transport 失敗。
- **response** — Metadata，只在 transport 已經有 metadata 可以報告時先有。提供時會附加喺 fault 上。
- **Returns** 一個 `PreflightFault`，code 視乎 `cause`：
  - `ERR_ABORTED` 或者名為 `AbortError` 嘅 `DOMException` 對應 `NET_ABORTED`，message 係 `Request was aborted`。
  - `ERR_TIMEOUT` 或者名為 `TimeoutError` 嘅 error 對應 `NET_TIMEOUT`，message 係 cause 嘅 message，如果為空就係 `Request timed out`。
  - 其他一律係 `NET_UNREACHABLE`，message 用 cause 嘅 message。

Cause 會保留為 `cause`。
