<ApiReference identity="@defjs/core:UseRequestConfig" />

```ts
type UseRequestConfig = {
  onDownloadProgress?: HttpProgressFn
  onUploadProgress?: HttpProgressFn
} & ({ abort?: AbortSignal; timeout?: never } | { abort?: never; timeout?: number })
```

[`HttpExecuteOptions`](/zh-Hant-HK/api/core/httpexecuteoptions-type) 之中屬於 HTTP 專用嘅部分，`HttpExecuteOptions` 另外再加 `signal`。

- `onDownloadProgress` 同 `onUploadProgress` 係 [`HttpProgressFn`](/zh-Hant-HK/api/core/httpprogressfn-type) callbacks，會收到帶有 `loaded`、`total` 同 `lengthComputable` 嘅 [`HttpProgressEvent`](/zh-Hant-HK/api/core/httpprogressevent-type)。
- 取消方式係 `abort` 或者 `timeout` 二揀一，唔可以同時用。Type 會拒絕兩者並存；runtime 時如果兩者都傳，會失敗並返回 `REQ_OPTIONS_INVALID` fault。
- `timeout` 必須係正安全整數，而且唔可以大過 `2_147_483_647`。佢會喺該次 call 取代 [`withTimeout`](/zh-Hant-HK/api/core/withtimeout) 設定嘅預設值；`abort` 就會同嗰個預設值合併。
