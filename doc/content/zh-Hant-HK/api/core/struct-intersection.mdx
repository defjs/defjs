<ApiReference identity="@defjs/core:struct.intersection" />

```ts
function intersection<const T extends readonly [StructLike, ...StructLike[]]>(
  ...structs: T
): T extends readonly [unknown]
  ? T[0]
  : T extends readonly [unknown, unknown, ...unknown[]]
    ? IntersectionStruct<T>
    : T[0] | IntersectionStruct<T>
```

`struct.intersection` 係 variadic：每個 struct 都作為獨立參數傳入。

- 用每個 struct 解析 input，再合併結果。
- 當所有 struct 都係 object struct，輸出係一個包含所有欄位嘅 object。冇任何 struct 聲明過嘅 keys 會被剔走。
- 當兩個 struct 對同一個 key 產出不相容嘅值，就會以 `invalid_intersection` 失敗。
- 只有每個 struct 都接受 `null` 時先會接受 `null`，包括標記咗 `.null()` 嘅巢狀交集。
- 只傳一個 struct 會原樣回傳，所以會保留佢本身嘅型別，包括 `.optional()` 同 `.null()`。唔傳任何 struct 會 throw `TypeError`，傳入非 struct 參數亦一樣。
- 展開可能只有一個成員嘅 tuple 時，會同時推導單成員同多成員兩種結果。因此，結果入面嘅 object 欄位可能係可選嘅。已知至少有兩個成員嘅 tuple 仍然保留交集型別對必需欄位嘅要求。

`IntersectionStruct<T>` 冇 export。佢係一個 `Struct`，input 同 output 都係各成員 type 嘅交集。
