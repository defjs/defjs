<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

`true` 嘅時候，HTTP 同 SSE requests 嘅 Fetch 會用 `credentials: 'include'`，所以跨來源 requests 都會帶上 cookies 同其他 credentials。`false` 或者從未設定嘅時候，`credentials` 保持未設定，Fetch 使用佢自己嘅預設值。

WebSocket constructor 唔會收到呢個設定。
