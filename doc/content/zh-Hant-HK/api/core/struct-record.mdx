<ApiReference identity="@defjs/core:struct.record" />

```ts
function record<S extends StructLike<unknown, unknown, boolean>>(value: S): RecordStruct<S>
```

- 用 `value` 解析 plain object 嘅每個 own key。其他任何嘢都會以 `invalid_type`（預期 `record`）失敗。
- 解析喺第一個失敗嘅 value 停低，`issue.path` 載有佢嘅 key。
- 輸出係一個 prototype 為 `null` 嘅新 object。
- 如果 `value` 唔係 struct，會 throw `TypeError`。

`RecordStruct<S>` 冇 export。佢係 `Struct<{ [key: string]: StructInput<S> }, { [key: string]: Output }>`，其中 `Output` 係冇 `undefined` 嘅 `Infer<S>`。`S` 係 optional struct 嘅時候，value 係 `undefined` 嘅 key 會喺輸出入面被省略。
