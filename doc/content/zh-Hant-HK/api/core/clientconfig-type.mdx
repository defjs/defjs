<ApiReference identity="@defjs/core:ClientConfig" />

```ts
interface ClientConfig {
  endpoint: string
  headers?: Headers
  http: { handle: FetchHandle }
  interceptors: Interceptor[]
  querySerializer?: QuerySerializer
  timeout?: number
  withCredentials?: boolean
  xsrf?: {
    cookieName: string
    headerName: string
    tokenProvider?: (context: { request: HttpRequest }) => string | null | undefined
  }
  sse: ClientSSEConfig
  webSocket: ClientWebSocketOptions
}
```

`createClient` 建立、而每個 option helper 都會修改嘅 resolved snapshot。HTTP 相關 member 來自一個冇 export 嘅 `HttpClientConfig` base，上面直接寫出嚟。

套用任何 option 之前，`endpoint` 係 `''`，`interceptors` 係空，`http.handle` 同 `sse.handle` 係 global `fetch`。`webSocket.handle` 係 `globalThis.WebSocket`，其他 `webSocket` 設定未設定。`withXSRF` 會喺 `xsrf.cookieName` 同 `xsrf.headerName` 被省略時，分別填入 `XSRF-TOKEN` 同 `X-XSRF-TOKEN`。
