<ApiReference identity="@defjs/core:struct.or" />

```ts
function or<const T extends readonly [StructLike, ...StructLike[]]>(...options: T): UnionStruct<T>
```

`struct.or` 係 variadic：每個 option 都作為獨立參數傳入。

- 按次序逐個嘗試 option，並回傳第一個解析成功嘅結果。
- 如果全部都唔符合，會喺 union 自己嘅 path 報一個 `invalid_union` issue。個別 option 嘅 issues 唔會報告。
- 如果某個 option 唔係 struct，會 throw `TypeError`。

`UnionStruct<T>` 冇 export。佢係一個 `Struct`，input 同 output 都係各 option type 嘅聯合（唔包括 `undefined`）。如果係帶 tag 嘅 object，優先用 [`struct.discriminatedUnion()`](/zh-Hant-HK/api/core/struct-discriminatedunion)，佢會報告被揀中 option 嘅 issue。
