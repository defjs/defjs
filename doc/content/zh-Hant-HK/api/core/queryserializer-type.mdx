title: 'QuerySerializer'
description: '將已編碼嘅 query object 序列化成 query string 嘅函數。'
---

<ApiReference identity="@defjs/core:QuerySerializer" />

```ts
type QuerySerializer = (query: { [key: string]: unknown }) => string
```

`query` 係線上 object：aliases 已經套用，`Date` 值已經係 ISO 字串，`bigint` 值已經係字串。巢狀 object 同 array 會原樣保留。回傳嘅 query string 唔好帶開頭嘅 `?`；佢會原封不動咁使用，唔會再經 `URLSearchParams`。Interceptors 見到嘅 `queryParams` 係 `new URLSearchParams(queryString)`。

用 `withQuerySerializer` 設定。冇設定嘅話，query 會用 `URLSearchParams`：array 會重複 key，巢狀 object 會失敗。如果 builder 回傳 `URLSearchParams`，就會跳過 serializer。
