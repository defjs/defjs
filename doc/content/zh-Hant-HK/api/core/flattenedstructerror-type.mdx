<ApiReference identity="@defjs/core:FlattenedStructError" />

```ts
interface FlattenedStructError {
  formErrors: string[]
  fieldErrors: { [key: string]: string[] }
}
```

`StructError.flatten()` 嘅結果。`formErrors` 放 path 為空（root 層級）嘅 issue 嘅 messages。`fieldErrors` 按 path 第一段做 key 放 messages，所以巢狀 issue 會歸入佢哋嘅頂層 field。
