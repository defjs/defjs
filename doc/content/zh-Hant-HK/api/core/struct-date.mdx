---

<ApiReference identity="@defjs/core:struct.date" />

```ts
function date(): Struct<Date | number | string, Date>
```

- 接受 `Date`、毫秒 timestamp 或者字串，並用 `new Date(value)` 轉換。
- 輸出係 `Date`。如果轉出嚟係無效日期，就會以 `invalid_type` 失敗。
- 編碼上線嗰陣，個值會變成 ISO 8601 字串（`toISOString()`）。
