<ApiReference identity="@defjs/core:SSEHandler" />

```ts
type SSEHandler = (req: HttpRequest) => Promise<EventStreamHandle<unknown>>
```

SSE interceptor 收到嘅 `next` 函數。`next(req)` 只會向內走：先經過喺呢個 interceptor 之後註冊嘅 interceptors，再去到開啟 stream 嘅 transport。Chain settle 之後先呼叫佢會 reject。

`EventStreamHandle` extend 咗 `AsyncDisposable`。自行 build handle 嘅 short-circuit 實作必須 provide `[Symbol.asyncDispose](): PromiseLike<void>`，再接去同一條 close lifecycle。
