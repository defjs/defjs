<ApiReference identity="@defjs/core:struct.urlencoded" />

```ts
function urlencoded<T extends ObjectShape>(shape: T): ObjectStruct<T>
```

解析方式同 [`struct.object()`](/zh-Hant-HK/api/core/struct-object) 一樣，另外帶有 `urlencoded` codec tag。

- Tag 只會喺呢個 struct 嘅值係 request body root 嗰陣先生效。Body 之後會以 `URLSearchParams` 同 `application/x-www-form-urlencoded;charset=UTF-8` 送出。
- Array 會重複欄位名，`undefined` 欄位會被略過。巢狀 object 或者 `Blob` 會令 request 以 `REQ_BUILD_FAILED` 失敗。
- `struct.parse` 會忽略個 tag。佢唔接受 `URLSearchParams` instance，只接受 plain object。
