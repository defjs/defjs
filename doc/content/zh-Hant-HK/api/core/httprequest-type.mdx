```ts
interface HttpRequest {
  abort?: AbortSignal
  baseEndpoint?: string
  body?: Blob | ArrayBuffer | FormData | URLSearchParams | ReadableStream<Uint8Array> | object | string | number | boolean | null
  bodyContentType?: string | null
  downloadProgress?: HttpProgressFn
  endpoint: string
  headers?: Headers
  method: string
  operation?: string
  queryParams?: URLSearchParams
  queryString?: string
  readonly responseType?: HttpResponseType
  readonly errorResponseType?: HttpResponseType
  timeout?: number
  uploadProgress?: HttpProgressFn
  withCredentials?: boolean
  xsrf?: {
    cookieName: string
    headerName: string
    tokenProvider?: (context: { request: HttpRequest }) => string | null | undefined
  }
  // plus the @internal bodyContentTypeSource field
}
```

Builder 執行完之後嘅 request，由 handlers、interceptors 同 `fetchHandler` 使用。

- `body` 已經係 wire value。JSON 嘅話佢係 **JSON text string**；HMAC 或 digest 要對呢個 string 簽，唔好對原本嘅 struct input。
- `bodyContentType` 以普通 field 保存 builder body 推斷出嚟嘅類型，所以 `{ ...req }` 複本仍然保留。佢只喺 `body` 仍然係 builder 嘅值時生效；替換後嘅 body 會重新偵測，所以要用 `content-type` header 聲明佢嘅類型。對未改動嘅 body，冇明確 header 時，`null` 會抑制 library 嘅推斷，但原生 Fetch 仍然可能為 string 加返佢自己嘅 type。FormData 就會用實際嘅 multipart boundary。
- HTTP 永遠唔會將推斷出嚟嘅 Content-Type 寫入 `headers`；interceptors 只會見到已聲明嘅 headers。明確嘅 `content-type` header 永遠優先於 `bodyContentType` 同自動偵測，無論佢由 builder、client defaults、interceptor，定係原始 `fetchHandler` request 設定。`body: undefined` 冇 library 推斷嘅 Content-Type。簽名方應讀取 `headers.get('content-type') ?? request.bodyContentType`；唔好設定內部欄位。
- `endpoint` 係已填好 path parameters 嘅 path；`baseEndpoint` 係 client endpoint。
- Interceptors 見到嘅 `queryParams` 係 `new URLSearchParams(queryString)`。Builder 如果回傳 `URLSearchParams`，就會原個 instance 傳過去。
- `operation` 係靜態、低 cardinality 嘅 endpoint identity，供 telemetry 同 diagnostics 用。
- `downloadProgress` 同 `uploadProgress` 係 `HttpExecuteOptions` 嘅 `onDownloadProgress` 同 `onUploadProgress` hooks。
- `responseType` 同 `errorResponseType` 係 readonly：佢哋由 endpoint 嘅 `output` 同 `error` struct kind 推導出嚟，唔可以改。只有對應嘅 struct 聲明咗，先會設定。用 `makeResponse` short-circuit 嘅 interceptor 會讀佢哋，以配合 transport。
