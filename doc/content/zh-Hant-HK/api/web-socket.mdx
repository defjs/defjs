# WebSocket

聲明一個 socket，用 client 呼叫操作，傳送／接收 typed messages，之後關閉。

## defineWebSocket()

<ApiSignature name="defineWebSocket" />

- **definition** — `path`、一個 `incoming` struct，以及必填、為正整數嘅 `maxIncomingQueueSize`；可選 `outgoing` 同 `input` structs、`operation`、static `protocols`，以及非負嘅 `maxOutgoingQueueSize`。只要聲明咗 `input`，就必須明確提供 `builder`。`input` 只定義入參，每個值放喺邊度只由 builder 決定。只有冇 `input` 嘅定義先可以省略 `builder`。呢啲 `definition` members 寫喺 [`WebSocketDefinition`](/zh-Hant-HK/api/core/websocketdefinition-type)。`builder` 恰好喺聲明咗 `input` 嗰陣先必填。
- **Returns** 一個操作。第一個參數係 [`Client`](/zh-Hant-HK/api/core/client-type)。之後嘅參數只係 input。呼叫就開啟 session。

<include cwd>examples/api/define-web-socket.ts#example</include>

呼叫 return `[null, session, connection]` 或者 `[error, undefined, connection?]`。逐次呼叫嘅 options 要由 [`RequestOptions`](/zh-Hant-HK/api/core/requestoptions-type) 派生 client 傳入。WebSocket 讀 `signal`、`beforeConnect`、`heartbeat`、`protocols` 同 `reconnect`，並忽略 HTTP progress field。

`beforeConnect`、`heartbeat`、`protocols` 同 `reconnect` 各自喺該次呼叫成個取代 client 嘅值。Protocol 優先次序係派生 client，然後 `withWebSocketProtocols`，最後係 definition 嘅 `protocols`。`heartbeat.timeoutMs` 係等確認嘅時間，唔係請求 deadline。

## WebSocketSession

<ApiSignature name="WebSocketSession" />

自己 own 嘅 scope 優先用 `await using ownedSession = session` cleanup。Manual `session.close()` 同 `await session.closed` 仍然用得。

```ts
async function consume(
  session: WebSocketSession<unknown, never>,
): Promise<void> {
  await using ownedSession = session;
  for await (const message of ownedSession.receive) console.log(message);
}
```

`closed` report 嘅係 logical terminal state。Async disposer 會 request native close，再等 Defjs-owned teardown；但如果一直收唔到 close event，就會 bound 喺一秒，亦可能用名為 `TimeoutError` 嘅 `DOMException` reject。佢證明唔到 physical TCP connection 已經 close。

### WebSocketState

`'idle' | 'connecting' | 'open' | 'closing' | 'closed' | 'reconnecting' | 'aborted' | 'error'`

### WebSocketConnectionInfo

`generation`（reconnect 就會 increment），以及一旦知道就有嘅 `url`、`protocol` 同 `extensions`。

### WebSocketCloseInfo

<ApiSignature name="WebSocketCloseInfo" />

`kind` 係 `closed`、`aborted` 或者 `error`。`cause` 喺 `closed` 上唔存在，喺 `aborted` 上可選，喺 `error` 上必填。`code`、`reason` 同 `wasClean` 可以出現喺每個 variant。手動 `session.close()` 會喺 close event 自己冇呢兩項時，填上 `{ kind: "closed" }` 嘅 `code` 同 `reason`。

## WebSocketExecuteOptions

<ApiSignature name="WebSocketExecuteOptions" />

`WebSocketExecuteOptions` 係 [`UseWebSocketConfig`](/zh-Hant-HK/api/core/usewebsocketconfig-type)：`beforeConnect`、`heartbeat`、`protocols`、`reconnect` 同 `signal`。`WebSocketHeartbeatConfig`：`intervalMs`，可選 `message`、`isAck`、`timeoutMs`。冇 `timeout` 或 `abort` field。

`signal` 覆蓋成個 session，包括 open 之後。Deadline 係 `AbortSignal.timeout(ms)`，分類為 `NET_TIMEOUT`。手動 abort 係 `NET_ABORTED`。冇只限啟動嘅 deadline，亦冇 client 層級嘅預設 deadline。`signal` 係該次呼叫嘅 signal；喺應用程式程式碼用 `AbortSignal.any` 合併 signal。`heartbeat` 成個換走；佢嘅 `timeoutMs` 等確認，唔係請求 deadline。

設定 `reconnect` 時，`attempts` 預設係每次斷線 3 次；`0` 就停用。成功 `open` 會重設預算同退避指數，所以每次新嘅斷線都由第 1 次重試開始。省略 `attempts` 唔代表同一次斷線可以無限重試。預設值同驗證規則請見 [Client](/zh-Hant-HK/api/client)。

## 訊息

`incoming` 係一個 struct。Text、`ArrayBuffer`、typed-array 同 `Blob` frames 會當 UTF-8 讀、`JSON.parse`，再對住個 struct 檢查。JSON parse 或者 struct 失敗嘅 frame 會報去 `session.onRuntimeError`，而且唔會入 queue。冇 client invalid-frame option。

`outgoing` 係一個 struct。`session.send` 接受嗰個 struct 嘅 `StructInput`，encode aliases，然後 `JSON.stringify`。編碼之後，如果 JSON 無法忠實表示某個值，會喺傳送或者加入重連 queue 之前 throw `TypeError`，包括非有限數、functions、symbols、`Map`、`Set`、streams，同冇 JSON 表示方式嘅 class instances。巢狀值會用同 HTTP JSON bodies 一樣嘅檢查。Heartbeat 亦會用呢個檢查；heartbeat 序列化失敗會結束 session。幾種 message kinds 就用 `struct.discriminatedUnion`。

```ts
session.send({ type: "message", text: "Hello" });
```

睇 [WebSocket guide](/zh-Hant-HK/docs/web-socket) 同 [Open a WebSocket session](/zh-Hant-HK/recipes/websocket-session)。

## WebSocketDefinition

`path`、`incoming`、必填嘅 `maxIncomingQueueSize`，可選 `outgoing` / `input` / `operation` / `protocols` / `maxOutgoingQueueSize`。Builder 只可以 return `path` 同 `query`。只要聲明咗 `input`，就必須明確提供 `builder`。`input` 只定義入參，每個值放喺邊度只由 builder 決定。只有冇 `input` 嘅定義先可以省略 `builder`。

## WebSocketEndpoint

`defineWebSocket` 嘅回傳。第一個參數係 client。之後嘅參數只係 input。

## WebSocketRequestShape

只有 `path` 同 `query`。`headers` 同 `body` 係 `never`。

## UseWebSocketConfig

`beforeConnect`、`heartbeat`、`protocols`、`reconnect` 同 `signal`。`WebSocketExecuteOptions` 就係呢一片。冇 `abort` field。

## SocketAwaitResult

`[null, session, connection]` 或者 `[error, undefined, connection?]`。

## ManualSocketCloseReason

用 `session.close()` 閂嗰陣記低嘅 reason。

## WebSocketHeartbeatConfig

`intervalMs`，可選 `message`、`isAck`、`timeoutMs`。

## WebSocketIncomingData

解碼之後嘅 incoming frame：`incoming` struct 嘅 `Infer`。

## WebSocketOutgoingData

`session.send` 接受嘅 value：`outgoing` struct 嘅 `StructInput`；冇聲明就係 `never`。

## SocketLifecycleOutcome

一次連線嘗試嘅結果（`closeInfo`、`connection`、`cause`、`opened`），供 reconnect 邏輯使用。佢唔係 session 嘅最終結果；最終結果請見 `WebSocketCloseInfo`。
