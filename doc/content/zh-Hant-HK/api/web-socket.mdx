# WebSocket

宣告一個 socket，用 client 呼叫操作，傳送同接收帶型別嘅訊息，之後關閉。

## defineWebSocket()

<ApiSignature name="defineWebSocket" />

- **definition** — `path`、一個 `incoming` struct，以及必填、為正整數嘅 `maxIncomingQueueSize`；可選 `outgoing` 同 `input` struct、`operation`、靜態 `protocols`，以及非負嘅 `maxOutgoingQueueSize`。只要宣告咗 `input`，就必須明確提供 `builder`。`input` 只定義參數，每個值放喺邊度只由 builder 決定。只有冇 `input` 嘅定義先可以省略 `builder`。呢啲 `definition` 成員記錄喺 [`WebSocketDefinition`](/zh-Hant-HK/api/core/websocketdefinition-type)。`builder` 只有喺宣告咗 `input` 嗰陣先必填。
- **Returns** 一個操作。第一個參數係 [`Client`](/zh-Hant-HK/api/core/client-type)。之後嘅參數只係 input。呼叫就會開啟 session。

<include cwd>examples/api/define-web-socket.ts#example</include>

呼叫回傳 `[null, session, connection]` 或者 `[error, undefined, connection?]`。逐次呼叫嘅選項要由 [`RequestOptions`](/zh-Hant-HK/api/core/requestoptions-type) 派生 client 傳入。WebSocket 讀 `signal`、`beforeConnect`、`heartbeat`、`protocols` 同 `reconnect`，並忽略 HTTP progress 欄位。

`beforeConnect`、`heartbeat`、`protocols` 同 `reconnect` 各自喺該次呼叫成個取代 client 嘅值。協議優先次序係派生 client，然後 `withWebSocketProtocols`，最後係定義嘅 `protocols`。`heartbeat.timeoutMs` 係等確認嘅時間，唔係請求截止期限。

`closed` 報告嘅係邏輯終止狀態。async disposer 會要求原生關閉，再等 Defjs 擁有嘅 teardown；但如果一直收唔到 close event，就會限制喺一秒之內，亦可能用名為 `TimeoutError` 嘅 `DOMException` reject。佢證明唔到實體 TCP 連線已經關閉。

### WebSocketState

`'idle' | 'connecting' | 'open' | 'closing' | 'closed' | 'reconnecting' | 'aborted' | 'error'`

### WebSocketConnectionInfo

`generation`（每次 open 遞增），以及一旦知道就有嘅 `url`、`protocol` 同 `extensions`。

### WebSocketCloseInfo

<ApiSignature name="WebSocketCloseInfo" />

`kind` 係 `closed`、`aborted` 或者 `error`。`cause` 喺 `closed` 上唔存在，喺 `aborted` 上可選，喺 `error` 上必填。傳入嘅原始 frame 或者已解碼訊息佇列溢出時，`cause.code === "CAP_QUEUE_OVERFLOW"`；同一個 cause 會令 `receive` reject，並傳俾 `onRuntimeError`。心跳逾時同重連次數用盡仍然用一般 runtime `Error` 做 cause，冇獨立而穩定嘅錯誤碼。`code`、`reason` 同 `wasClean` 可以出現喺每個變體。手動 `session.close()` 會喺 close event 冇帶呢兩項時，喺 `{ kind: "closed" }` 上面填上 `code` 同 `reason`。

## WebSocketExecuteOptions

<ApiSignature name="WebSocketExecuteOptions" />

`WebSocketExecuteOptions` 係 [`UseWebSocketConfig`](/zh-Hant-HK/api/core/usewebsocketconfig-type)：`beforeConnect`、`heartbeat`、`protocols`、`reconnect` 同 `signal`。`WebSocketHeartbeatConfig`：`intervalMs`，可選 `message`、`isAck`、`timeoutMs`。冇 `timeout` 或 `abort` 欄位。

`signal` 覆蓋成個 session，包括 open 之後。截止期限係 `AbortSignal.timeout(ms)`，分類為 `NET_TIMEOUT`。手動 abort 係 `NET_ABORTED`。冇只限啟動嘅截止期限，亦冇 client 層級嘅預設截止期限。`signal` 係該次呼叫嘅 signal；喺應用程式程式碼用 `AbortSignal.any` 合併 signal。`heartbeat` 成個換走；佢嘅 `timeoutMs` 等確認，唔係請求截止期限。

builder 同攔截器鏈每次操作只會執行一次。重連會重用已建構嘅 path/query 同擷取嘅 protocols，並喺 `beforeConnect` 之前建構 URL。如果攔截器冇取代 request 嘅 base endpoint，重連亦會代入新揀選嘅端點。呢個 hook 唔可以喺同一個 session 內輪換 URL 或者子協議憑證；請用新嘅 input 或 client 設定開始新操作。

設定 `reconnect` 時，`attempts` 預設係每次斷線 3 次；`0` 就停用。成功 `open` 會重設預算同退避指數，所以每次新嘅斷線都由第 1 次重試開始。省略 `attempts` 唔代表同一次斷線可以無限重試。預設值同驗證規則請見 [Client](/zh-Hant-HK/api/client)。

## 訊息

`incoming` 係一個 struct。文字、`ArrayBuffer`、typed array 同 `Blob` frame 會當 UTF-8 讀取、`JSON.parse`，再對住個 struct 檢查。JSON 解析或者 struct 失敗嘅 frame 會報去 `session.onRuntimeError`，而且唔會入佇列。冇 client 層級嘅 invalid-frame 選項。

`outgoing` 係一個 struct。`session.send` 接受嗰個 struct 嘅 `StructInput`，編碼 alias，然後 `JSON.stringify`。編碼之後，如果 JSON 無法忠實表示某個值，會喺傳送或者加入重連佇列之前 throw `TypeError`，包括非有限數、函式、symbol、`Map`、`Set`、串流，同冇 JSON 表示方式嘅 class 實例。巢狀值會用同 HTTP JSON body 一樣嘅檢查。心跳亦會用呢個檢查；心跳序列化失敗會結束 session。多種訊息種類就用 `struct.discriminatedUnion`。

## WebSocketDefinition

`path`、`incoming`、必填嘅 `maxIncomingQueueSize`，可選 `outgoing` / `input` / `operation` / `protocols` / `maxOutgoingQueueSize`。builder 只可以回傳 `path` 同 `query`。只要宣告咗 `input`，就必須明確提供 `builder`。`input` 只定義參數，每個值放喺邊度只由 builder 決定。只有冇 `input` 嘅定義先可以省略 `builder`。

## WebSocketEndpoint

`defineWebSocket` 嘅回傳。第一個參數係 client。之後嘅參數只係 input。

## WebSocketRequestShape

只有 `path` 同 `query`。`headers` 同 `body` 係 `never`。

## UseWebSocketConfig

`beforeConnect`、`heartbeat`、`protocols`、`reconnect` 同 `signal`。`WebSocketExecuteOptions` 就係呢一部分。冇 `abort` 欄位。

## SocketAwaitResult

`[null, session, connection]` 或者 `[error, undefined, connection?]`。

## ManualSocketCloseReason

用 `session.close()` 關閉嗰陣記錄低嘅 reason。

## WebSocketHeartbeatConfig

`intervalMs`，可選 `message`、`isAck`、`timeoutMs`。

## WebSocketIncomingData

解碼之後嘅 incoming frame：`incoming` struct 嘅 `Infer`。

## WebSocketOutgoingData

`session.send` 接受嘅值：`outgoing` struct 嘅 `StructInput`；冇宣告就係 `never`。

## SocketLifecycleOutcome

一次連線嘗試嘅結果（`closeInfo`、`connection`、`cause`、`opened`），供重連邏輯使用。佢唔係 session 嘅最終結果；最終結果請見 `WebSocketCloseInfo`。
