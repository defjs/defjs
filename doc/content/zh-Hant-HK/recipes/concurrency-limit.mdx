# 並發限制與池化呼叫

喺 `Client` 上面使用 `concurrencyLimitHttpInterceptor` 作為 client 層級隔艙（FIFO 排隊，並支援可選嘅 `maxQueue` 溢出保護），再用 `@defjs/core/concurrent`（`concurrentMap`、`concurrentMapSettled`、`concurrentAll`、`concurrentAllSettled`）進行直接綁定到該 `Client` 嘅快速失敗或全數結算並行呼叫。
