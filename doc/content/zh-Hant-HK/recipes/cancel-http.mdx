# Cancel 一個 HTTP call

將 caller 嘅 signal 同 deadline 合埋放喺 `signal`。`AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` 係一條 signal。手動 abort 分類為 `NET_ABORTED`。Deadline 分類為 `NET_TIMEOUT`。

詳情睇 [HTTP](/zh-Hant-HK/docs/http#cancel-the-work)。

<include cwd meta="cancel-report.ts">
  examples/recipes/cancel-http.ts#example
</include>

```txt
caller cancelled
```

Cancellation 淨係話你 caller 觀察到咩。佢唔證明 server-side write 已經 rollback — mutation retries 要靠 idempotency contract。
