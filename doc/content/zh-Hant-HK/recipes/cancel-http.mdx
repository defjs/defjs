# 取消 HTTP 呼叫

利用 `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` 將呼叫端嘅 `AbortController` 同逾時期限結合埋一齊，並透過 `client({ signal })` 傳入。Defjs 會將呼叫端手動中斷歸類為 `NET_ABORTED`，而將逾時中斷歸類為 `NET_TIMEOUT`。

取消請求只係反映 client 端觀察到嘅狀態——並唔保證伺服器端嘅寫入操作已經復原（rollback）。針對寫入操作嘅重試，請務必配合冪等鍵（idempotency key）保護。詳情請參閱 [HTTP 取消與逾時期限](/zh-Hant-HK/docs/http#cancel-the-work)。
