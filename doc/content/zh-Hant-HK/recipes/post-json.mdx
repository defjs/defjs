# POST JSON

將 typed body 交畀 builder。Logical field names 留喺 TypeScript；struct 上面嘅 wire aliases 會變成 JSON keys。Object body 係 `application/json`。

詳情睇 [Commands](/zh-Hant-HK/docs/commands) 同 [HTTP](/zh-Hant-HK/docs/http)。

</include>

`api.example.com` 係 placeholder。如果 server 回應 `201` 同 `{ "id": 1, "name": "Ada", "email": "ada@example.com" }`，snippet 會 print：

```txt
Created Ada → 201
```
