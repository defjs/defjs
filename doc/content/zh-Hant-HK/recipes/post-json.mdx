# POST JSON

將 typed body 交畀 builder。Logical field names 留喺 TypeScript；struct 上面嘅 wire aliases 會變成 JSON keys。Object body 係 `application/json`。

詳情睇 [HTTP](/zh-Hant-HK/docs/http) 同 [Client](/zh-Hant-HK/docs/client)。

`api.example.com` 係 placeholder。如果 server 回應 `201` 同 `{ "id": 1, "status": "paid", "customer_name": "Ada" }`，snippet 會 print：

```txt
Created paid → 201
```
