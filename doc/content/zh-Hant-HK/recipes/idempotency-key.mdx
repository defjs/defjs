# 冪等鍵

預設情況下，`withRetry` 淨係會重試冪等嘅 HTTP 方法（`GET`、`HEAD`、`PUT`、`DELETE`、`OPTIONS`、`TRACE`）。當為 `POST` 或 `PATCH` 端點啟用重試嗰陣，請將 `withRetry` 同 `idempotencyKeyHttpInterceptor()` 配對使用，令同一個邏輯呼叫嘅每次重試都會重用 `req.correlationId` 作為佢嘅 `Idempotency-Key` header，而後續獨立呼叫就會獲得全新嘅 key。
