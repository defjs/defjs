# Undici Pool HTTP handle

喺高吞吐量嘅 Node.js BFF 同後端服務入面，透過 [`withHTTPHandle`](/zh-Hant-HK/api/core/withhttphandle) 注入共用嘅 `undici.Pool`，令多條上游連線保持預熱而且數量有界，同時令 SDK 定義（`sdk/orders.ts`）完全保持平台無關。記得喺關閉服務時呼叫 `await pool.close()`。
