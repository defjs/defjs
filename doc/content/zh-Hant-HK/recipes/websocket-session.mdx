# 開啟 WebSocket 會話

如果伺服器收到 `{ "type": "subscribe", "symbol": "ACME" }` 後回覆 `{ "type": "tick", "symbol": "ACME", "price": 142.5 }`，腳本會輸出：

```txt
ACME 142.5
```

- 重連（`withRetry`）同心跳偵測（`withWebSocketHeartbeat`）都係喺 client 端 opt-in 開啟嘅。
- 瀏覽器環境嘅 WebSocket 喺握手階段無法發送自訂 HTTP headers；請改用 Cookie、子協議或短期連線 ticket 代替。詳情請參閱 [WebSocket 會話](/zh-Hant-HK/docs/web-socket)。
