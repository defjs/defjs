# 用 ETag 同 304 revalidate

`ok` 只代表 2xx，所以 `304` 會以 `HTTP_STATUS` fault 到。Redirect status 亦唔係 error body，所以唔好聲明 `error`：body 根本唔會被讀，fault 帶住 status，你自己 return cached product。

睇 [HTTP](/zh-Hant-HK/docs/http)。
