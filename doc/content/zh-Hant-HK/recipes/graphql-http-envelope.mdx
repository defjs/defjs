# 解包 GraphQL HTTP Envelope

Defjs 並唔內建 GraphQL client 或者 `errorPolicy`。你可以將基於 HTTP 嘅 GraphQL 當成一般標準 `POST` 操作嚟建模，由 `builder` 發送 `{ query, operationName, variables }`。喺 Envelope Struct 上將 `data` 標記為 `.nullish()`，令省略 `data` 或回傳 `data: null` 都可以順利通過結構驗證，然後喺應用程式嘅輔助函式入面解包 `errors[]`：

- HTTP `200` 淨係代表 GraphQL envelope 完整送達。`errors[]` 入面嘅業務錯誤（就算同時伴隨 `data: null`）屬於應用層嘅結果，而唔係 `RES_STRUCT_MISMATCH` fault。
- 關於點解特定協議嘅 envelope 應該留喺應用程式輔助函式處理，請參閱[核心架構](/zh-Hant-HK/docs/design-decisions)。
