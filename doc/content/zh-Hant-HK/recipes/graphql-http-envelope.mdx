# Unwrap 一個 GraphQL HTTP envelope

Defjs 唔會實作 GraphQL `errorPolicy`。將 wire model 成 HTTP POST，由 builder 擺放 query document 同 variables。Envelope 嘅 `data` 要聲明為 `.nullish()`，等缺少 `data` 同 `data: null` 都可以交到你嘅 helper，再先處理 `errors[]`，之後先檢查 `data`。

睇 [Design Decisions](/zh-Hant-HK/docs/design-decisions)。

HTTP 成功只代表 envelope 到咗。Application errors 會留喺 `errors[]`，直至你嘅 unwrap throw 或回傳，包括 `data: null` 嘅 response。例子會將缺少 `data` 或 `data: null` 並帶有 `errors[]` 嘅情況，當成 application errors，唔係 Struct mismatches。
