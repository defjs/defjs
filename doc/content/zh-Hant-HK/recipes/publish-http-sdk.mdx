# 建置並發佈 SDK [#publish-an-http-sdk-without-hiding-execute]

Defjs SDK 將共用嘅 `struct` schema（`src/schema/`）同按業務域劃分嘅操作定義模組（`src/request/`）組織成可以按需 tree-shake 嘅 npm 套件，同時將 `createClient(...)`、端點、身分憑證同攔截器完全留畀使用方應用程式掌控。

有別於傳統 OpenAPI 生成器將接口封裝喺帶狀態嘅 `Service` 類別（例如 `ObjectsService.putObject(...)`）入面，Defjs SDK **淨係匯出獨立嘅純函數操作定義**（`putObject`、`getObject`、`listObjectsV2`），喺應用程式嗰邊直接傳入 `client` 調用。

---

## 1. 定義 SDK 套件結構

以兼容 Amazon S3 協議嘅物件儲存 SDK（`@company/s3-sdk`）為例，將套件拆分成兩層：

- **`src/schema/`**：跨接口重用嘅 `struct` schema 同 `Infer<typeof ...>` TypeScript 型別（利用同名匯出值同型別，令使用方淨係匯入一個識別符就可以同時當作執行時 schema 同靜態型別用）。
- **`src/request/`**：按資源域劃分嘅操作模組（`buckets.ts`、`objects.ts`）。每個模組淨係匯出獨立嘅 `defineRequest` 純函數，透過同步純函數 `builder` 將調用方嘅扁平入參分發去 `path`、`query`、`headers` 同二進制 `body`。

- **純函數匯出，棄用 `Service` 類別**：每個操作（`listBuckets`、`listObjectsV2`、`getObject`、`putObject`、`deleteObject`）都直接匯出成獨立嘅 `defineRequest` 純函數，千祈唔好用 `class` 或者命名空間物件包住。獨立純函數令調用方式同 `@defjs/core` 完全一致（`await putObject(client, input)`），而且配合 `"sideEffects": false` 可以畀各類打包工具徹底 tree-shake 剔除未引用嘅端點。
- **結構化 JSON、二進制數據與空回應體**：`listBuckets` 同 `listObjectsV2` 用 `.alias()` 解碼並映射 JSON 欄位；`getObject` 將回應體解碼成二進制 `Blob`（`output: struct.blob()`）；`putObject`、`headObject` 同 `deleteObject` 針對空回應體省略 `output`，調用方依然可以喺返回元組嘅第 3 項 `response.headers` 讀取 `etag` 等回應標頭。
- **外部執行時對等依賴**：`@defjs/core` 保持為 `peerDependency`，同使用方應用程式共用同一個實例。

## 2. 建置並檢查打包 Tarball

使用 `tsdown` 打包產出 `dist/index.js` 同 `dist/index.d.ts`，發佈前先檢查套件內容：

```sh
bun install
bun run build
bun pm pack --dry-run
bun pm pack
```

確認 `dist/index.js` 同 `dist/index.d.ts` 都有包含喺 tarball 入面。

---

## 3. 喺應用程式入面使用呢個 SDK

將你發佈嘅 SDK 同 `@defjs/core` 一齊安裝到應用程式：

```sh
bun add @company/s3-sdk @defjs/core@^0.8.0
```

因為 SDK 唔綁定任何 Client，使用方應用程式自己掌控服務端點（AWS S3、Cloudflare R2 或 MinIO）、簽名攔截器同重試策略，並以純函數方式直接調用匯入嘅操作定義。因為 `syncReport` 有三個呼叫，所以按步驟命名每個錯誤（`putErr`、`listErr`、`getErr`），並回傳 error-first tuple，其中嘅錯誤會包裝失敗嘅步驟，就好似 Go 嘅 `fmt.Errorf("put object: %w", err)`。只有 `main` 會記錄佢：

## 4. 測試與發佈

為匯出嘅定義編寫[記憶體 handle 測試](/zh-Hant-HK/recipes/test-with-handle)，覆蓋路徑／查詢／標頭／二進制請求體映射、`output` 解碼、`ETag` 回應標頭、宣告過嘅 `HTTP_STATUS`（`S3Error`）Fault 以及取消功能。驗證通過後，即可發佈套件：

```sh
bun publish --access public
```

詳情請參閱 [HTTP 操作](/zh-Hant-HK/docs/http)、[Client](/zh-Hant-HK/docs/client)、[測試](/zh-Hant-HK/docs/testing) 與 [核心架構](/zh-Hant-HK/docs/design-decisions)。
