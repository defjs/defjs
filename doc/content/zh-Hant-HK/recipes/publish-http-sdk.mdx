# 建置並發佈 SDK [#publish-an-http-sdk-without-hiding-execute]

Defjs SDK 將純粹嘅操作定義同 Struct schema 打包成 npm 套件發佈，同時將 `createClient(...)`、端點、身分憑證同攔截器完全留畀使用方應用程式掌控。

---

## 1. 定義 SDK 套件結構

將你嘅操作定義、barrel 匯出入口、`package.json` 同 `tsconfig.json` 擺喺專屬嘅套件目錄入面，並將 `@defjs/core` 宣告為 `peerDependency`：

- `@defjs/core` 保持為外部嘅執行時 `peerDependency`，同使用方應用程式共用同一個實例。
- `"sideEffects": false` 畀各類打包工具喺應用程式淨係引用部分操作嗰陣，自動 tree-shake 剔除用唔著嘅操作。

---

## 2. 建置並檢查打包 Tarball

使用 `tsdown` 打包產出 `dist/index.js` 同 `dist/index.d.ts`，發佈前先檢查套件內容：

```sh
bun install
bun run build
bun pm pack --dry-run
bun pm pack
```

確認 `dist/index.js` 同 `dist/index.d.ts` 都有包含喺 tarball 入面。

---

## 3. 喺應用程式入面使用呢個 SDK

將你發佈嘅 SDK 同 `@defjs/core` 一齊安裝到應用程式：

```sh
bun add @company/orders-sdk @defjs/core@^0.6.0
```

應用程式建立自己嘅 `Client`，並將佢傳入匯入嘅操作：

<include cwd meta='title="app.ts"'>
  examples/recipes/publish-http-sdk/app.ts#example
</include>

```txt
paid
```

喺正式生產代碼入面，將相對路徑匯入 `./src/orders.ts` 換成 `@company/orders-sdk`，並移除 `withHTTPHandle(...)`，即可改用平台原生嘅 `fetch`。

---

## 4. 測試與發佈

為匯出嘅定義編寫[記憶體 handle 測試](/zh-Hant-HK/recipes/test-with-handle)，覆蓋請求映射、`output` 解碼、宣告過嘅 `HTTP_STATUS` 錯誤以及取消功能。驗證通過後，即可發佈套件：

```sh
bun publish --access public
```

詳情請參閱 [HTTP 操作](/zh-Hant-HK/docs/http)、[Client](/zh-Hant-HK/docs/client)、[測試](/zh-Hant-HK/docs/testing) 與 [核心架構](/zh-Hant-HK/docs/design-decisions)。
