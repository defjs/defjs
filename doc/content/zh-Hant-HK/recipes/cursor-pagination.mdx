# 游標分頁

將分頁操作定義留喺 SDK 模組（`listOrders`），並將游標接續邏輯包入純應用程式輔助函式（`listAllOrders`）入面，持續 yield Go 風格嘅 `[err, item]` tuple，遇到失敗或者呼叫端中斷就即刻停低。
