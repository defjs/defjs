# 使用本地 Fetch Handle 進行測試

`withHTTPHandle(...)` 可以為單一 client 實例換走底層嘅 `fetch` 函式，同時完整走勻整個 Defjs 流程——包括 input 驗證、`builder` 映射、URL 解析、攔截器、狀態碼分類以及 Struct 解碼——完全唔需要開啟任何真實嘅網絡 socket：
