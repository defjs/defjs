# Defjs

**TypeScript SDK 与弹性客户端工具包 —— 写一次 API 契约定义，执行细节交给每个应用自己配置。**

无论你是发布独立的 npm SDK，还是只想把团队内部项目的前后端接口层整理清楚，Defjs 都把接口的两端职责拆开：

- **SDK 契约定义（`@defjs/core`、`@defjs/cli`）** —— 使用 `defineRequest`、`defineEventStream` 和 `defineWebSocket` 声明带类型的 HTTP、SSE 与 WebSocket 操作及其 `struct` schema（既可手写，也可从 OpenAPI 2.0/3.0/3.1/3.2 规范生成为无状态 ESM 模块）。定义本身是纯数据：只导入它不会发起任何网络调用，也不会绑定全局 Client。
- **应用弹性执行（`@defjs/core`）** —— 应用在自身边界处创建 `Client`（`createClient(withEndpoint(...))`），挂上凭据与拦截器（`basicAuth*`、`idempotencyKeyHttpInterceptor`、`concurrencyLimitHttpInterceptor`），配置 P2C 负载均衡与 `outlierDetection`（`halfOpen`、`maxEjectionPercent`），开启 `429`/`Retry-After` 重试，通过 `@defjs/core/concurrent` 并发扇出，或借助 `@defjs/core/port` 桥接 Worker 与浏览器扩展。

## 为什么把定义与 Client 拆开？

| 职责划分     | 接口定义（纯契约，业务 `src/api/` 或公共 SDK）                                                    | 应用程序（运行时执行）                                 |
| ------------ | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| **负责什么** | HTTP 方法、路径模板、`input` / `output` / `error` 数据结构、`builder` 参数放置，以及自定义 `meta` | 接口域名、认证凭据、鉴权拦截器、负载均衡、超时与清理   |
| **交付形式** | 可在浏览器、SSR 和测试之间直接复用的纯 ESM 模块与 `.d.ts` 类型声明                                | 面向浏览器、Node 服务端或本地测试的具体运行时配置      |
| **核心好处** | 与运行环境解耦；同一套接口定义不用改代码就能跑在线上、SSR 和离线单元测试里                        | 重试、故障切换、监控上报与连接释放完全由应用自己说了算 |

## 支持的传输协议与返回元组

每个操作都会返回一个针对对应协议生命周期设计的三元素错误优先元组：

| 传输协议                                  | 入口函数            | 元组结构                     | 怎么取消或关闭                                                              |
| ----------------------------------------- | ------------------- | ---------------------------- | --------------------------------------------------------------------------- |
| **[HTTP](/zh-Hans/docs/http)**            | `defineRequest`     | `[err, data, response]`      | 通过 `client({ signal })` 取消进行中的请求                                  |
| **[SSE](/zh-Hans/docs/sse)**              | `defineEventStream` | `[err, stream, open]`        | 用 `await using` 或 `stream.close()` + `await stream.closed` 安全释放流     |
| **[WebSocket](/zh-Hans/docs/web-socket)** | `defineWebSocket`   | `[err, session, connection]` | 用 `await using` 或 `session.close()` + `await session.closed` 优雅关闭会话 |

HTTP 请求失败时，元组是 `[err, undefined, undefined]`，因为响应元数据（`HttpMeta`）已经直接挂在 `err` 上。对于 SSE 和 WebSocket，只要建立连接失败前已经拿到了启动快照，第三项就会保留该快照。
