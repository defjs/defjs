本站发布面向助手的英文 Markdown。下面这些地址没有语言前缀，也不是本地化指南的译文。

## 页面索引 [#llms-txt]

[llms.txt](/llms.txt) 列出英文页面，并链接到对应网页。助手需要先找到页面时，从这里开始。

## 汇编指南 [#llms-full]

[llms-full.txt](/llms-full.txt) 把英文指南合成一个文件。需要在一次上下文中提供较广的背景，且 token 预算允许一份大文档时使用。

## 单页 Markdown [#page-markdown]

每个英文页面也可以通过 `/llms.mdx/<path>/content.md` 获取 Markdown。例如，[快速开始的 Markdown](/llms.mdx/docs/start/content.md) 就是快速开始页的英文正文。

## 核对版本 [#version]

本站记录默认分支；项目安装的 `@defjs/core` 版本可能不同。采用建议之前，先按已安装的包核对 API。向 AI 工具提供代码或上下文之前，先移除密钥并确认项目的数据使用政策。
