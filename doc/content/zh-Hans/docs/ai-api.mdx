本站发布为助手生成的英文 Markdown。这些地址没有语言前缀，也不是本地化指南的译文。

## 页面索引 [#llms-txt]

[llms.txt](/llms.txt) 列出英文页面，并链接到对应网页。助手需要先找到页面时，从这里开始。

## 汇编指南 [#llms-full]

[llms-full.txt](/llms-full.txt) 把英文指南合并成一个文件。助手需要在一份文档中获得较广的上下文，且 token 预算允许时使用。

## 单页 Markdown [#page-markdown]

每个英文页面也提供 Markdown 版本：`/llms.mdx/<path>/content.md`。例如，[快速开始的 Markdown](/llms.mdx/docs/start/content.md) 就是快速开始页的英文正文。

## 核对版本 [#version]

本站记录的是默认分支；项目安装的 `@defjs/core` 版本可能不同。采用建议之前，先按已安装的包核对 API。向 AI 工具提供代码或上下文之前，先移除密钥并确认项目的数据使用政策。
