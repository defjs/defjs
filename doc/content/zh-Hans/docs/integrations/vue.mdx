# Vue

`@defjs/vue` 通过 `createClientPlugin(client)`、`HTTP_CLIENT` 标识与 `injectClient()`，将消费方应用自有的 `@defjs/core` Client 注入到 Vue 3.2+ 应用中。你的 SDK 定义始终保持为纯净的 `@defjs/core` 模块，对 Vue 实现完全零依赖。

```sh
bun add @defjs/core @defjs/vue vue
```

## `@defjs/vue` 负责什么 vs. 你负责什么

- **由 `@defjs/vue` 提供**：`createClientPlugin(client)`、`HTTP_CLIENT`（`InjectionKey<Client>`）以及 `injectClient(key?)`。
- **由你的应用全权管理**：创建 [`DerivableClient`](/zh-Hans/api/core/derivableclient-type)、在 Watcher（`onCleanup`）或组合式函数（`onScopeDispose`）中取消在途请求、关闭 SSE/WebSocket 长连接句柄，以及接入诸如 Vue Query 等数据管理库。
- **重要须知**：`injectClient()` 返回的是可调用的 `DerivableClient` 函数对象。在执行操作的地方调用 `client({ signal })`（如 `getOrder(client({ signal }), input)`）。切勿将 `client` 直接作为第一个参数传给 `watch(client, ...)` 或 `computed(client)`，因为 Vue 会将函数参数当成响应式 Getter 来执行。

## 2. 在子树中注入与覆盖 Client

`injectClient(key?)` 会向上查找距离最近的 `key` Provider（默认查找 `HTTP_CLIENT`）。若在活跃的 Vue 注入上下文（`setup()` 或 `app.runWithContext()`）之外调用，或者该 key 未曾 provide 过 Client，则会抛出 `Error` 异常。

- 若封装的辅助函数支持可选显式传入 Client（如 `explicitClient ?? injectClient()`），则只有在走降级分支时才要求处于活跃的 Vue 注入上下文中。请始终在 `setup()` 内部同步获取 Client，切勿在 `await` 之后调用。

## 3. 在作用域销毁时清理 SSE 与 WebSocket 长连接

对于在 Watcher 之外（例如普通的 Composable 或组件生命周期中）发起的异步任务，可结合使用 `AbortController` 与 `onScopeDispose`。在作用域销毁时取消握手、关闭在销毁后才 resolve 的晚到句柄、消费唯一的异步迭代器，并等待 `.closed`：

<include cwd>examples/vue/realtime-scope.vue#example</include>

- 停止当前作用域会使 SSE 的 `for await` 循环正常结束。
- 取消 WebSocket 会话会使其以 `aborted` 终结，并使 `session.receive` 以 `AbortError` 报错。因此在销毁后请保护好 `catch` 块，并在 `finally` 中注销 `onStateChange` 与 `onRuntimeError` 监听器。

---

## 4. SSR 与应用作用域

- **浏览器环境**：当服务地址与拦截器对所有请求全局安全通用时，每个 Vue 应用共享一个 Client 实例即可。
- **服务端渲染（SSR）**：当请求头、Cookie、租户或认证凭据因每个 SSR 请求而异时，务必为每个服务端请求单独创建并安装全新的 Client。
- 卸载 Vue 应用或销毁组件作用域**不会**自动中断活跃的 HTTP 请求，不会关闭 SSE/WebSocket 长连接，也不会销毁底层的 Core Client。
