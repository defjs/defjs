# Vue

`@defjs/vue` 通过 `createClientPlugin(client)`、`HTTP_CLIENT` 和 `injectClient()`，把应用自己的 `@defjs/core` Client 接入 Vue 3+ 应用。SDK 定义本身依然是纯 `@defjs/core` 模块，不依赖 Vue。插件底层只用到 `provide` / `inject`；下面例子里的 `<script setup>` 和 `onScopeDispose` 需要 Vue 3.2+。

```sh
bun add @defjs/core @defjs/vue vue
```

## `@defjs/vue` 管什么，应用管什么

- **`@defjs/vue` 提供**：`createClientPlugin(client)`、`HTTP_CLIENT`（`InjectionKey<DerivableClient>`）和 `injectClient(key?)`。
- **应用自己负责**：创建 [`DerivableClient`](/zh-Hans/api/core/derivableclient-type)、在 watcher（`onCleanup`）或组合式函数（`onScopeDispose`）里中止未完成的请求、关闭 SSE / WebSocket 句柄，以及对接 Vue Query 等查询库。
- **注意避坑**：`injectClient()` 返回的 `DerivableClient` 本身是个可调用对象（带函数签名），发请求时调用 `client({ signal })` 就好（比如 `getOrder(client({ signal }), input)`）。**千万别**把 `client` 直接作为第一个参数传给 `watch(client, ...)` 或 `computed(client)`，因为 Vue 会把函数参数当成响应式 getter 来执行。

## 2. 在子树中注入与覆盖 Client

`injectClient(key?)` 会顺着组件树向上找最近一次提供的 `key`（默认 `HTTP_CLIENT`）。如果在活跃的 Vue 注入上下文（`setup()` 或 `app.runWithContext()`）之外调用，或者根本没提供这个 key，就会抛出 `Error`。

## 3. 在作用域销毁时清理 SSE 与 WebSocket 流

对于放在 watcher 外面（比如组合式函数或组件初始化里）的流式任务，把 `AbortController` 和 `onScopeDispose` 配起来用就行。传进去的 `signal` 同时管着建连阶段和已打开的流，所以清理时只要调一下 `abort()` 就够了。消费完它唯一的异步迭代器后，在 `finally` 里关闭句柄并等待 `.closed`：

<include cwd>examples/vue/realtime-scope.vue#example</include>

- 元组里的 `err` 分支拿的是握手建连阶段的失败（包括 HTTP 503）。迭代器外面的 `catch` 抓的是连上之后出现的异常；无论哪种情况，`finally` 都会把流关掉并等它彻底结束。
- 销毁作用域后，SSE 的 `for await` 循环会直接正常结束。
- 取消 WebSocket 会话会让它按 `aborted` 结束，同时让 `session.receive` 抛出 `AbortError`。清理时记得在 `catch` 里判断下是不是已经主动销毁，并在 `finally` 里注销 `onStateChange` 和 `onRuntimeError` 监听器。

## 4. SSR 与应用作用域

- **浏览器**：域名和拦截器不随单个请求变化时，每个 Vue 应用共享一个 Client 就够了。
- **SSR**：请求头、Cookie、租户或凭据随每个请求变化时，就为每个 SSR 请求新建并安装独立的 Client。
- 卸载 Vue 应用或销毁组件作用域**不会**自动中止还没完成的 HTTP 请求，也不会关掉 SSE/WebSocket 流或销毁 Client。

## 公共导出与相关指南

- `HTTP_CLIENT` —— 供原生 `provide` / `inject` 使用的 `InjectionKey<DerivableClient>`。
- `createClientPlugin(client)` —— 在 `HTTP_CLIENT` 下提供 `client` 的 Vue `Plugin`。
- `injectClient(key?)` —— 读取离当前作用域最近提供的 Client（默认 `HTTP_CLIENT`）。
