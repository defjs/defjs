# Vue

`@defjs/vue` 通过 `createClientPlugin(client)`、`HTTP_CLIENT` 与 `injectClient()`，把应用自有的 `@defjs/core` Client 接入 Vue 3.2+ 应用。SDK 定义保持为纯 `@defjs/core` 模块，不依赖 Vue。

```sh
bun add @defjs/core @defjs/vue vue
```

## `@defjs/vue` 负责什么，应用负责什么

- **由 `@defjs/vue` 提供**：`createClientPlugin(client)`、`HTTP_CLIENT`（`InjectionKey<DerivableClient>`）和 `injectClient(key?)`。
- **由应用负责**：创建 [`DerivableClient`](/zh-Hans/api/core/derivableclient-type)，在 watcher（`onCleanup`）或组合式函数（`onScopeDispose`）中中止在途工作，关闭 SSE/WebSocket 句柄，以及接入 Vue Query 等查询库。
- **重要**：`injectClient()` 返回 `DerivableClient` 函数对象。在操作运行处调用 `client({ signal })`（例如 `getOrder(client({ signal }), input)`）。不要把 `client` 作为第一个参数传给 `watch(client, ...)` 或 `computed(client)`，因为 Vue 会把函数参数当作响应式 getter。

## 2. 在子树中注入与覆盖 Client

`injectClient(key?)` 查找 `key` 最近的 Provider（默认 `HTTP_CLIENT`）。在活跃的 Vue 注入上下文（`setup()` 或 `app.runWithContext()`）之外调用，或该 key 没有提供 Client 时，抛出 `Error`。

- 后代组件读取到 `childClient`，兄弟子树仍使用根 Client。

## 3. 在作用域销毁时清理 SSE 与 WebSocket 流

对于在 watcher 之外（组合式函数或组件中）启动的工作，把 `AbortController` 与 `onScopeDispose` 配合使用。该 signal 覆盖启动阶段和已打开的流，因此中止它就是全部的清理。消费唯一的异步迭代器，然后在 `finally` 中关闭句柄并等待 `.closed`：

<include cwd>examples/vue/realtime-scope.vue#example</include>

- 元组的错误分支显示初始握手失败（包括 HTTP 503）。迭代器的 `catch` 显示启动后的失败；`finally` 块仍会关闭并等待流。
- 停止作用域会让 SSE 的 `for await` 循环正常结束。
- 取消 WebSocket 会话会使其以 `aborted` 终结，并使 `session.receive` 以 `AbortError` 报错。因此在销毁后请保护好 `catch` 块，并在 `finally` 中注销 `onStateChange` 与 `onRuntimeError` 监听器。

---

## 4. SSR 与应用作用域

- **浏览器**：当端点与拦截器与具体请求无关时，每个 Vue 应用共享一个 Client。
- **SSR**：当请求头、cookie、租户或凭据因请求而异时，为每个 SSR 请求创建并安装新 Client。
- 卸载 Vue 应用或销毁组件作用域**不会**中止 HTTP 请求、关闭 SSE/WebSocket 流或销毁核心 Client。
