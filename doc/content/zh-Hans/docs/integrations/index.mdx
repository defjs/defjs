# 集成概览

集成在明确的扩展点上扩展应用自有的 `Client`，不修改 `@defjs/core`，也不把 SDK 定义耦合到某个框架或遥测栈。SDK 定义始终保持为纯 `@defjs/core` 模块；消费方应用自行选择安装哪些集成。

每个 Defjs 插件都遵循**薄插件契约**：

- **不做隐式缓存或状态管理**：插件从不保存响应、重试请求或管理查询状态。
- **不替换传输层**：插件从不包装或替换底层 HTTP、SSE 或 WebSocket 传输。
- **生命周期由调用方持有**：卸载 UI Provider 或关闭遥测 SDK 不会自动取消进行中的请求，也不会关闭活跃的流。

## 两种插件架构

### 1. 框架插件（`@defjs/react`、`@defjs/vue`）

中间件插件是一个返回 [`ClientOption`](/zh-Hans/api/core/clientoption-type) 的工厂函数。当传递给 `createClient(...)` 时，它会通过 `withInterceptors` 追加 HTTP、SSE 和/或 WebSocket 拦截器：
