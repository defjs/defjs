# 集成概览

扩展集成机制允许在明确的扩展点上增强消费方应用自有的 `Client`，而无须修改 `@defjs/core` 核心逻辑，更不会将 SDK 接口定义与特定 UI 框架或遥测链路强行耦合。你的 SDK 定义始终保持为纯净的 `@defjs/core` 模块；由具体的消费方应用自主决定安装哪些集成扩展。

所有官方 Defjs 插件均严格恪守**轻量插件契约（Thin Plugin Contract）**：

- **零隐式缓存与状态管理**：插件绝不擅自缓存响应数据、不静默重试请求，也不维护任何业务 Query 状态。
- **绝不篡改底层传输层**：插件绝不包装或替换原生的 HTTP、SSE 或 WebSocket 传输链路。
- **生命周期完全归调用方所有**：卸载前端 UI Provider 或停止遥测 SDK 不会自动取消正在进行中的网络请求，也不会擅自关闭活跃的长连接流。

## 两种插件架构

### 1. 框架插件（`@defjs/react`、`@defjs/vue`）

框架插件的作用是通过框架原生的依赖注入机制（React Context 或 Vue 的 `provide` / `inject`），将应用中已创建的 [`DerivableClient`](/zh-Hans/api/core/derivableclient-type) 沿着组件树向下传递：

<Tabs items={["sdk/orders.ts", "app/main.tsx", "app/OrderCard.tsx"]}>
<Tab value="sdk/orders.ts">

```ts
import { defineRequest, struct } from "@defjs/core";

export const Order = struct.object({
  id: struct.number(),
  status: struct.string(),
});

export const getOrder = defineRequest({
  method: "GET",
  path: "/orders/:id",
  input: struct.object({ id: struct.number() }),
  builder: (input) => ({ path: { id: input.id } }),
  output: Order,
});
```

</Tab>
<Tab value="app/main.tsx">

```tsx
import { createClient, withEndpoint } from "@defjs/core";
import { ClientProvider } from "@defjs/react";
import { OrderCard } from "./OrderCard.tsx";

const client = createClient(withEndpoint("https://api.example.com"));

export function App() {
  return (
    <ClientProvider client={client}>
      <OrderCard id={42} />
    </ClientProvider>
  );
}
```

</Tab>
<Tab value="app/OrderCard.tsx">

```tsx
import { useClient } from "@defjs/react";
import { getOrder } from "../sdk/orders.ts";

export function OrderCard({ id }: { id: number }) {
  const client = useClient();
  // 在 useEffect 或 TanStack Query 中调用 getOrder(client({ signal }), ...)
  void id;
  void getOrder;
  void client;
  return null;
}
```

</Tab>
</Tabs>

### 2. 中间件插件（`@defjs/opentelemetry-server`）

中间件插件是一个返回 [`ClientOption`](/zh-Hans/api/core/clientoption-type) 的工厂函数。当传递给 `createClient(...)` 时，它会通过 `withInterceptors` 追加 HTTP、SSE 和/或 WebSocket 拦截器：

<Tabs items={["plugins/request-id.ts", "app/client.ts"]}>
<Tab value="plugins/request-id.ts">

  examples/integrations/request-id.ts#example

</Tab>
<Tab value="app/client.ts">

```ts
import { createClient, withEndpoint } from "@defjs/core";
import { withRequestIdHeader } from "../plugins/request-id.ts";

export const client = createClient(
  withEndpoint("https://api.example.com"),
  withRequestIdHeader(),
);
```

</Tabs>

关于洋葱拦截链顺序、安全重试边界以及流式生命周期钩子的详细说明，请参阅[中间件](/zh-Hans/docs/interceptors)。
