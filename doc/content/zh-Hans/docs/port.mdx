# Port 传输层（`@defjs/core/port`）

`@defjs/core/port` 允许隔离上下文（`SharedWorker`、Dedicated Worker、沙箱 `iframe`、Electron 渲染进程，或 WebExtension 的 Popup / Side Panel / Content Script）通过单个多路复用端口执行纯 `@defjs/core` SDK 定义，无需将定义耦合到代理传输层。

- 零运行时依赖；作为可选子路径 `@defjs/core/port` 和 `@defjs/core/port/webext` 提供，未导入时零打包体积开销
- 在同一条端口连接上并发共享 HTTP（含 `ReadableStream` 上传/下载）、SSE（`text/event-stream`）与 WebSocket 连接
- **默认故障封闭安全策略（Fail-closed）**：除非宿主机显式指定 `allowedOrigins`、`allowRequest` 或 `allowAnyOrigin: true`，否则 `attachPortHost` 将拒绝所有流量

```bash
bun add @defjs/core
```

## MV3 WebExtension 代理（`@defjs/core/port/webext`）

WebExtension 的 `runtime.Port` 无法直接跨 Chromium/Firefox/Safari 扩展边界传递 `ArrayBuffer` 对象，而且 Manifest V3 的 Service Worker 在休眠时会自动断开连接。`@defjs/core/port/webext` 提供了零依赖的结构适配函数 `fromWebExtPort`（无需 `@types/chrome`），采用 `"json"` 分块 Base64 帧格式，并支持惰性连接器函数，在 Service Worker 休眠唤醒后自动重连：
