# Client

`Client` 是消费方应用的执行配置。`createClient(...)` 返回一个 [`DerivableClient`](/zh-Hans/api/core/derivableclient-type)。用请求选项调用这个工厂会得到一个 `Client` 值，操作接受的就是 `Client` 值。它不可调用。从 SDK 导入操作，选定服务地址、凭证、拦截器和传输，再把 client 传给操作。`getUser(client({ abort }), { id: 1 })` 启动一次声明了 input 的调用。`health(client)` 启动一次没有 input 的调用。整个 input struct 可选时，`search(client)` 和 `search(client, input)` 都合法。没有第三个 options 参数。调用操作即开始它。`await` 只等待 error-first tuple。

SDK 的定义不绑定这个实例。浏览器、服务端请求和本地测试可以用不同的 client 调用同一个导出的操作。它们仍遵循同一份 Defjs 契约和兼容的 Core 版本。为你通过该 client 调用的操作配置它的服务地址。

同一个 client 值可以传给多次操作。应用选择缓存和重试策略，并拥有自己启动的工作。HTTP 不会自动重试。流的重连需要显式启用。

工厂是一个函数，同时也是不带请求选项的 `Client`。不要把工厂传给 React 的 state setter：`setState(factory)` 会把它当成 updater 来调用。不要把它当作 Vue 的 `watch` 或 `computed` 源：那些 API 会调用函数。派生出的 client 值是普通对象。

## 派生 client

`client(options?)` 返回一个仅供单次调用的 `Client` 值。调用 `client(options)` 时，七个已知字段从参数对象复制出来：顶层快照进一个新的 options 对象。未知字段会被忽略，值为 `undefined` 的字段会被省略。没有父级叠加：`client()`、`client(undefined)` 和 `client({})` 返回一个不带请求选项的 client。嵌套的 `heartbeat`、`protocols` 和 `reconnect` 的值按引用保留，不克隆。WebSocket 在操作运行时读取它们（那时会复制 heartbeat 的字段和 protocols 列表），所以派生之后再改这些对象，仍可能影响后来的调用。应用应当在传入之后把它们当作不可变。派生不产生 I/O。会抛错的 getter 会从 `client(options)` 中逃出，工厂仍可继续使用。client 值不可调用；每次调用创建一个。

`abort` 不会组合。复用携带 `abort` 的 client 值会在多次调用间共享这个 signal，所以每次调用创建一个 client 值。要组合 signal，在应用代码里用 `AbortSignal.any`。

`createClient` 给出的基础配置由每个 client 值共享，运行时不会冻结。它按约定固定：库不会改它，应用也不应该改。client 上的 [`RequestOptions`](/zh-Hans/api/core/requestoptions-type) 就是那份顶层快照。应用代码把 client 传给操作。它不读取这份内部状态。

## 请求选项

[`RequestOptions`](/zh-Hans/api/core/requestoptions-type) 有七个扁平字段。每种协议只读取自己认识的字段，其余忽略。把 `heartbeat` 传给 HTTP 操作会被忽略，这不是 fault。SSE 从请求选项里只读取 `abort`。SSE 重连来自 client 配置（`withSSEReconnect`），所以 `client({ reconnect })` 只影响 WebSocket。没有编译期的协议过滤。

| 字段                 | 使用者               | 规则                                                                                        |
| -------------------- | -------------------- | ------------------------------------------------------------------------------------------- |
| `abort`              | HTTP、SSE、WebSocket | 中止该次调用。期限是 `AbortSignal.timeout(ms)`（`NET_TIMEOUT`）。手动中止是 `NET_ABORTED`。 |
| `onUploadProgress`   | HTTP                 | SSE 和 WebSocket 忽略。                                                                     |
| `onDownloadProgress` | HTTP                 | SSE 和 WebSocket 忽略。                                                                     |
| `beforeConnect`      | WebSocket            | 替换该次调用的 client 设置。                                                                |
| `protocols`          | WebSocket            | 替换 client 上的列表。不是追加。                                                            |
| `heartbeat`          | WebSocket            | 整体替换。`timeoutMs` 是心跳等待确认的时间，不是请求期限。                                  |
| `reconnect`          | WebSocket            | 整体替换。                                                                                  |

没有 `timeout` 字段，没有 `signal` 字段，也没有 client 级的默认期限。对 SSE 和 WebSocket，`abort` 覆盖整条连接，包括已经打开之后。没有仅限启动期的期限。应用若需要一个，就自己建 `AbortController`，用定时器以 `new DOMException("...", "TimeoutError")` 中止它，并在 await 返回后清掉定时器。见 [SSE](/zh-Hans/docs/sse#close-and-dispose)。

`HttpExecuteOptions` 是 HTTP 切片：`abort` 加上进度回调。`EventStreamExecuteOptions` 是 `{ abort? }`。`WebSocketExecuteOptions` 是 WebSocket 切片再加上 `abort`。

## 按传输区分的结果

- HTTP → `[error, data, response]`
- SSE → `[error, stream, open]`。`open` 对于 Defjs 原生 handle 或透传同一 live `open` 对象的 wrapper，是返回 handle 所属连接首次成功握手的快照；自定义 handle 或覆盖 `open` 的 wrapper 则以其当前公开 `open` 为准，即使已发生重连也一样，`stream.open` 仍保持实时更新（见 [SSE](/zh-Hans/docs/sse)）。
- WebSocket → `[error, session, connection]`

`error` 有值时，在使用成功值之前先返回。

清理归你：abort HTTP，close SSE + `await stream.closed`，close WebSocket + `await session.closed`。

## 服务端 vs 浏览器作用域

服务端上，options 或 interceptor 闭包会捕获鉴权、cookie、用户、租户时，把 Client 建在请求边界里。Client 身份本身不是安全边界。

## 迁移

| 旧                                          | 新                                             |
| ------------------------------------------- | ---------------------------------------------- |
| `client.execute(getUser(input), options)`   | `getUser(client(options), input)`              |
| `execute(cmd, { timeout: 5000 })`           | `client({ abort: AbortSignal.timeout(5000) })` |
| `execute(cmd, { signal })`                  | `client({ abort: signal })`                    |
| `client({ abort })({ onDownloadProgress })` | `client({ abort, onDownloadProgress })`        |
| `createClient(withTimeout(5000), ...)`      | 在调用处传入 `abort`，或包一层应用函数         |
