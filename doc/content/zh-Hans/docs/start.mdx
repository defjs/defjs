# 快速开始：定义你的第一个操作 [#getting-started-one-http-request]

跟着这篇指南，你会写一个定义 `GET /orders/:id` 的操作模块，然后分别用两种方式跑通它：先用本地内存句柄离线跑一次，再连到真实后端服务。

## 1. 安装 `@defjs/core`

`@defjs/core` 是一个零运行时依赖的 ESM 包，浏览器、Bun 和当前 LTS 版本的 Node.js 都能直接跑。请确认项目的 `package.json` 里配置了 `"type": "module"`。

```sh
bun add @defjs/core
```

## 2. 拆开写接口定义和调用代码

不管你是发布独立的 SDK，还是只想理顺自己项目里的接口层，都推荐把操作定义放在单独的模块（`src/define-request.ts`），把配置 `Client` 并发起调用留在业务入口（`src/execute-locally.ts` 或 `src/real-api.ts`）：

### 这三个文件各管什么？

1. **`src/define-request.ts`（只管接口定义）**：
   - 用 `struct` 声明入参 `input`、`output`（对应 `2xx` 成功响应）和 `error`（对应非 `2xx` 错误响应）。
   - 提供同步、无副作用的纯函数 `builder`（不要写 `async`，也不要读写外部状态），把 `input` 映射到 `{ path }`。只要声明了 `input`，就必须显式写 `builder`。
   - 只导出 `getOrder`，不在定义文件里创建或绑死任何 `Client`。
2. **`src/execute-locally.ts`（离线本地测试）**：
   - 通过 `withHTTPHandle(...)` 挂上本地模拟句柄，不用启动后端服务也能把输入校验、URL 拼接、状态码分发和 `struct` 校验解码完整跑一遍。
3. **`src/real-api.ts`（线上真实请求）**：
   - 导入完全一样的 `getOrder`，换上带真实域名 `withEndpoint(...)` 的 `Client` 直接发起调用。

## 3. 在本地跑一下看看

用 Bun 直接运行 `src/execute-locally.ts`：

```sh
bun src/execute-locally.ts
```

终端会打印：

```txt
Loaded paid from 200
```

如果把入参从 `{ id: 7 }` 改成 `{ id: 8 }`，本地测试句柄会返回 `404`，Defjs 会自动把声明好的 `error` struct 解码并挂到 `err.data` 上：

```txt
Order not found
```

## 4. 读懂错误优先的返回元组

每次 HTTP 调用都会返回一个三元素元组 `[err, data, response]`，不会在调用处 `throw` 异常。调用完紧接着写 `if (err)`，并在 `if` 块里面直接 `return` 退出（就像 Go 语言里的 `if err != nil` 一样）：

- **`2xx` 成功返回时**：`err` 为 `null`，`data` 是通过 `struct` 校验的结果值（`Order`），`response` 是 `DecodedResponse<Order>`。
- **返回非 `2xx` 状态码时**：`err.code` 为 `"HTTP_STATUS"`，`err.status` 是状态码数字（例如 `404`），声明了 `error` schema 时 `err.data` 是解码后的错误结构体（`NotFound`）。
- **入参不对、解码失败或网络故障时**：通过 `err.code` 一眼判断问题出在哪个环节：
  - `REQ_INPUT_INVALID` / `REQ_BUILD_FAILED` —— 调用方传错参数，或 `builder` 执行时抛出了异常
  - `RES_MEDIA_TYPE_INVALID` —— 操作声明了 JSON 返回体，但服务端返回的 `Content-Type` 不是 JSON（在读取响应体之前就会提前拦截）
  - `RES_DECODE_FAILED` / `RES_STRUCT_MISMATCH` —— 响应体无法读取、JSON 语法错误，或字段格式和 `struct` 不匹配
  - `NET_UNREACHABLE` / `NET_ABORTED` / `NET_TIMEOUT` —— 底层网络不通、调用方主动取消，或 `AbortSignal.timeout(ms)` 超时

想给单次调用临时加超时或取消信号？用 `client({ signal })` 派生一个一次性 `Client` 传给操作就行（不会影响原来的 `client`）：

```ts
await getOrder(client({ signal: AbortSignal.timeout(5_000) }), { id: 7 });
```
