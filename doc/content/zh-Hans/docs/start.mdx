# 快速起步：定义你的第一个 SDK 操作 [#getting-started-one-http-request]

在本指南中，你将创建一个定义了 `GET /orders/:id` 的 SDK 模块，并在两个不同的应用模块中调用它：一个使用本地 Mock handle 进行离线测试，另一个直接连接线上真实 API 服务。

## 1. 安装 `@defjs/core`

`@defjs/core` 是一个零依赖的纯 ESM 软件包，支持在现代浏览器、Bun 以及 Node.js（22.18+ 或 24+ 可直接原生运行 `.ts` 文件）中运行。请确保项目的 `package.json` 中配置了 `"type": "module"`。

```sh
bun add @defjs/core
```

### 这三个文件是如何协同工作的？

1. **`src/define-request.ts`（SDK 契约定义）**：
   - 使用 `struct` 声明调用入参 `input`、成功响应 `output`（对应 `2xx` 状态码）以及非成功响应 `error`（对应非 `2xx` 状态码）。
   - 提供一个同步、纯净的 `builder` 函数，负责将 `input` 映射为 `{ path }`。一旦声明了 `input`，就必须提供显式的 `builder`。
   - 导出 `getOrder` 操作函数，期间不创建、不绑定任何 Client。
2. **`src/execute-locally.ts`（离线本地测试执行）**：
   - 通过 `withHTTPHandle(...)` 配置 Client，无需发起任何真实网络请求，即可跑通完整的 Defjs 执行链路（包括入参校验、URL 组装解析、HTTP 状态码分发以及响应 Struct 校验解码）。
3. **`src/real-api.ts`（线上生产执行）**：
   - 导入完全相同的 `getOrder` 操作，利用 `withEndpoint(...)` 配置真实服务的基地址，直接向后端发起网络请求。

## 3. 运行本地示例

使用 Bun 直接运行 `src/execute-locally.ts`：

```sh
bun src/execute-locally.ts
```

终端将输出成功获取到的订单信息：

```txt
Loaded paid from 200
```

如果将入参从 `{ id: 7 }` 改为不存在的 `{ id: 8 }`，Mock 逻辑会返回 `404`，此时 Defjs 会将之前声明的 `error` struct 正确解码并挂载在 `error.data` 上：

```txt
Order not found
```

## 4. 理解错误优先元组

所有 HTTP 调用均返回 `[error, data, response]` 结构的三元组：

- **业务请求成功（`2xx`）**：`error` 为 `null`，`data` 为经过校验与解码的 `output` 数据（`Order`），`response` 为 `DecodedResponse<Order>`。
- **返回了已声明的非 `2xx` 状态码**：`error.code` 为 `'HTTP_STATUS'`，`error.status` 为具体的数字状态码（例如 `404`），`error.data` 则是按声明解码好的 `error` struct（`NotFound`）。
- **入参、解码或底层网络异常**：`error.code` 会清晰指出故障发生的具体阶段：
  - `REQ_INPUT_INVALID` / `REQ_BUILD_FAILED` —— 调用方传入了无效入参，或者 `builder` 执行时抛出了异常
  - `RES_MEDIA_TYPE_INVALID` —— 声明了 JSON 响应体，但服务端返回的 `Content-Type` 并非 JSON（在读取 body 之前立即中断拦截）
  - `RES_DECODE_FAILED` / `RES_STRUCT_MISMATCH` —— 响应体无法读取，或返回的 JSON 数据结构与 Schema 不匹配
  - `NET_UNREACHABLE` / `NET_ABORTED` / `NET_TIMEOUT` —— 底层网络连不上、手动取消请求，或是触发了 `AbortSignal.timeout(ms)` 超时期限

如果你需要为某次单次调用设置超时或传递取消信号，可以通过派生 Client 轻松实现：`getOrder(client({ signal: AbortSignal.timeout(5_000) }), { id: 7 })`。
