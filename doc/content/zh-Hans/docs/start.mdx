# 快速开始：一次 HTTP 请求

你会定义 `GET /users/:id`，用显式 Client 去 `execute`，并把 `200` 和声明过的 `404` 都解出来。本地 handler 保证第一次能离线跑；换成真实服务时，command 不用改。

## 第 1 步 — 安装

`@defjs/core` 是 ESM，可运行在 Node.js、Bun 或 Deno 上。Node.js 22.18+（或 24+）通过类型擦除直接运行 `.ts`；更早的 22.x 需要 `--experimental-strip-types`。package.json 里保留 `"type": "module"`。浏览器里照样需要 bundler 和 Fetch。

## 第 2 步 — 定义请求

建 `src/get-user.ts`。Input struct 是调用方的值。`builder` 把这个值放到请求上。这里整个 input 就是 path 对象，所以没有 alias 的标量字段会填上 `:id`。

<include cwd meta="get-user.ts">
  examples/start/define-request.ts#example
</include>

`output` 是 2xx body。`error` 是其余每个状态。各一个 struct。这些 body 形状不同时，用 `struct.or(...)` 或判别联合。

`defineRequest(...)` 返回 endpoint。调用 `getUser(...)` 创建不透明命令，再交给 `client.execute(...)`。上面的 `builder` 是摆放 input 的函数，它不是 endpoint。

## 第 3 步 — 本地执行

给 Client 接上一个 Client 级的本地 Fetch handle，不用联网也能跑。Defjs 照样会校验输入、拼 `Request`、按状态分派、解析 body。

## 结果对不上时

- 坏输入 → `REQ_INPUT_INVALID`；冲突的取消 options → `REQ_OPTIONS_INVALID`；`builder` 失败 → `REQ_BUILD_FAILED`
- 非 2xx 状态 → `HTTP_STATUS`；声明过 `error` 且其 body 解码成功时，`error.data` 带类型
- 声明过的 JSON body 媒体类型不对 → `RES_MEDIA_TYPE_INVALID`，在读 body 之前就报
- 声明过的 body（2xx 是 `output`，其余是 `error`）解不出来 → `RES_DECODE_FAILED` 或 `RES_STRUCT_MISMATCH`，与状态无关
- Fetch 失败 / 取消 / 超时 → `NET_UNREACHABLE` / `NET_ABORTED` / `NET_TIMEOUT`

`timeout` 必须是 `1..2_147_483_647` 的正安全整数。合法取消形状：`{ timeout }`、`{ abort }`，或 `{ signal, timeout }` / `{ signal, abort }`。`{ abort, timeout }` 一起传是非法的。取消只说明调用方看到了什么——无法说明服务端写入是否已经提交。
