# 快速起步：定义你的第一个 SDK 操作 [#getting-started-one-http-request]

在本指南中，你将创建一个定义 `GET /orders/:id` 的 SDK 模块，并在两个独立的应用程序模块中调用它：一个使用离线的 mock 传输层，另一个指向真实 API。

## 1. 安装 `@defjs/core`

`@defjs/core` 是一个零依赖的 ESM 包，可在浏览器、Bun 以及 Node.js 当前 LTS 中运行。请确保项目的 `package.json` 中设置了 `"type": "module"`。

```sh
bun add @defjs/core
```

## 2. 定义 SDK 并在应用中调用

把操作定义放在独立的 SDK 模块（`src/define-request.ts`）中，在应用程序（`src/execute-locally.ts` 或 `src/real-api.ts`）中创建 Client：

### 这三个文件是如何协同工作的？

1. **`src/define-request.ts`（SDK 定义）**：
   - 使用 `struct` 声明 `input`、`output`（对应 `2xx` 响应）以及 `error`（对应非 `2xx` 响应）。
   - 提供一个同步、纯的 `builder`，把 `input` 映射为 `{ path }`。只要声明了 `input`，就必须提供显式 `builder`。
   - 导出 `getOrder`，不创建也不捕获 Client。
2. **`src/execute-locally.ts`（离线测试执行）**：
   - 用 `withHTTPHandle(...)` 配置 Client，无需网络即可跑通完整的 Defjs 流水线（输入校验、URL 解析、状态码分发与响应 struct 解析）。
3. **`src/real-api.ts`（生产执行）**：
   - 导入完全相同的 `getOrder` 操作，通过 `withEndpoint(...)` 配置真实基地址并调用它。

## 3. 运行本地示例

使用 Bun 直接运行 `src/execute-locally.ts`：

```sh
bun src/execute-locally.ts
```

终端会输出：

```txt
Loaded paid from 200
```

如果把 `input` 从 `{ id: 7 }` 改为 `{ id: 8 }`，mock 会返回 `404`，Defjs 会把声明的 `error` struct 解码到 `err.data`：

```txt
Order not found
```

## 4. 理解错误优先元组

每次 HTTP 调用都解析为 `[err, data, response]`。调用后立即检查 `if (err)` 并在该块内部离开，就像 Go 的 `if err != nil`：

- **`2xx` 成功时**：`err` 为 `null`，`data` 是通过校验的 `output` 值（`Order`），`response` 是 `DecodedResponse<Order>`。
- **返回已声明的非 `2xx` 状态码时**：`err.code` 为 `'HTTP_STATUS'`，`err.status` 是状态码数字（例如 `404`），`err.data` 是通过校验的 `error` struct（`NotFound`）。
- **输入、解码或网络 fault 时**：`err.code` 指明失败发生在哪个阶段：
  - `REQ_INPUT_INVALID` / `REQ_BUILD_FAILED` —— 调用方输入无效，或 `builder` 抛出了异常
  - `RES_MEDIA_TYPE_INVALID` —— 声明了 JSON body，但响应的 `Content-Type` 不是 JSON（在读取 body 之前就被拒绝）
  - `RES_DECODE_FAILED` / `RES_STRUCT_MISMATCH` —— body 无法读取，或与 schema 不匹配
  - `NET_UNREACHABLE` / `NET_ABORTED` / `NET_TIMEOUT` —— 传输失败、手动取消，或 `AbortSignal.timeout(ms)` 到期

需要为单次调用设置期限或取消信号时，派生一个单次调用的 Client 值：`getOrder(client({ signal: AbortSignal.timeout(5_000) }), { id: 7 })`。
