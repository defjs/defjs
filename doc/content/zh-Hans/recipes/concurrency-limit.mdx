# 并发限制与池化调用

在 `Client` 上使用 `concurrencyLimitHttpInterceptor` 作为客户端级并发舱壁（支持 FIFO 排队以及可选的 `maxQueue` 溢出保护），并配合 `@defjs/core/concurrent`（`concurrentMap`、`concurrentMapSettled`、`concurrentAll`、`concurrentAllSettled`）直接绑定该 `Client` 执行快速失败（fail-fast）或全量汇总（settled）的并发调用。
