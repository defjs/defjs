# POST JSON

把带类型的输入对象传给 `builder`，返回 `{ body: input }`。`.alias("customer_name")` 让你在 TypeScript 中保持 `customerName`，在网络上编码为 `"customer_name"`，并从 `201` 响应中解码回来。
