# 取消一次 HTTP

把调用方的 signal 和期限组合到 `abort` 上。`AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` 是一个 signal。手动中止归类为 `NET_ABORTED`。期限归类为 `NET_TIMEOUT`。

细节见 [HTTP](/zh-Hans/docs/http#cancel-the-work)。

<include cwd meta="cancel-report.ts">
  examples/recipes/cancel-http.ts#example
</include>

```txt
caller cancelled
```

取消只说明调用方观察到了什么。它不能证明服务端写入已经回滚——mutation 重试还是要有幂等契约。
