# 取消 HTTP 调用

用 `AbortSignal.any([controller.signal, AbortSignal.timeout(5_000)])` 把调用方 `AbortController` 与期限组合起来，并通过 `client({ signal })` 传入组合后的 signal。Defjs 把调用方手动中止归类为 `NET_ABORTED`，把超时中止归类为 `NET_TIMEOUT`。

运行输出：

```txt
caller cancelled
```

取消只报告 Client 观察到的结果——它不保证服务端回滚了写操作。变更类重试请用幂等键保护。见 [HTTP 取消与超时](/zh-Hans/docs/http#cancel-the-work)。
