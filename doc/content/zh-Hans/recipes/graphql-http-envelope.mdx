# 拆开 GraphQL HTTP 信封

Defjs 不实现 GraphQL `errorPolicy`。把线上建模成一次 HTTP POST，builder 放上 query 文档和变量，再在你自己的 helper 里拆 `errors[]` / 缺失的 `data`。

见 [设计决策](/zh-Hans/docs/design-decisions)。


HTTP 成功只说明信封到了。应用错误留在 `errors[]` 里，直到你的拆包函数抛出或返回。
