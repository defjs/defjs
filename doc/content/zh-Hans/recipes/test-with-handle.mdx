# 使用本地 Fetch Handle 编写测试

`withHTTPHandle(...)` 仅针对单个 Client 实例替换其底层的 `fetch` 实现，同时完整跑通入参校验、`builder` 参数映射、URL 目录安全检查、中间件拦截链、HTTP 状态码分流以及 Struct 解码等全部流程，期间完全无需打开任何真实网络 Socket：
