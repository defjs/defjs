# 声明了 404 的 GET

在 `defineRequest` 上同时声明 `output`（用于 2xx 响应）和 `error`（用于非 2xx 响应）。在调用点用 `error?.code === "HTTP_STATUS" && error.status === 404` 分支，读取带类型的 `error.data`。

若服务端对 `GET /orders/7` 请求返回 `200` 状态码以及 `{ "id": 7, "status": "paid" }`，该脚本将打印：

```txt
Loaded paid from 200
```

- 每个非 `2xx` 状态都会产生 `HTTP_STATUS`。声明 `error` 会把错误 body 解码并校验到 `error.data`；省略 `error` 时 `error.data` 为 `undefined`，且不读取 body。
- 声明的 `error` body 媒体类型错误、JSON 无效或未通过 struct 校验时，操作改为返回 `RES_*` Fault。由于单个 `error` struct 覆盖所有非 `2xx` 状态，不同错误状态返回不同结构时应使用 `struct.or(...)`。

见 [HTTP 请求](/zh-Hans/docs/http) 与 [错误处理](/zh-Hans/docs/errors)。
