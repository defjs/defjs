# Undici Pool HTTP 句柄

在高吞吐量的 Node.js BFF 与后端服务中，通过 [`withHTTPHandle`](/zh-Hans/api/core/withhttphandle) 注入共享的 `undici.Pool`，即可让多个上游连接保持预热与有界复用，同时让 SDK 定义（`sdk/orders.ts`）保持彻底的平台中立性。切记在服务关闭阶段调用 `await pool.close()` 释放连接池。
