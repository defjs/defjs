# 幂等键

默认情况下，`withRetry` 只会重试幂等的 HTTP 方法（`GET`、`HEAD`、`PUT`、`DELETE`、`OPTIONS`、`TRACE`）。当需要为 `POST` 或 `PATCH` 接口启用重试时，请将 `withRetry` 与 `idempotencyKeyHttpInterceptor()` 配合使用，使同一次逻辑调用的每一次重试都复用 `req.correlationId` 作为 `Idempotency-Key` 请求头，而后续新发起的调用则获得全新的键。
