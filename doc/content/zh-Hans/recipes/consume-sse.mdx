# 消费 SSE 流

若服务端的第一个事件为 `line`，数据为 `{ "text": "build started" }`，脚本会打印：

```txt
build started
```

- 除非在 Client 上配置了 [`withSSEReconnect(...)`](/zh-Hans/api/core/withssereconnect)，否则 SSE 不会在网络或读取失败后自动重连。
- 设置了 `withSSEReconnect(...)` 时，`attempts` 每次中断默认为 `3`，并在成功握手后重置（`attempts: 0` 关闭重连）。没有自定义 `shouldReconnect` 时，只有 `GET`、`HEAD`、`OPTIONS`、`PUT` 和 `DELETE` 请求会重连。带 `ReadableStream` body 的请求永远不会重连。见 [SSE 事件流](/zh-Hans/docs/sse)。
