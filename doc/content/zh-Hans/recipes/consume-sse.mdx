# 消费 SSE 流

一条流只配一个 async iterator。把 `close` + `await stream.closed` 放进 `finally`，提前退出才不会把 Fetch 尝试漏掉。

细节见 [SSE](/zh-Hans/docs/sse)。

`api.example.com` 是占位地址。假设服务器的第一个事件是 `message`，数据为 `{ "text": "hello from the server" }`，这段代码会输出：

```txt
hello from the server
```

SSE 默认不重试网络或读取失败；必须用 `withSSEReconnect(...)` 显式启用。提供 reconnect 配置后，`attempts` 默认是 `3`；`attempts: 0` 禁用重试。未提供 `shouldReconnect` 时，只有 `GET`、`HEAD`、`OPTIONS`、`PUT` 和 `DELETE` 请求会重连；请求体为 `ReadableStream` 的请求不会重连。
