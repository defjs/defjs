# 游标分页

将分页操作定义保留在 SDK 模块（`listOrders`）中，把游标翻页逻辑放进纯应用辅助函数（`listAllOrders`）里，按 Go 风格逐项 yield `[err, item]` 元组，并在遇到错误或调用方中止时立即停止。
