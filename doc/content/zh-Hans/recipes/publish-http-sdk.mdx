# 构建并发布 SDK [#publish-an-http-sdk-without-hiding-execute]

Defjs SDK 将共享的 `struct` schema（`src/schema/`）与按业务域划分的操作定义模块（`src/request/`）组织为可按需 tree-shake 的 npm 包，同时把 `createClient(...)`、端点地址、认证凭据和拦截器留在消费方应用中。

不同于传统 OpenAPI 生成器将接口封装在带状态的 `Service` 类（如 `ObjectsService.putObject(...)`）中，Defjs SDK **只导出独立的纯函数操作定义**（`putObject`、`getObject`、`listObjectsV2`），在应用侧直接传入 `client` 调用。

---

## 1. 组织并定义 SDK 包

以兼容 Amazon S3 协议的对象存储 SDK（`@company/s3-sdk`）为例，将包拆分为两层：

- **`src/schema/`**：跨接口复用的 `struct` schema 与 `Infer<typeof ...>` 类型（利用 TypeScript 值与类型同名合并导出，让消费方导入同一个标识符即可同时用作运行时 schema 和静态类型）。
- **`src/request/`**：按资源域划分的操作模块（`buckets.ts`、`objects.ts`）。每个模块只导出独立的 `defineRequest` 纯函数，通过同步纯函数 `builder` 将调用方扁平入参分发到 `path`、`query`、`headers` 和二进制 `body`。

- **纯函数导出，摒弃 `Service` 类**：每个操作（`listBuckets`、`listObjectsV2`、`getObject`、`putObject`、`deleteObject`）都直接导出为独立的 `defineRequest` 纯函数，不要用 `class` 或命名空间对象包裹。纯函数与 `@defjs/core` 原生调用方式完全一致（`await putObject(client, input)`），且配合 `"sideEffects": false` 可让打包器彻底剔除未引用的接口。
- **结构化 JSON、二进制流与空响应体**：`listBuckets` 和 `listObjectsV2` 使用 `.alias()` 解码并映射 JSON 字段；`getObject` 将响应体解码为二进制 `Blob`（`output: struct.blob()`）；`putObject`、`headObject` 和 `deleteObject` 针对空响应体省略 `output`，调用方仍可从返回元组的第 3 项 `response.headers` 读取 `etag` 等响应头。
- **外部运行时对等依赖**：`@defjs/core` 保持为 `peerDependency`，与消费方应用共享。

## 2. 构建并验证 tarball

用 `tsdown` 打包 `dist/index.js` 和 `dist/index.d.ts`，发布前检查包内容：

```sh
bun install
bun run build
bun pm pack --dry-run
bun pm pack
```

确认 tarball 中包含 `dist/index.js` 和 `dist/index.d.ts`。

---

## 3. 在应用中使用 SDK

把 SDK 与 `@defjs/core` 一起安装：

```sh
bun add @company/s3-sdk @defjs/core@^0.8.0
```

由于 SDK 不绑定任何客户端，消费方应用自行掌控服务端点（AWS S3、Cloudflare R2 或 MinIO）、签名拦截器与重试策略，并以纯函数方式直接调用导入的操作定义。因为 `syncReport` 发起三次调用，所以它按步骤给每个错误命名（`putErr`、`listErr`、`getErr`），并返回错误优先元组，其中的错误包装了失败的那一步，就像 Go 的 `fmt.Errorf("put object: %w", err)`。只有 `main` 会记录它：

## 4. 测试并发布

用[内存句柄测试](/zh-Hans/recipes/test-with-handle)覆盖导出的定义：路径/查询/请求头/二进制请求体映射、`output` 解码、`ETag` 响应头读取、声明的 `HTTP_STATUS`（`S3Error`）Fault 和请求取消。验证通过后发布包：

```sh
bun publish --access public
```

见 [HTTP 请求](/zh-Hans/docs/http)、[Client](/zh-Hans/docs/client)、[测试](/zh-Hans/docs/testing) 与 [核心架构设计](/zh-Hans/docs/design-decisions)。
