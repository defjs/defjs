<ApiReference identity="@defjs/core:AnyStruct" />

```ts
type AnyStruct = Struct<any, any, boolean>
```

`defineRequest`、`Fault`、`HttpCommand` 等 endpoint 与 client 泛型所用的宽泛约束。需要精确的 input 与 output 推断时，优先使用具体的 `Struct<...>`。
