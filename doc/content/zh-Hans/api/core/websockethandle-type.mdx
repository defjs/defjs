<ApiReference identity="@defjs/core:WebSocketHandle" />

```ts
type WebSocketHandle = Omit<
  WebSocket,
  | 'binaryType'
  | 'CLOSED'
  | 'CLOSING'
  | 'CONNECTING'
  | 'dispatchEvent'
  | 'onclose'
  | 'onerror'
  | 'onmessage'
  | 'onopen'
  | 'OPEN'
  | 'readyState'
> & { readonly readyState: number }
```

去掉事件 handler 属性、`binaryType`、`dispatchEvent` 以及状态常量之后的 DOM `WebSocket`。因此自定义实现需要提供 `url`、`protocol`、`extensions`、`bufferedAmount`、`send`、`close`、`addEventListener`、`removeEventListener`，以及数值型的 `readyState`。

属性存在时，传输层会设置 `binaryType = 'arraybuffer'`；不存在时则忽略。如果 setter 抛错，传输层会先尽力请求关闭已构造的 handle，再让该次尝试以 `NET_UNREACHABLE` 失败，不会让 socket 脱离清理责任。这个属性只是优化，解码器也接受 Blob 帧。这是 [`WebSocketHandleConstructor`](/zh-Hans/api/core/websockethandleconstructor-type) 所产生的实例类型。
