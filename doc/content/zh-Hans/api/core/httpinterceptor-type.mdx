<ApiReference identity="@defjs/core:HttpInterceptor" />

```ts
interface HttpInterceptor {
  kind: 'http'
  fn: InterceptorFn
}
```

由 `createHttpInterceptor` 创建。`kind` 是判别字段，使 `withInterceptors` 能在同一个列表里接受 HTTP、SSE 与 WebSocket interceptor。
