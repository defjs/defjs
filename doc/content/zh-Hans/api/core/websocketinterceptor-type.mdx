---
title: 'WebSocketInterceptor'
description: 'withInterceptors 接受的带标签的 WebSocket interceptor。'
---

<ApiReference identity="@defjs/core:WebSocketInterceptor" />

```ts
interface WebSocketInterceptor {
  kind: 'web-socket'
  fn: WebSocketInterceptorFn
}
```

由 `createWebSocketInterceptor(fn)` 创建。`kind` 标记让 `withInterceptors` 可以在同一个列表里接受 HTTP、SSE 和 WebSocket interceptor；对 WebSocket command 只会运行 `kind: 'web-socket'` 的 interceptor。
