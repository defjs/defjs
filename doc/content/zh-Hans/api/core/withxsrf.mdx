```ts
function withXSRF(options?: {
  cookieName?: string
  headerName?: string
  tokenProvider?: (context: { request: HttpRequest }) => string | null | undefined
}): ClientOption
```

为 **HTTP** 请求启用 XSRF token 转发。SSE 和 WebSocket 请求不会带上该 header。

- `cookieName` 默认为 `XSRF-TOKEN`，`headerName` 默认为 `X-XSRF-TOKEN`。
- 只有以下条件全部满足时才会设置该 header：方法不是 `GET`、`HEAD`、`OPTIONS` 或 `TRACE`；请求尚未带有该 header；client 有 endpoint；并且在浏览器中，请求 URL 与页面同源。
- 没有 `tokenProvider` 时，token 从 `document.cookie` 读取并做 URL 解码。浏览器之外没有 cookie，所以不会设置 header。
- 有 `tokenProvider` 时，永远不会读取 cookie。provider 收到请求，其结果就是 token。空字符串、`null` 或 `undefined` 表示不设置 header。

请求层面的行为见 [HTTP 指南](/zh-Hans/docs/http)。
