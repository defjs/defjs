---

<ApiReference identity="@defjs/core:withCredentials" />

```ts
function withCredentials(value: boolean): ClientOption
```

为 `true` 时，HTTP 和 SSE 请求的 Fetch 使用 `credentials: 'include'`，因此跨源请求也会携带 cookie 等凭据。为 `false` 或从未设置时，不设置 `credentials`，由 Fetch 使用它自己的默认值。

WebSocket 构造函数不会收到这项设置。
