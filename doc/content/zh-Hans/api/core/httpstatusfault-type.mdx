title: 'HttpStatusFault'
description: '非 2xx 响应的 fault，类型由声明的 error struct 决定。'
---

<ApiReference identity="@defjs/core:HttpStatusFault" />

```ts
type HttpStatusFault<TErr extends AnyStruct | undefined = undefined> = HttpStatusFaultOf<
  [TErr] extends [undefined] ? undefined : Infer<TErr>
>
```

`TErr` 是 endpoint 声明的 `error` struct，没有声明时为 `undefined`。适用于任何非 2xx 状态。endpoint 声明了 `error` 且 body 解码成功时，`data` 就是该 body，`response` 也带着它。省略 `error` 时 body 永远不会被读取，`data` 为 `undefined`，`response` 只有元数据。成员形状见 [`HttpStatusFaultOf`](/zh-Hans/api/core/httpstatusfaultof-type)。
