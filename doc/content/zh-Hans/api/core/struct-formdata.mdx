---

<ApiReference identity="@defjs/core:struct.formData" />

```ts
function formData<T extends ObjectShape>(shape: T): ObjectStruct<T>
```

解析行为与 [`struct.object()`](/zh-Hans/api/core/struct-object) 相同，并带有 `formData` codec 标签。

- 这个标签只在该 struct 的值是请求 body 根时生效。此时 body 以 `FormData` 发送，multipart 边界由平台生成。
- 数组会重复字段名，`undefined` 字段被跳过，`Blob` / `File` 值作为文件追加。嵌套对象会让请求以 `REQ_BUILD_FAILED` 失败。
- `struct.parse` 忽略这个标签。它不接受 `FormData` 实例，只接受普通对象。
