```ts
interface FormattedStructError {
  _errors: string[]
  [key: string]: FormattedStructError | string[]
}
```

`StructError.format()` 的结果。叶子 message 放在 `_errors` 下；嵌套的 key 对应出错的 path。字面上就叫 `_errors` 的 path 段会存成 `\_errors`。
