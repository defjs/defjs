<ApiReference identity="@defjs/react:ClientProviderProps" />

```ts
interface ClientProviderProps {
  client: Client
  children?: ReactNode
}
```

- `client` — 必填。由应用持有的 Defjs client。
- `children` — 可选。可以调用 `useClient` 的 React 子树。
