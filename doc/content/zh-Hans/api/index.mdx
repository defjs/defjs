# API 参考

按职责选择入口：SDK 作者使用 `defineRequest`、`defineEventStream`、`defineWebSocket` 和 `struct.*` 定义并导出契约；应用使用 `createClient`、`with*` 配置和 `client.execute(...)` 执行这些定义创建的 command。

下面的签名描述 Defjs 的运行时契约。完整开发流程见[快速开始](/zh-Hans/docs/start)和[构建并发布 SDK](/zh-Hans/recipes/publish-http-sdk)。
