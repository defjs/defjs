# API 参考

编写或使用 Defjs SDK 时查阅本参考。SDK 作者从 [`defineRequest`](/zh-Hans/api/core/definerequest)、[`defineEventStream`](/zh-Hans/api/core/defineeventstream)、[`defineWebSocket`](/zh-Hans/api/core/definewebsocket) 和 [Struct](/zh-Hans/api/struct) 开始。应用用 [Client 配置](/zh-Hans/api/client) 调用这些操作，用[错误](/zh-Hans/api/errors)处理结果。

下面的签名描述 Defjs 的运行时契约。完整开发流程见[快速开始](/zh-Hans/docs/start)和[构建并发布 SDK](/zh-Hans/recipes/publish-http-sdk)。
