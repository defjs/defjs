## 4. Multi-Upstream Resilience (Deterministic Seeded Fault & Tail Latency)

> Topology (`SEED=20261124`): Upstream **A** responds in 5 ms (`200`), Upstream **B** serves 60% 5 ms / 40% 300 ms tail (`200`), and Upstream **C** returns 40% `503`, 40% `429` (`Retry-After: 1`), and 20% `200`. Each candidate issues 200 logical calls at concurrency 8 with upstream server PRNG state and counters reset identically before each run (unseeded client `Math.random()` jitter and concurrency-8 scheduling can still introduce minor variance).
